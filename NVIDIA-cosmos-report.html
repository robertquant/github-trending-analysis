📋 项目概述

NVIDIA Cosmos 是 NVIDIA 推出的开源世界基础模型 (World Foundation Model, WFM) 平台，专为物理 AI (Physical AI) 开发而设计。该平台提供了一系列预训练的世界模型、数据集和工具，使开发者能够为机器人、自动驾驶汽车和工业视觉系统构建物理 AI 应用。

项目已从最初的单一仓库发展为独立的 nvidia-cosmos GitHub 组织，包含多个子项目和工具链。仅主仓库的 GitHub 重定向链接就获得了超过 8,000 颗星标，显示出极高的社区关注度。

核心定位

Cosmos 不是通用视频生成模型（如 Sora），而是专注于物理世界建模与仿真——理解物理规律、预测未来状态、生成合成训练数据，并推理物理环境中的因果关系。

🏗️ 技术架构

Cosmos 最新版本 (Cosmos 3) 采用了突破性的 Mixture of Transformers (MoT) 混合 Transformer 架构，推理模块和生成模块使用不同的 Transformer，实现高效生成和推理。该平台是"全能模态" (Omnimodal) 的，能够联合处理和生成语言、图像、视频、音频和动作序列。
