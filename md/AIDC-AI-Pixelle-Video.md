## 项目简介

Pixelle-Video 是一个开源的 AI 全自动短视频引擎，核心理念是 **"一句话生成视频"**。用户只需输入一个主题关键词，系统即可自动完成：文案撰写 → AI 配图/视频生成 → 语音合成 → 背景音乐添加 → 一键合成视频的全流程，零门槛、零剪辑经验。

---

## 核心功能

### 全自动生成流程
- **AI 智能文案** — 根据主题自动创作解说词
- **AI 生成配图** — 每句话配上精美 AI 插图（FLUX 等模型）
- **AI 生成视频** — 支持 WAN 2.1 等视频生成模型
- **AI 语音合成** — Edge-TTS、Index-TTS 等多种方案 + 声音克隆
- **背景音乐** — 内置 BGM 或自定义音乐
- **一键合成** — 自动合成完整短视频

### 扩展模块（2026 年新增）
- **数字人口播** — AI 虚拟人播报视频
- **图生视频** — 图片转动态视频内容
- **动作迁移** — 上传参考视频和图片进行动作迁移

### 灵活定制
- **多种 LLM** — GPT、通义千问、DeepSeek、Ollama 等
- **ComfyUI 工作流** — 可替换生图模型、TTS 引擎等任意组件
- **多种模板** — 竖屏/横屏/方形，支持自定义 HTML 模板
- **多种 TTS** — Edge-TTS、Index-TTS、声音克隆

## 快速上手

### Windows 一键整合包（推荐）
```
1. 下载 Windows 一键整合包并解压
2. 双击运行 start.bat 启动 Web 界面
3. 浏览器打开 http://localhost:8501
4. 配置 LLM API Key 和图像生成服务
5. 输入主题，点击生成！
```

### 源码安装 (macOS/Linux)
```bash
# 安装依赖
brew install ffmpeg  # macOS
# 或 sudo apt install ffmpeg  # Ubuntu

# 克隆项目
git clone https://github.com/AIDC-AI/Pixelle-Video.git
cd Pixelle-Video

# 启动
uv run streamlit run web/app.py
```

### Docker 部署
```bash
docker-compose up -d
```

### 完全免费方案
- LLM: Ollama 本地运行（免费）
- 图像生成: ComfyUI 本地部署（免费）
- TTS: Edge-TTS（免费）
- **总费用：0 元**

## 亮点与不足

### ✅ 亮点
1. **真正的全自动** — 从文案到成片，输入主题即可
2. **模块化架构** — ComfyUI 工作流，组件可自由替换
3. **零门槛** — Windows 一键整合包，无需编程经验
4. **完全可免费** — Ollama + ComfyUI 本地部署 = 0 元
5. **持续迭代** — 数字人口播、动作迁移等前沿功能
6. **多 LLM 支持** — GPT/通义千问/DeepSeek/Ollama 等

### ⚠️ 不足
1. **依赖外部服务** — 需要配置 LLM API 和 ComfyUI
2. **视频质量不稳定** — AI 生成内容质量受模型限制
3. **本地部署要求高** — 完全本地运行需要较好的 GPU
4. **中文为主** — 虽有英文 README，但主要面向中文用户
