## 快速上手指南

### 1. 访问官网注册

打开 [domain.digitalplat.org](https://domain.digitalplat.org/)，使用 GitHub 账号登录并完成身份验证。

### 2. 选择域名后缀

从可用的后缀中选择（如 .us.kg、.dpdns.org、.qzz.io），输入想要的域名前缀。

### 3. 注册域名

确认域名可用后，点击注册。系统即时分配，无需等待审核。

### 4. 配置 DNS

将域名指向你的 DNS 服务商（推荐 Cloudflare），添加 A/CNAME 记录指向你的服务器。

### 5. 部署上线

配置 Web 服务器（Nginx/Caddy 等），绑定域名，网站即可上线。

```bash
# 示例：使用 Cloudflare 管理 DNS
# 1. 在 FreeDomain 注册 yourname.us.kg
# 2. 登录 Cloudflare → 添加站点 → 输入 yourname.us.kg
# 3. 在 FreeDomain 面板中将 NS 记录改为 Cloudflare 提供的 NS
# 4. 在 Cloudflare 添加 DNS 记录：
#    A    yourname.us.kg    →    你的服务器IP
# 5. 等待 DNS 传播（通常几分钟）
```
