## 项目简介

**Build A Large Language Model (From Scratch)** 是 ML 教育领域传奇人物 **Sebastian Raschka** 的里程碑式作品。配套 Manning 出版的纸质书，通过 **7 个核心章节 + 5 个附录**，手把手带你用 PyTorch 从零实现一个 **GPT-2 级别的 LLM**。

从文本数据处理、注意力机制、GPT 架构，到预训练、分类微调、指令微调，每个概念都以清晰文字 + 图示 + 可运行代码呈现。所有代码在**普通笔记本电脑**上即可运行，无需 GPU。

Bonus 材料更是极其丰富：Llama 3.2、Qwen3、Gemma 3/4、Olmo 3 从零实现，LoRA、DPO、GRPO 强化学习，17 小时配套视频课程，170 页练习 PDF。

## 快速上手

### 克隆并运行
```bash
git clone --depth 1 https://github.com/rasbt/LLMs-from-scratch.git
cd LLMs-from-scratch
pip install -r requirements.txt

# 从第 2 章开始
jupyter notebook ch02/01_main-chapter-code/ch02.ipynb
```

### Docker 环境
```bash
docker build -t llms-from-scratch -f setup/Dockerfile .
docker run -it -p 8888:8888 llms-from-scratch
```
