## 项目简介

**Hermes Agent** 是 Nous Research 于 2026 年 2 月 25 日发布的开源 AI Agent 框架。核心突破是内置**学习循环（Learning Loop）**——Agent 在使用过程中自动从经验中提取"技能"，形成可复用的知识库。使用越多，能力越强，任务完成时间可降低约 40%。

支持 200+ 模型、40+ 工具、7 种终端后端、6 大消息平台。10 周内斩获 14.4 万 Stars，位列 GitHub 全球第 49 名。零 CVE 安全记录，$5 VPS 即可运行。

---

## 六大核心能力

### 🧠 自进化学习循环
Agent 从每次任务中提取经验，自动生成可复用"技能"。独创 Agent-curated Memory 机制，使用越多效率越高，约 40% 任务时间缩减。

### 👤 Honcho 用户建模
基于辩证法（Dialectic）的深度用户理解系统。自动构建用户画像、偏好模型和工作流模式，实现真正的个性化 Agent 体验。

### 🔍 FTS5 会话搜索
基于 SQLite FTS5 的全文本搜索引擎，秒级检索历史会话和技能库。支持语义化查询，跨会话上下文无缝衔接。

### ⚡ 200+ 模型 / 7 终端
支持 OpenRouter、NVIDIA NIM、Nous Portal 等 200+ 模型。7 种终端后端（Local、Docker、SSH、Modal、Daytona、Vercel Sandbox、Singularity）。

### 🌐 6 大消息平台
Telegram、Discord、Slack、WhatsApp、Signal、CLI 全覆盖。消息网关统一架构，一次配置多平台部署。

### 🔬 研究就绪 + RL 环境
内置 Atropos 强化学习环境、轨迹压缩（Trajectory Compression）。面向 Agent 研究者的理想实验平台。

## 快速上手

### pip 安装
```bash
pip install hermes-agent
hermes init
hermes chat
```

### Docker 部署
```bash
docker run -d \
  -e OPENROUTER_API_KEY=your_key \
  -v hermes-data:/app/data \
  ghcr.io/nousresearch/hermes-agent:latest
```

### 连接消息平台
```bash
hermes connect --platform telegram
hermes connect --platform discord
```
