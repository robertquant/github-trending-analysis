# Supermemory 深度分析摘要

- **Stars**: 23.6k | **Forks**: 2.1k | **语言**: TypeScript

- **分析日期**: 2026-06-01

## 一句话概述
Supermemory 是一个开源的 AI 记忆引擎，自动从对话中提取事实、构建用户画像、处理知识更新与矛盾，为 AI Agent 和应用提供统一的记忆/RAG/上下文 API。

## 核心亮点
1. **三大基准测试 #1**: LongMemEval (81.6%)、LoCoMo、ConvoMem 均排名第一
2. **统一上下文栈**: 记忆 + RAG + 用户画像 + 连接器，一个 API 搞定
3. **自动遗忘机制**: 识别临时信息并自动过期，矛盾自动解决
4. **50ms 用户画像**: 一次调用获取完整静态+动态用户画像
5. **MCP 原生支持**: 一行命令集成 Claude Desktop / Cursor / VS Code
6. **6+ 连接器**: Google Drive、Gmail、Notion、OneDrive、GitHub 等
