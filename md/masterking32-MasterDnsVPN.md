## 项目简介

MasterDnsVPN 是一个**科学研究导向的 DNS 隧道 VPN**，通过将 TCP 流量封装在 DNS 查询和响应中，在互联网审查和封锁环境中建立通信通道。在伊朗长达 70+ 天的全国断网中经受住了实战检验——当 99% 国际带宽被切断时，DNS 基础设施仍然可用。

**核心理念**：DNS 是互联网基础设施中最不可封禁的协议——封掉 DNS 就等于摧毁网络自身。MasterDnsVPN 利用这一特性，将加密数据伪装成普通 DNS 流量。

## 核心功能

- **自定义轻量协议** — 开销仅 5-7 字节，比 DNSTT 低 88%，比 SlipStream 低 71%
- **低开销 ARQ** — 自动重传请求机制，高丢包环境下保持可靠传输
- **多路径解析器** — 8 种内置负载均衡模式，自动健康检查与故障切换
- **会话多路复用** — SOCKS5/4 代理支持，多连接并行传输
- **灵活加密** — XOR / ChaCha20 / AES-128/192/256-GCM 可选
- **压缩支持** — ZSTD / LZ4 / ZLIB 可选
- **MTU 自动发现** — 自动协商最优传输单元
- **本地 DNS 缓存** — 内置 DNS 解析器，避免 DNS 泄露

## 技术架构

```
Client App → SOCKS5 Proxy → MasterDnsVPN Client
    → 加密 + 压缩 + 自定义协议封装
    → DNS Queries (通过多个 DNS Resolver)
    → MasterDnsVPN Server (权威 DNS)
    → 解密 + 解压 → 目标 TCP 连接 → Internet
```

- **Go 语言实现** — 跨平台编译，单二进制文件部署
- **自定义隧道协议** — 非基于标准 DNS TXT/CNAME，自研轻量协议
- **多路径解析器管理** — 轮询、加权、最少连接、延迟优先等 8 种策略
- **解析器健康检查** — 自动检测不可用解析器并禁用，恢复后自动重新激活
- **数据包复制** — 关键数据包通过多解析器同时发送
- **打包控制块** — 多个控制信息打包到单个 DNS 响应中
