## 一、项目概览

Everything Claude Code (ECC) 是一个 **AI 编程代理性能优化系统**。它不是简单的配置文件集合，而是一个包含代理配置、技能模块、本能系统、记忆管理和安全审计的完整增强框架。

**核心数据：**
- **48个代理配置** — 针对全栈开发、安全审计、数据工程等场景优化
- **182个技能模块** — 涵盖12+编程语言生态（TS/Python/Go/Java/Rust/C++/...）
- **68个遗留命令shim** — 向后兼容支持
- **6个平台** — Claude Code / Cursor IDE / Codex CLI / OpenCode / Antigravity / Gemini CLI
- **997+测试用例** — 确保系统可靠性

**项目起源：** 作者用10+个月时间，每天高强度使用 Claude Code 构建真实商业产品（zenith.chat），逐步提炼出这套最佳实践体系。

### 关键技术创新

**1. 代理配置系统**
48个针对不同场景优化的配置文件，每个定义了代理的行为模式、技能集、约束条件和输出格式。实现"对场景用对代理"的精细化分工。

**2. 持续学习 v2**
基于本能（Instinct）的学习系统，每次交互评估置信度并更新本能库。支持导入/导出学习成果，从"被动执行"进化为"主动学习"。

**3. AgentShield 安全审计**
在 Claude Code 黑客松上构建。1282个测试用例、102条安全规则、98%代码覆盖率。采用红蓝对抗方法检测攻击和防御漏洞。

**4. Rust 控制平面 (v2.0)**
负责状态同步、观察者生命周期管理和跨会话编排，为多代理协作提供高性能基础设施。

## 七、快速上手

```bash
# npm 一键安装（推荐）
npx ecc-universal@latest

# 或克隆仓库
git clone https://github.com/affaan-m/everything-claude-code.git
cd everything-claude-code && npm install && npm run setup

# 选择代理配置
ecc use agent fullstack        # 全栈开发代理
ecc use agent security         # 安全审计代理

# 启用技能模块
ecc skill enable react-patterns
ecc skill enable python-testing

# 启动 Dashboard GUI (v2.0)
ecc dashboard

# 运行安全审计
ecc shield scan ./src
```
