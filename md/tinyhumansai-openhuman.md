## 项目简介

**OpenHuman** 是一个开源的桌面 AI 助手，核心理念是打造一个完全私有、运行在本地的个人 AI 超级智能。它通过 **Memory Tree** 技术自动构建你的个人知识图谱，集成 **118+ 第三方服务**（Gmail、Notion、GitHub、Slack、Stripe、Calendar、Drive、Linear、Jira 等），每 20 分钟自动同步数据到本地 Obsidian 知识库。

与其他需要终端配置的 Agent 不同，OpenHuman 提供简洁的桌面 UI 和吉祥物角色，几分钟内从安装到使用。灵感来自 Karpathy 的 obsidian-wiki 工作流。

---

## 六大核心能力

### 🧠 Memory Tree + Obsidian Wiki
所有连接数据被规范化为 ≤3k token 的 Markdown 块，分层摘要存储在本地 SQLite 中，同时生成 Obsidian 兼容的 .md 知识库。

### 🔌 118+ 一键 OAuth 集成
Gmail、Notion、GitHub、Slack、Stripe、Calendar、Drive、Linear、Jira 等，一键 OAuth 连接，自动暴露为类型化工具。

### 🔄 20 分钟自动同步 (Auto-fetch)
每 20 分钟遍历活跃连接，拉取最新数据到 Memory Tree。Agent 在你早上醒来前就已有今天的上下文。

### ⚡ TokenJuice 智能压缩
HTML→Markdown、URL 缩短、非 ASCII 字符清理，最高节省 80% token 消耗。

### 🎙️ 原生语音 + 桌面吉祥物
STT 语音输入 + ElevenLabs TTS 输出 + 唇形同步，桌面吉祥物可加入 Google Meet 作为真实参与者。

### 🛡️ 本地隐私 + 模型路由
数据本地加密存储，模型路由自动分发推理/快速/视觉任务，可选 Ollama 完全离线。

## 技术架构

- **前端/桌面**：Tauri (Rust) 跨平台桌面应用
- **存储**：SQLite 本地数据库 + Obsidian 兼容 Vault
- **压缩**：TokenJuice token 压缩层
- **集成**：118+ OAuth 连接器，20 分钟 Auto-fetch
- **语音**：STT + ElevenLabs TTS + Google Meet Agent
- **模型**：自动路由（推理/快速/视觉）+ Ollama 可选
- **语言**：Rust（高性能 + 内存安全）
