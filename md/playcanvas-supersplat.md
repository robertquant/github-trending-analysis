## 📌 项目概览

**SuperSplat** 是由 PlayCanvas 团队开发的一款免费、开源、完全运行在浏览器中的 3D Gaussian Splat 编辑器。基于 WebGPU/WebGL 技术，用户无需安装任何桌面软件，即可对 3D 高斯泼溅场景进行查看、编辑、优化和发布。

3D Gaussian Splatting（3DGS）是近年来计算机视觉领域的突破性技术，通过从照片或视频中重建 3D 场景，生成由数百万个高斯原语组成的点云表示。SuperSplat 填补了这一新兴领域缺乏免费易用编辑工具的空白。

### 核心特性

- **可视化编辑** — 选择、移动、删除高斯点，实时预览效果
- **多格式支持** — 兼容 .ply 和 .splat 文件格式
- **场景优化** — 裁剪、压缩、LOD 处理，优化 Web 发布
- **零安装部署** — 完全基于浏览器运行，无需本地安装
- **一键发布** — SuperSplat 2.0 支持在线发布和分享场景
- **多语言支持** — 内置国际化 i18n

## 🚀 快速开始

### 在线使用（推荐）

直接访问 **https://superspl.at/editor** 即可开始使用，无需安装。

### 本地开发

```bash
# 克隆仓库
git clone https://github.com/playcanvas/supersplat.git
cd supersplat

# 安装依赖（需要 Node.js 18+）
npm install

# 启动开发服务器
npm start
# 浏览器打开 http://localhost:3000
```

### 基本操作

- **导入场景**：拖拽 .ply 或 .splat 文件到编辑器窗口
- **选择高斯点**：使用点选、框选或球形选择工具
- **编辑操作**：删除选中点、移动、缩放等变换操作
- **导出结果**：将编辑后的场景导出为 .ply 或压缩的 .splat 格式
