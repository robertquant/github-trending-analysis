## 项目简介与核心功能

Odoo 是一套基于 Web 的开源商业应用套件，由比利时公司 Odoo S.A. 开发维护。采用模块化架构，提供 30+ 个核心应用和数千个社区插件，覆盖企业运营全场景。

### 核心应用模块

- **CRM 客户关系管理** — 从线索到客户的完整销售管道管理
- **eCommerce 电子商务** — 集成在线商店，支持支付/库存/物流
- **会计与财务** — 自动发票、银行对账、多币种、税务合规
- **制造与仓储** — MRP、PLM、质量管控、仓库管理
- **项目管理** — 看板、甘特图、时间追踪
- **人力资源** — 招聘、休假、绩效、薪酬一体化
- **POS 收银系统** — 离线/在线收银，硬件无缝集成
- **网站构建器** — 拖拽式建站，内置 SEO 和博客

**模块化设计理念：** 每个应用可独立运行，也可无缝集成。按需选择模块，从小团队起步，随业务增长灵活扩展。

## 技术架构与特点

### 核心技术栈

| 层级 | 技术 |
|---|---|
| 后端 | Python (自研 ORM, MVC 架构) |
| 前端 | JavaScript, OWL (Odoo Web Library), QWeb 模板引擎 |
| 数据库 | PostgreSQL |
| 样式 | SCSS |
| 平台 | Odoo.sh (PaaS + IaaS) |

### 架构亮点

- **ORM 层：** 自研高性能 ORM，支持字段定义、关系映射、继承机制和数据验证
- **模块系统：** 每个功能模块是独立 Python 包，包含模型、视图、控制器和安全规则
- **OWL 框架：** 自研前端响应式框架，基于 Web Components 标准
- **QWeb 模板：** XML 模板引擎，用于 HTML 视图和 PDF 报告
- **多进程架构：** 支持 Gevent 和多 Worker 模式
- **API 层：** 内置 JSON-RPC 和 XML-RPC 接口

### Odoo.sh 云平台

官方一站式开发托管平台：数据库复制、Staging 环境、自动测试、SSH 访问、24/7 监控。

## 快速上手指南

### 方式一：Docker 一键部署（推荐）

```bash
git clone https://github.com/odoo/odoo.git
cd odoo
docker-compose up -d
```

### 方式二：源码安装

```bash
pip install -r requirements.txt
createdb odoo-db
python3 odoo-bin -d odoo-db --db_host localhost -r odoo -w odoo --addons-path addons
# 浏览器访问 http://localhost:8069
```

### 方式三：Odoo.sh 云平台

1. 注册 odoo.sh 账号
2. Fork odoo/odoo 到你的 GitHub
3. 连接 GitHub 仓库到 odoo.sh
4. 自动构建、测试、部署

> **首次体验建议：** 先在 [Odoo Online](https://www.odoo.com/sl) 免费试用在线版本，了解功能后再决定自托管还是云服务。
