## 项目背景与故事

John Washam 并非科班出身。他自学编程后，立志进入亚马逊等大公司工作。为此他制定了为期数月的疯狂学习计划——每天学习 8-12 小时，系统地攻克数据结构、算法、系统设计等核心计算机科学知识。最终他成功入职亚马逊，并将自己的完整学习路线图开源，这就是 **Coding Interview University** 的由来。

这份学习计划不仅仅是知识点的罗列，更是一份真实可行的路线图，附带着作者的亲身经历和实用建议。

## 亮点与不足

### ✅ 亮点
1. **真实故事背书** — 作者真实地从自学到入职亚马逊，非纸上谈兵
2. **覆盖极广** — 从算法基础到系统设计，几乎没有盲区
3. **多语言支持** — 15+ 种语言翻译，全球可达
4. **记忆工具** — 内置 Flashcards 和 Anki 卡片，科学记忆
5. **持续更新** — 超过 8 年的持续维护
6. **完全免费** — CC-BY-SA-4.0 开源许可

### ⚠️ 不足
1. **非交互式** — 纯 Markdown，缺少互动练习环境
2. **学习曲线陡峭** — 完整学习需要数月，对初学者可能造成心理压力
3. **内容过多** — 可能导致"选择困难"，需要自我把控节奏
4. **偏重算法** — 对实际工程技能（如项目经验、团队协作）覆盖较少

## 实用建议

1. **不要试图一次学完** — 按照计划分阶段进行，每天固定时间学习
2. **动手实现** — 不要只看不做，每种数据结构和算法都要自己实现一遍
3. **使用 Flashcards** — 利用记忆卡片巩固知识，避免遗忘
4. **刷题结合** — 学完一个主题后立即到 LeetCode 上做对应题目
5. **选对语言** — 建议用 Python 做学习语言，用 Java/C++ 准备面试
