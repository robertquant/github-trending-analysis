## 📋 项目简介

**daily_stock_analysis**（简称 DSA）是一个基于大语言模型（LLM）的智能股票分析系统，支持 A 股、港股、美股三大市场。它将多源行情数据、实时新闻、技术指标和舆情分析融合，通过 LLM 生成结构化的「决策仪表盘」，并自动推送到企业微信/飞书/Telegram/Discord/Slack/邮件等多个渠道。

核心亮点：**零成本、全自动、开箱即用**。

### 核心功能

| 功能 | 说明 |
|------|------|
| AI 决策报告 | 核心结论、评分、趋势、买卖点位、风险警报、催化因素、操作清单 |
| 多市场数据聚合 | A股/港股/美股/ETF，行情/K线/技术指标/资金流/筹码/新闻/公告/基本面 |
| Web/桌面工作台 | 手动分析、历史报告、回测、持仓管理、深浅色主题 |
| Agent 策略问股 | 11种内置策略（均线、缠论、波浪、趋势等），多轮追问 |
| 智能导入 | 图片、CSV/Excel、剪贴板导入；代码/名称/拼音补全 |
| 多渠道推送 | 企微/飞书/TG/Discord/Slack/邮件 |

## 🚀 快速上手

### 方式一：GitHub Actions（5分钟部署）

1. Fork 本仓库（顺手 Star ⭐）
2. Settings → Secrets → Actions → 配置 API Key（如 ANSPIRE_API_KEYS）
3. 配置通知渠道（如 TELEGRAM_BOT_TOKEN + TELEGRAM_CHAT_ID）
4. 配置自选股：`STOCK_LIST = "600519,hk00700,AAPL"`
5. 启用 Actions → 手动测试 → 完成

默认每个工作日 18:00（北京时间）自动执行。

### 方式二：本地运行

```bash
git clone https://github.com/ZhuLinsen/daily_stock_analysis.git
cd daily_stock_analysis
pip install -r requirements.txt
cp .env.example .env && vim .env
python main.py           # 运行分析
python main.py --webui   # 启动 Web 工作台
```

### 常用命令

```bash
python main.py --debug          # 调试模式
python main.py --dry-run        # 试运行
python main.py --stocks 600519  # 指定股票
python main.py --market-review  # 大盘复盘
python main.py --schedule       # 定时任务
```
