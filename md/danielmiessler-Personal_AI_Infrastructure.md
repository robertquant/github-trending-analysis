## 项目简介

**PAI (Personal AI Infrastructure)** 是由安全研究员 Daniel Miessler 创建的开源「人生操作系统」。它捕获你是谁、你在乎什么、你要去哪里——然后帮助你到达那里。

核心理念：**AI 应该为每个人赋能，而不仅仅是顶层的 1%。**

### 三层架构

- **PAI** — 操作系统本身。技能、记忆、Algorithm、Telos、身份文件。
- **Pulse** — 人生仪表盘 (`localhost:31337`)。可视化面板、语音、Hook、定时任务。
- **The DA** — 数字助手。独立的身份、声音和人格，你与 AI 交互的主要界面。

---

## 核心功能

### 理想状态驱动 (Ideal State Driven)
通过 **ISA (Ideal State Artifact)** 精确定义「完成状态」——类似软件 PRD，但适用于任何创造性任务。系统将理想状态分解为 **ISC (Ideal State Criteria)** 验证清单，逐步逼近目标。

### Algorithm v6.3.0 — 七阶段循环
```
OBSERVE → THINK → PLAN → BUILD → EXECUTE → VERIFY → LEARN
```
每个非平凡任务都经过这个科学方法式循环。自动选择 MINIMAL/NATIVE/ALGORITHM 模式和 E1-E5 层级。

### 文本优先，无 RAG
自 2025 年 6 月起完全弃用 RAG，用富文本 + ripgrep 实现同等效果。

### 主要特性
- **45 个技能 + 171 个工作流** — 代码包裹提示词，而非提示词包裹代码
- **记忆系统 v7.6** — WORK/KNOWLEDGE/LEARNING/RELATIONSHIP/OBSERVABILITY 五层记忆
- **37 个 Hook** — 覆盖全生命周期事件
- **思维技能库** — 第一性原理、委员会辩论、红队测试、根因分析等
- **自我改进循环** — 捕获成功/失败信号，持续优化
- **结构化隐私** — Containment Guard + 12 道安全门

## 快速上手

### 前置要求
- Bun 运行时
- Git
- Claude Code CLI
- （可选）ElevenLabs API Key

### 一键安装
```bash
curl -sSL https://ourpai.ai/install.sh | bash
```

### 安装后配置
```bash
# 打开人生仪表盘
open http://localhost:31337

# 在 Claude Code 中运行访谈（最关键！）
/interview
```

### 访谈四阶段
1. **TELOS** — 使命、目标、信念、智慧、挑战、书籍、心智模型
2. **IDEAL_STATE** — 成功的定义
3. **Preferences** — 工具、约定、工作风格
4. **Identity** — DA 人格最终调优

> ⚠️ 没有完成 TELOS，你的 DA 没有优化目标——这一步至关重要！
