## 📌 项目简介

**RuView** 是一个基于 WiFi 信号的开源空间智能感知平台，由 `ruvnet` 开发维护。它将普通 WiFi 路由器发出的无线电波转化为实时感知数据——检测人员存在、测量呼吸和心率、追踪运动轨迹、监控房间状态——全部**无需摄像头、无需穿戴设备、甚至可以穿墙工作**。

## 🏗️ 技术架构

### 系统架构

```
WiFi Router → 无线电波穿过房间 → 人体散射 → ESP32 Mesh 捕获 CSI
    ↓
多频段融合: 3 通道 × 56 子载波 = 168 虚拟子载波/链路
    ↓
多基融合: N×(N-1) 链路 → 注意力加权跨视角嵌入
    ↓
信号处理: Hampel → SpotFi → Fresnel → BVP → 频谱图
    ↓
AI 骨干 (RuVector): 注意力机制 + 图算法 + 压缩 + 场模型
    ↓
输出: 实时姿态 / 呼吸 / 心率 / 房间指纹 / 漂移告警
```

### 核心技术亮点

- **RuVector AI 骨干** — 注意力机制 + 图神经网络 + 信号压缩的统一管线
- **WiFlow 架构** — 17 COCO 关键点姿态估计，无需摄像头训练
- **自学习 WiFi AI (ADR-024)** — 128 维嵌入向量，自监督对比学习，55 KB 模型运行在 ESP32
- **60 个 WASM 边缘模块** — 13 个类别、609 个测试，直接在 ESP32 上运行（5-30 KB/模块）
- **多频 Mesh 扫描** — 6 个 WiFi 通道跳频，利用邻居路由器作为免费雷达照射源
- **Ed25519 见证链** — 每次测量都有密码学认证
- **MicroLoRA 适配** — 每房间仅 1,792 参数微调，减少 93% 重训练数据

## 🚀 快速上手

### 方式一：Docker 体验（无需硬件）

```bash
docker pull ruvnet/wifi-densepose:latest
docker run -p 3000:3000 ruvnet/wifi-densepose:latest
# 打开 http://localhost:3000
```

### 方式二：ESP32-S3 硬件（$9）

```bash
# 刷入固件
python -m esptool --chip esp32s3 --port COM9 --baud 460800 \
  write_flash 0x0 bootloader.bin 0x8000 partition-table.bin \
  0xf000 ota_data_initial.bin 0x20000 esp32-csi-node.bin

# 配网
python firmware/esp32-csi-node/provision.py --port COM9 \
  --ssid "YourWiFi" --password "secret" --target-ip 192.168.1.20

# 启动感知
node scripts/rf-scan.js --port 5006
node scripts/snn-csi-processor.js --port 5006
node scripts/mincut-person-counter.js --port 5006
```

> **注意**: ESP32-C3 和原版 ESP32 不支持（单核不足）。推荐 ESP32-S3。
