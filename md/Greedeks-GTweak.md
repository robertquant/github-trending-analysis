## 项目简介

**GTweak** 是一款便携式 Windows 系统优化配置工具，使用 C# / WPF 构建，基于 .NET Framework 4.8。它将 30+ 种系统调优操作整合到一个图形界面中，无需安装，即开即用，覆盖隐私保护、系统精简、界面定制、性能优化、服务管理等多个维度。

- **GitHub**: https://github.com/Greedeks/GTweak
- **最新版本**: v5.2.0
- **许可证**: 开源

## 核心功能

### 六大功能模块

| 模块 | 功能 |
|------|------|
| **隐私保护** | 禁用 Windows/NVIDIA/Intel 遥测与键击记录器，阻止影子域名数据收集，禁用任务计划中的用户数据收集任务 |
| **系统精简** | 禁用 Defender/SmartScreen/VBS/UAC，暂停更新，卸载 OneDrive/Edge/WebView2，移除 Cortana/Copilot/Recall |
| **界面定制** | 更换主题、调整窗口设置、自定义任务栏布局和图标，禁用个性化广告与系统通知 |
| **性能优化** | 应用极限性能电源方案，禁用不必要服务，清理 RAM/临时文件，NTFS 压缩节省空间 |
| **服务管理** | 禁用不必要系统服务，禁用 IPv6/Teredo/ISATAP，禁用磁盘碎片整理与诊断工具 |
| **高级工具** | 以 TrustedInstaller 权限执行自定义脚本(.ps1/.cmd/.bat/.reg)，查看硬件配置与系统监控 |

## 快速上手指南

### 1. 下载最新版本

前往 [GitHub Releases](https://github.com/Greedeks/GTweak/releases) 下载最新 v5.2.0 的 `.zip` 压缩包。

### 2. 解压并添加杀毒白名单

解压到任意目录。如果 Windows Defender 拦截，请添加到排除项：

```
设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护 → 排除项 → 添加文件夹
```

### 3. 以管理员身份运行

右键 `GTweak.exe` → 以管理员身份运行。

### 4. 创建系统还原点

首次使用建议先创建还原点：`系统属性 → 系统保护 → 创建`。

### 5. 按需选择优化项

在左侧导航栏切换模块（隐私/系统/界面/服务/应用/工具），勾选需要优化的项目，点击应用。建议先从**隐私保护**模块开始。
