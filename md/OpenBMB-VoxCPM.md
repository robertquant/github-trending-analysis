# OpenBMB/VoxCPM - 深度分析摘要

> Tokenizer-Free 多语言语音合成系统 | 基于 MiniCPM-4 的扩散自回归 TTS 模型

| 项目 | 详情 |

| 输出音质 | 48kHz |
| 推理速度 | RTF 0.15 |

## 核心创新

1. **无分词器架构** — 跳过传统 TTS 的音素分词阶段，直接从文本生成连续语音表示
2. **扩散自回归建模** — 结合扩散模型与自回归建模的双重优势
3. **上下文感知** — 基于 MiniCPM-4 LLM 基座，根据文本语义自动调节语气与情绪
4. **零样本声音克隆** — 仅需几秒参考音频即可复刻目标音色
5. **Voice Design** — 通过自然语言描述从零设计全新声音角色
