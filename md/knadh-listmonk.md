## 项目简介

**listmonk** 是一个独立、自托管的 Newsletter（电子通讯）和邮件列表管理器。它将所有功能打包在一个 Go 单二进制文件中，仅需 PostgreSQL 作为数据库，即可提供企业级的邮件营销管理能力。

核心定位：**为注重数据隐私和成本控制的团队/个人提供免费、高性能的邮件列表管理方案。**

---

## 核心功能

| 功能 | 说明 |
|------|------|
| **邮件列表管理** | 支持单向和双向确认（Double Opt-in）列表，可管理数百万订阅者 |
| **活动（Campaign）管理** | 支持定时发送、活动分析、打开率/点击率统计 |
| **多用户与权限** | v4+ 引入细粒度的用户角色和权限管理，支持按列表分配访问权限 |
| **OIDC/SSO** | 支持 OpenID Connect 单点登录，方便企业集成 |
| **事务性邮件** | 支持发送事务性（Transactional）邮件 |
| **SMS 网关** | 内置短信网关支持 |
| **高性能** | 运行仅需约 57MB 内存，可处理大批量发送 |
| **单二进制部署** | 零外部依赖（除 PostgreSQL），Docker 和二进制两种安装方式 |
| **现代仪表盘** | 基于 Vue.js + Buefy 的美观管理界面 |
| **多语言** | 支持多语言界面（i18n） |

## 技术架构

```
┌─────────────────────────────────────────────┐
│              listmonk 架构                    │
├─────────────────────────────────────────────┤
│  前端: Vue.js + Buefy UI                     │
│  后端: Go (41.2%)                            │
│  数据库: PostgreSQL (唯一依赖)                │
│  部署: 单二进制 / Docker                      │
│  认证: 内置 + OIDC SSO                       │
└─────────────────────────────────────────────┘
```

**技术特点**：
- **Go 后端**：编译为单个二进制，跨平台部署，无需运行时环境
- **PostgreSQL**：使用成熟的关系数据库，支持大规模订阅者管理
- **Vue.js 前端**：现代化响应式管理界面
- **API 优先**：提供完整的 RESTful API，支持程序化操作

## 快速上手指南

### 方式一：Docker 部署（推荐）

```bash
# 下载 docker-compose.yml
curl -LO https://github.com/knadh/listmonk/raw/master/docker-compose.yml

# 启动服务
docker compose up -d

# 访问 http://localhost:9000
```

### 方式二：二进制部署

```bash
# 下载最新版本
wget https://github.com/knadh/listmonk/releases/latest/download/listmonk_6.1.0_linux_amd64.tar.gz
tar -xzf listmonk_6.1.0_linux_amd64.tar.gz

# 生成配置文件
./listmonk --new-config
# 编辑 config.toml，设置 PostgreSQL 连接信息

# 初始化数据库
./listmonk --install

# 启动服务
./listmonk

# 访问 http://localhost:9000
```

### 发送第一封 Newsletter

1. 登录后，进入 **Lists** 页面创建一个邮件列表
2. 通过导入 CSV 或 API 添加订阅者
3. 进入 **Campaigns** 页面，点击 **New Campaign**
4. 使用内置编辑器编写邮件内容（支持模板）
5. 选择目标列表，设置发送参数
6. 点击发送或设定定时发送
