## 项目简介

**React Doctor** 是由 Million.js 团队开源的 React 代码质量诊断工具。一条命令扫描整个代码库，输出 **0-100 健康评分** 和可操作的诊断报告。特别针对 **AI 编程 Agent 生成的低质量 React 代码** 设计。支持 Next.js、Vite、React Native，内置 60+ 规则覆盖状态管理、性能、架构、安全、可访问性和死代码检测。

---

## 六大核心能力

### 🏥 0-100 健康评分
75+ 为 Great，50-74 为 Needs Work，50 以下为 Critical。团队可追踪分数变化趋势。

### 🤖 AI Agent 深度集成
运行 install 命令即可教 Cursor、Claude Code、Codex 等 50+ AI Agent React 最佳实践。

### 🔍 60+ 专业规则
覆盖状态与副作用、性能反模式、架构问题、安全漏洞、可访问性、死代码六大维度。

### ⚡ CI/CD 集成
官方 GitHub Action 支持 PR 自动评论、分数输出、diff 模式仅扫描变更文件。

### 🔌 双引擎 Lint 插件
同一套规则同时提供 oxlint 和 ESLint 插件，自动合并现有配置。

### 📊 Node.js API + 排行榜
提供 diagnose() 编程 API。官方排行榜：nodejs.org 87、tldraw 76、excalidraw 69。

## 技术架构

- **CLI**：npx 零配置，一行命令启动
- **双通道扫描**：Lint Pass（60+ 规则）+ Dead Code Pass 并行执行
- **插件系统**：oxlint 插件 + ESLint Flat Config 插件
- **AI Agent**：AGENTS.md 集成 50+ 编程 Agent
- **CI/CD**：官方 GitHub Action + PR 评论
- **API**：Node.js diagnose() API + JSON 结构化输出
- **框架**：Next.js / Vite / React Native 自动检测

## 快速上手

### 一键扫描
```bash
npx -y react-doctor@latest .
```

### 安装到 AI Agent
```bash
npx -y react-doctor@latest install
```

### GitHub Actions
```yaml
- uses: actions/checkout@v5
  with:
    fetch-depth: 0
- uses: millionco/react-doctor@main
  with:
    diff: main
    github-token: ${{ secrets.GITHUB_TOKEN }}
```
