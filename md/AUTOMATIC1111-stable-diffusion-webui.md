## 项目简介

**Stable Diffusion WebUI (A1111)** 是由匿名开发者 AUTOMATIC1111 创建的 Stable Diffusion 本地 Web 界面，基于 Gradio 库构建。自 2022 年发布以来，成为全球数百万用户接触 AI 图像生成的第一扇门。

支持 txt2img、img2img、Inpainting、Outpainting 等全套生成模式，集成 GFPGAN/CodeFormer 人脸修复、RealESRGAN 超分辨率、Textual Inversion、LoRA、Hypernetworks 等能力。最低仅需 4GB VRAM，一个 GPU 即可在本地生成高质量 AI 图像。拥有庞大的扩展生态系统——ControlNet、ADetailer 等数千个社区插件。

## 六大核心优势

### 🔌 一键安装 + 4GB 显存
一行命令安装运行，最低 4GB VRAM 即可生成图像。支持 NVIDIA、AMD、Intel GPU 和 Apple Silicon。

### 🧩 庞大的扩展生态
数千个社区扩展——ControlNet、ADetailer、OpenPose、Infinite Image Browsing 等。功能几乎无限扩展，形成强大的生态壁垒。

### 🎯 精细提示词控制
注意力权重语法 ((word))、(word:1.21)，负向提示词，Prompt Editing 中途切换，Composable-Diffusion (AND 语法)。无 Token 数量限制。

### ⚡ xformers + FP8 加速
xformers 显著提速，FP8 低精度支持减少显存占用。多种采样器可选 (Euler, DPM++, UniPC 等)。

### 📐 全模型支持
SD 1.5 / SD 2.0 / SDXL / SD3 / Alt-Diffusion 全系列。safetensors 安全格式，VAE 独立切换，Checkpoint 热加载。

### 🔗 API + 自动化
完整的 RESTful API，支持编程调用和批量处理。可集成到自动化工作流中，搭配 Google Colab 云端运行。

## 快速上手

### Windows (NVIDIA GPU)
```bash
git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui.git
cd stable-diffusion-webui
webui-user.bat
```

### Linux
```bash
sudo apt install wget git python3 python3-venv libgl1 libglib2.0-0
git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui.git
cd stable-diffusion-webui
bash webui.sh
```

### 优化启动参数
```bash
# 启用 xformers 加速 + 中等显存模式
webui-user.bat --xformers --medvram

# 启用 API + 局域网访问
webui-user.bat --api --listen
```

启动后打开浏览器访问 `http://127.0.0.1:7860`
