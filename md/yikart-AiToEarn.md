## 项目简介

**AiToEarn** 是一个开源的 AI 内容营销智能体平台，核心理念是"用 AI 赚钱"。它为 OPC（一人公司）、创作者、品牌与企业提供从 **内容创作 → 多平台发布 → 自动互动 → 效果变现** 的全链路 AI 自动化能力。

覆盖全球 **12 个主流社交媒体**：抖音、小红书、快手、B站、TikTok、YouTube、Facebook、Instagram、Threads、X（Twitter）、Pinterest、LinkedIn。

---

## 四大核心 Agent 能力

### 💰 Monetize · 内容变现
内置内容交易市场，创作者可接商家推广任务，按 CPS（按成交）、CPE（按互动）、CPM（按曝光）三种模式结算。

### 📢 Publish · 多平台发布
一键将内容分发到全球 12+ 主流平台，支持日历排期统一规划发布时间。

### 💬 Engage · 智能互动
浏览器插件实现全平台自动化互动：自动点赞/收藏/关注、AI 智能评论回复、高转化信号挖掘、品牌舆情监测。

### 🎨 Create · AI 内容创作
Agent 驱动的内容生产线：视频生成（Grok/Veo/Seedance）、图片生成（Nano Banana）、视频翻译带口型匹配、批量内容生成。

## 技术架构

- **前端**：Next.js / React + TypeScript
- **桌面端**：Electron + SQLite
- **后端**：Node.js，Nx Monorepo 架构，pnpm 工作区
- **数据库**：MongoDB + Redis
- **协议**：MCP（Model Context Protocol）支持 Claude/Cursor 集成
- **部署**：Docker 一键部署（含 MongoDB + Redis）
- **插件**：浏览器扩展 + OpenClaw（龙虾）集成

## 快速上手

### 方式一：网页直接使用（零配置）
直接访问 aitoearn.cn（中国）或 aitoearn.ai（国际），注册即用。

### 方式二：Docker 私有化部署
```bash
git clone https://github.com/yikart/AiToEarn.git
cd AiToEarn
docker compose up -d
# 访问 http://localhost:8080
```

### 方式三：MCP 集成 Claude/Cursor
```json
{
  "mcpServers": {
    "aitoearn": {
      "type": "http",
      "url": "https://aitoearn.ai/api/unified/mcp",
      "headers": { "x-api-key": "你的API-Key" }
    }
  }
}
```
