## 项目简介

**knowledge-work-plugins** 是 Anthropic 官方开源的插件仓库，专门为 **Claude Cowork**（Anthropic 的智能办公桌面应用）构建。它提供了 11 个开箱即用的职业插件，覆盖销售、法务、财务、市场、产品、数据、客服等多个核心业务领域。同时兼容 Claude Code 终端环境。

每个插件将 Claude 转变为特定岗位的专家，并支持企业定制——替换连接器、添加公司术语、调整工作流，打造专属 AI 助手。

## 核心功能

- **角色专精**：每个插件针对一个职业角色（销售、财务、法务等），内置领域专业知识和最佳实践
- **Skill + Command + Connector 三位一体**：自动触发的技能、显式调用的斜杠命令、外部工具连接器
- **零代码定制**：所有组件均为 Markdown/JSON 文件，无需编码、无需基础设施、无需构建步骤
- **企业级连接器**：内置对 Slack、Notion、HubSpot、Jira、Snowflake 等 50+ 工具的原生支持
- **Claude Code 兼容**：不仅限于 Cowork，同样可在 Claude Code 终端中使用

## 技术架构

### 插件结构

```
plugin-name/
├── .claude-plugin/plugin.json   # 插件清单 (Manifest)
├── .mcp.json                    # 工具连接 (Connectors via MCP)
├── commands/                    # 斜杠命令 (Slash Commands)
└── skills/                      # 领域知识 (Skills, 自动激活)
```

### 三层架构

1. **Skills（技能层）**：编码领域专业知识、最佳实践、工作流程。Claude 在相关场景自动调用，无需显式触发
2. **Commands（命令层）**：用户显式触发的动作，如 `/finance:reconciliation`、`/data:write-query`
3. **Connectors（连接层）**：通过 MCP（Model Context Protocol）协议连接外部工具

### 技术亮点

- **纯文件驱动**：Markdown + JSON，零代码门槛
- **MCP 协议标准**：基于 Anthropic 2025 年 12 月发布的开放标准
- **热插拔设计**：安装即生效，Skills 自动匹配场景
- **企业可定制**：替换连接器、添加公司术语、调整工作流

## 快速上手

### Claude Cowork（桌面应用）

1. 访问 claude.com/plugins 浏览可用插件
2. 根据角色选择对应插件，一键安装
3. 插件自动激活，Skills 智能匹配场景，也可使用斜杠命令显式调用

### Claude Code（终端）

```bash
# 添加插件市场
claude plugin marketplace add anthropics/knowledge-work-plugins

# 安装具体插件
claude plugin install sales@knowledge-work-plugins
claude plugin install finance@knowledge-work-plugins
claude plugin install data@knowledge-work-plugins

# 使用斜杠命令
/sales:call-prep        # 准备销售通话
/finance:reconciliation # 财务对账
/data:write-query       # 编写 SQL 查询
```

### 自定义插件

```bash
git clone https://github.com/anthropics/knowledge-work-plugins.git
cd knowledge-work-plugins
cp -r sales my-custom-plugin
# 编辑 .claude-plugin/plugin.json、skills/、commands/ 即可
```
