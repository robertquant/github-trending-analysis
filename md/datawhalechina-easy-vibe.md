## 📖 项目简介与核心功能

easy-vibe 是由 DatawhaleChina（开源 AI 学习社区）推出的 Vibe Coding 2026 课程项目。它旨在成为零基础学习者掌握"氛围编程"（Vibe Coding）的第一门现代编程课程——通过自然语言与 AI 协作来构建软件，而非传统手写代码。

**核心理念**：在 AI 时代，编程的门槛不再是语法和算法，而是"如何有效地用自然语言描述需求、引导 AI 构建产品"。easy-vibe 将这一理念系统化为 4 条渐进式学习路径。

**核心数据**：
- 4 条渐进式学习路径（快速首胜 → 产品原型 → 全栈产品 → AI-Native）
- 9 大知识领域（前端/后端/数据库/部署/支付/跨平台/AI 集成/DevOps/产品设计）
- 80+ 互动主题，每章配有可运行的代码示例
- Vibe Stories：真实用户从零到产品的学习旅程
- llms.txt：为 AI Agent 自动发现而优化的课程索引文件

## 🏗️ 技术架构与特点

- **渐进式学习路径** — 从"5 分钟做出第一个产品"到"Claude Code Agent Teams"，4 个阶段覆盖从入门到 AI-Native
- **多工具链覆盖** — Cursor、Bolt.new、Lovable、v0、Replit、Windsurf、Claude Code 等主流 Vibe Coding 工具
- **跨平台实战** — 微信小程序、Android、iOS、PWA、Chrome 扩展、Electron、NFT、VS Code 扩展、Qt
- **Claude Code 深度指南** — MCP（Model Context Protocol）、Skills、Agent Teams 工作流完整教程
- **中文优先** — 面向中文开发者社区，填补中文 Vibe Coding 教育空白
- **社区驱动** — Vibe Stories 收集真实案例，contributors 来自清华等高校

```bash
# 学习路径概览
Path 1: 快速首胜 (Fast First Win)
  → 5 分钟内用 Bolt.new / v0 做出第一个产品
Path 2: 产品原型 (Product Prototype)
  → 用 Cursor / Windsurf 构建可交互原型
Path 3: 全栈产品 (Full-Stack Product)
  → 前端 + 后端 + 数据库 + 部署 + 支付完整链路
Path 4: AI-Native 开发
  → Claude Code MCP/Skills/Agent Teams 高级工作流
```
