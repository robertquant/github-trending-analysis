## 项目概述

MoneyPrinterTurbo 是一个开源的 AI 短视频全自动生成工具。用户输入主题或关键词，系统自动完成脚本撰写、素材匹配、AI 配音、字幕生成到视频合成的全流程，约 3 分钟即可输出高清短视频成品。

## 技术架构

| 模块 | 技术栈 |
|------|--------|
| LLM 服务 | LiteLLM 统一接口，支持 15+ 供应商、100+ 模型 |
| TTS 语音 | edge-tts / CosyVoice / Azure TTS 等 9+ 引擎 |
| 素材检索 | Pexels / Pixabay API，匹配准确率约 88% |
| 视频合成 | MoviePy + FFmpeg + ImageMagick |
| 用户界面 | Streamlit Web UI / REST API / CLI |

## 核心创新点

- **端到端自动化**：关键词到成品视频全流程无需人工干预
- **多模型统一接入**：LiteLLM 实现 100+ 模型自由切换
- **智能素材匹配**：基于语义关键词自动检索，88% 匹配准确率
- **模块化 MVC 架构**：高度解耦，便于二次开发
- **批量生成**：一次生成多版本，支持 A/B 测试

## 应用场景

自媒体短视频批量生产、在线教育视频制作、企业营销视频、新闻资讯视频化、API 自动化流水线
