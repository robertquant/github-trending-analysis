# MOSS-TTS 深度分析报告

**项目**: OpenMOSS/MOSS-TTS | **团队**: 复旦大学 NLP / MOSI.AI | **日期**: 2026-05-29 | **综合评分**: 9.0/10

## 项目概述

MOSS-TTS 是复旦大学邱锡鹏教授领衔的 OpenMOSS 团队开源的语音生成模型家族，包含旗舰版(1.7B/8B)、轻量版 Nano(0.1B)、对话版 TTSD 和语音到语音大模型 MOSS-Speech，覆盖端侧到生产级全场景。Apache 2.0 协议。

## 技术架构

- **CAT 架构**: 自研 MOSS-Audio-Tokenizer + 可变比特率 RVQ，高效压缩 24kHz 音频
- **双阶段生成**: 语言模型建模序列依赖 + 扩散变换器精炼音频波形
- **Nano 纯自回归**: 0.1B 参数，48kHz 双声道，支持 ONNX CPU 推理
- **层拆分架构**: MOSS-Speech 在预训练 LLM 上冻结权重新增语音层

## 核心创新

1. **零样本克隆 SOTA** - Seed-TTS-Eval 基准超越所有开源模型，3秒音频复刻
2. **60分钟长音频** - 一次性稳定生成，Token 级时长控制
3. **0.1B 端侧实时** - 100ms 出声，纯 CPU 运行
4. **llama.cpp 集成** - 2026.3 新增首选实现，降低部署门槛
