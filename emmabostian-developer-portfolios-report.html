📚 项目概述

developer-portfolios 是由 Spotify 前端工程师 Emma Bostian 创建并维护的社区驱动型策展项目，旨在收集和展示全球优秀开发者的个人作品集网站，为正在构建或改进自己作品集的开发者提供灵感。

起源故事：该项目灵感来源于开发者 Ali Spittel 的一条推文，鼓励开发者展示自己的作品集。Emma 将这一想法发展为一个系统化的 GitHub 仓库，任何开发者都可以通过提交 PR 来添加自己的作品集。

截至分析时，项目已收录来自全球的 1,683 位开发者的作品集，涵盖前端工程师、后端开发者、全栈工程师、AI/ML 工程师、游戏开发者、DevOps 工程师等几乎所有技术方向。

  • PR 贡献机制：设有完善的 CONTRIBUTING.md 贡献指南，开发者通过 Fork → 修改 → PR 的标准流程提交作品集
  • 配套网站：除了 GitHub README 外，还提供了独立的 Developer Portfolios Website，支持随机浏览功能
  • 结构化元数据：每个作品集条目包含开发者姓名、技术方向标签（如 [Full Stack Developer]、[AI Engineer]）和作品集链接
  • 持续集成：社区维护者定期审核和合并 PR，确保内容质量和链接有效性
