一、项目概述

Win11Debloat 是由开发者 Raphire（Jeffrey） 维护的开源 PowerShell 脚本项目，定位是「一个简单、轻量、易于使用的 Windows 减负与自定义脚本」。它的核心理念是：无需安装、一行命令即可运行，让用户无需手动在系统设置中逐项翻找、逐个卸载应用，就能快速把一台「开箱即用、塞满广告和遥测」的 Windows 变得清爽干净。

该项目是已停止维护的 Sycnex/Windows10Debloater 的精神继承者。Raphire 在原项目基础上 fork 并持续开发，将其扩展为同时覆盖 Windows 10 与 Windows 11，并更名为 Win11Debloat。截至分析日，项目已积累 超过 4.8 万 Star，是 GitHub 上同类工具中关注度最高的项目之一，且保持高频更新（最新 Release 为 2026.06.14）。

「脚本在保证不会无意中破坏任何系统功能方面下了很大功夫，但仍请自担风险使用。」—— 项目 README

项目除面向普通家庭用户外，还专门为系统管理员与高级用户设计了进阶能力：强大的命令行参数、Windows 审计模式（Audit Mode）支持，以及向其他 Windows 用户应用更改的能力，使其在企业 IT 部署场景中同样实用。

二、技术架构

Win11Debloat 是一个纯 PowerShell 脚本项目，仓库体积很小（约 2.2 MB），没有编译产物、没有重型运行时依赖，本质上由一组 .ps1 脚本与若干资源文件组成。这种极简架构正是其「轻量、免安装」定位的技术基础。

核心组成与技术实现：

  • 主脚本 Win11Debloat.ps1：入口脚本，负责整体编排、用户交互（交互式菜单）与流程控制。
  • 模块化拆分：将不同功能领域（应用卸载、注册表调整、任务栏/开始菜单设置等）拆分为独立的辅助脚本（如 Get-RegFileOperations.ps1），便于维护与单元测试。
  • 注册表驱动（Registry Tweaks）：绝大多数系统行为调整通过修改 Windows 注册表键值实现，这也是 topics 中标注 registry-tweaks 的由来——轻量、可逆、可脚本化。
  • 三种运行方式：
    • 快速方式（Quick method）：通过 PowerShell 一行命令从官方短链拉取并执行：
& ([scriptblock]::Create((irm "https://debloat.raphi.re/")))
  • 传统方式（Traditional）：下载 ZIP，双击 Run.bat，接受 UAC 提权。
  • 高级方式（Advanced）：手动 Set-ExecutionPolicy 后在 PowerShell 中以管理员身份运行，支持命令行参数。

运行模式与可逆性设计：脚本提供交互式菜单（默认）和命令行参数（CLI）两种使用方式，所有改动都被设计为可回退——几乎所有被移除的应用都能通过 Microsoft Store 重新安装，项目 Wiki 提供完整的「还原更改」指南。最新的 2026.06.14 版本还专门重构了脚本以解决 Windows Defender / Bitdefender 的误报问题。

进阶/企业特性：支持 Windows 审计模式（Audit Mode）、Sysprep 模式（将更改应用到 Windows 默认用户配置文件，使所有新用户自动获得优化后的设置），以及向其他指定用户应用更改——这是面向 IT 管理员与 OEM 预装场景的关键能力。

架构小结：以「PowerShell 脚本 + 注册表调整」为骨，以「交互菜单 + CLI 参数 + 可逆设计 + Sysprep/Audit 模式」为肉，用最小的依赖实现最大化的系统自定义覆盖面。

三、核心功能与创新点

Win11Debloat 的功能覆盖面非常广，几乎涵盖了 Windows 用户日常抱怨的所有「痛点」。下表按领域归类：

🗑️ 应用卸载

  • 批量移除各类预装 UWP/系统应用
  • 移除后可经 Microsoft Store 重装

🔒 隐私 & 建议内容

  • 关闭遥测、诊断数据、活动历史、应用启动追踪、定向广告
  • 关闭提示/技巧/建议、定位服务、查找我的设备
  • 关闭锁屏 Spotlight、Edge/MSN 广告与新闻流、M365 广告

🤖 AI 功能（紧跟前沿）

  • 禁用并移除 Microsoft Copilot
  • 关闭 Windows Recall、Click to Do
  • 阻止 AI 服务（WSAIFabricSvc）自启动
  • 关闭 Edge / Paint / Notepad 中的 AI 功能

⚙️ 系统设置

  • 恢复旧版 Win10 风格右键菜单
  • 关闭鼠标加速、粘滞快捷键、Storage Sense
  • 关闭快速启动、BitLocker 自动加密、待机时联网

🚀 Windows Update

  • 阻止更新一发布就自动获取
  • 阻止登录时更新后自动重启
  • 关闭 Delivery Optimization（P2P 分发）

🪟 开始菜单 & 搜索

  • 清空/替换开始菜单磁贴、隐藏推荐区
  • 关闭搜索中的 Bing 网页结果与 Copilot 集成
  • 关闭搜索高亮（动态/品牌内容）

📊 任务栏

  • 图标左对齐、隐藏搜索/任务视图/小组件/聊天
  • 右键菜单启用「结束任务」选项
  • 启用「最后活动点击」行为、多显示器图标显示

📁 文件资源管理器

  • 显示文件扩展名、隐藏文件
  • 自定义导航窗格、恢复常用文件夹到「此电脑」
  • 隐藏 3D 对象/OneDrive 等冗余项

🔀 多任务 & 可选功能

  • 关闭窗口贴靠、Snap Assist、Snap Layout 建议
  • 一键启用 Windows Sandbox、WSL

🎮 其他 & 浏览器

  • 关闭 Xbox Game Bar 及游戏录屏（消除弹窗）
  • 清理 Brave 浏览器中的 AI/加密货币/新闻臃肿项

核心创新与差异化亮点：

  • 紧跟 Windows 演进，覆盖最新「AI 臃肿」：第一时间提供关闭 Copilot、Recall、Click to Do 及各原生应用 AI 功能的开关，这是很多老牌减负工具尚未覆盖的前沿需求，也是其近期更新的重点（扩展 AI 遥测拦截）。
  • 「温和且可逆」的安全哲学：相较于某些激进减负工具（可能破坏系统更新或功能），Win11Debloat 明确强调「不会无意破坏系统功能」，并提供完整还原路径，降低了小白用户的试错成本。
  • 企业级部署能力：Sysprep 模式 + Audit 模式 + 多用户应用，使其不止是「个人玩具」，而能融入企业镜像制作与 MSP 批量装机流程。
  • 双模交互（菜单 + CLI）：交互式菜单照顾普通用户，命令行参数照顾自动化/脚本化场景，一套脚本兼顾两类人群。
  • 简短官方短链分发：debloat.raphi.re 一行命令，极大降低了使用门槛。

四、应用场景

  • 个人电脑开箱清理：新买的笔记本/品牌机预装大量第三方软件、广告与遥测，普通用户一键运行即可获得清爽纯净的桌面，这是最典型、受众最广的场景。
  • 隐私敏感用户：重视数据隐私、不希望微软收集诊断数据与使用习惯的用户，可批量关闭遥测、定位追踪、广告 ID。
  • 游戏玩家主机优化：关闭 Xbox Game Bar 弹窗、释放后台资源、关闭动画与透明效果以追求更稳定的帧率与更低输入延迟。
  • 企业 IT / MSP 批量装机部署：利用 Sysprep 与 Audit 模式，将优化后的设置写入默认用户配置，使批量下发的设备开箱即统一、干净，显著降低运维与排障成本（Reddit r/msp 社区即有 MSP 在新机预配流程中使用）。
  • VDI / 虚拟桌面镜像瘦身：在虚拟桌面基础架构中，去除冗余应用与服务能减小镜像体积、降低资源占用、提升并发密度。
  • 老旧硬件提速：在低配机器上关闭后台服务、动画、透明效果与 P2P 更新，缓解卡顿（需注意社区共识：减负对性能的提升有限，主要价值在「干净」与「隐私」）。
  • 内容创作者 / 开发者工作环境：恢复经典右键菜单、显示文件扩展名、启用 WSL 与 Sandbox，快速搭建高效开发环境。
需要客观指出：多家媒体（如 PCMag、XDA）实测表明，减负工具对真实性能提升往往有限，其核心价值更多在于「移除干扰、提升隐私、统一体验」而非「显著提速」。理性使用，避免过度激进。
