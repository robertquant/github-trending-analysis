项目概述

Agent-Reach 是一个面向 AI Agent 的互联网信息获取脚手架工具。它解决了一个核心痛点：AI Agent（如 Claude Code、Cursor、OpenClaw 等）虽然已经具备强大的编程和分析能力，但在访问互联网内容时几乎是"盲"的——Twitter 需要付费 API、Reddit 服务器 IP 被 403 封锁、B 站海外 IP 无法访问、小红书需要登录才能浏览。

Agent-Reach 通过整合多个成熟的开源 CLI 工具（twitter-cli、rdt-cli、yt-dlp、Jina Reader 等），将 17+ 平台的信息获取能力统一封装到一个安装命令中，实现零 API 费用、Cookie 本地存储、一键安装即可使用。

核心价值主张："Give your AI Agent one-click access to the entire internet" — 用一个 CLI 命令，让你的 AI Agent 具备跨平台的信息获取能力，无需付费 API，无需复杂配置。

技术架构

架构设计：脚手架模式（Scaffolding）

Agent-Reach 明确定位为"脚手架"而非"框架"。它不封装上游工具的调用逻辑，而是负责选型、安装、配置和诊断。安装完成后，AI Agent 直接调用上游工具（如 twitter search、yt-dlp、rdt search），没有中间包装层。

核心创新点

1. 脚手架思维而非框架思维
与 LangGraph、CrewAI 等 Agent 框架不同，Agent-Reach 不构建新的运行时或抽象层。它专注于解决"工具选型和配置"这个重复性工作，安装后 Agent 直接调用上游工具，零性能损耗。
2. 零 API 费用 + Cookie 本地化
所有平台均通过开源 CLI 工具或 Cookie 认证访问，无需付费 API（Twitter API 约 $215/月）。Cookie 仅存储在本地 ~/.agent-reach/config.yaml（权限 600），不上传不外传。
3. Agent 原生设计（Agent-Native）
安装命令设计为"发给 Agent 的一段话"，Agent 读取 install.md 后自主完成全部安装。同时通过 SKILL.md 机制让 Agent 自动学会使用各平台工具，无需人工记忆命令。
4. 内置诊断系统（agent-reach doctor）
一条命令即可查看所有渠道的运行状态，清晰标注哪些可用、哪些需配置、如何修复。大幅降低排查成本。
5. 覆盖中国互联网生态
除国际平台外，深度整合小红书、B 站、抖音、微信公众号、微博、V2EX、雪球、小宇宙等中国平台，这在同类工具中极为罕见。
