🏗️ 技术架构

SIA 的核心是一个三代 Agent 协作架构，通过元 Agent → 目标 Agent → 反馈 Agent的迭代循环实现自改进：

┌─────────────────────────────────────────────────────┐ │ SIA 迭代循环 │ │ │ │ ┌──────────┐ 生成初始 ┌──────────────┐ │ │ │ Meta-Agent│──────────────→│ Target Agent │ │ │ │ (元代理) │ 脚手架 │ (任务代理) │ │ │ └──────────┘ └──────┬───────┘ │ │ ↑ │ │ │ │ 执行任务 & 记录日志 │ │ │ ↓ │ │ │ ┌───────────────┐ │ │ │ │Feedback Agent │ │ │ │ │ (反馈/改进代理) │ │ │ │ └───────┬───────┘ │ │ │ │ │ │ │ ┌──────────────────────┤ │ │ │ ↓ ↓ │ │ │ 更新 Harness 更新 Weights │ │ │ (脚手架/提示词) (模型微调) │ │ └────────────────────────────── │ │ │ │ 重复 N 代（Generation 1 → 2 → ... → N） │ └─────────────────────────────────────────────────────┘

1. Meta-Agent（元代理）

读取任务描述，生成针对特定任务定制的初始 Target Agent。它本质上是一个 LLM → Agent Code 的元编程过程：输入是任务规格说明，输出是一个完整的可执行 Agent 脚本。

2. Target / Task-Specific Agent（目标代理）

在 Meta-Agent 生成的脚手架内执行具体任务，记录完整的操作日志和执行结果。这个 Agent 每一代都会被重新生成或增量修改。

3. Feedback / Improvement Agent（反馈代理）

审查 Target Agent 的执行日志，识别改进机会，并执行双重更新：

  • Harness Updates（脚手架更新）：修改 Agent 的工作流、提示词、工具调用逻辑
  • Weight Updates（权重更新）：通过微调（Fine-tuning）调整模型内部参数
🔑 核心创新：传统的自改进系统要么只优化提示词/工作流（如 DSPy），要么只训练模型权重（如 RLHF）。SIA 是第一个在单一闭环中同时迭代两者的框架——这正是其性能大幅超越基线的原因。

迭代流程

  1. Generation 0：Meta-Agent 根据任务描述生成初始 Agent
  2. Generation N：Target Agent 执行任务 → Feedback Agent 分析日志 → 同时更新 Harness + Weights
  3. Generation N+1：使用更新后的 Agent 重新执行，重复直到收敛或达到最大代数

💡 核心创新点

1. 双重更新闭环（Harness + Weight Updates）

这是 SIA 最根本的创新。传统方法的局限：

  • 仅 Harness 优化（如 DSPy、PromptBreeder）：受限于提示词表达力的上限
  • 仅 Weight 优化（如 RLHF、DPO）：优化目标与实际任务脱节

SIA 将两者融合：Feedback Agent 同时生成脚手架修改方案和微调数据，使 Agent 的"行为策略"和"底层能力"同步进化。实验表明，单独使用 Harness 更新或 Weight 更新均无法达到 SIA-W+H 的效果。

2. 元编程式 Agent 生成

Meta-Agent 不是简单地生成提示词，而是直接生成可执行的 Python Agent 代码。这意味着每代的 Agent 可以拥有完全不同的架构、工具链和推理策略——进化不仅是参数调整，更是架构搜索。

3. 通用任务适配

框架不限定特定领域。只需提供任务描述和数据，SIA 即可自动生成、执行、改进 Agent。已验证的领域包括：

  • 法律推理（LawBench：191 个罪名分类）
  • 机器学习工程（MLE-Bench：真实 Kaggle 竞赛）
  • GPU Kernel 优化（AlphaFold-3 TriMul Triton Kernel）
  • 生物信息学（单细胞 RNA 测序去噪）

4. MLE-Bench 排行榜冠军

SIA 在 OpenAI 的 MLE-Bench Hard（基于真实 Kaggle ML 竞赛的高难度基准）上登顶排行榜第一，超越了包括 Karpathy 的 AutoResearcher 在内的所有专门化 Agent。这证明了其通用自改进能力的实际价值。
