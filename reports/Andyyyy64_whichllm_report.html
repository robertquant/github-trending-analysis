📋 项目概述

whichllm 是一个开源命令行工具（CLI），旨在解决本地 LLM 部署中最核心的难题：在众多模型中，哪一个真正适合我的硬件并且表现最佳？

该工具自动检测用户的 GPU/CPU/RAM 配置，从 HuggingFace 实时获取模型数据，并基于多维度真实基准测试（LiveBench、Artificial Analysis、Aider、Chatbot Arena ELO 等）进行智能排名，而非简单地推荐"能塞进显存的最大的模型"。

💡 核心理念：能塞进显存只是第一步。知道哪个模型在能跑的里面是最好的，才是 whichllm 真正解决的问题。

💡 核心创新点

  • 基于证据的排名，而非参数量启发式：顶级推荐由真实基准数据决定，而非简单选择"能装下的最大模型"。一个 27B 的高质量模型可能比 32B 的旧模型排名更高。
  • 时效性感知（Recency-aware）：陈旧的排行榜得分会被降权。2024 年的模型不能凭过时分数超越新一代模型。每次排名都显示基准快照日期，让过时推荐自我暴露。
  • 五级证据分级体系：从"直接匹配"到"自报分数"五级递减，有效防止小模型借用大模型家族的分数。家族成员参数量差异超过 2 倍时自动拒绝继承。
  • 架构感知的 VRAM 估算：VRAM = 权重 + GQA KV 缓存 + 激活值 + 框架开销，并考虑量化效率、后端因素、MoE 活跃/总参数区分、统一内存 vs 独立 PCIe 部分卸载建模。
  • 一键运行与代码生成：whichllm run 自动创建隔离环境、下载模型、启动对话；whichllm snippet 生成即用 Python 代码。
  • GPU 模拟与升级规划：购买硬件前即可模拟任意 GPU 性能表现，对比升级候选方案。
  • Live HuggingFace 数据：模型数据直接从 HuggingFace API 实时获取，附带精选冻结后备数据应对离线场景。

⚡ 典型工作流

# 1. 自动检测硬件，推荐最佳模型
$ whichllm

# 2. 模拟特定 GPU（购买前测试）
$ whichllm --gpu "RTX 4090"

# 3. 对比升级方案
$ whichllm upgrade "RTX 4090" "RTX 5090" "H100"

# 4. 反向查找：某模型需要什么硬件？
$ whichllm plan "llama 3 70b"

# 5. 一键运行模型对话
$ whichllm run "qwen 2.5 1.5b gguf"

# 6. 生成 Python 代码片段
$ whichllm snippet "qwen 7b"

# 7. JSON 输出用于脚本
$ whichllm --top 1 --json
