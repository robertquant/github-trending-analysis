# Trivy 深度分析摘要 | aquasecurity/trivy

**分析日期:** 2026-06-05 | **综合评分:** 8.8/10

## 项目概览
Trivy 是 Aqua Security 开发的开源安全扫描器，CNCF 毕业项目。以"一个工具覆盖所有云原生安全扫描需求"为核心理念，支持漏洞、IaC 配置错误、密钥泄露、许可证合规、SBOM 和云安全扫描。

## 关键数据
- **Stars:** 32,200+ | **Contributors:** 513+ | **Releases:** 178+
- **语言:** Go | **许可证:** Apache 2.0
- **CNCF 状态:** 毕业项目（最高级别）

## 核心优势
1. **全能一体化:** 漏洞 + IaC + 密钥 + 许可证 + SBOM + 云扫描，单一二进制文件
2. **极简体验:** 开箱即用，自动更新漏洞数据库，支持离线扫描
3. **生态完善:** GitHub Actions、Trivy Operator (K8s)、主流镜像仓库全覆盖
4. **供应链安全:** 支持 VEX 文档和 SPDX/CycloneDX 格式 SBOM

## 风险提示
- 2026 年 3 月供应链攻击事件（CVE-2026-33634），trivy-action 被篡改用于窃取 CI/CD 凭证
- 建议始终使用 pinned commit hash 引用 GitHub Actions
