📖 项目概述

train-llm-from-scratch 是由 Fareed Khan 开发的端到端 LLM 训练教学项目。它从下载原始数据集开始，到生成可推理的文本输出结束，完整覆盖了大语言模型训练的全流程。项目基于 Transformer 架构（源自论文 Attention is All You Need），使用 PyTorch 从零实现，不依赖任何高级框架封装。

核心理念：让开发者能够用单块 GPU 训练自己的百万甚至十亿参数级语言模型，理解 LLM 内部工作机制的每一步。作者发现 13M 参数的模型已经能够生成语法正确的文本，这为后续领域微调提供了基础。

项目提供了两套训练配置：

  • 13M 参数模型 — 可在 Colab/Kaggle T4 上训练，一天内完成
  • 2B 参数模型（2,141,346,251 参数）— 需要 A100/RTX 4090 级别 GPU

🔨 技术架构

项目采用经典的 GPT 风格 Decoder-only Transformer 架构，完全使用 PyTorch 手动实现。

|                  Transformer Model                 |
+---------------------------------------------------+
|  Token Embedding (vocab_size -> n_embed)           |
|  + Position Embedding (context_length -> n_embed)  |
+---------------------------------------------------+

           v
+---------------------------------------------------+
|         Transformer Block x N_BLOCKS               |
|  +---------------------------------------------+  |
|  | LayerNorm -> Multi-Head Attention            |  |
|  |   Head_1  Head_2  ...  Head_n               |  |
|  |   (Q,K,V) (Q,K,V)     (Q,K,V)              |  |
|  | + Residual Connection                        |  |
|  +---------------------------------------------+  |
|  +---------------------------------------------+  |
|  | LayerNorm -> MLP                             |  |
|  |   Linear(n_embed -> 4*n_embed) -> ReLU       |  |
|  |   Linear(4*n_embed -> n_embed)               |  |
|  | + Residual Connection                        |  |
|  +---------------------------------------------+  |
+---------------------------------------------------+
           |
           v
+---------------------------------------------------+
|  LayerNorm -> Linear(n_embed -> vocab_size)        |
+---------------------------------------------------+

💡 核心创新点

1. 极致透明度

所有 Transformer 组件均手动实现，没有使用 nn.Transformer 等封装。每一行代码都可以追溯到论文中的数学公式，便于理解注意力机制、残差连接、LayerNorm 的具体作用。

2. 单 GPU 可训练

13M 参数模型可在免费的 Colab T4 上一天内训练完成，2B 模型只需单块 A100 或 RTX 4090。通过详细的 GPU 兼容性对照表（覆盖 25+ GPU 型号），用户可以精确评估自己的硬件能训练多大的模型。

3. 13M 参数的"临界点"发现

作者通过实验发现 13M 参数是 LLM 开始产生语法正确、语义有一定意义文本的临界点。此前作者训练的 2.3M 模型只能输出无意义的词组。这一发现为"小型 LLM 用于特定领域任务"提供了实验依据。

4. 训练 Loss 深度分析

项目提供了百万参数和十亿参数模型的训练 Loss 对比图，揭示了关键差异：

  • 大模型初始 Loss 更高且波动更剧烈，需要更多数据和精心调参
  • 学习率衰减对大模型效果显著，对小模型影响有限
  • 大模型容易过拟合，需要更深的架构设计

5. 完整的数据管道

从 .jsonl.zst 压缩文件下载 -> tiktoken 分词 -> HDF5 高效存储 -> 批量迭代器，提供了一条可复用于其他数据集的完整数据处理流水线。
