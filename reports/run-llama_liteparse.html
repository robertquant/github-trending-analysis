📋 项目概述

LiteParse 是由 LlamaIndex（即 run-llama 组织）开发并开源的文档解析工具。它是 LlamaParse 云服务背后的核心文本提取引擎，以独立开源项目的形式发布，专注于 快速、轻量、本地化 的文档解析。

LiteParse 能够从 PDF、Office 文档（DOCX、PPTX、XLSX）和图片中提取具有 空间布局感知 的文本内容，保留文本的坐标位置和边界框信息（bounding boxes），为下游 AI Agent 工作流提供高质量的解析输入。

核心定位

  • 无云依赖 — 完全本地运行，无需 API 密钥或网络连接
  • 无 LLM 消耗 — 不调用任何大模型，零 token 成本
  • 无 GPU 需求 — 纯规则引擎，不依赖任何 AI 模型
  • 多格式支持 — PDF、DOCX、PPTX、XLSX、图片等
  • 多语言接口 — CLI、Python、Node.js/TypeScript、Rust、WASM

🏗️ 技术架构

LiteParse v2.0 采用了全新的 Rust 重写架构，核心理念是 "将文本投射到空间网格"，而非尝试将复杂文档转换为 Markdown。

架构分层

  • 核心解析引擎（Rust） — 负责底层的 PDF 文本提取和空间布局计算，使用 Rust 编写以确保极致性能和内存安全
  • WASM 编译层 — 将 Rust 核心编译为 WebAssembly，使其能在浏览器、Edge Runtime、Cloudflare Workers 等任何支持 WASM 的环境运行
  • 多语言绑定层
    • Python 通过原生绑定调用 Rust 核心
    • Node.js/TypeScript 提供 CLI 工具和 npm 包 @llamaindex/liteparse
    • Rust 作为 crate 直接使用
    • WASM 用于浏览器和 Edge 环境
  • HTTP 服务层（liteparse-server） — 开源自托管 HTTP 后端，适用于需要 API 服务的场景

两步工作流设计

  1. 快速文本提取 — 原始文本和空间坐标的高效抽取
  2. 结构化解析 — 利用空间信息还原文档的逻辑结构

这种设计的核心哲学是：现代 LLM 已经具备阅读表格的能力，因此无需花费算力将表格转换为特定格式，只需保留空间布局信息让 LLM 自行理解。

空间布局感知

与传统 PDF 解析器不同，LiteParse 不只是提取纯文本，而是为每个文本块提供：

  • 精确的坐标位置（x, y）
  • 边界框信息（bounding box）
  • 页码和阅读顺序

这些信息让下游的 AI 模型能够理解文档的视觉结构，从而更准确地处理表格、多栏布局和图文混排等复杂场景。

💡 核心创新点

1. 空间网格投射模型

突破传统 PDF 解析的"文本流"思路，将文本投射到二维空间网格，保留完整的视觉布局语义。这一设计让 LLM 能够像"看"文档一样理解文档结构。

2. 100 倍性能飞跃（Rust 重写）

v2.0 用 Rust 完全重写核心引擎，相比 v1 实现了最高 100 倍的性能提升。每秒可解析 200-500 页文档，远超同类工具。

3. 全平台 WASM 部署

通过 WASM 编译，实现"一次编写，到处运行"。可在 Cloudflare Workers 边缘节点、浏览器、移动设备等环境毫秒级解析 PDF。

4. Model-Free 智能解析

不依赖任何 AI 模型，完全基于规则和空间算法。零 GPU、零 token 消耗，彻底消除运行成本，同时保持高解析质量。

5. Agent-First 设计理念

专为 AI Agent 工作流优化，作为文档处理链路的第一环节。提供 Agent Skill 定义、沙箱执行环境等 Agent 生态支持。

6. LlamaParse 核心引擎开源

将 LlamaParse（商业云服务）的核心处理引擎开源，让社区能够免费获得与商业产品同等质量的解析能力。

🎯 应用场景

1. RAG（检索增强生成）管道

作为 RAG 系统的文档预处理环节，将 PDF/Office 文档高质量地转换为向量数据库可索引的结构化文本。配合 LanceDB 等向量数据库使用效果尤佳。

2. AI Agent 文档处理

为 AI Agent 提供本地化的文档解析能力。Agent 可自主解析上传的文档，无需将文件发送到第三方云服务，保障数据隐私和安全。

3. 金融研究 Agent

LlamaIndex 官方提供了基于 LiteParse 构建金融研究 Agent 的完整教程，可解析财报、研报等复杂金融文档。

4. CI/CD 自动化文档处理

在 CI/CD 流水线中自动解析和验证生成的文档，如测试报告、API 文档等。

5. 边缘计算文档解析

通过 WASM 在 Cloudflare Workers 等 Edge Runtime 上运行，实现就近解析，减少数据传输延迟。

6. 浏览器端文档处理

在浏览器中直接解析 PDF，无需后端服务器支持，适合隐私敏感场景和离线应用。

7. 自托管文档解析服务

使用 liteparse-server 快速搭建私有文档解析 API，替代云服务，满足合规需求。
