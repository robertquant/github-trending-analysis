📋 项目概述

openai/plugins 是 OpenAI 官方维护的 Codex 插件示例集合，为 AI 编码助手 Codex 提供可复用的扩展能力。 该仓库定义了一套标准化的插件结构，每个插件位于 plugins/<name>/ 目录下，包含必需的 .codex-plugin/plugin.json 清单文件，以及可选的 skills、MCP 配置、agents、commands、hooks 和 assets 等组件。

GitHub: https://github.com/openai/plugins

文档: Build Plugins – Codex

🏗️ 技术架构

Codex 插件系统采用模块化设计，支持多种扩展方式。核心架构如下：

plugins/ ├── figma/ # Figma 设计集成 │ ├── .codex-plugin/ │ │ └── plugin.json # 插件清单（必需） │ ├── skills/ # 技能定义 │ ├── .app.json # 应用集成配置 │ ├── .mcp.json # MCP 协议配置 │ ├── agents/ # 插件级 Agent │ ├── commands/ # 自定义命令 │ ├── hooks.json # 钩子配置 │ └── assets/ # 静态资源 ├── notion/ # Notion 集成 ├── build-ios-apps/ # iOS 应用构建 ├── build-macos-apps/ # macOS 应用构建 ├── build-web-apps/ # Web 应用部署 ├── expo/ # React Native / Expo ├── netlify/ # Netlify 部署 ├── remotion/ # 视频生成 └── google-slides/ # Google Slides 集成

核心组件说明：

  • plugin.json — 插件元数据清单，定义名称、版本、描述和入口
  • skills/ — 预定义的提示工作流，让 Codex 能自动执行特定任务序列
  • .mcp.json — Model Context Protocol 配置，连接外部工具和数据源
  • .app.json — 应用集成配置，定义第三方服务连接
  • agents/ — 插件级 Agent 定义，实现自主任务执行
  • commands/ — 自定义命令，用户可通过 CLI 直接调用
  • hooks.json — 事件钩子，在特定触发条件下自动执行操作

💡 核心创新点

  • 一体化插件架构：将 Skills、MCP、Agents、Commands、Hooks 五种扩展模式统一在一个插件框架内，开发者无需学习多种集成方式，一套结构即可覆盖所有扩展场景。
  • 声明式插件清单：通过 plugin.json 声明式定义插件能力，Codex 运行时自动发现和加载，降低了插件开发门槛。
  • MCP 原生支持：内置对 Anthropic 推出的 Model Context Protocol 的支持，体现了 OpenAI 在工具层面对开放标准的兼容态度。
  • 全平台覆盖：从 iOS/macOS 原生应用到 Web 部署、从设计到代码、从文档到演示，覆盖开发全链路。
  • 可复用与可组合：插件之间可以组合使用，开发者可以将 Figma 插件与 build-web-apps 插件配合，实现从设计稿到上线部署的完整自动化。
  • 社区驱动生态：开源仓库配合社区资源（如 awesome-codex-plugins），形成快速增长的插件市场。
