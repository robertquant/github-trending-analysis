📚项目概述

Project N.O.M.A.D.（Node for Offline Media, Archives, and Data）是由 Crosstalk Solutions 开发的一款完全离线、自包含的知识与教育服务器。它将维基百科、AI 聊天、离线地图、教育课程、数据分析工具等多项核心能力整合到一个 Docker 容器编排平台中， 仅需一条太阳能板即可运行，号称"末日生存电脑"。

⚙技术架构

Project N.O.M.A.D. 采用 Docker 容器化架构，所有服务组件均以独立容器运行，通过 Docker Compose 进行编排管理。核心架构包含一个自研的 "Command Center" 管理 UI 和 API 层，统一管理所有容器化工具和资源的安装、配置与更新。

💡核心创新点

1. "一键式"离线知识堡垒
只需 3 行命令即可安装完整的离线知识服务器，集成维基百科（约 50-996GB）、AI 聊天、离线地图、教育课程等，真正实现"即插即用"的离线知识中心。
2. 容器化编排 + 统一管理 UI
自研的 Command Center 提供了一站式管理界面，用户无需手动配置各个 Docker 容器，安装、更新、管理全部通过 Web UI 完成，极大降低了使用门槛。
3. AI + RAG 知识增强
集成 Ollama 本地大模型推理 + Qdrant 向量数据库，支持文档上传和语义搜索（RAG），在完全离线环境下实现 AI 增强的知识检索和对话。
4. 极低功耗设计
核心服务可在最低 4GB RAM 的设备上运行，配合一块太阳能板即可供电，适用于极端环境、野外作业、灾难应急等场景。
5. 零遥测 + 隐私优先
项目内置零遥测设计，仅在安装时需要网络连接，运行期间完全离线。唯一的外部请求是用于检测网络连通性的 Cloudflare 端点。
6. 灵活的 AI 后端支持
除默认的 Ollama 外，还支持 OpenAI API 兼容的后端（如 LM Studio、llama.cpp），用户可根据硬件条件灵活选择推理方案。
