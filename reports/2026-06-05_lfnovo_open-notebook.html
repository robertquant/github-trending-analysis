📋 项目概述

Open Notebook 是由开发者 Luis Novo (lfnovo) 于 2024 年 10 月 发起的开源项目，定位为 Google NotebookLM 的完全开源、隐私优先的替代方案。项目在 2025-2026 年间获得了爆发式增长，GitHub Stars 已达约 24,000，成为 AI 知识管理领域最受欢迎的开源项目之一。


项目的核心理念是：在一个由人工智能主导的世界中，思考和获取新知识的能力不应成为少数人的特权，也不应被单一供应商所限制。


开源 隐私优先 自托管 多模型支持 本地部署 AI 知识管理 播客生成 多语言

🏗️ 技术架构

三层异步优先架构

Open Notebook 采用经典的三层架构设计，强调模块化、可扩展性和多 AI 供应商灵活性：


层级 技术栈 职责
前端层 Next.js + React + TypeScript 现代 SPA 界面、多语言 UI（中/英/日/葡/俄/孟）
后端层 Python 3.11+ + FastAPI API 服务、AI 编排、内容处理、异步任务
数据层 SurrealDB（文档+关系型混合数据库） 文档存储、向量搜索、全文检索、关系管理

AI 集成层

通过 LangChain 作为 AI 编排框架，并引入 Esperanto 库实现了对 18+ AI 供应商 的统一接入：


能力 支持的供应商
LLM 推理 OpenAI, Anthropic, Google, Ollama, Groq, DeepSeek, Mistral, xAI, Perplexity, Azure OpenAI, OpenRouter, DashScope, MiniMax, LM Studio 等
Embedding OpenAI, Google, Ollama, Azure OpenAI, Mistral, Voyage
语音转文本 OpenAI, Groq, ElevenLabs
文本转语音 OpenAI, Google, ElevenLabs

部署架构

项目提供 Docker 一键部署，所有服务打包在单个 docker-compose.yml 中：


  • SurrealDB 容器 — 数据持久化，支持 RocksDB 存储引擎
  • Open Notebook 容器 — 前端 + 后端一体化，暴露端口 8502（Web）和 5055（API）
  • 支持 Ollama 本地模型 — 完全零 API 费用的本地 AI 方案
  • 支持部署到 Railway、云服务器 等多种环境

架构亮点： 容器化的三层架构确保了松耦合，前端可独立升级；SurrealDB 的文档+关系混合模式既支持灵活的内容存储，又提供向量检索能力；LangChain + Esperanto 的 AI 层使得切换模型供应商只需更改配置。

💡 核心创新点

1. 数据主权与隐私设计

与 Google NotebookLM 将数据存储在云端不同，Open Notebook 采用 100% 本地化 设计。所有研究材料、笔记、对话内容完全存储在用户自有基础设施上，无需将敏感数据上传至第三方。这对于处理商业机密、学术研究数据或个人隐私内容的用户至关重要。

2. 多模型自由选择与成本控制

支持 18+ AI 供应商，用户可根据需求灵活选择：

  • 零成本方案：使用 Ollama + 开源模型（Llama、Qwen、DeepSeek 等）完全本地运行
  • 性价比方案：使用 Groq 免费层或 DeepSeek 等低成本 API
  • 高质量方案：使用 OpenAI GPT-4o、Anthropic Claude 等顶级模型
  • 不同任务可配置不同模型（如用便宜模型做 Embedding，用强模型做对话）

3. 高级播客生成系统

这是 Open Notebook 相较 NotebookLM 的显著差异化特性：

  • 支持 1-4 位主播（NotebookLM 仅支持 2 位）
  • 可创建自定义主播人设档案（Episode Profiles）
  • 完全可控的播客脚本编辑
  • 支持多种 TTS 引擎生成语音

4. 内容转换引擎（Content Transformations）

提供可自定义的内容处理管线，支持：

  • 自动摘要、关键信息提取
  • 自定义转换动作（用户可定义自己的处理逻辑）
  • 支持对 PDF、视频、音频、网页、Office 文档等多模态内容统一处理

5. 完整 REST API 与 MCP 集成

提供全功能的 REST API，支持程序化访问所有功能，可与 Claude Desktop、VS Code 等 MCP 客户端集成，实现 AI 工作流自动化。这是 NotebookLM（无 API）完全不具备的能力。

6. 三层容器式信息组织

独创的笔记本（Notebook）→ 源（Source）→ 笔记（Note）三层信息架构，清晰地将原始材料、中间处理和最终洞察分层管理，符合学术研究和知识管理的自然工作流。

Open Notebook 优势

  • ✅ 完全数据主权，零隐私风险
  • ✅ 模型自由切换，成本可控
  • ✅ 开源可定制，社区驱动
  • ✅ API + MCP 集成能力
  • ✅ 更灵活的播客控制
  • ✅ 无供应商锁定

Open Notebook 劣势

  • ❌ 引用/溯源功能尚待完善
  • ❌ 音频生成质量不及 Google
  • ❌ 需要自行部署和维护
  • ❌ 协作功能仍有限
  • ❌ 实时前端更新仍在开发中
  • ❌ 非技术用户门槛较高

总结：Open Notebook 是目前最成熟的 NotebookLM 开源替代方案。它在数据隐私、模型灵活性和可定制性方面远超 Google NotebookLM，特别适合对数据安全有严格要求的学术机构、企业和个人研究者。虽然音频生成质量和协作功能还有提升空间，但其快速的迭代节奏（已迁移到 Next.js 前端、新增 REST API、MCP 集成）和活跃的社区（24K+ Stars, Discord 社区）表明项目正处于健康的高速发展期。


推荐人群：注重隐私的研究者、需要 AI 辅助知识管理的企业、开源爱好者、播客创作者、技术型学习者。
