01 项目概述

OpenMontage 的核心定位是："AI 编程助手即编排器（orchestrator）"。它本身不包含中央代码调度器，而是把"一整套专业视频生产流水线"以 YAML 流水线清单 + Markdown 技能文件 + Python 工具 的形式喂给任意 AI 编程 Agent，让 Agent 像真人制作团队一样完成从研究、编剧、配音、素材生成到剪辑、合成的全过程。

一句话概括它的差异化：大多数 AI 视频工具只给你"一段由 prompt 生成的片段"，而 OpenMontage 给你的是一条端到端的生产流水线——并且这条流水线在没有付费视频生成 API 的情况下，也能用免费/开源的真实素材拼出成片，而不是简单地"给静态图片做 Ken Burns 推拉"。

02 技术架构

OpenMontage 采用 Agent-First（智能体优先）架构。这一点非常关键：它没有任何中心化的代码编排器，AI 编程助手本身就是编排器。所有创意决策、编排逻辑、评审标准、质量门槛都以人类可读的指令文件（YAML + Markdown）形式存在，可被检视、可被定制，每一个决策都被记录、可审计。

两大合成引擎

Remotion

基于 React 的程序化视频引擎。弹簧动画图像场景、数据卡片、章节标题、TikTok 风格逐字字幕、场景转场（淡入/滑动/擦除/翻转）。当未配置视频生成 Provider 时，Agent 生成静态图片并由 Remotion 将其动画化为完整视频。

HyperFrames

基于 HTML/CSS/GSAP 的程序化视频引擎（Node.js ≥ 22）。动态排版、产品宣传、发布短片、自定义动态图形、网站转视频、骨骼式 SVG 角色动画。通过 npx hyperframes 消费。

03 核心创新点

① 真实素材纪录片流水线（免付费视频模型）

这是最硬核的差异化。OpenMontage 不止能做"静态图动画化"，还能从 Archive.org、NASA、Wikimedia Commons 及 Pexels/Unsplash 等免费来源构建 CLIP 语义可检索的素材语料库，按语义排序检索真实动态素材，剪辑成时间线，渲染成片。官方明确强调："这不是通常那种'给几张静态图加动画就叫视频'的把戏。"

② Agent 即编排器，零代码调度器

所有编排逻辑存在于 可读的指令文件中（YAML 清单 + Markdown 技能），而非黑盒代码。这意味着 Agent 的每一步决策都可以被检视、追溯、定制。每个决策都记录了"考虑过的备选方案、置信度分数、选择理由"，形成可审计的决策轨迹。

③ 7 维度评分式 Provider 选择 + 生产级质量门槛

  • 评分选择：每次工具选择在 7 个维度打分——任务契合度(30%)、输出质量(20%)、可控性(15%)、可靠性(15%)、成本效率(10%)、延迟(5%)、连续性(5)，自动选最优匹配并记录决策。
  • 合成前校验：若交付承诺被违反（如"动态为主"的视频却有 80% 静态图）、幻灯片风险分过高、渲染器缺失，则阻断渲染——在浪费 GPU 之前拦截坏计划。
  • 合成后自检：每次渲染后运行 ffprobe 校验、4 点抽帧检查黑帧/损坏叠加层、音频电平分析、交付承诺核验、字幕存在性检查。自检不过，视频不交付。
  • 幻灯片风险评分：6 维分析防止"动画版 PPT"式输出。

④ 参考视频驱动的创作

可粘贴一个 YouTube/Short/Reel/TikTok/本地片段作为参考，Agent 分析其转写、节奏、场景、关键帧、风格，输出 2-3 个差异化概念 + 诚实的工具路径 + 成本预估 + 全量生产前的样本。你拿到的是"保留什么、改变什么、花多少钱、实际长什么样"，而非"瞎猜的 prompt 意大利面"。

⑤ 内置实时网络研究（防幻觉）

Web 研究是一等公民阶段。在写一个字的剧本之前，Agent 会跨 YouTube、Reddit、Hacker News、新闻站点、学术来源执行 15-25+ 次网络搜索，在结构化研究简报中引用一切——让视频基于真实、最新的信息，而非幻觉事实。

⑥ 预算治理（无意外账单）

执行前预估成本 → 预留预算 → 执行后对账；支持 observe/warn/cap 三种模式；默认超过 $0.50 的动作需确认；总预算上限默认 $10，可配置。Agent 在花钱之前告诉你将要花多少。

⑦ 零 API key 也能出片 + 本地 GPU 免费视频生成

开箱即用：Piper TTS（离线旁白）+ 开放档案素材 + Remotion/HyperFrames 合成 + FFmpeg 后期，零密钥即可成片。有 GPU 时，make install-gpu 解锁 WAN 2.1、Hunyuan、CogVideo、LTX-Video 等本地免费视频生成模型。
