🏗️ 技术架构与内容体系

项目采用模块化教程架构，覆盖 Claude Code 的全部 10 大核心功能域：

01. Slash Commands

用户自定义快捷命令（/optimize, /pr 等），15 分钟上手

02. Memory

跨会话持久化上下文：项目级 / 目录级 / 个人级记忆

03. Skills

可复用的自动调用能力，含脚本和模板（代码审查、文档生成等）

04. Subagents

专用 AI 子代理：代码审查、测试工程师、文档撰写、安全审计

05. MCP Protocol

Model Context Protocol — 接入 GitHub、数据库、文件系统等外部工具

06. Hooks

事件驱动自动化：5 类 29 种事件（PreToolUse, PostToolUse 等）

07. Plugins

打包完整工作流（PR 审查、DevOps 自动化、文档生成）

08. Checkpoints

会话快照与回滚，支持安全实验和 A/B 方案对比

09. Advanced Features

Plan Mode、Extended Thinking、后台任务、权限管理、Headless 模式

10. CLI Reference

完整命令行参考：交互模式、管道模式、JSON 输出、CI/CD 集成
