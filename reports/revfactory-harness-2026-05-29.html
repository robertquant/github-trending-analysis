一、项目概述

revfactory/harness 是一个专为 Claude Code 设计的元技能（Meta-Skill）插件， 核心能力是将一句自然语言描述自动转化为完整的 AI Agent 团队架构和配套技能配置。 用户只需说 "build a harness for this project"， 系统便会自动分析项目领域、设计团队结构、生成 Agent 定义文件和技能文件。

核心理念：不是手动组装 Agent，而是描述你的领域需求，让 Harness 自动生成协调的多 Agent 团队 —— 这是「Harness Engineering」范式的代表。

项目定位于 Claude Code 生态的 L3 Meta-Factory 层（元工厂层）， 具体属于 Team-Architecture Factory（团队架构工厂）子层。 它不直接执行任务，而是生成执行任务的团队。

三、核心创新点

1. Meta-Skill 设计范式

Harness 不是框架而是「元技能」—— 一个生成其他技能的技能。这打破了传统「你构建」的框架模式，转向「它生成」的工厂模式。用户不需要编写 Agent 代码，只需描述意图。

2. 六种经过验证的架构模式

不是从零设计 Agent 协作方式，而是提供六种工业级模式（Pipeline、Fan-out/Fan-in、Expert Pool、Producer-Reviewer、Supervisor、Hierarchical Delegation），覆盖绝大多数多 Agent 协作场景。

3. Progressive Disclosure 上下文管理

生成的技能采用渐进式信息揭露策略，在 Agent 运行时按需加载上下文，而非一次性注入所有信息，有效控制 token 消耗和上下文窗口。

4. 内建验证与测试体系

Phase 6 提供 Trigger 验证、Dry-run 测试以及 with-skill vs without-skill 对比测试。A/B 实验数据显示：使用 Harness 后平均质量评分提升 60%（49.5→79.3），15/15 胜率，输出方差降低 32%。

5. 完整的生态定位体系

项目清晰定义了自身在 Claude Code 生态中的 L3 Meta-Factory / Team-Architecture Factory 定位，并与邻居项目（Archon、meta-harness、ECC 等）明确区分，形成可组合的生态。
