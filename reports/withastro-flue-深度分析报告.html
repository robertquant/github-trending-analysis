1项目概述

过去两年，第一批「真正的 Agent」（如 Anthropic 的 Claude Code、OpenAI 的 Codex）证明了一个新范式： 给模型任务而非步骤，让它在所提供的上下文与工具环境中自主完成。然而，要复制这种能力， 开发者通常需要从零搭建一整套底层基础设施——会话管理、工具调用、文件系统、安全隔离、持久化、可观测性……

Flue 的使命，就是把这套架构「平台化」。它提供一套内置的 TypeScript harness， 让任何模型（如 anthropic/claude-sonnet-4-6）都能获得真正自主工作所需的全部上下文与环境：

  • 统一抽象：用 createAgent() 声明式地组合 model + tools + skills + sandbox + instructions，即可获得一个能自主工作的 Agent。
  • 本地或托管：通过 CLI 在本地运行 Agent，或部署到 Cloudflare Workers、GitHub Actions、GitLab CI、Render、Daytona 等运行时。
  • 安全沙箱：支持本地、虚拟容器、远程容器三种沙箱模式，让 Agent 可以安全地修改文件、运行代码。
  • 可观测：原生支持 OpenTelemetry、Braintrust、Sentry 导出遥测数据。

一句话定位：不是「又一个 Agent SDK」，而是「构建下一代自主 Agent 的工程框架 / 运行底座」。

2技术架构

🏗️ 整体架构：Monorepo + 运行时核心

项目采用 pnpm workspace + Turborepo 的 Monorepo 组织，核心是一个名为 @flue/runtime 的运行时，外围环绕 30+ 个生态包：

// 典型 Agent 定义（来自官方 README）
import { createAgent, type AgentRouteHandler } from '@flue/runtime';
import { local } from '@flue/runtime/node';
import triage from '../skills/triage/SKILL.md' with { type: 'skill' };

export default createAgent(() => ({
  model: 'anthropic/claude-sonnet-4-6',
  tools: [...githubTools],   // 强类型工具
  skills: [triage, verify],  // 可复用「技能」
  sandbox: local(),       // 安全沙箱
  instructions,              // 自主行为指令
}));

🔁 六大核心能力

① Agents

跨对话与事件保持上下文，朝目标自主推进。

② Workflows

结构化自动化，代码引导推理从输入到产出。

③ Sandboxes

安全环境：工具调用、文件修改、自主完成真实工作。

④ Durable Execution

故障/重启后仍能保留已接受工作的进展（持久恢复）。

⑤ Subagents

⑥ Skills + MCP

可复用「技能包」+ 接入 MCP 认证工具与服务。

3核心创新点

  • 🎯 「Harness 而非 SDK」的范式定位。不与 LangChain/Mastra 这类「编排库」正面竞争，而是补齐「让 Agent 像 Claude Code 一样真正自主」所缺的运行底座（会话、文件、沙箱、持久化）。这是市场空白。
  • 🛡️ 一等公民的沙箱（Sandbox）抽象。本地 / 虚拟容器 / 远程容器（Daytona 等）三态可切换。把「Agent 安全执行任意代码」从工程难题变成一行配置：sandbox: local()。
  • ⏳ Durable Execution（持久执行）。借鉴 Inngest/Temporal 的思想，让长周期、可能失败的 Agent 任务在崩溃后可恢复，已完成的「接受工作」不丢失。多数 Agent 框架尚不具备。
  • 🧠 Skills（技能）作为一等概念。借鉴 Claude Code 的 SKILL.md 模式，将「可复用领域专长/工作流」打包成模块，Agent 按需加载——比纯 prompt 注入更工程化。
  • 🌐 Channels 原生集成 20+ 系统。Slack/Teams/Discord/GitHub/Zendesk/Shopify/Stripe……Agent 直接接入「业务发生地」，省去大量胶水代码。
  • 🚀 部署无关。同一 Agent 定义可跑在 Node、Cloudflare Workers、GitHub Actions、GitLab CI、Render——契合「Agent 即基础设施」趋势。
  • 📦 由 Astro 团队背书。withastro 拥有百万级开发者基础与优秀的 DX 口碑，工程规范（Biome + Turborepo + Knip）与文档质量有保障。

4应用场景

🤖 DevOps / 代码型 Agent

自动 分流 bug 报告（如 README 示例）：复现 → 诊断根因 → 判断是否预期 → 尝试修复，全程在沙箱内安全执行。

💬 客服与对话自动化

接入 Slack/Discord/Zendesk/Intercom，构建能查询数据库（Postgres/Mongo/Redis）、调用 Stripe/Shopify 工具的自主客服 Agent。

🔁 持久化工作流

需要多步骤、可能失败重试的业务流（审批、数据处理、报告生成），用 Durable Execution 保证可靠完成。

🏗️ 企业内部「Agent 平台」

作为企业自建 Agent 基础设施底座，统一会话、权限、可观测性（OTel/Sentry），而非每团队各写一套。
