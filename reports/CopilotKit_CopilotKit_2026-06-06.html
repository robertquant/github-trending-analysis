二、技术架构

2.1 AG-UI 协议

AG-UI 是 CopilotKit 的核心创新，它是一个开放、轻量级、基于事件的双向通信协议：

  • 传输层：通过标准 HTTP 流式传输 JSON 事件序列，可选二进制通道
  • 双向通信：支持 Agent → UI（推送状态、渲染指令）和 UI → Agent（用户操作反馈）两个方向
  • 事件驱动：所有交互建模为单一有序事件流，简化了状态管理
  • 框架无关：独立协议设计，不绑定特定的前端或后端框架

该协议已被 Oracle、Pydantic 等公司采纳和支持，正在成为 Agent-UI 交互的行业标准。

三、核心创新点

1. AG-UI 协议 — 行业首创

AG-UI 是第一个专门针对 Agent-UI 交互设计的开放协议。它将 Agent 与用户的交互从"黑箱"变成了可观测、可控制的事件流，使 Agent 的行为可以实时呈现在 UI 上。

2. Generative UI — 动态 UI 生成

不同于传统的文本/Markdown 输出，CopilotKit 允许 AI Agent 动态生成并渲染 React 组件。例如，Agent 可以直接在界面中渲染图表、表单、卡片等交互式组件。

3. Human-in-the-Loop — 人机协作

内置人工确认（Human Confirmation）流程，Agent 在执行关键操作前可以请求用户确认，实现安全可控的 Agent 自动化。

4. 实时上下文共享

Agent 可以实时读取和感知前端 UI 的状态（如当前页面内容、用户输入、组件状态），从而做出更精准的响应和操作。

5. Shared UI State

Agent 和前端 UI 共享同一份状态，Agent 的操作直接反映在 UI 上，无需手动同步。
