📋 项目概述

Production Agentic RAG Course 是由 Jam with AI 团队（Shirin Khosravi Jam 和 Shantanu Ladhwe，两位拥有 17 年以上 AI/ML 经验的工程师）创建的开源教学项目。该项目以构建一个 arXiv 论文智能助手为主线，通过 7 周渐进式教学，手把手带你从基础设施搭建到最终实现具备自主决策能力的 Agentic RAG 系统。

核心理念：先夯实搜索基础，再叠加 AI 能力 与大多数直接跳到向量搜索的教程不同，本项目遵循「专业路径」：先掌握 BM25 关键词搜索基础，再用向量搜索进行混合检索增强。这正是生产级 RAG 系统的构建方式，而非忽略搜索基础的「AI-first」方案。

项目最终产物是一个完整的 AI 研究助手，能自动获取学术论文、理解内容、并通过 Telegram 机器人回答研究问题，支持多步推理、文档评估和自适应检索。

Python 3.12+ FastAPI OpenSearch 2.19 LangGraph Docker PostgreSQL 16 Apache Airflow 3.0 Ollama Redis Langfuse Jina AI Gradio

🏗️ 技术架构

项目采用模块化、分层架构，每周在前一周的基础上渐进式构建，形成完整的生产级技术栈：

Week 1 — 基础设施层
Docker Compose + FastAPI + PostgreSQL + OpenSearch + Airflow
搭建完整的微服务基础设施，包含健康检查、自动文档和服务编排
Week 2 — 数据管道层
arXiv API + Docling PDF 解析 + Airflow DAG
自动化学术论文获取、解析与存储，支持速率限制和重试机制
Week 3 — 搜索基础层
BM25 关键词搜索 + OpenSearch Query DSL
构建专业搜索基础设施，掌握 BM25 算法原理与过滤/排序查询
Week 4 — 语义增强层
智能分块 + Jina Embeddings + RRF 混合搜索
基于章节的智能文档分段，融合关键词与语义检索的混合搜索
Week 5 — RAG 管道层
Ollama 本地 LLM + SSE 流式响应 + Gradio UI
完整 RAG 流水线，Prompt 优化减少 80%，6x 速度提升，流式输出
Week 6 — 生产运维层
Langfuse 追踪 + Redis 缓存
端到端可观测性、性能监控、智能缓存（150-400x 加速）
Week 7 — 智能代理层
LangGraph Agent + 文档评分 + 查询重写 + Telegram Bot
自主决策的 Agentic RAG：护栏机制、自适应检索、推理透明度

💡 核心创新点

1. 「搜索先行」的教学方法论 区别于市面上「上来就向量搜索」的教程，本项目坚持先建立 BM25 搜索基础再叠加 AI 层。这种方法更贴近真实企业的 RAG 构建实践，学习效果更扎实。
2. 完整的生产级技术栈 从数据摄取（Airflow）到搜索（OpenSearch）到 LLM 推理（Ollama）再到监控（Langfuse）和缓存（Redis），覆盖了 RAG 系统在生产环境中需要的每一个环节，而非简单的 demo 原型。
3. 渐进式架构演进 7 周内容设计为层层递进：基础设施 → 数据管道 → 关键词搜索 → 语义搜索 → RAG → 监控 → Agent。学习者可以清晰地理解每个组件的定位和价值，避免「一上来就被复杂性淹没」。
4. Agentic RAG 自主决策架构 Week 7 实现了完整的 Agent 能力：查询验证护栏、文档相关性评分、查询自动重写、自适应多轮检索、推理步骤追踪。这不是简单的 retrieve-then-generate，而是具备反思和调整能力的智能系统。
5. 本地化 + 零成本运行 通过 Ollama 运行本地 LLM，所有服务在 Docker 中运行，学习成本几乎为零。仅需可选的 Jina API Key（免费额度足够）和 Telegram Token，体现了对学习者的友好设计。

📝 总结

jamwithai/production-agentic-rag-course 是目前 GitHub 上最全面、最贴近生产实践的 Agentic RAG 开源课程。它不是又一个快速入门 demo，而是一套精心设计的 7 周学习路径，从 Docker 基础设施到 LangGraph 智能代理，从 BM25 搜索原理到 Redis 缓存优化，每一个环节都经过深思熟虑。

特别值得推荐的是其「搜索先行」的教学理念——这恰恰是大多数 AI 教程忽视的、但在真实生产环境中至关重要的基础能力。无论你是想系统学习 RAG 的 AI 工程师，还是需要快速搭建生产 RAG 系统的技术团队，这个项目都值得一学。
