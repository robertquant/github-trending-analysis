📋 项目概述

ESPectre 是由 Francesco Pace 开发的一款开源运动检测系统，它通过分析 Wi-Fi 信号中的信道状态信息（Channel State Information, CSI）来检测人体运动。该项目运行在廉价的 ESP32 微控制器上（成本仅约 €10），无需摄像头、麦克风或任何专用传感器硬件，即可实现对人体存在的感知。

当人在房间内移动时，会干扰 Wi-Fi 无线电波的传播路径，ESPectre 通过捕捉这些微小的信号变化来推断运动状态。它原生支持通过 ESPHome 集成到 Home Assistant 智能家居平台中，可替代传统 PIR 红外传感器或毫米波雷达。

🔑 一句话总结

用一块 €10 的 ESP32 开发板，让普通的 Wi-Fi 信号变成全屋运动传感器 — 无摄像头、无麦克风、纯信号处理。

🏗️ 技术架构

核心原理：Wi-Fi CSI 感知

Wi-Fi CSI（信道状态信息）描述了无线信号在发射端和接收端之间传播时经历的物理信道特性，包括多径衰落、信号衰减和相位偏移等。当人体在 Wi-Fi 信号覆盖区域内移动时，会改变信号的反射和散射路径，导致 CSI 数据发生可检测的扰动。

ESPectre 利用 ESP32 的 Wi-Fi 射频子系统提取 CSI 数据，然后通过专用算法（NBVI 算法）对信号进行实时分析，过滤噪声和环境漂移，最终输出运动/静止状态判定。

关键模块

  • CSI 数据采集模块：利用 ESP32 的 Wi-Fi 射频子系统以高频率（可达 180 包/秒）提取 CSI 数据，包括子载波幅度和相位信息
  • NBVI 算法引擎：核心信号处理算法，解决信号漂移和环境变化问题，无需手动标定即可适应不同环境
  • ESPHome 集成组件：原生 ESPHome 外部组件，支持 YAML 声明式配置，提供运动/静止二元传感器实体
  • Micro-ESPectre：独立的 R&D 分支，面向快速原型开发、算法实验和学术研究，支持更灵活的参数调整
  • 低功耗模式：支持 ESP32 的 Light Sleep 模式，适合电池供电场景

💡 核心创新点

1. 🚀 零额外硬件的运动检测

传统方案需要 PIR 传感器（无法检测静止目标）或毫米波雷达（成本高、配置复杂）。ESPectre 仅需一块标准 ESP32 开发板，利用已有的 Wi-Fi 射频前端即可完成运动检测，将 BOM 成本降至接近零。

2. 🧠 NBVI 自适应算法 — 无需标定

大多数 Wi-Fi CSI 感知系统需要在部署时进行繁琐的标定流程。ESPectre 引入了 NBVI（Normalized Bessel Variance Index）算法，能够自动适应环境变化和信号漂移，真正实现了"即插即用"的部署体验。

3. 🔒 隐私优先设计

不使用摄像头或麦克风，完全基于 RF 信号分析。无法获取图像或声音信息，从根本上杜绝了隐私泄露风险。特别适合浴室、卧室等私密空间的 occupancy sensing。

4. 🏠 Home Assistant 深度集成

通过 ESPHome 原生集成，用户只需在 YAML 配置文件中添加几行代码即可部署。支持 OTA 固件更新、自动发现、以及 Home Assistant 自动化联动，对智能家居用户极为友好。

5. 🧱 Micro-ESPectre 研究平台

提供了独立的研发分支（Micro-ESPectre），面向学术研究者和极客用户，支持快速算法实验和参数调优，降低了 Wi-Fi 感知领域的研究门槛。

📊 竞争力分析

ESPectre 的核心竞争力在于零额外硬件成本 + 隐私优先 + 开源可定制的三重组合。虽然 mmWave 雷达在定位精度和微动检测方面更优，PIR 在简单场景中更可靠，但 ESPectre 在"穿墙检测 + 无需标定 + 低成本"这个交叉领域几乎没有直接竞争者。对于 Home Assistant 用户来说，它是一个极具吸引力的补充方案。
