💡 三、核心创新点

1. 本地优先的隐私架构

OpenMed 最大的创新在于将医疗 NLP 推理完全放在本地。在医疗行业，患者数据隐私是头等大事（HIPAA、GDPR 等法规要求）。传统云端 API 方案意味着患者数据必须发送到第三方服务器，而 OpenMed 彻底消除了这一风险。

2. 跨平台统一模型名称

同一模型名称可在不同平台自动适配：在 Apple Silicon 上使用 MLX 加速，在非 Apple 硬件上自动回退到 PyTorch 检查点。开发者只需维护一套代码。

3. 智能实体合并（Smart Entity Merging）

解决了 Transformer 分词器将连续 PII 片段（如日期 "01/15/1970"）碎片化的问题，通过后处理智能合并，保持实体完整性。

4. 多语言去标识化体系

支持 12 种语言的 PII 检测与去标识化，覆盖全球主要语言，并针对各国特有的身份标识（巴西 CPF、荷兰 BSN、印度 Aadhaar、意大利 Codice Fiscale 等）提供本地化支持。

5. 多种脱敏策略

  • mask：用标签替换（如 [NAME], [DATE]）
  • replace：基于 Faker 的格式保持替换，地区感知
  • hash：加密哈希
  • shift_dates：日期偏移（可配置偏移天数）

6. 从研究到生产的完整路径

提供 Python API → REST API → Docker → iOS App 的完整部署链，并且有 AWS Marketplace 集成和 SageMaker Notebook 支持。
