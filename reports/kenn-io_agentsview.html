📋 一、项目概述

AgentsView 是一款本地优先（Local-first）的 AI 编码代理会话智能分析工具，由 Python 数据分析领域标志性人物、pandas 库创建者 Wes McKinney 主导开发。该项目旨在解决一个日益突出的痛点：随着 AI 编码代理（如 Claude Code、Codex、Gemini CLI 等）的广泛使用，开发者缺乏一个统一的工具来浏览、搜索、追踪成本和理解这些代理的会话历史。

核心理念：一个二进制文件，无需账户，所有数据本地存储。AgentsView 自动发现本机上 20+ 编码代理的会话数据，同步到本地 SQLite 数据库，并通过一个精美的 Web UI 呈现完整的分析视图。

2. 本地优先 + 隐私至上

无遥测、无分析追踪、无需账户。服务器默认绑定 127.0.0.1，唯一的外部请求是可选的启动时更新检查（可通过 --no-update-check 禁用）。所有数据完全存储在本地。

3. 100x 性能优势 — ccusage 的终极替代

由于会话数据已在 SQLite 中索引，agentsview usage 的查询速度比每次重新解析原始会话文件的工具（如 ccusage）快 100 倍以上。支持：

  • 按日/按模型的成本细分
  • 日期范围过滤（--since、--until）
  • 代理类型过滤（--agent）
  • JSON 输出用于脚本集成
  • 时区感知的日期分桶
  • 可集成到 shell prompt / 状态栏

4. 智能 Prompt Cache 感知成本计算

通过 LiteLLM 定价数据，AgentsView 能够区分缓存创建 token 和缓存读取 token，提供比简单 input/output 统计更精确的成本估算。这对于 Claude Code 等大量使用 prompt caching 的代理尤为重要。

5. 会话统计分析（Session Stats）

agentsview stats 提供丰富的窗口化会话分析：

  • 会话类型分类（automation / quick / standard / deep / marathon）
  • 会话时长分布、用户消息数、峰值上下文长度、每轮工具使用数
  • 缓存经济学分析
  • 工具/模型/代理混合比例
  • 时间维度的小时级分解
  • 可选的 Git 成果指标（commits/LOC/文件变更/PR 数）

6. 团队协作支持（PostgreSQL 后端）

通过 agentsview pg push 和 agentsview pg serve，可以将本地数据推送到共享的 PostgreSQL 实例，为团队提供统一的代理使用分析仪表盘。

✅ 优势

  • 作者背景卓越 — Wes McKinney（pandas 创始人）在开发者工具和数据领域有深厚积累，项目质量和长期维护有保障
  • 解决真实痛点 — AI 编码代理的 token 成本追踪和会话回溯是每个重度使用者的刚需
  • 覆盖面广 — 20+ 种代理的统一支持，在同类工具中无出其右
  • 隐私设计优秀 — 完全本地运行，无任何外部数据泄露风险
  • 性能卓越 — SQLite 索引使得查询速度碾压同类工具
  • 安装体验好 — 一行命令安装，支持 macOS/Windows/Linux + Docker + Homebrew
  • 灵活的部署模式 — CLI/Web/桌面/PostgreSQL 团队模式，适配不同场景

⚠️ 局限性

  • 依赖 CGO — Go 编译需要 CGO_ENABLED=1 和 FTS5 标签，在某些环境可能有编译障碍
  • 仅支持本地代理 — 无法追踪基于 Web 的 AI 编码工具（如 ChatGPT、Claude.ai 网页版）的使用
  • 成本估算依赖外部定价 — LiteLLM 定价数据的准确性和时效性可能不完全可靠
  • 功能仍快速迭代 — 项目处于活跃开发期，API 和功能可能变动
