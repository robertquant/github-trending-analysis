📖 项目概述

Heretic 是由 Philipp Emanuel Weidmann 开发的开源工具，用于全自动移除基于 Transformer 架构的语言模型中的"安全对齐"（Safety Alignment）机制——即模型的审查/拒绝回答行为。与传统需要昂贵后训练（post-training）或微调的方法不同，Heretic 通过数学手段直接修改模型权重，实现无需 GPU 集群即可完成的审查移除。

该项目在 GitHub 上迅速走红，被评为 Trendshift 当日 #1 仓库。社区已基于 Heretic 创建了超过 3000 个衍生模型，并在 Hugging Face 上公开发布。

🔧 技术架构

1. 方向性消融（Directional Ablation / Abliteration）

Heretic 的核心技术基于 Arditi et al. (2024) 提出的 abliteration 方法。其原理是：

  • 使用一组"有害"（harmful）和"无害"（harmless）提示词，分别提取模型在第一 token 输出时各 Transformer 层的残差向量
  • 计算两类残差向量的均值差（difference of means），得到"拒绝方向"（refusal direction）
  • 对模型中每个 Transformer 组件（attention out-projection 和 MLP down-projection）的权重矩阵，沿拒绝方向进行正交化，抑制该方向的传播

2. Optuna TPE 参数优化器

Heretic 的关键创新在于将 abliteration 参数化，并使用 Optuna 的 TPE（Tree-structured Parzen Estimator）算法自动搜索最优参数组合。优化目标是联合最小化：

  • 模型对"有害"提示的拒绝次数
  • 修改后模型与原始模型在"无害"提示上的KL 散度（衡量模型能力保留程度）

3. 可优化参数详解

参数作用
direction_index选择使用哪一层的拒绝方向，支持浮点数插值
max_weight / min_weight控制消融权重核的形状和幅度
max_weight_position最大权重在层中的位置
min_weight_distance最小权重与最大权重的距离

4. 三大技术创新

灵活的消融权重核：非恒定权重形状 + 自动优化，相比手动调参获得更好的合规性/质量权衡。

浮点拒绝方向索引：支持相邻层拒绝方向的线性插值，解锁了超出原始方向向量的搜索空间。

分组件参数：Attention 和 MLP 组件使用独立消融参数，因为 MLP 干预通常对模型能力损害更大。

5. 高级消融技术

技术说明
正交消融标准拒绝方向移除方法
幅度保持正交消融（Derestriction）保留更多模型能力的同时移除拒绝行为
Pre-bias / Router-bias影响 MoE 模型中的专家路由，可与残差正交化叠加

🚀 快速上手

pip install -U heretic-llm
heretic Qwen/Qwen3-4B-Instruct-2507

仅需两行命令即可开始。Heretic 会自动基准测试系统性能、确定最优批大小、运行 Optuna 优化搜索最佳消融参数。

量化模式（低显存）

heretic --model Qwen/Qwen3-4B-Instruct-2507 --quantization bnb_4bit

通过 bnb_4bit 量化，可大幅降低 VRAM 需求（v1.2 版本降低约 70%）。
