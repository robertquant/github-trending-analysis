📋 项目概述

Supermemory 是一个开源的 AI 记忆引擎和上下文工程平台，旨在解决大语言模型（LLM）在对话间"失忆"的核心痛点。项目由 supermemoryai 研究实验室开发，目前已在 GitHub 上获得 23,600+ Stars 和 2,100+ Forks，是当前 AI 记忆层领域最受关注的项目之一。

项目的核心理念可以用一句话概括："你的 AI 忘记了对话间的一切。Supermemory 修复了这个问题。"

Supermemory 在三大 AI 记忆基准测试中均排名第一：LongMemEval（81.6%）、LoCoMo 和 ConvoMem，证明了其在记忆提取、知识更新和个性化方面的技术领先性。

核心组件详解

  • 记忆引擎 (Memory Engine)：从对话中提取结构化事实，跟踪信息更新，自动解决矛盾（如 "我刚搬到旧金山" 会覆盖 "我住在纽约"），自动遗忘过期的临时信息。
  • 用户画像系统 (User Profiles)：分为静态画像（长期稳定事实，如职业、偏好）和动态画像（近期活动，如正在开发的项目）。单次调用约 50ms 即可获取完整画像。
  • 混合搜索 (Hybrid Search)：将 RAG 文档检索和个性化记忆检索合二为一，一次查询同时返回知识库内容和用户相关记忆。
  • 连接器系统 (Connectors)：支持 Google Drive、Gmail、Notion、OneDrive、GitHub、Web Crawler 等外部数据源的实时 webhook 同步。
  • 多模态提取器：支持 PDF 解析、图片 OCR、视频转录、代码 AST 感知分块等多种数据格式的自动化处理。

核心 API 示例

import Supermemory from "supermemory";
const client = new Supermemory();

// 存储记忆
await client.add({
  content: "用户喜欢 TypeScript，偏好函数式编程",
  containerTag: "user_123",
});

// 获取用户画像 + 搜索相关记忆
const { profile, searchResults } = await client.profile({
  containerTag: "user_123",
  q: "用户喜欢什么编程风格？",
});

// profile.static  → ["喜欢 TypeScript", "偏好函数式编程"]
// profile.dynamic → ["正在做 API 集成"]

💡 核心创新点

🔄 记忆 vs RAG 的本质区别

Supermemory 明确区分了"记忆"和"RAG"：RAG 是无状态的文档检索，而记忆是关于用户的、有时间感知的、会自动更新的事实跟踪系统。

⏰ 自动遗忘机制

系统能识别临时性信息（如 "我明天有考试"）并自动过期处理，矛盾信息自动解决，噪音不会成为永久记忆。

⚡ 50ms 用户画像

一次 API 调用即可获取完整用户画像（静态 + 动态），延迟仅约 50ms，可直接注入系统提示词。

🔗 统一上下文栈

记忆、RAG、用户画像、连接器、文件处理 — 全部整合在一个系统中，无需分别配置向量数据库、嵌入管线或分块策略。

🔗 MCP 原生支持

一行命令 npx install-mcp 即可集成到 Claude Desktop、Cursor、VS Code 等主流 AI 开发工具中。

📊 开源 MemoryBench

提供标准化的基准测试框架，让记忆解决方案的对比变得透明和可复现。
