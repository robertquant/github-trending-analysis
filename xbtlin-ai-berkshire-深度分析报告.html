📋 一、项目概述

AI Berkshire（AI 时代的伯克希尔）是一套基于 Anthropic Claude Code 的投资研究 Skill 合集。它把 巴菲特（Warren Buffett）、芒格（Charlie Munger）、段永平、李录 四位价值投资大师的方法论系统化、结构化，通过多 AI Agent 协作实现专业级投资研究。

普通人问 AI 得到的是"看起来对的分析"，用 AI Berkshire 得到的是"可以拿来做决策的投研报告"。

项目作者 xbtlin 用这套框架进行真实实盘交易，并公开了收益截图：2024 全年收益 +69.29%，2025 年至今收益 +66.38%，连续两年大幅跑赢全球主要指数。这种"以真金白银背书"的透明度，在 AI 工具项目中极为罕见。

2. Agent 层 —— 多智能体对抗

以 /investment-team 为例，Team Lead（用户）统筹下，4 个独立 Agent 同时研究一家公司，各自搜索网络、交叉验证数据、独立给出结论，最后综合。这等于 4 倍搜索量、4 倍信息源、4 个独立视角，从根本上突破单 prompt 的上下文局限。

3. 工具层 —— 金融严谨性（tools/financial_rigor.py）

这是项目工程严谨性的核心体现。LLM 心算不可靠，PE 算错小数点就可能导致错误决策。该工具集解决此痛点：

功能命令解决的问题
市值验算verify-market-cap股价 × 总股本 精确计算，检测单位错误
估值验算verify-valuationPE/PB/ROE/FCF Yield 精确十进制
多源交叉验证cross-validateN 来源同数据比对，超容差告警
三情景估值three-scenario乐观/中性/悲观目标价
Benford 定律检测benford财务数据首位数字分布异常识别
精确计算器calc替代 LLM 心算的任意财务表达式
设计原则：所有计算使用 Python decimal.Decimal（精确十进制），非 float。"0.1 + 0.2 = 0.3" 在金融场景中不允许失败。

💡 三、核心创新点

① 强制给结论，不打太极

直接问 AI"拼多多值不值得买"，得到的是"一方面…另一方面…投资有风险"的两面讨好分析，没法拿来做决策。AI Berkshire 强制输出 通过/不通过/灰色地带，带具体价格区间和分层（激进/稳健/保守）建议。"镜子测试"：5 句话说不完整 = 不买，没有例外。

② 四大师视角对抗，制造真实矛盾

以拼多多为例，四视角会产生真实张力：

大师视角判断评分
段永平商业模式好生意，C2M 难复制3.7/5
巴菲特财务估值扣现金 PE 仅 6.3x，印钞机4.4/5
芒格逆向思考护城河比想象浅，抖音 3 年做到 4 万亿 GMV3.5/5
李录长期确定性管理层文化隐患，10 年后不确定2.0/5

巴菲特说"真便宜"，李录说"不确定就不买"——这种冲突才是投资决策的真实状态，单一 prompt 无法制造。

③ 结构化反偏见机制（5 层"防骗"）

AI 最危险的不是给错答案，而是给一个看起来很对但经不起推敲的答案。项目内置五重防护：

  • 信息丰富度评级（A/B/C）：防止"资料多=确定性高"幻觉
  • 芒格式逆向检验：强制思考失败场景（"什么情况下拼多多会死？"）
  • 快速否决清单：8 条红线一票否决（管理层诚信污点 → 直接否决）
  • 反共识检查："聪明人为什么在做空？"发现被忽视风险
  • 留白原则：数据不足标注"灰色地带"，不用推测伪装确定性

④ 金融数据精确性 + 可复现流程

通过 decimal.Decimal 精确算术 + 多源交叉验证，杜绝 LLM 心算误差。同时保证同样输入 → 结构一致、深度一致输出，使 7 家公司横向对比、同公司半年后重测成为可能。

⑤ 多 Agent 并行 = 研究深度倍增

4 个"分析师"各自做完整研究而非拆分单 prompt，等于 4 倍信息量与独立判断，再由 Team Lead 综合。

⚖️ 六、优势与局限

✅ 核心优势

  • 实盘透明背书：2024 +69.29%、2025 至今 +66.38%，富途账户截图公开，可信度极高
  • 方法论结构化：四大师 + 5 层反偏见机制，直击 LLM 投资分析的核心痛点
  • 工程严谨：decimal.Decimal 精确算术、多源交叉验证、Benford 检测
  • 场景完整：16 个 Skill 覆盖从筛选、研究、财报、持仓到异动归因全链路
  • 文档极佳：README 含大量真实输出示例、表格对比、可复现命令

⚠️ 潜在局限

  • Token 消耗高：4 Agent 并行研究成本不菲（社区反映用 qwen 等替代降本）
  • 依赖 Claude Code：强绑定 Anthropic 生态，迁移成本高
  • 数据接入有限：路线图显示实时 Wind/Bloomberg/Yahoo MCP 接入仍在规划中
  • 历史业绩 ≠ 未来：2024-2025 多为港股科技牛市，超额收益部分源于 Beta
  • 不构成投资建议：研究框架而非自动交易，仍需用户自主决策
