📋 项目概述

Claude Code 是由 Anthropic 官方打造的 终端原生 AI 编程代理（Agentic Coding Tool）。 它直接运行在开发者的终端环境中，能够深入理解整个代码库，自主执行编码任务——包括文件编辑、命令运行、Git 操作、代码审查等。 作为 Anthropic 旗下增长最快的开源项目，Claude Code 已获得超过 125,000 个 GitHub Stars， 在 2026 年 Q1 的开发者调查中，46% 的专业开发者将其列为主要 AI 编程工具。

2026 年 1 月，Anthropic 还推出了 Cowork（"Claude Code for general computing"），仅用 10 天由 4 名工程师构建完成， 进一步扩展了 Claude Code 从编码到通用计算的代理愿景。

🏗 技术架构

Claude Code 采用分层架构设计，从底层模型调用到顶层用户交互形成完整的代理执行管线：

  • 核心语言：TypeScript，通过 npm 包 @anthropic-ai/claude-code 分发
  • 模型层：基于 Anthropic Claude 系列模型（Opus/Sonnet/Haiku），支持模型切换与 prompt caching
  • 工具系统：内置 Read/Edit/Write/Glob/Grep/Bash 等核心工具，支持文件操作、代码搜索和命令执行
  • 权限沙箱：多层权限控制体系，包括自动允许、用户确认、工具级别权限设置
  • MCP 集成层：通过 Model Context Protocol 连接数百种外部工具和数据源，实现可扩展的工具生态
  • 插件系统：支持 Skills（技能）、Agents（子代理）、Hooks（钩子）和 MCP Servers 四种插件类型
  • 记忆系统：基于文件的持久化记忆（CLAUDE.md + memory/），支持跨会话上下文保持
  • Git 原生集成：直接操作 Git 工作流——提交、分支管理、PR 创建、代码审查
  • 多界面支持：CLI、桌面应用（Mac/Windows）、Web 应用（claude.ai/code）、IDE 插件（VS Code、JetBrains）

架构亮点：代理循环（Agent Loop）

Claude Code 的核心是一个自主代理循环——接收用户指令后，自动分解任务、调用工具、观察结果、迭代优化， 直到任务完成。与传统的"建议式"编程助手不同，它能独立执行多步骤复杂任务，包括跨文件重构、调试、测试编写等。

💡 核心创新点

  • 终端原生的代理式开发： 不依赖任何特定 IDE，直接在终端中运行。开发者无需离开命令行环境即可完成从编码到部署的全流程。 这是与 Cursor（绑定编辑器）和 Copilot（绑定 IDE 插件）的显著区别。
  • Plan Mode（规划模式）： 面对复杂任务时，Claude Code 可以先进入规划模式，分析代码库、设计实现方案、与用户确认后再执行， 避免了大量无效修改。这体现了"先思考、后行动"的工程理念。
  • Hooks 自动化系统： 支持在工具调用前后执行自定义 Shell 命令，实现项目规则强制执行、自动化工作流集成和安全防护。 例如可以在每次文件编辑后自动运行 lint，或在提交前检查测试通过状态。
  • MCP 协议深度集成： Model Context Protocol 是 Anthropic 推动的开放标准，Claude Code 作为一等公民支持 MCP， 可连接数据库、API、内部工具等外部系统，极大扩展了能力边界。
  • 四类插件扩展体系： Skills（自定义斜杠命令）、Agents（专用子代理）、Hooks（生命周期钩子）、MCP Servers（外部工具连接）， 形成了完整的扩展生态。社区已贡献大量高质量插件。
  • 上下文智能管理： 自动管理上下文窗口压缩、prompt caching（5 分钟 TTL 缓存策略）、会话恢复， 在处理大型代码库时仍能保持高效。子代理机制将繁重任务隔离，保护主上下文窗口。
