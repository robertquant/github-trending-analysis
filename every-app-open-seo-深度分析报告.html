1项目概述

OpenSEO 是一个 100% 开源的全流程 SEO 平台，明确定位为 Semrush 与 Ahrefs 的开源替代品。它不是又一个小工具的拼凑，而是试图用「按量付费 + 自托管 + AI 原生」三张牌，去正面挑战动辄每月上百美元订阅的商业 SEO 巨头。

"If tools like Semrush or Ahrefs are too expensive or bloated, OpenSEO is a pay-as-you-go alternative that you actually control." —— 项目 README

核心理念

  • 为人民而生（for the people）：打破 SEO 数据被少数昂贵 SaaS 垄断的局面，让独立开发者、小团队、内容创作者都能负担得起专业级 SEO 数据。
  • 按量付费，没有订阅：软件本身 $0，用户自带 DataForSEO API Key，只为实际查询的数据付费 —— 一次关键词研究约 $0.035，一次站点审计约 $0.01。
  • 给你和你的 AI Agent 用：不止是给人用的图形界面，更是首个把 MCP（Model Context Protocol）与 Agent Skills作为一等公民的 SEO 工具。
  • 真正可控：支持 Docker 与 Cloudflare 完整自托管，可 fork 后用自己的方式「vibe code」定制专属 SEO 工具。

3核心创新点

OpenSEO 的真正护城河不在「又一个 SEO 界面」，而在于它对「AI 时代 SEO 工具应该长什么样」的前瞻性回答。

① 原生 MCP Server —— SEO 数据成为 Agent 的「工具箱」
这是 OpenSEO 区别于所有传统 SEO 工具的最大亮点。通过暴露标准化的 MCP 接口，AI Agent 可在编辑器/对话框里直接：跑关键词研究、检查 SERP、对比域名、审查外链。SEO 从「打开网页手动操作」变成「一句话驱动 Agent 完成」。
② Agent Skills —— 可复用的 SEO 工作流包
预置 7 个开箱即用的 Skill：seo-project-setup、seo-coach、keyword-research、keyword-clustering、competitive-landscape、competitor-analysis、link-prospecting。用 npx skills add every-app/open-seo 一键安装到 Claude Code / Codex。
③ AI 品牌可见性 & AI 搜索提示词探索
面向 LLM 时代的前瞻功能：追踪你的品牌在 ChatGPT / Google AI Overview 等 AI 回答中的出现情况、竞品提及、被引用来源；并探索用户可能向 AI 工具提问的 prompt。传统 SEO 工具几乎都还停留在「Google 蓝色链接」时代。
④ 透明到极致的「成本参考表」
README 里直接给出每类操作的 DataForSEO 计费公式与示例（如 100 次关键词研究 ≈ $3.5）。这种把成本完全摊在阳光下的诚实态度，在 SaaS 世界里极其罕见，大幅降低了用户的决策焦虑。
