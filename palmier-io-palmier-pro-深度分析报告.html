📌一、项目概述

Palmier Pro 的核心理念可以用一句话概括：把"生成式 AI"从独立的网页工具里解放出来，搬进真正的非线性编辑（NLE）时间线。

过去用 AI 生成视频，流程是割裂的：你在某个生成网站出片 → 下载 → 导入 Premiere/CapCut → 再剪辑。Palmier Pro 把这一切打通——生成、剪辑、导出全部发生在同一条时间线上，而且这条时间线还对 AI 智能体开放：通过 MCP（Model Context Protocol），Claude Code、Codex、Cursor 可以像操作代码仓库一样操作你的视频工程。

"The video editor built for AI. Generate, edit, and export production-ready AI videos without leaving your timeline."

把"为 AI 而生"的视频编辑能力产品化并开源，让任何人都能在自己 Mac 上拥有一个 agent 可驱动的时间线编辑器。

🏗️二、技术架构

Palmier Pro 的架构可以拆为编辑内核 + 生成式 AI 层 + 智能体/MCP 层三大部分。

① Swift 原生编辑内核
用 Swift 从零构建（非 Electron / 非 Web 套壳），充分利用 Apple Silicon 性能；目标对标 Premiere Pro，提供专业级时间线编辑能力。
② 内置生成式 AI
直接在时间线内调用 SOTA 模型生成视频/图像：Seedance、Kling、Nano Banana Pro。生成素材落在轨道上，与实拍/传统素材混合编辑。
③ MCP Server（HTTP）
应用打开时在本地暴露 MCP 服务 http://127.0.0.1:19789/mcp，让外部 agent 以结构化方式读写时间线工程。
④ In-app Agent
除外部 MCP 外，内置应用内智能体，可与用户在同一工程上协同工作（边聊边剪）。

Agent 接入方式（一行命令）

对各类主流编码 agent / 客户端都做了开箱即用的接入：

  • Claude Code：claude mcp add --transport http palmier-pro http://127.0.0.1:19789/mcp
  • Codex：codex mcp add palmier-pro --url http://127.0.0.1:19789/mcp
  • Cursor：应用内 Help → MCP Instructions → Install in Cursor，或手写 ~/.cursor/mcp.json
  • Claude Desktop：内置 mcpb 包，一键安装 Desktop Extension

这意味着 agent 能"看见并操作"视频工程：裁剪片段、重新排序、整理素材、生成新镜头、替换画面——而不仅仅是生成一段视频就结束。

开源与商业化边界

项目采用清晰的"开源核心 + 闭源增值"策略：

  • 开源 GPLv3 视频编辑器本体（不含生成式 AI）、MCP server、应用内 agent 聊天
  • 闭源 生成式 AI 处理（模型调用/后端推理）
  • 免费 编辑器本体（无需登录，可作为 CapCut/Premiere 用）；MCP server 免费
  • 付费 生成式 AI 功能需登录 + 订阅（按 credit 计费）

平台与系统要求

仅支持 macOS 26（Tahoe） 且为 Apple Silicon。这是有意为之：Swift 原生 + Apple 芯片的能效/媒体引擎，是它性能与体验的根基，但也直接把 Windows/Linux 用户挡在门外。

💡三、核心创新点

  • Agent 可直接操作时间线（最大差异化）：通过 MCP 把 NLE 时间线变成 agent 可编程的"数据结构"。Claude/Codex 不只是"帮你生成一段视频"，而是能像改代码一样改你的剪辑工程——这在视频编辑领域几乎没有同类。
  • 生成式 AI 内嵌时间线，而非外挂：生成、剪辑、导出在同一轨道闭环，告别"生成网站 → 下载 → 导入"的割裂流程。
  • Swift 原生 + Apple Silicon 优先：从零构建的原生 Mac 应用，性能/能效/系统集成度远超 Electron 方案。
  • 生成式素材与传统剪辑混合：不强制"纯生成"，实拍素材与 AI 生成素材可在同一时间线混编。
  • 开源核心 + 订阅增值的健康模式：编辑器与 MCP 完全开源免费，生成式 AI 闭源收费——既建立了开源社区信任，又保留商业化抓手。
  • 主流编码 agent 全家桶适配：Claude Code / Codex / Cursor / Claude Desktop 一键接入，踩在 MCP 生态爆发的时间窗口上。

🎬四、应用场景

📺 内容创作者 / 自媒体
用 agent 批量整理素材、生成 B-roll、自动裁剪口播，几分钟产出可发布短片。
📣 营销 / 广告团队
快速产出 AI 广告与发布视频（团队本就有"电影级 AI 营销视频"服务基因）。
🤖 AI Native 开发者
把视频剪辑变成 agent 工作流的一部分，集成进自动化 pipeline / 多模态 agent。
🎓 教学 / 演示视频
用自然语言驱动时间线生成教学/产品演示片段。
🎨 独立影视 / 实验创作
混合实拍与 AI 生成镜头做实验性短片、概念片。
🧩 MCP 生态实验场
作为"agent 操作富媒体创作工具"的范例，验证 MCP 在非代码领域的潜力。

差异化小结：Palmier Pro 不与成熟 NLE 比"功能全面性"或"专业调色"，而是开辟一个全新细分——"让 AI agent 直接驱动视频时间线"。它的真正对手不是 Premiere，而是"AI 视频生成工具 + 手动剪辑"的割裂现状。最大护城河：① MCP 直驱时间线的产品形态先发、② Swift 原生 Mac 体验、③ 开源核心带来的社区与信任。最大短板：平台单一（仅 macOS 26/Apple Silicon）、功能成熟度远不及老牌 NLE、强依赖订阅付费的生成式 AI。

⚖️六、优势与局限

✅ 优势

  • 独一无二的产品形态：Agent 经 MCP 直驱时间线，视频编辑领域暂无同类。
  • Swift 原生 + Apple Silicon：性能/能效/集成度优于 Electron 类方案。
  • 生成式 AI 内嵌：生成—剪辑—导出同一轨道闭环，告别割裂流程。
  • 开源核心（GPLv3）+ 健康商业化：编辑器/MCP 免费，社区信任 + 订阅抓手并存。
  • 踩准 MCP 生态爆发窗口：Claude Code/Codex/Cursor/Desktop 一键接入。
  • YC S24 背书 + 聚焦团队：创始人大厂背景，方向清晰。

⚠️ 局限

  • 平台极度受限：仅 macOS 26（Tahoe）+ Apple Silicon，排除 Win/Linux/Intel Mac 全部用户。
  • 成熟度尚早：对标 Premiere 为"北极星"，当前功能深度/插件生态远不及老牌 NLE。
  • 核心体验依赖订阅：生成式 AI（最大卖点）需登录 + 付费，免费版只是"普通编辑器 + MCP"。
  • 方向经历过转型：代码理解 → 营销视频 → 编辑器，需观察产品定力。
  • 闭源后端：生成式 AI 处理闭源，难以自托管/离线，对隐私敏感场景不友好。
  • macOS 26 门槛：系统版本要求新，潜在用户装机量受限。

🏆七、综合评分与推荐

综合评分：8.4 / 10 —— 一个定位锐利、形态创新、踩准 MCP 浪潮的早期产品。它抓住了"AI 视频创作割裂"的真实痛点，用"agent 直驱时间线 + 生成式 AI 内嵌 + Swift 原生"的组合打出清晰差异化。短板同样明确：平台单一、成熟度尚浅、核心卖点依赖订阅。

🎯 推荐人群

  • 🤖 AI Native 创作者 / 开发者：想把视频剪辑纳入 agent 工作流的人
  • 📣 营销 / 内容团队：需要快速量产 AI 广告、发布视频
  • 🍎 Mac + Apple Silicon 用户：追求原生体验的创作者
  • 🧪 MCP 生态尝鲜者：想验证"agent 操作富媒体工具"可能性的极客
  • 🎬 独立创作者：愿意用生成式素材混合实拍做实验性内容的人

🚫 暂不建议

  • Windows / Linux 用户、Intel Mac 用户
  • 需要顶级调色 / 复杂特效 / 广播级工作流的专业影视团队（现阶段选 DaVinci/Premiere 更稳）
  • 对生成式 AI 付费敏感、只想完全免费离线的用户
