💻 主语言

Unciv 是开发者 Yair Morgenstern（GitHub：yairm210）发起、由庞大社区共同打造的开源 4X 回合制文明策略游戏，目标是忠实复刻 Firaxis 的《席德·梅尔的文明 5》（Civilization V）。它的口号极其鲜明："fast, small, no ads, free forever"（快、小、无广告、永久免费）。玩家可以建立帝国、研究科技、扩张城市、外交斡旋、发动战争——在手机和电脑上获得原汁原味的 Civ V 体验，却不必掏一分钱。

区别于《文明 5》的 3D 写实画风，Unciv 选择了 2D 像素 / 简洁风：这既是出于移动端性能与包体体积的考量，也形成了独特的复古美学。但玩法内核严格对齐 Civ V——单位、奇观、科技树、政策、城邦、宗教等系统一应俱全，被 CivFanatics、r/civ、GamingOnLinux 等社区誉为"免费 Civ 体验的最佳选择"。

项目的活跃度堪称开源游戏圈的标杆：938 个 Release、Issue 编号已突破 #15,000，最新版本几乎每隔一两天就迭代一次，近期版本集中在大地图的内存与渲染性能优化。F-Droid、Flathub、Google Play、itch.io、AUR 等主流渠道全线分发，是极少数"既能上 Play 商店、又能进 FOSS 社区"的全平台游戏。

2) "一套代码，多端运行"是如何做到的？

LibGDX 的核心思想是后端抽象（Backend Abstraction）：把游戏逻辑全部放在平台无关的 core 模块，再由 android、desktop 等后端提供各自的入口与平台绑定（渲染、输入、文件 I/O）。Unciv 借此实现了从单一 Kotlin 代码库同时产出安卓 APK 与桌面可执行文件：

// LibGDX 多后端结构示意
core/      // 100% 共享：游戏逻辑、规则、渲染、UI（与平台无关）
├── android/  // 安卓后端：APK 入口、触屏适配、Android 文件系统
└── desktop/  // 桌面后端：Windows/macOS/Linux 入口、LWJGL 渲染
// 收益：玩法只写一遍，多端同步演进；甚至已被 Rosebud AI 团队移植到浏览器（仅改约 10 个核心文件）

正因为这套架构，Unciv 能做到安卓 / Windows / macOS / Linux 全平台同步发布同一版本，甚至第三方仅做少量适配就把它搬进了浏览器——证明了其代码组织的高度解耦。

3) 数据驱动的 Mod 体系（核心设计）

Unciv 把"Mod 友好（moddability-focused）"写进了项目自我定位，其底层是一套数据驱动的设计：游戏内容不是硬编码在逻辑里，而是以 JSON 文件描述。社区可以增、删、改几乎一切基础定义：

可 Mod 维度说明
Units / Nations / Buildings单位、国家（文明）、建筑、奇观的属性与效果
Resources / Terrains / Improvements资源、地形、地块改良（农场/矿/道路等）
Tech Tree / Policies科技树结构与前置关系、社会政策分支
Rulesets / Translations完整规则集（如自带 Civ V 基础包），以及社区维护的多语言翻译

🧩 设计哲学：因为内容即数据，玩家无需懂复杂工程，编辑 JSON + 扔进游戏目录就能自制文明、改科技树、加奇观。这使 Unciv 衍生出了庞大且自驱的 Mod 与翻译社区，是它生命力的重要来源。

💡 核心创新点

  1. 把商业 3A 大作《文明 5》做成"永久免费 + 开源 + 多端"：在 Firaxis 官方 Civ V 仍收费、且无官方移动版的空白地带，Unciv 用开源方式补齐了"手机上玩原汁原味 Civ V"的需求，被玩家社区奉为免费 Civ 的首选。
  2. 极致轻量与性能优先：以 2D 像素风换取极小体积、极低资源占用、流畅手感，老旧安卓机、低端笔记本都能跑；近期版本持续攻坚大地图内存与渲染瓶颈，工程上把"快与小"当成第一性目标。
  3. 数据驱动的强 Mod 体系：JSON 化的内容定义让造文明、改规则、加奇观门槛极低，催生了活跃的 Mod 与多语言翻译生态——社区既是用户也是共创者。
  4. 单一 Kotlin/LibGDX 代码库多端发布：一套 core 逻辑同步输出安卓与桌面，甚至被第三方仅改动约 10 个文件就移植进浏览器，体现高内聚低耦合的工程素养。
  5. 开源游戏里罕见的超高频迭代：938 个 Release、Issue 突破 #15,000、几乎一两日一更——在"开源游戏常因维护者流失而停摆"的普遍困境下，Unciv 展示了社区协作的可持续高产出。
  6. 联机 + 热座双模式多人：不仅单机，还通过 UncivServer 提供在线异步多人与同设备热座，把"和好友开一局文明"从桌面拓展到移动场景。
  7. FOSS 与应用商店双线分发：同时出现在 Google Play（面向大众）与 F-Droid / Flathub / AUR（面向开源社区），既保证触达，又守住自由软件的可审计性。
