项目概述

MemPalace 是由好莱坞女演员 Milla Jovovich（米拉·乔沃维奇）与开发者 Ben Sigman 联合创建的开源 AI 记忆系统。Jovovich 负责架构设计，Sigman 负责工程实现。

该项目于 2026年4月6日 在 GitHub 上发布后迅速走红，48小时内获得 22,000+ 颗星标。截至分析时，项目已获得超过 23,000 Stars 和近 3,000 Forks。

核心理念来自古希腊的「位置记忆法」(Method of Loci)，即著名的"记忆宫殿"技巧——通过将信息组织到空间结构中来增强记忆。MemPalace 将这一古老智慧映射到 AI 系统架构中，为大型语言模型提供持久化的跨会话记忆能力。

技术架构

分层记忆架构（Layered Memory Architecture）

MemPalace 采用受人类认知科学启发的三层记忆架构，每一层模拟人脑记忆的不同阶段：

🧠 工作记忆层 (Working Memory)

当前对话上下文的短期记忆，处理即时交互信息

↕

📖 情景记忆层 (Episodic Memory)

按时间线存储完整对话历史，保留事件的时间顺序与因果关系

↕

🏛️ 长期语义记忆 (Long-term Semantic Storage)

提取并存储结构化知识、用户偏好、决策记录等持久信息

核心设计哲学：「先存一切，再构建结构」

与传统 AI 记忆系统不同，MemPalace 不对对话内容进行摘要、压缩或改写。它采用逐字存储 (Verbatim Storage) 策略——完整保留原始对话数据，然后在原始数据之上构建结构化的索引和检索层。

Hacker News 社区讨论指出 MemPalace 的关键洞察："你不需要完整的对话记录，但你需要决策层"——记录什么被决定了、为什么决定、以及什么被拒绝了，由智能层进行综合。

可插拔后端 (Pluggable Backend)

MemPalace 的存储后端完全可插拔，用户可以根据需要选择不同的存储引擎。支持本地文件存储、向量数据库等多种后端选项，实现灵活部署。

同时支持 MCP (Model Context Protocol) 集成，可以与 Claude Code 等工具无缝对接。

核心创新点

  • 记忆宫殿映射：将古希腊「位置记忆法」首次系统性地应用于 LLM 记忆管理，通过空间隐喻组织信息结构，而非传统的向量相似度搜索
  • 逐字存储策略：放弃主流的"摘要压缩"方案，完整保留原始对话文本，通过语义索引在原始数据之上实现高保真检索
  • 零 API 调用：完全本地运行，无需任何外部 API 调用，既保护隐私又降低成本，适合离线和敏感场景
  • 最高基准测试成绩：在 LongMemEval 基准上达到 96.6% Recall@5，是目前免费 AI 记忆系统中的最高分
  • Aya Fork 高保真分支：社区衍生的 mempalace-Aya-fork 版本专注于高保真记忆检索，使用逐字文本存储 + 语义搜索，不做任何改写

应用场景

🤖 AI Agent 持久记忆

为自主 AI Agent 提供跨会话的持久记忆能力。Agent 可以记住之前的交互、决策和上下文，实现真正连续的个性化服务。

💬 对话式 AI 助手增强

让 ChatGPT、Claude 等对话 AI 拥有长期记忆，记住用户偏好、历史对话和个性化信息，大幅提升用户体验。

🔒 隐私敏感场景

零 API 调用 + 本地优先的特性，使得 MemPalace 特别适合医疗、金融、法律等对数据隐私要求极高的场景。

🔧 开发者工具集成

通过 MCP 协议与 Claude Code、Cursor 等开发工具集成，为编程助手提供项目上下文的长期记忆。

📊 知识管理系统

作为知识图谱的底层存储引擎，构建个人或组织的持久化知识库，支持语义检索和推理。
