一、项目概述

last30days-skill 是一个 AI Agent 技能（Skill），定位为「AI 驱动的社交搜索引擎」——它不是传统的关键词搜索，而是聚合 Reddit、X（Twitter）、YouTube、TikTok、Instagram、Hacker News、Polymarket、GitHub、Bluesky、Digg、Threads、Pinterest、Perplexity 等十余个平台最近 30 天的内容，按用户的真实互动（点赞、投票、真金白银的预测市场概率）进行评分，最终由 AI Agent 综合生成一份结构化的研究简报。

Google aggregates editors. /last30days searches people.

该项目由独立开发者 Matt Van Horn 创建，最初是为了追踪快速迭代的 AI 行业动态，后来演变为一个通用的多平台趋势研究工具。项目在 GitHub 上线后迅速走红，30 天内获得约 27,000+ Stars，登上 GitHub Trending 日榜第一。

三、核心创新点

核心突破：将十几个互不相通的社交平台通过 AI Agent 桥接在一起，用「人的真实互动」代替「编辑的排序」——这是 Google、ChatGPT、Gemini 等单一平台无法提供的搜索维度。

3.1 智能实体解析（v3 杀手级功能）

v3 不只是搜索关键词，而是在搜索前先理解话题：/last30days Peter Steinberger 会自动解析出 @steipete（X）、steipete（GitHub）、相关的 subreddit 和 YouTube 频道。这通过 Python 预研究引擎实现，确保搜索从一开始就瞄准正确的人和社区。

3.2 社交评分体系（Social Scoring）

不是 SEO 排序，而是真实的人类行为信号：Reddit upvotes、X likes、YouTube 播放量、TikTok 3.6M views、Polymarket 真金白银的赔率。每一个数据点背后都是真实的人类选择。

3.3 跨源聚类合并

同一故事出现在多个平台时（如一个新闻在 Reddit 讨论、X 转发、YouTube 评论），v3 会自动合并为一个故事簇，避免重复，同时展示多维度的人类反应。

3.4 Best Takes（最佳评论）

独有的幽默/机智评分器——从 Reddit 和 X 的海量评论中选出最有趣、最犀利、最易传播的「金句」，让研究简报不仅有用，还有趣。

3.5 可共享 HTML 简报

一键生成自包含的暗色主题 HTML 文件，可拖进 Slack、邮件、Notion。内联 CSS、无 JavaScript、可离线使用——专为分享而设计。

3.6 BYOK（Bring Your Own Keys）架构

没有中间商。用户携带自己的 API Key 和浏览器 Cookie，数据始终在本地。Reddit + HN + Polymarket + GitHub 零配置即可使用。

七、总结

last30days-skill 是 2026 年 AI Agent 生态中最具代表性的「技能型」工具之一。它不试图成为一个通用搜索引擎，而是精准地切入了一个被忽视的空白：用社交平台的真实人类互动来衡量信息价值。

其核心竞争力在于三点：

  • 多平台桥接：通过 BYOK 架构让 AI Agent 同时访问十几个围墙花园式社交平台
  • 社交评分：用 upvotes、likes、播放量、真金赔率替代传统 SEO 排序
  • AI 综合：将海量碎片化社交信号整合为一份可操作的研究简报

风险在于对第三方平台 API 的依赖（平台可能随时更改规则），以及完整功能需要用户自行配置多个 API Key 的门槛。但作为 MIT 开源项目，它已经建立了一个活跃的社区和可扩展的架构，这使其具有良好的持续进化能力。
