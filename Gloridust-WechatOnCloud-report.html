📋 项目概述

WechatOnCloud（云微 WOC）是一个创新性的开源项目，允许用户在自有 NAS 或服务器上运行"服务端微信"。项目的核心理念是"云微信，自由连接"——将微信从本地客户端扩展到云端，实现多设备浏览器共享同一个微信会话。

核心原理：每个微信实例 = 一个独立容器，容器内运行 Xvfb 虚拟显示 + 官方原版 Linux 微信，通过 KasmVNC 将画面串流到浏览器。多个浏览器连接同一实例即共享同一微信会话。自研面板作为唯一对外入口，通过 docker.sock 按需创建/销毁实例并反向代理。
Docker NAS 自部署 KasmVNC 多实例管理 PWA RBAC 权限 飞牛 NAS

💡 核心创新点

1. 服务端微信架构

将微信从本地客户端转变为可云端部署的服务，突破了微信"单设备登录"的限制。通过容器化技术实现了微信的轻量化、隔离化运行，每个微信会话独立互不干扰。

2. 微信本体运行时下载

创新性地将微信安装包与 Docker 镜像解耦——镜像不打包微信本体，而是在面板中一键"下载并安装"。镜像体积小、构建快，微信更新也无需重建镜像。

3. KasmVNC 凭据安全注入

VNC 连接凭据由面板服务端动态注入到实例容器，永远不下发到前端浏览器。用户通过面板的反向代理间接访问 VNC 画面，从根本上杜绝了凭据泄露风险。

4. 中文输入法 IME 修复

针对 KasmVNC 的中文输入问题进行了深度修复——仅在输入法"上屏"时刻将成品汉字整串发送进容器，规避了原生实现逐字符差分导致的丢字/卡顿问题。

5. 多端协作软锁

同一实例多人操作时自动进入只读模式 + 申请接管机制，通过心跳检测实现操作控制权的动态管理，避免"键鼠打架"。

6. PWA 支持

iOS Safari "添加到主屏幕"、桌面 Chrome "安装"，可当作原生 App 使用，移动端体验流畅。

🔒 安全分析

安全优势

  • 面板为唯一对外入口，微信实例不直接暴露
  • KasmVNC 凭据服务端注入，浏览器永远拿不到
  • Docker API 仅管理员可触达
  • 实例容器名由内部随机 ID 派生，防止注入
  • 支持外层套 HTTPS 反代获取 TLS

风险提示

  • 面板挂载了 docker.sock，等同于宿主 root 权限，管理端被攻破后果严重
  • 默认密码 (admin/wechat) 需及时修改
  • 不建议将面板裸暴露公网，应通过 VPN / 内网穿透访问
  • 微信登录态存储在容器中，容器被入侵则聊天记录泄露

📝 总结

WechatOnCloud 是一个设计精良、实用性极强的开源项目。它通过巧妙的技术方案——Docker 容器化 + KasmVNC 串流 + 自研管理面板——将微信从桌面应用转变为可云端部署的服务，解决了多设备、多用户共享微信会话的痛点。

项目的安全意识值得称赞：凭据服务端注入、面板唯一入口、RBAC 权限控制等设计体现了工程师对安全风险的深刻理解。中文输入法的深度修复也展示了对用户体验细节的追求。

作为两天内获得 500+ Star 的新兴项目，其社区关注度很高。主要风险在于个人维护的可持续性，以及微信官方政策的不确定性。但总体而言，这是一个值得关注的优秀开源项目，尤其在 NAS 自部署和微信远程办公场景中有着独特价值。
