🛰️项目概述

World Monitor 是一个实时全球情报仪表盘，核心理念是"把全世界的原始信号——船只、战机、警报、海底光缆、市场行情——汇聚到一个实时界面"。它被社区形容为"全球情报界的 Bloomberg 终端"，但完全免费、开源、可自托管，让原本只有政府和企业花数百万美元才能获得的态势感知能力走向大众。

项目的slogan是 "OSINT for everyone"（开源情报，人人可用）。它不只是一个漂亮的可视化前端，而是一套完整的情报聚合 + AI 合成 + 评分建模 + 多端交付平台，从一个代码库衍生出 6 个站点变体（world / tech / finance / commodity / happy / energy），既可作 Web 应用，也可打包成原生桌面应用。

"Most intelligence platforms are walled gardens. You pay for access, you use their interface… The data is locked behind a UI. World Monitor is designed differently." —— 官方开发者文档

核心架构亮点

① Proto-First 契约优先
所有 API 契约以 Protocol Buffers 为唯一真相源，自动生成 TypeScript 客户端与 OpenAPI 规范，运行时校验拒绝畸形请求，前后端永不漂移。
② 边缘函数 + 熔断器
每个服务域对应独立 edge function，按域瘦入口使冷启动降低约 85%；每个数据源配熔断器，上游故障不会拖垮整个 API。
③ 判别联合标记系统
所有地图标记（双引擎通用）携带 _kind 判别字段，统一标识类型，跨 globe.gl 与 deck.gl 引擎一致渲染。
④ 三层缓存 + ETag
Redis 三层缓存、CDN 缓存、Service Worker，配合 Cache-Control 与 ETag 实现高效边缘缓存与限流（Cloudflare 感知 IP）。
⑤ 浏览器侧本地 AI
通过 Transformers.js + ONNX 在浏览器内做模型推理，结合 Ollama 实现零 API Key 的完全本地化情报分析。
⑥ 单库多变体
一个代码库编译出 6 个站点变体（world/tech/finance/commodity/happy/energy）+ 一个可在应用内切换变体的 Tauri 桌面端。

💡核心创新点

1. 国家不稳定指数 CII（Country Instability Index）v8

项目的"招牌算法"。服务端权威计算的 CII v8 对 31 个一级国家进行 0–100 的压力评分，综合 12 类信号（军事活动、抗议、新闻速度、结构性风险等）。它不仅给数字，还与网络威胁情报联动——例如当某国 CII 上升且 C2 服务器聚集，可能暗示国家级容忍或支持。

2. 跨流信号关联（Cross-stream Correlation）

不止"看新闻"，而是把军事、经济、灾害、局势升级四类信号在时间与空间维度上做收敛关联，让用户看到事件如何同时影响多个维度——这是普通新闻聚合器做不到的。

3. 双地图引擎 + 56 图层

同时支持 3D 地球（globe.gl）与 WebGL 平面地图（deck.gl），通过判别联合标记统一 56 种图层类型，性能与表现力兼顾，可叠加显示航线、地震、军事基地、光缆、核设施等。

4. 金融雷达（Finance Radar）

覆盖 29 个证券交易所、大宗商品、加密货币，并自创 7 信号市场合成指标，把地缘事件与市场反应直接挂钩。

5. 完全本地化 AI（Local AI）

支持 Ollama / Groq / OpenRouter，无需任何 API Key 即可跑完全部情报分析；敏感环境可完全离线自托管，数据不出网。

6. 开发者平台（Open Typed API）

不同于"墙花园"式情报平台，World Monitor 把全部数据流、评分算法、聚合管道暴露为强类型 API，开发者可自建仪表盘、数据管道、Slack/Teams 告警机器人。
