①项目概述

Stirling-PDF 是由 Stirling-Tools 团队开发维护的开源 PDF 处理平台，自称为「GitHub 上排名第一的开源 PDF 应用」。它的核心定位是一个本地化、私有化部署的 PDF 全功能工具集，目标是成为 Adobe Acrobat 与 iLovePDF / Smallpdf 等在线服务的开源替代品。

区别于传统桌面 PDF 编辑器，Stirling-PDF 提供三种使用形态：个人桌面客户端、浏览器端 Web 应用、以及可自托管的服务端（含私有 REST API）。所有文档处理都在用户自己的基础设施上完成，不向外部发送任何文件，也不做任何出站调用或数据追踪，这一点对注重隐私的企业与个人极具吸引力。

💡 一句话定位： 把 iLovePDF / Smallpdf 约 90% 的功能打包进一个 Docker 容器，跑在你自己的服务器上，数据永远不出域。

②技术架构

Stirling-PDF 采用经典的 Java 服务端架构，以 Spring Boot 为后端核心，结合多个成熟的 PDF 处理开源库，整体架构清晰、易于自托管与扩展。

部署方式

  • 一行 Docker 启动： docker run -p 8080:8080 docker.stirlingpdf.com/stirlingtools/stirling-pdf
  • 支持桌面客户端（Windows/Mac/Linux 可执行文件）
  • 支持 Kubernetes 集群化部署（面向企业级吞吐）
  • 启动预热约 90 秒（Spring Boot + LibreOffice 初始化）
⚠️ 安全提示： 2025 年披露 CVE-2025-55150（SSRF 漏洞），攻击者可在 HTML→PDF 转换时绕过安全过滤进行服务端请求伪造。生产部署务必升级至已修复版本，并对不需要外部 URL 的实例限制出站网络。

④应用场景

  • 隐私敏感企业 / 政府： 合同、票据、人事档案等机密文件需在本地完成合并、签章、转换，绝不能上传至公有云
  • 自托管爱好者 (r/selfhosted)： 在 Homelab 中部署一个容器，替代多个在线 PDF 网站
  • 开发团队自动化： 通过 REST API 把 PDF 压缩、转换、水印嵌入 CI/CD 与业务流水线，批量处理海量文档
  • 中小型企业 (SME)： 以极低成本（一台服务器）获得接近 Adobe Acrobat 的功能集合，避免高昂订阅费
  • 法律 / 金融行业： 涂抹敏感信息、文件审计、合规留存等场景
  • 多语言团队： 40+ 界面语言，跨国协作无障碍

★总结

Stirling-PDF 是当前开源世界里最成熟、最全面的私有化 PDF 处理平台之一。它以 Spring Boot + PDFBox + LibreOffice 的经典技术栈，把 60+ 个常用 PDF 操作收敛进一个 Docker 容器，凭借「数据不出域 + 全平台形态 + 开发者 API + 无代码自动化」的组合，精准击中了隐私合规、自托管、批量自动化三大痛点。开核（open-core）商业模式让社区与企业需求得以兼顾，29M+ 下载量与 50K+ Stars 印证了其强大的市场认可度。对于任何需要可控、可自动化、可扩展 PDF 能力的团队或个人，它都是首选的开源方案。唯一需要注意的是持续关注安全公告（如 CVE-2025-55150）并及时升级。
