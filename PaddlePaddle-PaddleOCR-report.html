  • 检测骨干：基于 RT-DETR-L（Real-Time Detection Transformer），使用 HGNetV2-L 作为 CNN 骨干网络进行多尺度特征提取
  • 高效混合编码器：解耦尺度内交互和跨尺度融合，高效处理多尺度特征
  • IoU 感知查询选择：优化 Transformer 解码器的查询初始化
  • 端到端设计：无需 NMS 后处理和 anchor 设计

三、核心创新点

1. 极致轻量化与高性能并存

以仅 0.9B 参数的 VLM 模型，在 OmniDocBench 等权威评测中超越 Gemini-3-Pro、GPT-5.2 等数十亿甚至数百亿参数量级的商业模型。这是架构设计能力的集中体现。

2. 两阶段解耦架构

将版面分析和元素识别分离，第一阶段负责全局理解（定位+排序），第二阶段负责细粒度识别。这种设计既保证了效率，又允许各阶段独立优化和替换。

3. 动态分辨率视觉编码

采用 NaViT 风格的视觉编码器，支持任意分辨率输入，避免传统方法中固定缩放导致的信息丢失，尤其对高分辨率文档细节保留效果显著。

4. 3D 几何校正

业界首创在 OCR 流水线中引入 3D 曲面建模，从根本上解决弯曲、褶皱文档的识别难题，而非传统的 2D 透视变换。

5. LLM 生态深度集成

从 v3.0 开始将核心定位调整为"连接文档图像与 LLM 的桥梁"，输出 JSON/Markdown 等结构化格式，提供 MCP Server 支持 Claude Desktop 等 Agent 应用，与 Dify 等平台深度集成。

6. 浏览器端推理（v3.5+）

支持浏览器端直接运行 OCR，无需后端服务，拓展了应用场景的边界。
