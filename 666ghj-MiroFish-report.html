一、项目概述

MiroFish 是由 BaiFu（GitHub: 666ghj）开发的新一代 AI 预测引擎，基于多智能体（Multi-Agent）群体智能技术构建。 该项目从真实世界中提取种子信息（如突发新闻、政策草案、金融信号），自动构建高保真的平行数字世界。在这个空间中，数千个拥有独立人格、 长期记忆和行为逻辑的智能体自由交互并进行社会演化。用户可以从"上帝视角"动态注入变量，精确推导未来趋势。

核心理念： 在数字沙盘中预演未来，通过无数次模拟赢得决策先机。MiroFish 致力于创建一面映射现实的群体智能之镜， 通过捕捉个体交互引发的集体涌现，突破传统预测的局限性。

该项目由盛大集团提供战略支持和孵化，其模拟引擎基于 OASIS（Open Agent Social Interaction Simulations）框架， 该框架由 CAMEL-AI 研究社区开发，可扩展至百万级智能体。MiroFish 在 2026 年 3 月登上 GitHub 全球趋势榜第一名，引发了广泛关注。 值得一提的是，作者 BaiFu 是一名中国在校大学生，仅用 10 天时间便完成了项目的初始开发。

二、技术架构

+----------------------------------v-------------------------------+

+----------------------------------+-------------------------------+
                                   |
+----------------------------------v-------------------------------+
| ORCHESTRATION LAYER (编排层)                                      |
| 环境配置智能体 -> 人格模板 -> 智能体工厂                             |
+----------------------------------+-------------------------------+
                                   |
+----------------------------------v-------------------------------+
| SIMULATION LAYER (模拟层)                                         |
| OASIS 引擎: 并行智能体循环 (Platform A + Platform B)              |

2.3 核心工作流（五步预测管线）

  1. 图谱构建：种子提取 & 个体/集体记忆注入 & GraphRAG 构建
  2. 环境配置：实体关系提取 & 人格生成 & 智能体配置注入
  3. 模拟运行：双平台并行模拟 & 自动解析预测需求 & 动态时序记忆更新
  4. 报告生成：ReportAgent 利用丰富工具集生成深度分析
  5. 深度交互：与模拟世界中任意智能体对话 & 与 ReportAgent 互动

2.4 GraphRAG 知识图谱构建

MiroFish 选择 GraphRAG 而非传统向量搜索的原因在于：传统 RAG 将文档扁平化为向量，丢失了关系结构。GraphRAG 显式保留实体与关系（节点和边）， 使智能体能推理连接信息。图谱构建管线包括四步：

  • 实体提取：原始文本 -> LLM 分块 -> 实体识别（人物、组织、事件、政策），含共指消解和去重（余弦相似度 > 0.9 + 共享关系则合并）
  • 关系推理：实体对之间提取有向关系（如 influence_of、opposes、employs），支持多跳推理链，置信度 < 0.6 的边被剪枝
  • 上下文丰富化：实体/边赋予时间和空间限定符，Louvain 算法或 GNN 进行社区检测
  • 验证与剪枝：环检测、密度阈值过滤、时间一致性校验

最终图谱：典型种子（新闻/政策文档）约 10-100K 节点/边，大型种子（小说）可达 500K+ 节点。

2.5 Zep Cloud 记忆管理

无状态智能体每轮重置上下文，无法产生涌现学习。MiroFish 通过 Zep Cloud 实现持久化记忆：

  • 线程会话：每智能体独立命名空间，包含消息日志 + 自动摘要
  • 语义搜索：按语义查询记忆（"Alice 对监管了解了什么？"）
  • 混合记忆视野：短期记忆（最近 10 轮）+ 长期摘要记忆
  • 记忆更新协议：每次行动后追加观察 + 意图 -> 语义索引 -> 周期性 LLM 摘要压缩

记忆系统创造了迟滞效应：过去事件以非平凡方式影响未来行为——极化浪潮、信念转变、关系演化、派系凝聚力——使模拟展现真实的路径依赖性。

2.6 OASIS 双平台模拟引擎

MiroFish 同时在两个平台上运行模拟，建模跨环境动态：

  • Platform A（类 Twitter）：短帖、病毒式传播机制、高速度低深度，适合快速情绪级联
  • Platform B（类 Reddit）：线程讨论、投票机制、低速度高深度，适合理性辩论和派系形成

智能体可在双平台之间跨发，形成社区桥接。每个智能体每轮执行 23 种社交动作（发帖、回复、转发、投票、关注、提及、标签、表情反应等）， 并受速率限制以保证真实性。

2.7 智能体行为循环

每轮循环包含四步：

  1. 感知 (PERCEIVE)：获取关注用户的最新动态、从 Zep 检索个人记忆、查询知识图谱上下文
  2. 思考 (DELIBERATE)：LLM 调用（含人格、立场向量、目标、记忆上下文），输出动作选择 + 推理
  3. 行动 (ACT)：在平台上执行动作，记录事件流，索引内容
  4. 持久化 (PERSIST)：更新 Zep 记忆（行动+结果），更新内部状态，发送下游分析事件

三、核心创新点

1. 锚定现实的涌现预测

不同于传统的统计预测或孤立的 LLM 推理，MiroFish 将所有智能体行为锚定在从种子材料构建的知识图谱上。智能体不会虚构背景——它们在反映输入数据的结构化现实中运行。模拟成为"数字排演"，而非推测性虚构。

2. 持久记忆驱动的涌现

通过 Zep Cloud 实现的持久化记忆使智能体积累了经验，形成稳定的信念和关系。记忆创造了迟滞效应——早期分歧固化为根深蒂固的立场，暴露于反复反驳证据的智能体逐渐更新信念，联盟深化或瓦解。这是从马尔可夫（无记忆）到真实路径依赖的关键突破。

3. GraphRAG 结构化知识图谱

选择 GraphRAG 而非向量搜索是深思熟虑的架构决策。实体和关系作为显式节点和边保留，使智能体能直接查询连接信息并推理传递影响。多级摘要（全局、局部、模式）减少上下文窗口需求，支持 100K+ 节点图谱。

4. 双平台并行模拟

同时运行类 Twitter 和类 Reddit 两个平台，捕获不同社交动态：Twitter 上的快速情绪级联 vs Reddit 上的深度派系形成。跨平台传播机制（Reddit 热帖触发 Twitter 趋势）模拟了真实的信息流动。

5. 百万级可扩展性

基于 OASIS 框架，理论上可扩展至 100 万智能体。无状态智能体 + 分片记忆支持分布式执行，事件溯源和最终一致性模型实现水平扩展。

6. 后验交互与敏感性分析

模拟完成后，用户可以查询任意智能体的决策上下文、注入假设场景重跑子模拟、修改图谱或智能体参数重新模拟。这使 MiroFish 不仅是预测工具，更是一个可探索的假设分析平台。

四、应用场景

4.1 公共舆论模拟

输入新闻事件（如大学争议事件），模拟社交媒体情绪如何演变。识别关键影响者、转折点、极化动态，预测哪些叙事将获得关注。

4.2 金融市场预测

注入市场信号（美联储声明、财报），模拟交易员、分析师、散户投资者的反应。预测市场情绪、波动性、流动性效应。支持压力测试："如果盈利低于预期 20% 会怎样？"

4.3 危机公关模拟

建模危机如何在社交媒体上展开，在部署前测试消息策略，识别放大器账户和反叙事。

4.4 政策影响评估

模拟新政策如何影响不同利益相关方群体。预测采纳率、阻力、意外后果，识别胜选联盟和否决方。

4.5 文学创作推演

基于小说前 80 回的数十万字文本，深度预测遗失结局。MiroFish 已成功演示了《红楼梦》失佚结局的推演。

4.6 营销策略测试

在模拟环境中测试营销活动创意，观察消费者反应，优化策略后再在真实市场部署。

竞争优势：MiroFish 的独特之处在于将知识图谱锚定 + 持久记忆 + 百万级群体模拟 + 双平台社交动态四者结合。 这使它能捕捉传统统计模型无法处理的复杂社会动力学——群体行为、社会传染和涌现模式。作为完全开源项目，其可扩展性远超同类多智能体模拟框架。

六、局限性与风险

  • 非水晶球：模拟展示的是可能场景，非概率估计。尚无发布基准对比预测与实际结果
  • LLM 偏差传播：研究表明 LLM 智能体比真实人类更易出现群体行为，模拟群体极化速度快于真实群体
  • 知识图谱质量瓶颈：垃圾输入，垃圾输出。低质量种子材料导致低质量图谱和不现实的模拟
  • 计算成本高：1000 智能体 x 100 轮 = 10 万次 LLM 调用，约 $1000/次模拟
  • 早期阶段：v0.1.0 发布于 2025 年 12 月，API/架构可能变更

总结评价：MiroFish 代表了预测系统的新范式——用群体智能模拟替代统计推断。其架构设计精巧（分层解耦、事件驱动、模块可替换）， 理论基础扎实（涌现预测 + 知识锚定），且具备百万级扩展潜力。虽然目前处于 v0.1.0 早期阶段，实用性和准确性尚待验证， 但作为开源项目，它为多智能体预测系统提供了完整的蓝图。对于关注 AI 预测、多智能体系统和社会模拟的开发者和研究者，这是一个极具前瞻性和学习价值的项目。
