项目概述

Flowsint 是由 reconurge 组织开发的现代化开源 OSINT 调查平台，旨在为网络安全分析师、调查记者、执法机构和数字取证团队提供专业级的图可视化情报分析能力。该项目定位为商业工具 Maltego 的开源替代方案，以 Apache 2.0 协议发布。

与传统 OSINT 工具不同，Flowsint 将所有数据存储在用户本地机器上，强调隐私保护和数据主权。它通过模块化的 Enricher（数据丰富器）体系实现自动化情报收集，支持从域名、IP、ASN、社交媒体、加密货币钱包等多种实体类型出发，自动扩展和丰富调查图谱。

该项目目前正处于早期活跃开发阶段，已获得 4,000+ GitHub Stars，在 OSINT 社区引起了广泛关注，被认为是最有潜力的 Maltego 开源替代方案之一。

🏗️

技术架构

Flowsint 采用模块化单体架构（Modular Monorepo），各模块职责明确，通过清晰的依赖关系层叠组织：

flowsint-app (前端应用)
TypeScript 构建的现代化交互式图可视化界面，支持数千节点无延迟渲染
↓
flowsint-api (API 服务层)
FastAPI 提供的 REST API 端点，认证与用户管理，实时事件流
↓
flowsint-core (核心编排层)
数据库连接(PostgreSQL/Neo4j)、认证授权、Celery 异步任务、配置管理
↓
flowsint-enrichers (数据丰富引擎)
30+ 自动化 Enricher 模块，覆盖域名/IP/ASN/社交/加密货币等数据源
↓
flowsint-types (类型定义层)
Pydantic 数据模型，定义 Domain/IP/ASN/Email/Phone/Website/Crypto 等实体类型

核心创新点

🔗

图驱动的关联发现引擎

基于 Neo4j 图数据库构建，将所有 OSINT 实体（域名、IP、邮箱、社交账号、加密钱包等）建模为图节点，通过边关系自动发现和可视化隐藏的关联路径，实现从单一线索到完整关系网络的快速扩展。

⚙️

模块化 Enricher 体系

30+ 开箱即用的自动化数据丰富器，按实体类型分类（域名/IP/ASN/社交/加密货币等）。用户可通过标准的 Enricher 接口轻松扩展新的数据源，支持将 Transforms 串联（Chain）实现复杂调查工作流自动化。

🔒

完全本地化部署与数据主权

所有调查数据存储在用户本地机器上，不依赖任何云端服务。Docker 一键部署（make prod），强调 OSINT 调查中对隐私保护和数据主权的要求，特别适合安全敏感场景。

🧩

清晰的模块化架构

Monorepo 中划分 5 个独立模块（core/types/enrichers/api/app），每个模块有独立的依赖管理和测试套件。这种设计使新功能的添加路径清晰：新类型加到 types，新数据源加到 enrichers，新接口加到 api。

🔌

N8n 工作流集成

内置 N8n Connector 集成丰富器，允许与流行的自动化工作流平台 N8n 对接，实现 OSINT 数据管道的自动化编排，扩展了平台与外部生态系统的互操作能力。

🚀

高性能图可视化

前端应用针对大规模图渲染进行了性能优化，即使处理数千节点也能保持流畅交互体验，解决了传统 OSINT 工具在大量数据下界面卡顿的痛点。

🔧

应用场景

🛡️ 威胁情报分析

从恶意 IP 或钓鱼域名出发，自动关联其背后的 ASN、子域名、注册信息和关联 IP，快速构建攻击者基础设施画像。

🔍 数字取证调查

执法机构和数字取证团队可从单一线索（邮箱、用户名）出发，通过 Enricher 链式扩展，发现关联的社交媒体账号、数据泄露记录等。

📰 调查新闻

记者和调查人员可追踪组织背后的域名注册信息、关联实体、网站追踪器和加密钱包流向，支撑深度调查报道。

🏢 企业安全审计

企业安全团队可评估自身数字资产暴露面，发现未授权子域名、关联 IP 段、追踪脚本和数据泄露风险。

₿ 加密货币调查

追踪加密货币钱包的交易历史和 NFT 持有情况，辅助反洗钱（AML）和反欺诈调查。

🎓 安全研究与教育

作为 OSINT 教学和实践工具，帮助学生和入门安全研究员直观理解实体间的关联关系和信息收集方法论。

总结：Flowsint 的核心优势在于完全开源免费、本地化部署保护隐私、基于 Neo4j 的原生图数据库支持。虽然生态成熟度和数据源数量尚不及 Maltego，但其模块化架构和零成本特性使其成为中小型安全团队和个人研究者的理想选择。

快速上手

# 克隆仓库
git clone https://github.com/reconurge/flowsint.git
cd flowsint

# 一键启动（需要 Docker 和 Make）
make prod

# 访问 http://localhost:5173/register 创建账户
# 所有数据存储在本地，无需云端依赖

开发环境：开发者可使用 uv run pytest 在各模块中运行独立测试套件，使用 Poetry 管理依赖。项目欢迎社区贡献新的 Enricher、类型定义和 API 端点。
