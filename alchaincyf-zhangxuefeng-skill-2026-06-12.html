📋 项目概述

zhangxuefeng-skill 是一个基于开放的 Agent Skills 协议构建的 AI 认知蒸馏项目，由中国独立开发者花叔（Huashu / alchaincyf）创建。项目的核心目标是将中国教育咨询领域的标志性人物张雪峰的认知模式、决策逻辑和表达风格，系统地提炼并封装为一个可供 AI Agent 运行的"思维框架"。

「不是语录合集，是可运行的思维框架。」—— 项目 README

该项目由女娲.skill（nuwa-skill）自动生成。女娲的工作流程是：输入一个人物名字 → 6 个 Agent 并行调研（著作/对话/表达/批评/决策/时间线）→ 交叉验证提炼心智模型 → 构建 SKILL.md → 质量验证。整个蒸馏过程基于 5 本著作、15+ 篇权威媒体深度采访、30+ 条一手语录、11 个关键决策记录和完整人生时间线的深度调研。

项目兼容 50+ AI Agent Runtime，包括 Claude Code、Codex CLI、Cursor、OpenClaw、Hermes Agent、Gemini CLI、OpenCode 等，真正实现了"一次蒸馏，到处运行"。

🏗️ 技术架构

项目的核心是 Agent Skills 协议—— 一个开放的 AI Agent 技能分发标准。技术架构可以概括为以下几个层次：

📄 SKILL.md 核心文件

项目的灵魂文件，包含 YAML frontmatter（元数据）+ Markdown 正文（心智模型、决策启发式、表达DNA）。本质是一份精心结构化的 Markdown 文档，可被任何支持该协议的 AI Runtime 自动加载。

🔬 多维调研引擎

由女娲.skill 驱动的 6 Agent 并行调研架构：著作分析、对话抽取、表达DNA解码、外部批评收集、决策模式分析、人生时间线重建。输出 6 个独立调研文件，支持交叉验证。

🔌 跨 Runtime 兼容层

通过 npx skills add 统一安装命令，自动检测当前 Runtime（Claude Code / Codex / Cursor / OpenClaw / Hermes 等 55+ runtime），将 skill 放到对应目录。支持手动安装和纯文本引用模式。

✅ 质量验证体系

蒸馏完成后自动进行 3 个已知测试 + 1 个边缘测试 + 1 个风格测试，确保输出的思维模型在忠实度和可用性上达标。SKILL.md 持续迭代优化（如 darwin round 调优机制）。

💡 核心创新点

🧠 认知蒸馏而非简单模仿

不同于传统的 ChatGPT "角色扮演"（套用一个人设模板），该项目通过系统化调研提炼出5个核心心智模型、8条决策启发式和完整的表达DNA。AI 不是在"扮演"张雪峰，而是在用张雪峰的认知框架分析问题。

🔄 可复用的蒸馏方法论

女娲.skill 提供了一套完整的"人物蒸馏流水线"——输入名字，自动完成调研、提炼、验证全流程。目前已成功蒸馏乔布斯、马斯克、纳瓦尔、芒格、费曼、塔勒布等多个认知操作系统，证明了方法的通用性。

🌐 开放的 Agent Skills 协议

基于开放的 Agent Skills 标准构建，不绑定任何特定 AI Runtime。一次蒸馏，可在 Claude Code、Codex、Cursor、Gemini CLI 等 50+ runtime 中运行，真正实现了"认知资产的跨平台分发"。

🎭 保留内在张力与矛盾

特别值得关注的是，项目刻意保留了被蒸馏人物的5对内在张力（如"寒门代言人 vs 亿万富翁"），避免了脸谱化。这种对复杂性的尊重，使蒸馏出的认知模型更加立体和真实。
