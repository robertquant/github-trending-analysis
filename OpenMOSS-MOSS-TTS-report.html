🏗️ 技术架构

1. 核心基础：MOSS-Audio-Tokenizer（CAT 架构）

MOSS-TTS 建立在自研的 MOSS-Audio-Tokenizer 之上，采用因果 Transformer（Causal Transformer）架构作为音频分词器。该分词器利用可变比特率残差向量量化（RVQ）技术，结合统一的语义-声学表示，将 24kHz 音频进行高效压缩，为后续语言模型建模提供离散 token 序列。

2. 双阶段生成架构

旗舰版 MOSS-TTS 采用创新的双阶段生成架构：

  • 语言模型阶段：负责建模音频 token 的序列依赖关系，生成粗粒度的音频 token 序列
  • 扩散变换器（Diffusion Transformer）阶段：负责将粗粒度 token 精细化为高质量音频波形

两阶段协同工作，实现了高保真与长时长音频的兼顾生成。

3. MOSS-TTS-Nano：纯自回归架构

轻量版采用纯自回归架构（Audio Tokenizer + LLM），模型仅 0.1B 参数。支持 48kHz 双声道原生输出，专为端侧实时部署优化，支持 ONNX CPU 推理和流式输出。

4. MOSS-Speech：层拆分架构

语音到语音大模型采用层拆分（Layer Splitting）架构：在预训练文本 LLM 的基础上新增模态特定层，同时冻结预训练权重，在保留原 LLM 能力的同时引入语音理解，实现无需文本引导的端到端语音建模。

💡 核心创新点

1. SOTA 级零样本声音克隆

在 Seed-TTS-Eval 零样本基准上达到 SOTA，超越所有开源模型。仅需 3 秒参考音频即可高保真复刻说话人音色，Reddit 社区评价其"与 ElevenLabs 持平甚至更好"。

2. 超长稳定语音生成

一次性处理长达 60 分钟的长音频，解决了传统 TTS 在长文本生成中常见的音质衰减和说话人漂移问题。Token 级别的时长控制确保了整段音频的一致性。

3. 0.1B 参数端侧实时推理

Nano 版以仅 0.1B 参数实现 100ms 内极速出声，支持纯 CPU 和 ONNX 推理。开创性地将生产级 TTS 能力带入手机、IoT 等资源受限设备。

4. 统一多模态输入表征

文本通过 Text Tokenizer、音频通过 Audio Tokenizer 统一编码，打破了文本与声音的模态壁垒。支持从自然语言描述直接生成特定音色的 MOSS-VoiceGenerator 技术。

5. llama.cpp 生态集成

2026 年 3 月新增 llama.cpp 首选实现，提供端到端文档支持，使 MOSS-TTS 可直接在 llama.cpp 生态中部署推理，大幅降低了集成门槛。
