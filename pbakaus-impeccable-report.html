📋 项目概述

Impeccable 是由前 Google 开发者倡导者、jQuery UI 创始人 Paul Bakaus 创建的开源项目，旨在为 AI 编程助手（Claude Code、Cursor、Gemini CLI、Codex CLI 等）提供一套完整的专业设计语言和技能框架。

核心问题：所有 AI 模型都基于相同的 SaaS 模板训练，导致生成的 UI 千篇一律 — Inter 字体、紫蓝渐变、卡片套卡片、灰色文字配彩色背景。Impeccable 通过提供结构化的设计词汇和 27 条反模式规则来系统性地解决这一问题。

项目继承自 Anthropic 官方的 frontend-design 技能，在其基础上大幅扩展了专业设计知识、更精细的控制选项和跨平台兼容性。

🏗️ 技术架构

7 大领域参考文件

  • Typography — 字体系统、字体配对、模块化缩放、OpenType
  • Color & Contrast — OKLCH 色彩空间、着色中性色、暗色模式、无障碍
  • Spatial Design — 间距系统、网格、视觉层次
  • Motion Design — 缓动曲线、交错动画、减少动画偏好
  • Interaction Design — 表单、焦点状态、加载模式
  • Responsive Design — 移动优先、流式设计、容器查询
  • UX Writing — 按钮标签、错误消息、空状态

三层检测系统

  • 确定性反模式规则 (27条) — 无需 LLM，纯规则引擎检测 UI 问题
  • LLM 审查 (12条规则) — 利用 AI 进行深度设计审查
  • CLI 检测器 — 支持本地文件、HTML 文件、URL (Puppeteer) 扫描

CLI 检测覆盖 24 类问题：AI slop（侧边栏边框、紫蓝渐变、弹性缓动）和通用设计质量（行长、间距过紧、触控目标过小、跳过标题等）

💡 核心创新点

1. 人机共享设计语言

不再是模糊的 "make it pretty"，而是通过 /bolder、/quieter、/distill 等精确的设计指令，让人与 AI 之间建立真正有效的设计沟通。

2. 确定性反模式检测

27 条规则无需 LLM 或 API Key，纯规则引擎即可检测 "AI slop"。可在 CI/CD 流水线中直接集成，实现自动化设计质量把关。

3. 品牌 vs 产品寄存器

根据项目类型（品牌导向 vs 产品导向）自动调整设计默认值，确保输出结果与项目定位一致。

4. 跨工具统一体验

一套设计语言同时支持 11+ AI 编程工具，消除工具切换带来的设计一致性损失。

5. 实时浏览器迭代

/impeccable live 模式允许直接在浏览器中可视化地迭代 UI 元素，实现"所见即所得"的设计流程。

6. CLI 检测器 + URL 扫描

支持 Puppeteer 驱动的 URL 扫描和 --fast 正则模式，可对线上产品进行设计审计。

🎯 应用场景

独立开发者 / 小团队

没有专职设计师的团队，通过 Impeccable 让 AI 编程助手产出专业级 UI，显著提升产品视觉品质。一次 /impeccable polish 即可将原型级界面提升至可交付水平。

企业 CI/CD 流水线

在 CI 中集成 npx impeccable detect --json，自动检测代码中的设计反模式，防止 "AI slop" 进入生产环境。

设计系统维护

使用 /impeccable extract 和 /impeccable document 从现有代码中提取设计 Token 和组件，自动维护设计系统文档。

设计教育 / 新人培训

23 个命令本身就是一套完整的设计方法论。开发者在使用过程中自然学习字体配对、OKLCH 色彩、动效原理等专业知识。

📝 总结

Impeccable 是目前 AI 编程领域最具创新性的设计工具之一。它精准地识别了一个真实痛点 — AI 生成的 UI 千篇一律 — 并提供了一套完整、可操作、可自动化的解决方案。

核心价值：将专业设计知识从"隐式经验"转化为"显式语言"，让 AI 编程助手从"代码工具"进化为"设计伙伴"。

适合人群：使用 AI 编程工具（尤其是 Claude Code / Cursor）的前端开发者、独立开发者、以及希望提升 UI 品质但没有专职设计师的团队。

一句话评价：Impeccable 不是又一个 UI 框架，它是一种全新的思路 — 教会 AI 什么是好的设计。
