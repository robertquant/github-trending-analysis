Penpot 是一款面向团队规模化的开源设计与原型协作平台，被誉为"设计界的开源 Figma 对标者"。它的核心理念是：把设计资产的完整所有权交还给团队——既能用官方 SaaS，也能完全自托管在自有服务器上，满足严格的合规与数据治理要求。

与其他设计工具最大的不同在于：Penpot 从底层就建立在开放 Web 标准（SVG、CSS、HTML、JSON）之上，原生使用 SVG 渲染，并直接支持 CSS Grid 与 Flex 布局。这意味着设计师画出的界面，其结构与开发者写的代码天然同构——"设计即代码"，无需翻译层。

项目由西班牙公司 Kaleidos 主导维护，于 2015 年底立项（ClojureScript 原型诞生于一次 hackathon），2021 年发布 1.0 正式版，并入选 DPG（Digital Public Goods，数字公共产品）认证。如今它正通过 MCP Server、插件系统与开放 API，把设计平台推向"可编程、AI 驱动"的新阶段。

2) 为什么是 Clojure / ClojureScript？

Penpot 的技术选型在同类 Web 应用中相当独特：前后端统一使用 Lisp 方言（Clojure 后端 + ClojureScript 前端）。官方的解释集中在三点：稳定性、向后兼容性、语法抽象能力。

  • 同构共享代码：前端与后端能共享同一套数据结构（Clojure 的不可变持久数据结构），减少"接口层"的重复定义与不一致风险。
  • 不可变数据 + 函数式范式：天然适合实时协作场景下"状态变更 → 变更集（changeset）"的模型，多人编辑的合并、撤销重做更易推理。
  • REPL 驱动开发：开发体验流畅，2015 年仅用一周就在 hackathon 拿出了可运行原型。

3) Rust + WASM 渲染引擎（性能关键）

这是 Penpot 架构里最硬核的优化点。前端并非纯 ClojureScript 直接渲染 SVG，而是引入了一个约 22,000 行的 Rust 引擎，编译为 WASM 运行在浏览器中：

  • 将 ClojureScript 的设计数据解构为二进制打包结构体（binary-packed structs），写入 WASM 线性内存。
  • 渲染管线在 Rust 侧高速执行，规避了 JS 解释执行与频繁 GC 的开销，显著提升大画布的渲染与交互性能。
  • 这是 Penpot 在"开源 + Web 标准"约束下，逼近原生设计工具体验的关键工程。

💡 核心创新点

① 设计即代码：原生 SVG + CSS Grid / Flex

这是 Penpot 最本质的差异化。原生使用 SVG 而非私有渲染格式，并直接支持 CSS Grid 与 Flex 布局——设计师拖拽出的响应式布局，行为与真实前端代码一致。设计稿与生产代码之间几乎没有翻译损耗，开发者拿到的是可用的 SVG/CSS/HTML（Inspect 面板即时输出），而非需要"重新画一遍"的位图描述。

② 真正的自托管 + 数据主权

Penpot 是部署无关（Deployment-Agnostic）的设计平台：既能用 SaaS，也能完全部署在自有服务器。对金融、医疗、政企、信创等数据合规 / 自主可控需求强烈的场景，这是 Figma 这类纯云端闭源工具结构性无法提供的能力——设计资产永不离开你的基础设施。

③ 原生 Design Tokens：设计与开发的单一真相源

内置一流的原生 Design Tokens，配合 Components、Variants，构建可扩展、可复用、跨平台一致的设计系统。Tokens 作为设计与开发之间的"单一真相源（single source of truth）"，确保一致性、降低协作摩擦，让复杂设计系统的管理真正可行。

④ MCP Server：设计 ↔ 代码 ↔ AI 的多向工作流

Penpot 内置 MCP（Model Context Protocol）Server，把设计文件变为可被 AI 与代码工具读取的结构化数据。AI Agent 可以"读懂"设计稿、生成代码、同步设计系统——这是 Penpot 拥抱 AI 时代的核心入口，也让"设计即代码"理念升级为"设计可被 AI 消费"。

⑤ 开放可编程：REST API + 插件系统 + Webhooks

强大的开放 API（基于 access tokens）、Webhooks 与插件系统，使整个工作区可编程。团队可接入既有 CI/CD、设计令牌同步管线、自动化导出，甚至开发自定义插件扩展平台能力——无厂商锁定。

⑥ 开放标准 + MPL 2.0：无锁定、可商用

SVG/CSS/HTML/JSON 这些开放 Web 标准意味着设计文件永远可被标准工具读取，不会随平台消失而变成"数字废墟"；MPL 2.0 协议商用友好、弱传染性（文件级 copyleft），兼顾开源精神与企业可用性。

📋 总评

Penpot 是开源设计协作赛道里当之无愧的标杆项目。它以"开源 MPL 2.0 + 自托管数据主权 + 开放 Web 标准(SVG/CSS)原生 + Clojure/Rust-WASM 架构"为底座，构建出一个有别于 Figma 闭源云端路线的开放平台。其"设计即代码"理念——原生 SVG 渲染、CSS Grid/Flex 布局、原生 Design Tokens、Inspect 直出代码——让设计与开发真正同源，是它最锋利的差异化武器。

架构上，Penpot 展现出少见的工程深度（架构设计 9.3）：Clojure/ClojureScript 前后端同构共享数据结构与协作 changeset 模型，再用 22k 行 Rust/WASM 引擎把渲染性能拉满——这是在"Web 标准 + 开源"双重约束下的精妙取舍。开放性与数据主权（9.6）几乎满分：自托管、SVG/JSON 文件永不锁定、MCP Server 让设计可被 AI 消费、API/插件/Webhooks 全链路可编程。

主要权衡：① 性能体验（7.4）是相对最弱的一环，超大文件流畅度仍落后 Figma；② 生态（8.0）——插件、模板、社区资产尚不及 Figma 厚；③ 从 Figma 迁移存在损耗，Clojure 栈贡献门槛偏高。

结论：对于追求数据主权、设计-开发一体化、信创自主可控，或希望把设计资产纳入 AI/CI 可编程工作流的团队，Penpot 是当前最完整、最成熟的开源选择。它不是"便宜的 Figma 复制品"，而是一条以开放标准与数据所有权为核心理念的独立路线——值得设计与工程团队长期投入。
