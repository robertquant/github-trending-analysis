👁 项目概览

Frigate 是一个完整的、本地运行的网络视频录像机（NVR），专为 Home Assistant 设计，具备实时 AI 物体检测能力。它利用 OpenCV 和 TensorFlow 对 IP 摄像头的视频流进行本地实时物体检测，所有数据处理均在本地完成，无需将视频流发送到云端，充分保障用户隐私。

⚡ 核心功能

🎥

实时 AI 物体检测

使用 TensorFlow / ONNX 模型进行本地实时物体检测，支持人、车、动物等多种目标识别，所有处理完全本地化。

🎯

智能区域监控

内置遮罩和区域编辑器，可精确定义监控区域，只在需要的区域触发检测，大幅降低误报和资源消耗。

💻

多硬件加速

支持 Google Coral Edge TPU、NVIDIA GPU (TensorRT)、AMD GPU (ROCm)、Intel 等，AI 加速器以极低开销实现高 FPS。

🌐

WebRTC 低延迟直播

内置 go2rtc 支持 WebRTC 和 MSE 低延迟实时视频流，RTSP 重流减少对摄像头的直连数。

📋

24/7 录制 + 事件录制

支持全天候连续录制和基于检测事件的智能录制，灵活配置存储策略，自动管理磁盘空间。

🔗

Home Assistant 深度集成

作为 Home Assistant 自定义组件运行，MQTT 通信实现与智能家居系统的无缝联动和自动化。

🤖

GenAI 摘要 (v0.17)

最新版本引入 GenAI 驱动的事件摘要，使用结构化格式对检测事件进行智能总结。

📷

PTZ 自动追踪

支持 PTZ 摄像头的自动追踪功能，检测到目标后自动控制云台跟踪，保持目标在画面中。

🏗 技术架构

系统架构

Frigate 采用多进程架构，将视频解码、运动检测、物体检测和录制等功能分布在独立进程中运行，最大化利用多核 CPU 和专用硬件：

  • 视频输入层：通过 go2rtc 接入 RTSP/RTMP 等多种视频流协议
  • 运动检测层：使用极低开销的运动检测算法确定需要运行物体检测的区域
  • 物体检测层：TensorFlow / ONNX 模型在独立进程中运行，支持 Coral TPU / GPU 加速
  • 录制管理层：基于检测结果触发录制，管理 24/7 和事件录制
  • 通信层：通过 MQTT 与 Home Assistant 及其他系统集成
  • Web UI 层：TypeScript 构建的现代 Web 界面，支持实时预览、回放和配置

性能优化策略

  • 按需检测：仅在检测到运动时才运行物体检测，大幅节省计算资源
  • 区域过滤：通过遮罩和区域定义，只在感兴趣的区域进行检测
  • 多进程并行：强调实时性，不追求处理每一帧，优先保证实时 FPS
  • 硬件加速：AI 加速器（如 Coral TPU）以极低 CPU 开销实现高性能推理
  • RTSP 重流：减少与摄像头的直接连接数，降低摄像头负载

      - /path/to/storage:/media/frigate
      - /etc/localtime:/etc/localtime:ro
    ports:
      - "5000:5000"    # Web UI
      - "8554:8554"    # RTSP
      - "8555:8555/tcp" # WebRTC TCP
      - "8555:8555/udp" # WebRTC UDP

🚀 快速上手指南

Step 1: 准备硬件

  • 推荐：Intel NUC / 迷你主机 / 树莓派 5 + Google Coral Edge TPU
  • IP 摄像头（支持 RTSP 协议，如 Reolink、Amcrest、Tapo 等）

Step 2: Docker 部署

yaml 
# docker-compose.yml
services:
  frigate:
    container_name: frigate
    image: ghcr.io/blakeblackshear/frigate:stable
    shm_size: "256mb"
    devices:
      - /dev/bus/usb:/dev/bus/usb  # Coral TPU
      - /dev/dri/renderD128:/dev/dri/renderD128  # Intel GPU
    volumes:
      - /path/to/config:/config
      - /path/to/storage:/media/frigate
    ports:
      - "5000:5000"
      - "8554:8554"
      - "8555:8555/tcp"
      - "8555:8555/udp"
    environment:
      FRIGATE_RTSP_PASSWORD: "password"

Step 3: 配置摄像头

yaml 
# /config/config.yml
cameras:
  front_door:  # 摄像头名称
    enabled: true
    ffmpeg:
      inputs:
        - path: rtsp://admin:password@192.168.1.100:554/stream1
          roles:
            - detect
            - record
    detect:
      enabled: true
      width: 1920
      height: 1080
    record:
      enabled: true
      retain:
        days: 7
