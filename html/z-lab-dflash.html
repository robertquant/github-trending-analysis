1. 项目简介与核心功能

DFlash 是由 z-lab（Jian Chen, Yesheng Liang, Zhijian Liu）开发的下一代 LLM 推理加速框架。它用轻量级块扩散模型（Block Diffusion）替代传统投机解码中的自回归草稿模型，实现了 6× 以上的无损加速。

🎯 核心创新：用扩散替代自回归

传统投机解码（Speculative Decoding）使用小型自回归模型生成「草稿 token」，再由大模型并行验证。DFlash 则采用块扩散模型，在单次并行前向传播中生成一整块草稿 token，彻底突破了自回归的逐 token 生成瓶颈。

✨ 核心功能

  • 块扩散草稿生成：单次前向传播生成整个 token 块，替代逐 token 自回归
  • 无损加速：加速过程中不损失任何生成质量，输出与原始模型完全一致
  • 6×+ 加速比：相比无加速推理，实现 6 倍以上端到端加速
  • 20+ 模型支持：Gemma-4、Qwen3.5、Qwen3-Coder、Kimi-K2.5、MiniMax-M2.5、LLaMA-3.1 等
  • 多后端支持：vLLM (v0.20.1+)、SGLang、Transformers、MLX (Apple Silicon)
  • 轻量级：草稿模型极小，训练和部署成本低

🧬 块扩散模型原理

传统投机解码的瓶颈在于：草稿模型必须逐 token 自回归生成，即 K 个 token 需要 K 次前向传播。DFlash 的块扩散模型通过去噪（Denoising）过程，从噪声中一次性「还原」出 K 个 token，仅需一次前向传播。

1噪声初始化：将目标位置初始化为随机噪声 token
2条件去噪：以已生成上下文为条件，块扩散模型在单次前向中预测所有位置
3迭代精炼：可进行多轮去噪迭代，提升草稿质量（但通常 1 轮即足够好）
4并行验证：目标大模型一次性验证所有草稿 token，接受匹配的 token

7. 快速上手指南

安装（vLLM 后端）

# 安装 vLLM (>= v0.20.1) pip install vllm # 克隆 DFlash git clone https://github.com/z-lab/dflash.git cd dflash pip install -e .

运行加速推理

# 使用 DFlash 加速 Qwen3.5 python -m dflash.run \ --model Qwen/Qwen3.5-32B \ --draft-model dflash/draft-qwen3.5-32b \ --block-size 8 \ --backend vllm # 加速 Gemma-4 python -m dflash.run \ --model google/gemma-4-27b \ --draft-model dflash/draft-gemma4-27b \ --block-size 8

MLX 后端（Apple Silicon）

# 安装 MLX 依赖 pip install mlx-lm # 使用 MLX 后端加速 python -m dflash.run \ --model mlx-community/Qwen3.5-32B-4bit \ --draft-model dflash/draft-qwen3.5-32b \ --backend mlx

SGLang 后端

# 安装 SGLang pip install sglang[all] # 使用 SGLang 后端 python -m dflash.run \ --model Qwen/Qwen3.5-32B \ --draft-model dflash/draft-qwen3.5-32b \ --backend sglang

关键参数

  • --block-size：每次生成的草稿 token 数量（推荐 5-10）
  • --draft-model：块扩散草稿模型路径（项目提供预训练模型）
  • --backend：推理后端（vllm / sglang / transformers / mlx）
