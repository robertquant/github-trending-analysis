项目简介

OpenHuman 是由 TinyHumans AI Lab（创始人 Steven Enamakel）开发的开源桌面 AI 助手。其核心理念是打造一个完全私有、运行在本地的个人 AI 超级智能。与其他需要终端配置的 Agent 不同，OpenHuman 提供简洁的桌面 UI，几分钟内即可从安装到使用。它通过 Memory Tree 技术自动构建你的个人知识图谱，集成 118+ 第三方服务（Gmail、Notion、GitHub、Slack 等），每 20 分钟自动同步数据到本地 Obsidian 知识库，让 AI Agent 在几分钟内就拥有你的完整上下文——而不是几周。

Rust 桌面应用 118+ 集成 Memory Tree Obsidian 知识库 TokenJuice 压缩 本地隐私优先 语音 + Mascot
六大核心能力
🧠
Memory Tree + Obsidian Wiki
灵感来自 Karpathy 的 obsidian-wiki 工作流。所有连接的数据被规范化为 ≤3k token 的 Markdown 块，分层摘要存储在本地 SQLite 中，同时生成 Obsidian 兼容的 .md 知识库。几分钟内，Agent 就拥有你的完整上下文。
🔌
118+ 一键 OAuth 集成
Gmail、Notion、GitHub、Slack、Stripe、Calendar、Drive、Linear、Jira 等 118+ 服务，一键 OAuth 连接。每个连接自动暴露为类型化工具给 Agent 使用，无需手动配置 API Key。
🔄
20 分钟自动同步 (Auto-fetch)
每 20 分钟自动遍历所有活跃连接，拉取最新数据到 Memory Tree。无需手动触发、无需写轮询脚本——Agent 在你早上醒来前就已经有了今天的上下文。
⚡
TokenJuice 智能压缩
每个工具调用、网页抓取、邮件内容都经过 token 压缩层处理。HTML→Markdown、URL 缩短、非 ASCII 字符清理……同样的信息，最高节省 80% 的 token 消耗和成本。
🎙️
原生语音 + 桌面吉祥物
Agent 有一个桌面吉祥物，能说话、反应环境变化，甚至作为真实参与者加入你的 Google Meet。STT 语音输入 + ElevenLabs TTS 语音输出 + 唇形同步，后台持续思考。
🛡️
本地隐私 + 模型路由
所有工作流数据保存在本地设备，本地加密。内置模型路由自动将推理任务、快速任务、视觉任务分发到合适的 LLM。可选 Ollama 本地模型完全离线运行。

应用场景

开发者个人助手
连接 GitHub、Notion、Slack，自动同步代码仓库和文档。Agent 了解你的项目上下文，帮你写代码、Review PR、管理 Issue，甚至参与 Google Meet 会议做笔记。
📊
知识工作者
Gmail + Calendar + Drive + Notion 一键连接，Memory Tree 自动构建个人知识库。Obsidian 可视化浏览所有邮件、文档、日程摘要，AI 随时调用你的完整上下文。
🔒
隐私敏感用户
所有数据本地存储加密，可选 Ollama 完全离线运行。不信任云端 AI 处理敏感数据的用户——律师、医生、金融从业者——OpenHuman 让 AI 能力完全在本地运行。
🎯
团队协作
集成 Jira、Linear、Slack、Stripe 等 118+ 工具，自动同步团队数据。Agent 跨服务理解上下文，帮你追踪项目进度、生成报告、安排日程。
为什么 Trending？
痛点直击
现有 AI 助手（Claude Desktop、ChatGPT）每次对话都从零开始，需要几周才能了解你的工作上下文。OpenHuman 通过 Memory Tree + 20 分钟自动同步，在几分钟内就让 Agent 拥有你的完整知识图谱。
隐私趋势
2026 年用户对云端 AI 处理个人数据的隐私担忧日益增长。OpenHuman 的100% 本地运行 + 端侧加密直击这一趋势，获得隐私敏感用户的高度关注。
Rust 性能优势
用 Rust 构建桌面 AI 应用在 GitHub 上相对罕见。Rust 的内存安全 + 高性能为本地 Agent 提供了理想的运行时基础，吸引了大量 Rust 社区开发者关注。
Karpathy 效应
灵感来自 Karpathy 的 obsidian-wiki 和 LLM Knowledgebase 思路，这种"用 LLM 理解你自己"的理念在技术社区极具共鸣。
产品体验突出
UI-first 设计，桌面吉祥物，Google Meet 参与者，语音交互……相比终端优先的 Agent 框架，OpenHuman 的产品化程度远超同类。
