项目简介与核心功能

Medusa 是一个开源的无头（Headless）电商平台，被誉为"开源版 Shopify"。它提供了构建数字商务所需的全部基础模块，同时赋予开发者 100% 的代码和数据所有权。

与 SaaS 电商平台不同，Medusa 采用模块化无头架构，将后端与前端正交分离，开发者可自由选择 Next.js、Remix、Gatsby 等任何前端框架构建店面。

核心功能模块

  • 产品管理 — 支持多品类、多变体、多仓库的产品目录
  • 购物车与结账 — 灵活的购物车引擎，支持自定义结账流程
  • 订单管理 — 完整的订单生命周期管理，含退货、换货、索赔
  • 支付集成 — 内置 Stripe、PayPal 等支付网关，可扩展自定义支付
  • 配送物流 — 多仓库、多承运商支持，含实时费率计算
  • 促销与折扣 — 灵活的促销规则引擎（百分比/固定/买赠）
  • 多货币/多语言 — 原生国际化支持
  • B2B 功能 — 企业定价、批量订单、公司账户管理
  • Workflows — 声明式业务编排引擎，构建复杂业务逻辑
  • Admin Dashboard — 全新的现代化管理后台

快速上手指南

1. 创建项目

npx create-medusa-app@latest # 按提示选择项目名称、数据库等 # 自动安装后端 + Admin Dashboard + Next.js 店面

2. 启动开发服务

cd my-medusa-store npm run dev # 后端运行在 http://localhost:9000 # Admin 运行在 http://localhost:7001 # 店面运行在 http://localhost:8000

3. 配置数据库

# .env 文件 DATABASE_URL=postgres://user:password@localhost:5432/medusa REDIS_URL=redis://localhost:6379

4. 添加支付模块

npm install @medusajs/payment-stripe # 在 medusa-config.ts 中配置 Stripe 模块

5. 自定义产品 Workflows

// src/workflows/custom-create-product.ts import { createWorkflow, WorkflowResponse } from "@medusajs/framework/workflows-sdk" import { createProductStep } from "./steps/create-product" export const customCreateProductWorkflow = createWorkflow( "custom-create-product", (input) => { const product = createProductStep(input) return new WorkflowResponse(product) } )

6. 部署上线

# 方式一：Medusa Cloud（推荐） medusa cloud deploy # 方式二：Docker 自部署 docker compose up -d # 方式三：Vercel (店面) + Railway/Render (后端)
