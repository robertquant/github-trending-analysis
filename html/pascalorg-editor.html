📋 项目简介与核心功能

Pascal Editor 是一个完全运行在浏览器中的 3D 建筑编辑器，允许用户创建、编辑和分享 3D 建筑模型。它基于 React Three Fiber 和 WebGPU 构建，提供了一种轻量级、零安装的替代方案来替代 AutoCAD、Revit 等传统建筑软件。

  • 3D 建筑建模 — 支持墙体、楼板、天花板、屋顶等建筑元素的创建和编辑
  • 门窗放置 — 通过 CSG 布尔运算自动在墙体上切割门窗洞口
  • 多楼层管理 — 支持多层建筑，提供堆叠/展开/单独查看等多种视图模式
  • 区域划分 — 支持建筑内部空间的分区管理
  • 3D 扫描参考 — 可导入 3D 扫描数据作为设计参考
  • 项目分享 — 支持在线创建和分享建筑项目
  • 撤销/重做 — 内置 50 步历史记录，支持操作回溯
  • 数据持久化 — 自动保存到 IndexedDB

🏗️ 技术架构与特点

项目采用 Turborepo monorepo 架构，分为三个核心包，职责清晰分离：

editor-v2/ ├── apps/ │ └── editor/ # Next.js 应用（UI、工具、编辑器行为） ├── packages/ │ ├── core/ # 数据模式、状态管理、几何生成系统 │ └── viewer/ # 3D 渲染组件

核心架构亮点：

  • 节点系统 — 所有建筑元素以扁平字典存储，通过 parentId 构建层级树（Site → Building → Level → Wall/Slab/Zone...）
  • 脏标记机制 — 节点变更时标记为 dirty，系统仅在渲染帧中处理脏节点，性能高效
  • 场景注册表 — 将节点 ID 映射到 Three.js 对象，无需遍历场景图即可快速查找
  • CSG 布尔运算 — 使用 three-bvh-csg 在墙体上精确切割门窗洞口
  • 空间网格管理器 — 处理碰撞检测和放置验证
  • 三层状态管理 — useScene（场景数据）、useViewer（查看器状态）、useEditor（编辑器状态）各自独立

数据流：

用户操作 → Tool Handler → useScene.createNode/updateNode
  → 节点更新 & 标记 dirty → React 重渲染 NodeRenderer
  → useRegistry 注册 3D 对象 → System 检测 dirty 节点
  → 更新几何体 → 清除 dirty 标记

🔥 为什么火（Trending 原因）

  • 填补市场空白 — 浏览器端 3D 建筑编辑器几乎没有高质量开源方案，Pascal Editor 直接对标 AutoCAD/Revit
  • 技术前沿 — 采用 WebGPU 渲染器 + React Three Fiber，代表了 Web 3D 的最新技术方向
  • 架构优秀 — monorepo 分包、脏标记系统、CSG 布尔运算等设计展现了极高的工程质量
  • 零门槛使用 — 无需安装任何软件，打开浏览器即可使用
  • 社交媒体传播 — Facebook、Instagram、YouTube、Threads 等平台广泛传播演示视频
  • 开源免费 — MIT 协议，对比商业软件数千美元的年费，吸引力巨大
  • 活跃更新 — 2026年4月刚发布 v3.51.0，持续迭代新功能

🚀 快速上手指南

1

克隆仓库

git clone https://github.com/pascalorg/editor.git
cd editor
2

安装依赖（需要 Bun）

bun install
3

启动开发服务器

bun dev

自动构建 @pascal-app/core 和 @pascal-app/viewer，并启动 Next.js 编辑器开发服务器。打开 http://localhost:3000 即可使用。

4

生产构建

turbo build

前提条件：需要安装 Bun 运行时和支持 WebGPU 的浏览器（Chrome 113+）。
