📖 项目简介与核心功能

CodeGraph 是一个为 Claude Code 设计的本地代码知识图谱系统。它通过 tree-sitter 解析源代码，提取符号（函数、类、方法）和关系（调用、导入、继承），构建一个 SQLite 驱动的知识图谱，以 MCP 服务器形式为 Claude Code 提供"即时代码理解"能力。

核心功能

  • 智能上下文构建 — 一次工具调用返回入口点、相关符号和代码片段，无需昂贵的探索代理
  • 全文搜索 — 基于 FTS5 的即时符号搜索，跨整个代码库查找
  • 影响分析 — 追踪调用者、被调用者和符号的完整影响范围
  • 实时同步 — 文件监视器使用原生 OS 事件，防抖自动同步，零配置
  • 框架感知路由 — 识别 13+ Web 框架的路由文件并链接 URL 到处理器
  • CI 集成 — codegraph affected 命令追踪变更影响的测试文件
tree-sitter 解析 SQLite + FTS5 MCP 协议 文件监视 跨语言 增量索引 零配置

工作流程（4 步）

  • 1. 提取 — tree-sitter 将源代码解析为 AST，语言特定的查询提取节点和边
  • 2. 存储 — 所有数据存入本地 SQLite 数据库（.codegraph/codegraph.db），使用 FTS5 全文搜索
  • 3. 解析 — 解析引用关系：函数调用 → 定义、导入 → 源文件、类继承
  • 4. 自动同步 — MCP 服务器通过原生 OS 文件事件监视项目，增量同步，防抖 2 秒

技术亮点

  • tree-sitter 多语言解析 — 支持 19+ 编程语言，统一的 AST 提取管道
  • SQLite + FTS5 — 零依赖本地存储，毫秒级查询响应
  • MCP 协议集成 — 标准化的模型上下文协议，与 Claude Code 无缝对接
  • 原生文件监视 — FSEvents (macOS) / inotify (Linux) / ReadDirectoryChangesW (Windows)
  • 框架感知 — 自动识别 Django/Flask/FastAPI/Express/Spring/Rails 等 13 个框架的路由

🚀 快速上手指南

1. 一键安装

# 运行交互式安装器（自动配置 MCP 服务器 + 权限 + 全局指令） npx @colbymchenry/codegraph

2. 重启 Claude Code

# 重启 Claude Code 让 MCP 服务器加载 # 安装器已自动完成以下配置： # - ~/.claude.json 中添加 MCP 服务器配置 # - ~/.claude/settings.json 中设置权限白名单 # - ~/.claude/CLAUDE.md 中添加全局指令

3. 初始化项目

cd your-project codegraph init -i # 交互式初始化 + 索引构建

4. 开始使用

# Claude Code 会自动使用 CodeGraph 工具 # 当 .codegraph/ 目录存在时自动激活 # 也可使用 CLI 手动操作： codegraph status # 查看索引状态 codegraph search "auth" # 搜索符号 codegraph context "fix login bug" # 为任务构建上下文

5. CI 集成示例

#!/usr/bin/env bash AFFECTED=$(git diff --name-only HEAD | codegraph affected --stdin --quiet) if [ -n "$AFFECTED" ]; then npx vitest run $AFFECTED fi
