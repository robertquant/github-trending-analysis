关键技术创新

代理配置系统

48个针对不同场景优化的代理配置文件，包括全栈开发、API设计、数据库优化、安全审计、代码审查等。每个配置定义了代理的行为模式、技能集、约束条件和输出格式，实现"对场景用对代理"的精细化分工。

持续学习 v2

基于本能的学习系统，每次交互都会评估置信度并更新本能库。支持导入/导出学习成果，实现跨会话的知识进化。从"被动执行"进化为"主动学习"。

AgentShield 安全

在 Claude Code 黑客松上构建的安全审计器。1282个测试用例、102条安全规则、98%代码覆盖率。采用对抗性红蓝对抗方法，同时检测攻击和防御漏洞。

Rust 控制平面

v2.0 引入的 Rust 实现控制面板，负责状态同步、观察者生命周期管理和跨会话编排。为多代理协作提供高性能基础设施，alpha 阶段但架构已成型。

🚀 快速上手

# 方式一：npm 一键安装（推荐）
npx ecc-universal@latest

# 方式二：克隆仓库
git clone https://github.com/affaan-m/everything-claude-code.git
cd everything-claude-code
npm install
npm run setup

# 选择代理配置
ecc use agent fullstack        # 全栈开发代理
ecc use agent security       # 安全审计代理
ecc use agent data-engineer  # 数据工程代理

# 启用技能模块
ecc skill enable react-patterns
ecc skill enable python-testing

# 启动 Dashboard GUI (v2.0)
ecc dashboard

# 运行安全审计
ecc shield scan ./src
