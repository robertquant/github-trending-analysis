📚 项目简介与核心功能

knowledge-work-plugins 是 Anthropic 官方开源的插件仓库，专门为 Claude Cowork（Anthropic 的智能办公桌面应用）构建。它提供了 11 个开箱即用的职业插件，覆盖销售、法务、财务、市场、产品、数据、客服等多个核心业务领域。

核心功能

  • 角色专精：每个插件将 Claude 转变为特定岗位的专家（如销售代表、财务分析师、法律顾问）
  • Skill + Command + Connector 三位一体：自动触发的技能、显式调用的斜杠命令、外部工具连接器
  • 零代码定制：所有组件均为 Markdown/JSON 文件，无需编码、无需基础设施、无需构建步骤
  • 企业级连接器：内置对 Slack、Notion、HubSpot、Jira、Snowflake 等 50+ 工具的原生支持
  • Claude Code 兼容：不仅限于 Cowork，同样可在 Claude Code 终端中使用

⚙ 技术架构与特点

插件结构

plugin-name/ ├── .claude-plugin/plugin.json # 插件清单 (Manifest) ├── .mcp.json # 工具连接 (Connectors) ├── commands/ # 斜杠命令 (Slash Commands) └── skills/ # 领域知识 (Skills, 自动激活)

三层架构

  • Skills（技能层）：编码领域专业知识、最佳实践、工作流程。Claude 在相关场景自动调用，无需显式触发
  • Commands（命令层）：用户显式触发的动作，如 /finance:reconciliation、/data:write-query
  • Connectors（连接层）：通过 MCP（Model Context Protocol）协议连接外部工具 —— CRM、项目管理、数据仓库等

技术亮点

  • 纯文件驱动：Markdown + JSON，零代码门槛，任何人都能创建和定制插件
  • MCP 协议标准：基于 Anthropic 2025 年 12 月发布的开放标准，统一 AI 与工具的交互方式
  • 热插拔设计：安装即生效，Skills 自动匹配场景，Commands 立即可用
  • 企业可定制：替换连接器、添加公司术语、调整工作流，打造专属 AI 助手

🎯 应用场景

  • 销售团队：用 /sales:call-prep 自动准备客户通话要点，结合 HubSpot 数据生成竞品战卡
  • 财务部门：自动化月度对账流程，/finance:reconciliation 从 Snowflake 拉取数据并生成差异报告
  • 产品经理：从 Figma 设计稿和 Amplitude 数据自动生成 PRD，跟踪竞品动态
  • 法务团队：批量审查 NDA，自动标记风险条款，生成模板回复
  • 数据分析师：自然语言写 SQL 查询 BigQuery，自动生成可视化仪表板
  • 生物医药研发：检索 PubMed 文献、分析基因组数据、加速靶点发现
  • IT 管理：跨 Slack/Notion/Jira 全局搜索企业知识，一键定位信息
