📖 项目简介

DreamServer 是由 Light Heart Labs（创始人 Michael Bradley）打造的一站式本地AI平台。它的核心使命是让AI成为"主权人权"而非租用服务 — 用户在自己的硬件上运行完整的AI能力栈，无需云服务，无需订阅，无人监视。

项目口号"Five Companies Control AI. We're Taking It Back."（五家公司控制了AI，我们要夺回它）精准概括了其定位 — 对抗AI集中化，赋予个人完整的AI自主权。

🏗️ 技术架构与特点

架构设计

DreamServer 采用Docker Compose编排的微服务架构，每个服务作为独立扩展运行。安装器（DREAMGATE）采用6库13阶段的模块化设计，自动完成GPU检测、模型选择、凭证生成和服务编排。

# 一键安装命令 curl -fsSL https://raw.githubusercontent.com/Light-Heart-Labs/DreamServer/main/dream-server/get-dream-server.sh | bash

硬件自动检测

安装器自动检测GPU硬件并选择最优模型，覆盖全平台：

平台 支持范围 GPU后端
NVIDIA RTX 3060 ~ H100（0-5级） CUDA
AMD Strix Halo 64GB / 96GB 统一内存 ROCm
Apple Silicon M1 ~ M4 Ultra（0-4级） Metal
Intel Arc A380 ~ A770（2级） SYCL
CPU / 无GPU 任意硬件 Cloud模式回退

Bootstrap 模式

独创的引导模式：先下载1.5B小模型（不到1分钟），用户立即开始聊天，完整模型在后台下载，就绪后零停机热切换。

dream-cli 命令行工具

dream status # 健康检查 + GPU状态 dream list # 所有服务状态 dream mode cloud # 切换到云端API模式 dream mode local # 切回本地推理 dream mode hybrid # 本地主、云端备 dream model swap T3 # 切换硬件层级 dream enable n8n # 启用扩展 dream preset save gaming # 保存配置快照
