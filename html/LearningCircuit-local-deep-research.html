🎯 项目概览

什么是 Local Deep Research？

Local Deep Research（LDR）是一个完全本地运行的 AI 研究助手，由 LearningCircuit 团队开发。它的核心理念是：你拥有自己的数据，你看到它如何工作。用户可以用自然语言提出复杂问题，LDR 会自动搜索网络、学术论文和个人文档库，综合生成带引用的研究报告。

项目支持 20+ 研究策略，从快速摘要（30秒-3分钟）到深度分析报告（10-30分钟），覆盖从即时问答到学术研究的全场景。独特的知识库构建功能让每次研究的来源自动归档、索引，形成可复用的个人知识资产。

✨ 核心特性

🔍

多模式研究

快速摘要（30秒-3分钟）、深度分析、正式报告生成、个人文档搜索，20+ 研究策略灵活选择。

🤖

LangGraph Agent

自主式研究代理模式，LLM 自行决定搜索什么、使用哪个专业引擎（arXiv/PubMed/Semantic Scholar），以及何时综合结论。

📚

知识库构建

每次研究的来源自动下载到加密库中，提取文本、建立索引、支持搜索。知识随时间不断积累复利。

🔒

零遥测隐私

不收集、不传输、不存储任何用户数据。无分析 SDK、无回拨、无崩溃报告。网络请求仅由用户主动发起。

🔌

MCP 集成

通过 Model Context Protocol 与 Claude Desktop/Code 深度集成。8 个 MCP 工具覆盖搜索、研究、报告、文档分析等全部能力。

📊

期刊质量系统

自动评估期刊声誉，覆盖 212K+ 索引来源，包含掠夺性期刊检测。基于 OpenAlex、DOAJ 等权威数据源。

📰

研究订阅

订阅特定主题，定期接收 AI 驱动的研究摘要。支持日/周/自定义频率，智能过滤和总结最相关的发展。

🛡️

🔥 热门原因分析

  1. 隐私优先的时代需求 在数据隐私日益受关注的大环境下，LDR 的零遥测、零追踪、本地加密架构精准击中了用户痛点。记者、研究人员、企业敏感部门可以在不泄露查询的情况下进行深度研究。
  2. SimpleQA ~95% 准确率的硬实力 与 GPT Researcher 等 SOTA 系统相当的准确率，证明了本地化不意味着妥协性能。这一数据成为项目最有力的背书，在 r/LocalLLaMA 社区引发广泛讨论。
  3. LLM 无绑定策略 支持所有主流 LLM（Ollama、LM Studio、llama.cpp、OpenAI、Anthropic、Google、OpenRouter 100+ 模型），用户不被锁定在任何单一供应商。完全自主选择本地或云端。
  4. MCP 生态集成的前瞻性 作为首批提供完整 MCP Server 的研究工具，8 个 MCP 工具让 Claude Desktop/Code 用户可以无缝调用深度研究能力，抓住了 AI 工具链整合的浪潮。
  5. 知识复利效应 独特的知识库构建功能让每次研究自动归档来源、建立索引。研究不再是一次性的，而是持续积累的个人知识资产。这一"研究 → 下载 → 索引 → 再研究"的闭环极具吸引力。
  6. 国际化的社区传播 覆盖中文（掘金、知乎、CSDN、GitHubDaily）、日文（note.com、Qiita）、韩文（PyTorch Korea）、法文（Korben.info）等多个语言社区。LangChain 官方在 Twitter/LinkedIn 推广。Hacker News 190+ points 讨论。

🚀 快速开始

方式一：Docker Compose（推荐）

# CPU 版本（全平台） curl -O https://raw.githubusercontent.com/LearningCircuit/local-deep-research/main/docker-compose.yml docker compose up -d # GPU 版本（Linux + NVIDIA） curl -O https://raw.githubusercontent.com/LearningCircuit/local-deep-research/main/docker-compose.yml curl -O https://raw.githubusercontent.com/LearningCircuit/local-deep-research/main/docker-compose.gpu.override.yml docker compose -f docker-compose.yml -f docker-compose.gpu.override.yml up -d # 访问 http://localhost:5000

方式二：pip 安装

# 基础安装（含 SQLCipher 加密） pip install local-deep-research # MCP 支持（Claude Desktop 集成） pip install "local-deep-research[mcp]"

方式三：Python API

from local_deep_research.api import LDRClient, quick_query # 一行研究 summary = quick_query("username", "password", "量子计算最新进展") print(summary) # 客户端模式 client = LDRClient() client.login("username", "password") result = client.quick_research("量子计算有哪些实际应用？") print(result["summary"])

Claude Desktop MCP 配置

# claude_desktop_config.json { "mcpServers": { "local-deep-research": { "command": "ldr-mcp", "env": { "LDR_LLM_PROVIDER": "openai", "LDR_LLM_OPENAI_API_KEY": "sk-..." } } } }
