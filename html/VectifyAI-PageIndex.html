1. 项目简介与核心功能

PageIndex 是由 VectifyAI 开发的下一代 RAG（Retrieval-Augmented Generation）系统。它打破了传统向量数据库检索的范式，提出了一种无向量（Vectorless）、基于推理（Reasoning-based）的全新文档检索方法。

🎯 核心理念：相似性 ≠ 相关性

传统 RAG 依赖语义相似性进行检索，但在专业文档（金融报告、法律文件等）中，真正需要的是相关性，而获取相关性需要推理能力。PageIndex 正是为此而生。

✨ 核心功能

  • 无向量数据库：不使用任何向量数据库，通过文档结构和 LLM 推理进行检索
  • 无需分块（No Chunking）：文档按自然段落组织，无需人为切割
  • 类人检索：模拟人类专家浏览复杂文档的方式
  • 可解释、可追溯：检索基于推理路径，提供页码和章节引用
  • FinanceBench SOTA：在金融文档问答基准上达到 98.7% 准确率
  • 大规模扩展：通过 PageIndex File System 支持百万级文档

2. 技术架构与特点

🌲 树状索引结构

PageIndex 将 PDF 文档转换为类似「目录」的语义树结构，但专门针对 LLM 优化。工作流程分两步：

1生成树索引：从 PDF 中提取层级结构，构建「类目录」树
2推理式检索：LLM 沿树结构逐层推理，定位最相关的文档段落

🏗️ 技术栈

  • 语言：Python
  • LLM 接口：通过 LiteLLM 支持多模型（GPT-4o、Claude 等）
  • PDF 解析：标准 PDF 解析（开源版）/ 增强 OCR（云服务版）
  • Agent 集成：支持 OpenAI Agents SDK
  • 部署方式：本地自托管 / 云 API / MCP / 企业私有部署
  • 文件支持：PDF + Markdown

🧠 灵感来源：AlphaGo

PageIndex 的树搜索机制受到 AlphaGo 的启发——通过树搜索 + 推理来找到最优路径，而非简单的相似度匹配。这使检索过程更像人类专家的阅读和判断。
