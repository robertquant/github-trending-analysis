📋 项目简介与核心功能

microsoft/ai-agents-for-beginners 是微软官方推出的 AI Agent 入门课程，旨在帮助开发者从零开始学习构建 AI 智能体（Agent）。该项目是微软 "For Beginners" 系列课程的最新成员，与 ML for Beginners、Generative AI for Beginners 等经典课程一脉相承。

课程最初发布时包含 12 个课时，后逐步扩展至 18 个课时，涵盖了从基础概念到生产部署的完整知识体系。

核心特色：

  • 每课包含 文字教程 + 短视频 + Python 代码示例 + 扩展学习链接
  • 基于 Microsoft Agent Framework (MAF) 和 Azure AI Foundry Agent Service V2
  • 支持 50+ 种语言翻译（含简体中文、繁体中文）
  • 配套 Discord 社区支持和 GitHub Discussion

🏗️ 技术架构与特点

核心技术栈：

  • Microsoft Agent Framework (MAF) — 微软自研的 Agent 开发框架，提供统一的 Agent 构建抽象
  • Azure AI Foundry Agent Service V2 — Azure 云端的托管 Agent 服务，支持模型部署和工具集成
  • Python — 所有代码示例均使用 Python 编写
  • MCP / A2A / NLWeb — 涵盖最新的 Agentic 协议标准

架构特点：

  • 渐进式学习路径 — 从单 Agent 基础概念到多 Agent 协作，层层递进
  • 设计模式驱动 — 重点讲解 Tool Use、Planning、Multi-Agent、Metacognition 四大设计模式
  • 生产就绪导向 — 包含"AI Agents in Production"和"Securing AI Agents"等实战课程
  • 多提供商支持 — 除 Azure 外，部分代码也支持 OpenAI 兼容提供商（如 MiniMax）
  • 自动化翻译管线 — 通过 GitHub Action 自动维护 50+ 语言的翻译同步

🎯 应用场景

  • 企业自动化 — 构建 RAG 智能客服、文档处理 Agent、工作流自动化
  • 数据分析 — 多 Agent 协作完成复杂数据分析和报告生成
  • 代码辅助 — 基于 Tool Use 模式构建代码审查、测试生成 Agent
  • 计算机操作 — Computer Use Agent (CUA) 课程教授如何构建桌面/浏览器自动化 Agent
  • 教育与研究 — 高校和培训机构用作 AI Agent 入门教材
  • 个人学习 — 开发者系统性学习 AI Agent 从入门到生产化的完整知识链

🚀 快速上手指南

1. 克隆仓库（推荐 sparse checkout，避免下载大量翻译文件）：

git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git cd ai-agents-for-beginners git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'

2. 配置 Azure AI Foundry：

  • 注册 Azure 账户
  • 创建 Azure AI Foundry 资源
  • 获取 API Key 和 Endpoint

3. 配置环境变量：

export AZURE_AI_ENDPOINT="https://your-resource.services.ai.azure.com/api" export AZURE_AI_API_KEY="your-api-key" export MODEL_DEPLOYMENT_NAME="your-model-deployment"

4. 运行第一课代码：

cd code_samples/01-intro-to-ai-agents pip install -r requirements.txt python main.py

5. 按顺序学习课程： 每课约 30-60 分钟，包含阅读 + 视频 + 实践。
