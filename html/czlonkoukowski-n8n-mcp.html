⚙️核心功能

n8n-mcp 提供从节点查询到工作流部署的完整工具链

📖

节点知识库

覆盖 1,650 个 n8n 节点（820 核心 + 830 社区），99% 属性覆盖率，87% 文档覆盖率，包含 265 个 AI 工具变体。

🔍

智能搜索

支持关键词、节点类型、任务类型、元数据多维度搜索 2,352+ 工作流模板和 156 个真实配置示例。

✅

多级验证

从快速必填检查到完整工作流验证的四级验证体系，确保生成的配置在运行时万无一失。

🚀

直接部署

通过 n8n API 直接在工作流实例中创建、更新、测试和部署工作流，支持 Diff-based 部分更新节省 Token。

🤖

Chat Agent

零配置在线版本，一句话描述需求即可生成工作流，从 72,000+ 模式库中匹配并自动部署。

🔧

自动修复

自动检测和修复常见工作流错误，包括连接缺失、表达式语法错误、参数配置不当等问题。

claude_desktop_config.json 
// 在 Claude Desktop 配置文件中添加：
{
  "mcpServers": {
    "n8n-mcp": {
      "command": "npx",
      "args": ["-y", "n8n-mcp@latest"]
    }
  }
}
Terminal 
# 一行命令添加到 Claude Code
$ claude mcp add n8n-mcp -- npx -y n8n-mcp@latest

# 连接 n8n 实例（可选）
$ claude mcp add n8n-mcp -- npx -y n8n-mcp@latest \
    -e N8N_API_URL=http://localhost:5678 \
    -e N8N_API_KEY=your-api-key
.cursor/mcp.json 或 VS Code settings 
{
  "mcp": {
    "servers": {
      "n8n-mcp": {
        "command": "npx",
        "args": ["-y", "n8n-mcp@latest"]
      }
    }
  }
}
Terminal 
# 使用 Docker 运行
$ docker run -i --rm ghcr.io/czlonkowski/n8n-mcp

# 带环境变量的完整配置
$ docker run -i --rm \
    -e N8N_API_URL=http://host.docker.internal:5678 \
    -e N8N_API_KEY=your-api-key \
    ghcr.io/czlonkowski/n8n-mcp
零配置方案 
🌐 访问 dashboard.n8n-mcp.com

1. 注册免费账户（无需信用卡）
2. 获取 API Key
3. 连接 MCP 客户端或直接使用 Chat Agent

免费额度：
  - Chat Agent: 每天 5 次提示
  - MCP 工具: 每天 100 次调用
⚠️

安全提示：永远不要让 AI 直接编辑生产环境工作流！始终在开发环境测试，并备份重要工作流。
