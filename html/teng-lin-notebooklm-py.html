📖 项目简介与核心功能

notebooklm-py 是由 teng-lin 开发的非官方 Python 库，通过逆向工程 Google NotebookLM 的未公开 RPC API，为开发者提供 完整的编程接口 来操控 NotebookLM 的所有功能。

核心亮点：不仅实现了 Web UI 的全部功能，更暴露了 Web UI 不具备的高级能力，如批量下载、结构化导出、PPTX 幻灯片、思维导图 JSON 提取等。

🏗️ 技术架构与特点

  • 逆向工程 API：通过捕获和分析 NotebookLM 的内部 RPC 调用，实现了对未公开接口的完整封装
  • 异步架构：基于 asyncio 的异步设计，支持高效并发操作
  • 认证机制：通过 Playwright 浏览器自动化获取 Google 认证 Cookie，支持多账户切换和浏览器 Cookie 导入
  • 三端统一：Python API / CLI / Agent Skill 共享同一核心引擎
  • 跨平台：macOS（主要开发平台）、Linux、Windows 全支持，CI 全平台测试
  • Agent 技能生态：内置 Claude Code Skill、Codex AGENTS.md、npx skills 发现支持
# 核心架构概览
import asyncio
from notebooklm import NotebookLMClient

async def main():
    async with await NotebookLMClient.from_storage() as client:
        nb = await client.notebooks.create("Research")
        await client.sources.add_url(nb.id, "https://example.com")
        result = await client.chat.ask(nb.id, "Summarize this")
        await client.artifacts.generate_audio(nb.id)

asyncio.run(main())

🚀 快速上手指南

安装库与浏览器 
# 安装核心库 + Playwright
pip install "notebooklm-py[browser]"
playwright install chromium
登录 Google 账户 
# 打开浏览器进行 Google 登录
notebooklm login

# 验证认证状态
notebooklm auth check --test --json
创建笔记本并添加来源 
notebooklm create "My Research"
notebooklm use <notebook_id>
notebooklm source add "https://en.wikipedia.org/wiki/Artificial_intelligence"
notebooklm source add "./paper.pdf"
对话与生成内容 
# 与来源对话
notebooklm ask "What are the key themes?"

# 生成播客音频
notebooklm generate audio "make it engaging" --wait

# 生成测验
notebooklm generate quiz --difficulty hard

# 生成思维导图
notebooklm generate mind-map
下载生成的制品 
notebooklm download audio ./podcast.mp3
notebooklm download quiz --format markdown ./quiz.md
notebooklm download mind-map ./mindmap.json
