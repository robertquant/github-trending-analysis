📚Project Overview

K-Dense-AI/scientific-agent-skills is a comprehensive collection of 135 ready-to-use scientific and research skills for AI coding agents. It transforms any compatible AI agent (Cursor, Claude Code, Codex, Gemini CLI) into a powerful "AI Scientist" capable of executing complex multi-step scientific workflows across biology, chemistry, medicine, physics, engineering, and beyond.

Core Value Proposition: Instead of spending days configuring environments and reading API docs, researchers can install these skills once and immediately ask their AI agent to execute end-to-end scientific pipelines—from drug discovery to genomics to clinical research—with a single natural language prompt.

⚡Core Features

  • 135 Scientific Skills — Covering bioinformatics, cheminformatics, drug discovery, proteomics, clinical research, ML/AI, materials science, physics, engineering, geospatial science, lab automation, and scientific communication
  • 100+ Database Access — Unified access to PubChem, ChEMBL, UniProt, COSMIC, ClinicalTrials.gov, FRED, USPTO, KEGG, Reactome, STRING, and 70+ more scientific databases
  • 70+ Optimized Python Package Skills — Curated documentation and examples for RDKit, Scanpy, PyTorch Lightning, scikit-learn, BioPython, PennyLane, Qiskit, OpenMM, TimesFM, and more
  • Open Agent Skills Standard — Works with Cursor, Claude Code, Codex, Gemini CLI, and any agent supporting the standard
  • Security-Scanned — Weekly scans via Cisco AI Defense Skill Scanner; includes behavioral analysis
  • BYOK Desktop App — K-Dense BYOK: free, open-source AI co-scientist running locally with 40+ model support

🏗Technical Architecture

The project follows the Agent Skills Standard specification, where each skill is a self-contained folder with a SKILL.md file defining metadata, documentation, code examples, and best practices.
