📄 项目简介与核心功能

Paperless-ngx 是一个社区驱动的开源文档管理系统（DMS），能够将你的纸质文档转化为可搜索的在线档案——正如其名，less paper（少纸化）。

它是原版 Paperless 和 Paperless-ng 项目的官方继任者，由一个活跃的社区团队持续维护和推进开发。

OCR 光学字符识别 全文搜索 自动分类与标签 AI 增强元数据提取 多语言支持（Crowdin） Docker 一键部署 移动端友好 权限管理 自定义工作流 共享链接（可设过期时间）

架构亮点：

  • 前后端分离架构，Django REST API + Angular SPA
  • Celery 异步任务处理文档消费管道（OCR → 分类 → 索引）
  • 插件化的 AI 后端，支持 OpenAI、Azure、本地 Ollama 等
  • 完善的权限系统（多用户 + 组 + 角色控制）
  • Webhook 和 API 支持与外部系统集成

🎯 应用场景

  • 个人/家庭文档管理：银行对账单、税务文件、保险单、收据、合同等纸质文档的数字化归档
  • 小型企业文档管理：发票管理、合同归档、人事档案，替代昂贵的商业 DMS
  • HomeLab 爱好者：与 Nextcloud、Immich 等自托管服务组成完整的个人云方案
  • 合规与审计：需要长期保存和快速检索文档的场景
  • 无纸化办公：配合网络扫描仪实现自动文档摄取和分类

🚀 快速上手指南

一键安装（推荐）：

# 官方安装脚本，自动配置 Docker Compose 环境
bash -c "$(curl -L https://raw.githubusercontent.com/paperless-ngx/paperless-ngx/main/install-paperless-ngx.sh)"

手动 Docker Compose 部署：

# 1. 克隆仓库
git clone https://github.com/paperless-ngx/paperless-ngx.git
cd paperless-ngx/docker/compose

# 2. 复制配置文件并修改
cp docker-compose.env.example docker-compose.env
cp .env.example .env

nano docker-compose.env  # 编辑配置

# 3. 启动服务
docker compose up -d

从 Paperless-ng 迁移：

# 只需替换 Docker 镜像即可无缝升级
docker pull ghcr.io/paperless-ngx/paperless-ngx:latest
docker compose up -d
