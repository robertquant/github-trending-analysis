👁 项目简介与核心功能

roboflow/supervision 是由 Roboflow 团队开发的开源 Python 计算机视觉工具库，旨在为开发者提供可复用的 CV 后处理工具。它不负责模型训练或推理，而是专注于模型输出之后的所有工作：标注、可视化、追踪、区域计数、数据集管理等。

核心功能

🎨 丰富的标注器 (Annotators)
20+ 种可高度自定义的标注器：边界框、标签、热力图、轨迹线、模糊遮罩等，可自由组合构建完美可视化。
🚀 模型无关设计
支持 Ultralytics YOLO、Transformers、MMDetection、RF-DETR、Roboflow Inference 等主流检测/分割/分类模型的输出格式。
📡 视频追踪
内置 ByteTrack、BOT-SORT 等多目标追踪算法，支持跨帧目标跟踪、轨迹可视化、速度估算等高级功能。
📊 区域计数与分析
支持定义多边形区域进行进出计数、驻留时间分析、线段穿越检测，适用于零售、交通等场景。
🗃 数据集管理
支持 COCO、YOLO、Pascal VOC 等主流格式的加载、拆分、合并、转换和保存，一站式数据集处理。
💻 低代码 API
简洁直观的 Python API 设计，几行代码即可完成复杂的视觉任务管道搭建。

⚙ 技术架构与特点

Supervision 的核心设计理念是模型无关性和可组合性，其架构可以概括为以下几个层次：

1. 数据层 — sv.Detections / sv.Classifications

统一的检测/分类结果数据结构，无论底层使用什么模型，输出都标准化为同一格式。支持 from_ultralytics()、from_inference()、from_detectron2() 等多种转换方法。

2. 处理层 — Trackers / Filters / Utils

内置目标追踪器（ByteTrack、BOT-SORT）、检测过滤器（按类别、置信度、区域过滤）、几何变换工具（透视变换、坐标映射）等。

3. 可视化层 — Annotators

20+ 种可组合的标注器，每种都支持颜色、厚度、圆角等细节定制，可通过链式调用组合多种标注效果。

4. 数据集层 — DetectionDataset / ClassificationDataset

统一的 Dataset 抽象，支持惰性加载图片、数据集拆分/合并/过滤，以及 COCO/YOLO/VOC 格式之间的无损转换。

# 示例：完整的检测 + 追踪 + 区域计数管道 import supervision as sv from ultralytics import YOLO # 加载模型和视频 model = YOLO("yolov8n.pt") tracker = sv.ByteTrack() zone = sv.PolygonZone(polygon=[[...]]) annotator = sv.BoxAnnotator() zone_annotator = sv.PolygonZoneAnnotator(zone=zone) for frame in sv.get_video_frames_generator("input.mp4"): result = model(frame)[0] detections = sv.Detections.from_ultralytics(result) detections = tracker.update_with_detections(detections) zone.trigger(detections=detections) # 可视化 frame = annotator.annotate(frame, detections) frame = zone_annotator.annotate(frame)

🚀 快速上手指南

安装 Supervision

pip install supervision # 或带可选依赖 pip install supervision[assets]

加载模型并获取检测结果

import supervision as sv from PIL import Image from rfdetr import RFDETRSmall image = Image.open("photo.jpg") model = RFDETRSmall() detections = model.predict(image, threshold=0.5) print(len(detections)) # 输出检测到的目标数量

标注和可视化

import cv2 image = cv2.imread("photo.jpg") box_annotator = sv.BoxAnnotator() label_annotator = sv.LabelAnnotator() annotated = box_annotator.annotate( scene=image.copy(), detections=detections ) annotated = label_annotator.annotate( scene=annotated, detections=detections ) cv2.imwrite("result.jpg", annotated)

视频处理与追踪（进阶）

tracker = sv.ByteTrack() for frame in sv.get_video_frames_generator("video.mp4"): result = model.predict(frame) detections = tracker.update_with_detections(detections) # 添加追踪 ID 标注 labels = [f"#{tracker_id}" for tracker_id in detections.tracker_id] frame = label_annotator.annotate(frame, detections, labels)
