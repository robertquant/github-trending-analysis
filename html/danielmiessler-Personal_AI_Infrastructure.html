📋 项目简介

PAI (Personal AI Infrastructure) 是由知名安全研究员 Daniel Miessler 创建的开源项目，目前已发展到 v5.0.0，定位为「人生操作系统」(Life Operating System)。

PAI 的核心理念是：AI 应该为每个人赋能，而不仅仅是顶层的 1%。它不是一个简单的 AI 提示词集合，而是一套完整的个人 AI 基础设施——捕获你是谁、你在乎什么、你要去哪里，然后帮助你到达那里。

三层架构

🧠 PAI — 操作系统本身
包含技能系统、记忆、Algorithm 算法、Telos（目标体系）、身份文件等核心组件。
📡 Pulse — 人生仪表盘
运行在 localhost:31337 的统一守护进程，提供可视化面板、语音、Hook、定时任务等 22 个路由端点。
🤖 The DA — 数字助手
你的专属数字助手（Digital Assistant），拥有独立的身份、声音和人格，是你与 AI 交互的主要界面。

⚡ 核心功能与特点

🎯 理想状态驱动 (Ideal State Driven)

PAI 的哲学核心：AI 最大的未解决问题是「什么是好的/完成的」。PAI 通过 ISA (Ideal State Artifact) 来精确定义「完成状态」——类似软件 PRD，但适用于任何创造性任务。系统将理想状态分解为 ISC (Ideal State Criteria)，作为验证清单来逐步逼近目标。

🔄 Algorithm v6.3.0 — 七阶段循环

每个非平凡任务都经过这个科学方法式的循环：

OBSERVE → THINK → PLAN → BUILD → EXECUTE → VERIFY → LEARN

Sonnet 支持的模式分类器会根据复杂度自动选择 MINIMAL / NATIVE / ALGORITHM 模式和 E1-E5 层级。

📝 文本优先，无 RAG

重度偏好纯文本和 Markdown。自 2025 年 6 月起完全弃用 RAG，用富文本 + ripgrep 实现同等效果——无嵌入复杂度、无检索不稳定、无精度损失。

🧩 45 个技能 + 171 个工作流
技能是自激活的可组合域单元。层级：代码 → CLI → 工作流 → SKILL.md。代码包裹提示词，而非提示词包裹代码。
💾 记忆系统 v7.6
五层记忆：WORK（活跃任务）、KNOWLEDGE（知识图谱）、LEARNING（元模式）、RELATIONSHIP（DA-Principal 关系）、OBSERVABILITY（可观测性）。
🛡️ 结构化隐私
Containment Guard 在 PreToolUse 钩子中阻止跨区域泄露。12 道安全门在每次公开发布时运行。
🔊 37 个 Hook
覆盖 SessionStart、UserPromptSubmit、PreToolUse、PostToolUse、Stop、SubagentStop、PreCompact、SessionEnd 全生命周期。
🧠 思维技能库
第一性原理、委员会辩论、红队测试、根因分析、系统思维、迭代深化等高质量决策工具。
🔁 自我改进循环
捕获成功/失败信号（评分、情感、验证结果），持续优化系统表现——执行工作的系统也在变得更好。

组件 技术 说明

设计哲学

上下文脚手架 > 模型
AI 最常见的错误是不给模型全局上下文。PAI 是一个系统地为最强模型提供正确上下文的框架——模型不如它周围的上下文重要。
Bitter-Pilled 工程
随着模型变强，需要的指令越少。PAI 持续审计并删除过度指令——系统随模型增长而缩小。

🚀 快速上手指南

前置要求

  • Bun 运行时
  • Git
  • Claude Code CLI
  • （可选）ElevenLabs API Key — 用于语音功能

一键安装

curl -sSL https://ourpai.ai/install.sh | bash

安装器会自动完成：Bun/Git/Claude Code 验证 → ElevenLabs 密钥配置 → DA 身份向导（命名+声音+人格） → Pulse launchd 注册 → 验证。

安装后配置

# 打开人生仪表盘
open http://localhost:31337

# 在 Claude Code 中运行访谈（最关键的一步！）
/interview

访谈四阶段

1
TELOS — 使命、目标、信念、智慧、挑战、书籍、心智模型、叙事
2
IDEAL_STATE — 对你来说成功是什么样子？
3
Preferences — 工具、约定、工作风格
4
Identity — DA 人格最终调优

⚠️ 没有完成 TELOS，你的 DA 没有优化目标，这一步至关重要！
