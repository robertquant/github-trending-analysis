一、项目概述

iii（发音 "three eye"）是一个开源的实时服务编排引擎，其核心目标是让后端服务的组合、扩展和观测变得前所未有的简单。 项目由 iii-hq 团队开发，采用 Rust 编写引擎核心，提供 Node.js、Python、Rust 三种 SDK。

传统微服务架构中，每引入一个新的基础设施组件（队列、定时任务、HTTP 网关、可观测性工具），都需要独立集成、配置和运维。 iii 的理念是将这一切折叠到一个实时系统表面——通过统一的三个原语（Worker、Function、Trigger），让所有服务天生可组合、可观测。

核心理念：「Before iii」需要无数集成；「After iii」只需 iii worker add <anything>。 新的 Worker 加入后，自动进入实时目录，其他 Worker 立即可调用。这就是 iii 所称的「零集成」（Zero-Integration）范式。

二、技术架构

2.1 三大核心原语

⚙️
Worker
注册到 iii 引擎的进程。TypeScript API 服务、Python 数据管道、Rust 微服务都可以是 Worker。Worker 还可以在运行时创建其他 Worker。
⚡
Function
具有稳定标识符的工作单元（如 content::classify、orders::validate）。接收输入、执行工作、返回输出。
🔔
Trigger
触发函数执行的事件源。支持 HTTP 端点、Cron 定时、队列订阅、状态变更、流事件、直接调用等。声明式定义，iii 负责路由和序列化。

三、核心创新点

3.1 零集成范式（Zero-Integration）

传统微服务是「点对点集成」——每增加一个服务，需要配置 N 个连接。iii 提出了「共享运行时」的概念：所有 Worker 通过引擎的实时目录自动发现彼此，无需任何集成代码。

3.2 统一原语模型

Worker → Function → Trigger 三个原语覆盖了后端开发的所有场景。无论是 HTTP API、定时任务、消息队列还是流处理，都映射到同一套心智模型，极大降低了认知复杂度。

3.3 运行时自扩展

Worker 可以在运行时创建其他 Worker。这意味着 AI Agent 可以在运行过程中发现系统缺少某个能力，动态添加一个 Worker 来获得这个能力，然后立即调用它。这是 iii 在 AI Agent 集成方面的独特优势。

3.4 内建可观测性

所有通过 iii 注册的 Function 调用自动具有 Trace 和 Log，无需额外集成 OpenTelemetry 或类似工具。iii Console 提供实时可视化界面，开发者可以即时查看每个 Function 的执行状态。

3.5 极简 CLI
