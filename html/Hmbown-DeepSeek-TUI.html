Work Modes

三种工作模式

从审慎探索到全自动执行，按需选择

🔍

Plan 模式

只读探索模式。模型分析代码、提出方案，使用 update_plan 和 checklist_write 规划任务，不修改任何文件。适合代码审查和学习。

🤖

Agent 模式

默认交互模式。多步工具使用带审批门控，每步操作需要确认。模型通过 checklist_write 透明展示工作计划。

⚡

YOLO 模式

自动审批所有工具。适合受信工作区的快速迭代。仍维护计划和检查清单以保持可见性。开发者的效率利器。

Quickstart

快速上手

三步启动你的终端 AI 编码助手

1

安装

Terminal
# npm 安装（推荐） npm install -g deepseek-tui # 或 cargo 安装 cargo install deepseek-tui-cli --locked cargo install deepseek-tui --locked
2

配置 API Key

Terminal
# 交互式设置 deepseek auth set --provider deepseek # 或环境变量 export DEEPSEEK_API_KEY="your-key" # 验证 deepseek doctor
3

开始使用

Terminal
# 启动交互式 TUI deepseek # 单次提问 deepseek "explain this function" # YOLO 模式 deepseek --yolo # 恢复会话 deepseek resume --last
