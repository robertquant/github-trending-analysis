项目简介

🎨 AI 图像生成民主化的起点

Stable Diffusion WebUI (A1111) 是由匿名开发者 AUTOMATIC1111 创建的 Stable Diffusion 本地 Web 界面，基于 Gradio 库构建。自 2022 年发布以来，它成为了全球数百万用户接触 AI 图像生成的第一扇门。

支持 txt2img、img2img、Inpainting、Outpainting 等全套生成模式，集成 GFPGAN/CodeFormer 人脸修复、RealESRGAN 超分辨率、Textual Inversion、LoRA、Hypernetworks 等训练/微调能力。最低仅需 4GB VRAM（有用户报告 2GB 也可运行），一个 GPU 即可在本地生成高质量 AI 图像。

拥有庞大的扩展生态系统——ControlNet、ADetailer、Infinite Image Browsing 等数千个社区插件，让功能几乎无限扩展。支持 SD 1.5、SD 2.0、SDXL、SD3 全系列模型，是 AI 绘画领域当之无愧的传奇项目。

快速上手

# Windows (NVIDIA GPU) — 一键安装
git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui.git
cd stable-diffusion-webui
webui-user.bat

# Linux
sudo apt install wget git python3 python3-venv libgl1 libglib2.0-0
git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui.git
cd stable-diffusion-webui
bash webui.sh
# 启动参数优化
webui-user.bat --xformers --medvram

# 启用 API 模式
webui-user.bat --api --listen

# 访问 Web 界面
打开浏览器访问 http://127.0.0.1:7860
