📋 项目简介与核心功能

Cal.diy 是由 Cal.com 官方分拆出来的社区驱动、100% 开源的日程调度平台。在 Cal.com 宣布闭源后，Cal.diy 成为该项目唯一真正的开源分支。

核心定位：为所有人提供完全自主托管的调度基础设施，无需许可证密钥，无企业版功能锁定，所有代码均以 MIT 许可证发布。

核心功能

  • 事件调度 — 创建多种事件类型（一对一、团体、循环预约），灵活设置可用时间段
  • 日历集成 — Google Calendar、Microsoft Outlook/365、Apple Calendar 等
  • 视频会议 — Zoom、Daily.co、Webex 等无缝集成
  • CRM 集成 — HubSpot、ZohoCRM、Pipedrive、Basecamp 等
  • App Store 框架 — 可扩展的应用商店体系，支持自定义集成
  • 多语言支持 — 内置 i18n 国际化框架
  • API 支持 — 完整的 REST API (v2) 和 tRPC 接口

🎯 应用场景

  • 个人日程管理 — 自由职业者分享预约链接，让客户自助预约会议时间
  • 咨询服务 — 律师、顾问、教练等行业提供在线预约服务
  • 教育/辅导 — 教师和学生对一对一辅导时间进行调度
  • 远程面试 — HR 团队安排候选人面试时段，自动同步日历和视频会议
  • 医疗预约 — 诊所/心理咨询等场景的自助预约系统
  • SaaS 产品集成 — 作为调度引擎嵌入到其他产品中

⚠️ 官方声明：Cal.diy 推荐用于个人、非生产环境。商业/企业场景建议使用 Cal.com 商业版。

🔥 为什么火 (Trending 原因)

核心导火索：Cal.com 闭源事件

  • Cal.com 宣布闭源 — 2025年，Cal.com 联合创始人公开发表"Open source is dead"言论，宣布将核心代码转为闭源。社区哗然。
  • 社区反弹 — Reddit r/selfhosted 和 r/opensourcealternative 上出现大量讨论帖（数百条评论），用户纷纷寻找替代方案。
  • Cal.diy 应运而生 — 作为唯一官方认可的开源分支，自然承接了所有对开源调度工具有需求的用户。
  • "Do It Yourself" 理念共鸣 — 在数据隐私和自主托管日益受到重视的当下，Cal.diy 的命名和定位精准击中了自托管社区的需求。
  • MIT 许可证 — 相比 Cal.com 之前的 AGPL/自定义许可，MIT 是最宽松的开源许可证，极大降低了使用和二次开发的门槛。
