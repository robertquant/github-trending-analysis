📖 项目简介与核心功能

scrcpy（发音 "screen copy"）是 Genymobile 开发的一款开源工具，通过 USB 或 TCP/IP 将 Android 设备的屏幕（包括视频和音频）实时镜像到电脑上，并允许使用电脑的键盘和鼠标直接控制手机。它是目前 GitHub 上最受欢迎的 Android 投屏工具，拥有超过 14 万 Star。

核心特性

极致轻量
原生实现，仅显示设备画面，无多余 UI。不需要在设备上安装任何应用，不留任何残留。
超高性能
30~120fps 自适应帧率，1920x1080 及以上分辨率，延迟仅 35~70ms，启动约 1 秒。
音频转发
Android 11+ 支持音频同步转发到电脑，实现音画一体。
屏幕录制
内置录屏功能，支持 H.264/H.265 编码，直接保存为 MP4。
虚拟显示器
可在电脑上创建独立的 Android 虚拟屏幕，不影响手机本体显示。
摄像头镜像
Android 12+ 支持直接镜像设备摄像头画面，Linux 下可作为 V4L2 虚拟摄像头。
游戏手柄支持
支持通过 HID 模拟物理键盘/鼠标和游戏手柄操控设备。
跨平台
完整支持 Linux、Windows、macOS 三大平台。

架构亮点

  • 零安装设计：无需在 Android 设备端安装任何 APK，完全通过 ADB 协议与设备通信
  • 硬件编解码：利用设备端的硬件编码器（MediaCodec），将视频流高效推送到电脑
  • USB 与无线双模：USB 模式提供最低延迟，TCP/IP 模式提供无线便利
  • OTG 模式：无需 USB 调试即可通过 HID 协议控制设备
  • 单二进制文件：发布为单一可执行文件，无需安装，即开即用

🚀 快速上手指南

1. 安装

# Ubuntu/Debian sudo apt install scrcpy # macOS (Homebrew) brew install scrcpy # Windows (Scoop) scoop install scrcpy # Windows (winget) winget install Genymobile.scrcpy # Arch Linux sudo pacman -S scrcpy

2. 准备设备

在 Android 设备上开启「开发者选项」→「USB 调试」，然后用 USB 线连接电脑。

3. 基本使用

# 基本投屏（USB 连接） scrcpy # 无线连接（先 USB 配对一次） scrcpy --tcpip=<设备IP> # 高清模式 scrcpy --video-codec=h265 -m1920 --max-fps=60 # 录屏 scrcpy --record=demo.mp4 # 关闭手机屏幕投屏（省电） scrcpy --turn-screen-off # 虚拟显示器（独立屏幕） scrcpy --new-display=1920x1080 # 镜像摄像头 scrcpy --video-source=camera --camera-size=1920x1080
