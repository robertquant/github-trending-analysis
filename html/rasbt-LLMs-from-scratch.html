项目简介

📖 从零构建大语言模型的终极教程

这是 Sebastian Raschka（ML 教育领域最有影响力的作者之一）的里程碑式作品。配套 Manning 出版的纸质书 Build A Large Language Model (From Scratch)，通过 7 个核心章节 + 5 个附录，手把手带你用 PyTorch 从零实现一个 GPT-2 级别的 LLM。

从文本数据处理、注意力机制、GPT 架构实现，到预训练、分类微调、指令微调，每个概念都以清晰文字 + 图示 + 可运行代码呈现。所有代码在普通笔记本电脑上即可运行，无需 GPU。

Bonus 材料更是极其丰富：Llama 3.2、Qwen3、Gemma 3、Olmo 3 从零实现、LoRA、DPO、GRPO 强化学习、17 小时配套视频课程、170 页练习 PDF。

快速上手

# 克隆仓库
git clone --depth 1 https://github.com/rasbt/LLMs-from-scratch.git
cd LLMs-from-scratch

# 安装依赖（推荐使用 uv）
pip install uv
uv pip install -r requirements.txt

# 打开第 2 章开始学习
jupyter notebook ch02/01_main-chapter-code/ch02.ipynb
# 或使用 Docker 环境
docker build -t llms-from-scratch -f setup/Dockerfile .
docker run -it -p 8888:8888 llms-from-scratch

# 直接运行 GPT-2 文本生成
python ch05/01_main-chapter-code/gpt_generate.py
