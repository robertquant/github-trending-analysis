📚 项目简介

llama.cpp 是由 Georgi Gerganov 发起的开源 C/C++ 大语言模型推理引擎，现已成为 ggml-org 组织的核心项目，并已正式加入 Hugging Face 生态系统。它是目前本地运行 LLM 最流行的底层引擎，Ollama、LM Studio、GPT4All 等知名工具均基于 llama.cpp 构建。

项目目标极其明确：用最少的依赖、最广泛的硬件支持，实现最先进的 LLM 推理性能。从 Mac 到 PC、从手机到服务器、从 CPU 到 GPU，llama.cpp 几乎可以在任何设备上运行大模型。

零依赖 C/C++ 实现

纯 C/C++ 编写，无需 Python、PyTorch 等重量级依赖，编译即可运行，体积小巧。

极致量化支持

支持 1.5-bit 到 8-bit 全系列量化，将模型体积压缩数倍同时保持高质量输出。

全平台硬件加速

Apple Metal、NVIDIA CUDA、AMD HIP、Vulkan、SYCL、WebGPU 等 15+ 后端。

OpenAI 兼容 API

内置 llama-server，提供与 OpenAI API 兼容的 HTTP 接口，可直接替换生产环境。

⚙ 技术架构与特点

GGUF 模型格式

llama.cpp 使用 GGUF (Generalized GGML Universal Format) 作为核心模型格式。GGUF 将量化权重、模型元数据、词表等打包在单一文件中，支持 mmap 高效加载，是本地推理的事实标准格式。

⚡ 快速上手指南

  1. 安装 llama.cpp
    # macOS (Homebrew) brew install llama.cpp # Linux - 从源码编译 git clone https://github.com/ggml-org/llama.cpp cd llama.cpp && make -j$(nproc) # Windows (winget) winget install GGLORG.llama.cpp
  2. 下载并运行模型
    # 直接从 Hugging Face 下载并运行（推荐） llama-cli -hf ggml-org/gemma-3-1b-it-GGUF # 或使用本地 GGUF 文件 llama-cli -m my_model.gguf -cnv
  3. 启动 OpenAI 兼容 API 服务
    # 启动服务器（默认端口 8080） llama-server -hf ggml-org/gemma-3-1b-it-GGUF --port 8080 # 浏览器访问 http://localhost:8080 即可使用 WebUI # API 端点: http://localhost:8080/v1/chat/completions
  4. 使用 Python 调用
    pip install llama-cpp-python # Python 代码 from llama_cpp import Llama llm = Llama("model.gguf") output = llm("Hello, how are you?", max_tokens=100) print(output)
