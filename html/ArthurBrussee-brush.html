👁 项目简介

Brush 是一款由 Google DeepMind 研究员 Arthur Brussee 开发的开源 3D 重建引擎，核心基于 3D Gaussian Splatting (3DGS) 技术。项目的愿景是让 3D 重建技术「人人可用」——无论你使用什么操作系统、什么 GPU 厂商，甚至只需要一个浏览器。

🎯 核心功能

  • 3D 场景训练：接受 COLMAP 数据或 Nerfstudio 格式数据集，直接训练 Gaussian Splatting 模型
  • 实时训练可视化：训练过程中可交互查看场景，实时对比当前渲染与输入视角
  • 场景查看器：加载 .ply / .compressed.ply 文件，支持 URL 流式加载
  • 4D 动画支持：加载 .zip 包含的 splat 文件序列，展示动态动画（如 Cap4D）
  • 图像遮罩：支持透明度图像和区域遮罩，精确控制训练区域
  • CLI 工具：完整的命令行界面，支持 --with-viewer 实时调试
  • Rerun 集成：可使用 Rerun.io 进行额外的训练数据可视化

⚙ 技术架构与特点

Brush 的技术选型在 3D 重建领域独树一帜，完全抛弃了 Python/CUDA 的传统路线。

🔥 为什么火？Trending 原因分析

1. 填补了 3DGS 领域的跨平台空白

传统 3DGS 工具几乎全部依赖 CUDA，将 Mac 用户、AMD GPU 用户和移动端用户完全排除在外。Brush 是第一个真正实现「全平台可用」的 3DGS 引擎。

2. Rust + WebGPU 的技术吸引力

Rust 在系统编程领域的热度持续攀升，WebGPU 作为下一代 Web 图形标准备受关注。Brush 是这两个技术栈在 3D 重建领域的标杆级应用。

3. 零门槛体验

提供在线 Web Demo，用户无需安装任何软件即可在浏览器中体验 3D 重建和查看功能。Hacker News 社区评价：「50 MB 的 .ply 文件几乎瞬间加载，场景漫游流畅无闪烁」。

4. Gaussian Splatting 的爆发期

3DGS 是 2023-2025 年计算机视觉领域最热门的技术之一，SIGGRAPH 2025 上 NVIDIA 开源了 3DGUT，NAB 2026 大量产品采用 GS 技术。Brush 顺应了这一大趋势。

5. Google DeepMind 背书

作者 Arthur Brussee 来自 Google DeepMind，同时也是 Burn 框架的核心贡献者，项目有 Google Research 的基因。

⚡ 快速上手指南

安装

# 确保已安装 Rust 1.88+
rustup update stable

# 克隆仓库
git clone https://github.com/ArthurBrussee/brush.git
cd brush

# 构建并运行
cargo run --release

使用 COLMAP 数据训练

# 使用 CLI 训练
brush train --data /path/to/colmap/dataset

# 训练并打开查看器
brush train --data /path/to/dataset --with-viewer

查看 .ply 文件

# 本地查看
brush view --path scene.ply

# Web 端查看（URL 参数加载）
# 在浏览器中访问: https://brush.demo?url=https://example.com/scene.ply

Web 端开发

# 启动 Web Demo
npm run dev

# 构建 WASM
wasm-pack build

Android 构建

# 一次性设置
rustup target add aarch64-linux-android
cargo install cargo-ndk

# 构建 Rust 库
cargo ndk -t arm64-v8a -o app/src/main/jniLibs/ build --release

# 安装到设备
./gradlew installDebug
