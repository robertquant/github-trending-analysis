🛡 项目简介与核心功能

Shannon 是由 Keygraph 团队开发的自主式白盒 AI 渗透测试工具，专为 Web 应用和 API 安全测试而设计。它结合了源代码分析与动态漏洞利用，能够像一位「永不休息的高级安全工程师」一样自动完成完整的渗透测试流程。

核心理念：「无利用，不报告」（No Exploit, No Report）
Shannon 不会报告理论上的漏洞。只有当它成功利用一个漏洞并生成可复现的 PoC（概念验证）时，该漏洞才会出现在最终报告中。这意味着零误报。
  • 完全自主运行：一条命令即可启动完整渗透测试，自动处理 2FA/TOTP 登录、SSO、浏览器导航、漏洞利用和报告生成
  • 可复现的 PoC：最终报告只包含已验证的、可利用的漏洞，附带可复制粘贴的概念验证代码
  • OWASP 覆盖：识别并验证注入攻击、XSS、SSRF、身份认证/授权绕过等漏洞类别
  • 代码感知动态测试：分析源代码指导攻击策略，再通过实时浏览器和 CLI 工具验证漏洞
  • 并行处理：漏洞分析和利用阶段跨所有攻击类别并发执行

⚙ 技术架构与特点

Shannon 采用多智能体架构，以 Anthropic Claude Agent SDK 作为推理引擎，结合 Temporal 工作流引擎和 Docker 容器化隔离。

1
Pre-Reconnaissance（预侦察）
分析源代码，识别应用框架、入口点和潜在攻击面
2
Reconnaissance（侦察）
通过浏览器自动化进行实时应用探索，构建攻击面地图
3
Vulnerability Analysis（漏洞分析）
5 个并行 Agent 按 OWASP 分类寻找潜在漏洞，生成假设的可利用路径
4
Exploitation（漏洞利用）
将假设转化为实际攻击，使用浏览器自动化和 CLI 工具执行真实漏洞利用
5
Reporting（报告）
汇总已验证的发现，生成专业可操作的安全评估报告

🚀 快速上手指南

前置要求：Docker、Node.js 18+、Anthropic API Key（或其他支持的 AI 提供商）

# 1. 配置凭证（交互式向导，仅需一次）
npx @keygraph/shannon setup

# 或直接设置环境变量
export ANTHROPIC_API_KEY=your-api-key

# 2. 启动渗透测试
npx @keygraph/shannon start -u https://your-app.com -r /path/to/your-repo

# 3. 监控进度
npx @keygraph/shannon logs <workspace>
npx @keygraph/shannon status

# 4. 查看报告
# 报告保存在 ~/.shannon/workspaces/ 目录下
# deliverables/comprehensive_security_assessment_report.md

带认证的配置示例：

# my-app-config.yaml
authentication:
  login_type: form
  login_url: "https://your-app.com/login"
  credentials:
    username: "test@example.com"
    password: "yourpassword"
    totp_secret: "LB2E2RX7XFHSTGCK"  # 可选的 2FA

npx @keygraph/shannon start -u https://your-app.com -r /path/to/repo -c ./my-app-config.yaml
重要警告
Shannon 不是被动扫描器——它会主动执行攻击。切勿在生产环境运行！仅在沙箱、测试或本地开发环境中使用，并确保已获得系统所有者的明确书面授权。
