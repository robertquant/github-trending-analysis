📚 项目简介与核心功能

Pi 是一个开源 AI Agent 工具包（Agent Harness），由 Mario Zechner（badlogic）创建，2026 年 5 月从 badlogic/pi-mono 迁移至 earendil-works/pi 组织。项目秉持 Unix 哲学：每个组件做好一件事，通过组合产生强大能力。

核心组件

包名功能定位
pi-coding-agent 交互式编码代理 CLI 核心
pi-agent-core Agent 运行时（工具调用 + 状态管理） 引擎
pi-ai 统一多提供商 LLM API 核心
pi-tui 终端 UI 库（差分渲染） 界面
pi-chat Slack/Discord/Telegram 聊天机器人 集成

核心亮点

  • 统一 LLM API — 一套 API 无缝切换 OpenAI、Anthropic、Google、本地模型（vLLM/MLX），无需改代码
  • 自扩展设计 — TypeScript 插件 API，可编写自定义工具和扩展
  • 本地模型优先 — 原生支持 vLLM Pod 和 Apple Silicon (MLX-Swift)，离线可用
  • 供应链安全 — 依赖精确锁定、shrinkwrap、npm audit 签名验证、CI 审计
  • OSS 会话共享 — pi-share-hf 将编码会话发布至 HuggingFace，帮助改进 Agent

⚙ 技术架构与特点

架构分层

┌─────────────────────────────────────────┐ │ pi-coding-agent (CLI 层) │ │ 交互式终端、用户输入、命令处理 │ ├─────────────────────────────────────────┤ │ pi-agent-core (运行时层) │ │ Agent Loop、工具调用、状态管理 │ │ 扩展加载、事件系统 │ ├─────────────────────────────────────────┤ │ pi-ai (LLM 抽象层) │ │ 统一 API：OpenAI / Anthropic / Google │ │ 本地模型：vLLM / MLX / Ollama │ ├─────────────────────────────────────────┤ │ pi-tui (渲染层) │ │ 差分渲染、Markdown 流式输出 │ └─────────────────────────────────────────┘

关键技术特点

  • TypeScript 全栈 — 统一语言，类型安全，Node.js/Bun 双运行时支持
  • Monorepo 架构 — npm workspaces，统一构建和测试
  • 差分渲染引擎 — pi-tui 实现终端高效增量更新，流畅展示 Agent 思考过程
  • Agent Loop — 处理用户消息 → 执行工具调用 → 反馈结果的完整编排循环
  • 安全供应链 — 依赖精确版本锁定、pre-commit 钩子、npm audit 签名、shrinkwrap 生成

🎯 应用场景

  • 日常编码助手 — 终端内交互式 AI 编码，支持多文件编辑、Git 操作、代码审查
  • 本地/离线开发 — 搭配 vLLM 或 MLX 在本地运行模型，数据不出本机
  • 团队 ChatOps — 通过 pi-chat 桥接 Slack/Discord/Telegram，实现自动化工作流
  • AI Agent 研究 — 基于 pi-agent-core 构建自定义 Agent，研究工具调用和推理策略
  • 多模型对比 — 通过统一 API 快速切换不同 LLM 提供商，对比效果
  • 开源协作 — 使用 pi-share-hf 共享编码会话，贡献真实 Agent 使用数据

2

配置 API Key

设置至少一个 LLM 提供商的密钥（支持 OpenAI、Anthropic、Google 等）

export ANTHROPIC_API_KEY="sk-..." export OPENAI_API_KEY="sk-..."
3

启动 Agent

cd your-project pi
4
