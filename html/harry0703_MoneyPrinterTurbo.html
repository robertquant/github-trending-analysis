一、项目概述

MoneyPrinterTurbo 是一个基于 AI 大语言模型的开源短视频全自动生成工具。用户只需提供一个主题或关键词，系统即可在约 3 分钟内自动完成从脚本撰写、素材匹配、AI 配音、字幕生成到最终视频合成的全流程，输出高清短视频成品。

该项目凭借其"一键生成"的极简理念和完整的 MVC 架构设计，在 GitHub 上积累了超过 5.37 万 Stars，成为 AI 视频创作领域的标杆级开源项目。它特别适合内容创作者、自媒体运营者快速批量生成知识科普、资讯汇总类短视频内容。

三、核心创新点

  • 全流程自动化：从关键词到成品视频的端到端自动化，无需人工干预视频剪辑过程，极大降低短视频创作门槛
  • 多模型统一接入：通过 LiteLLM 实现对 15+ 供应商、100+ 模型的统一调用接口，用户可自由切换 LLM 后端而无需修改代码
  • 智能素材匹配算法：基于 LLM 提取的语义关键词自动检索素材库，实现约 88% 的素材匹配准确率，大幅减少人工筛选工作量
  • 模块化 MVC 架构：各功能模块（LLM/TTS/素材/合成）高度解耦，代码结构清晰，便于二次开发和功能扩展
  • 批量生成能力：支持一次性生成多个视频版本供选择，适合 A/B 测试和内容筛选场景
  • 多尺寸高清输出：支持竖屏 9:16 (1080x1920)、横屏 16:9 (1920x1080) 等多种视频规格，覆盖主流短视频平台需求

自媒体内容创作

API 集成与自动化

通过 REST API 接入企业工作流，实现视频内容的自动化生产流水线。
