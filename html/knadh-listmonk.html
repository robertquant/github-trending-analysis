项目简介

listmonk 是一个独立、自托管的 Newsletter 和邮件列表管理器，由 knadh 开发维护。它将所有功能打包在一个 Go 单二进制文件中，仅需 PostgreSQL 作为数据库，即可提供企业级的邮件营销管理能力。

核心定位：为注重数据隐私和成本控制的团队/个人提供免费、高性能的邮件列表管理方案。

技术架构

前端：Vue.js + Buefy UI（现代响应式管理界面）
后端：Go（编译为单二进制，跨平台部署）
数据库：PostgreSQL（唯一外部依赖）
认证：内置 + OIDC SSO（v4+）
部署：Docker Compose / 原生二进制
API：完整 RESTful API

技术特点

  • • Go 后端：编译为单个二进制，跨平台部署，无需运行时环境
  • • PostgreSQL：成熟稳定的关系数据库，支持大规模订阅者管理
  • • Vue.js 前端：现代化 SPA 管理界面，操作流畅
  • • API 优先：完整 RESTful API，支持程序化操作和集成

快速上手指南

Docker 部署（推荐）

# 下载 docker-compose.yml
curl -LO https://github.com/knadh/listmonk/raw/master/docker-compose.yml

# 启动服务
docker compose up -d

# 访问 http://localhost:9000

二进制部署

# 下载最新版本
wget https://github.com/knadh/listmonk/releases/latest/download/listmonk_6.1.0_linux_amd64.tar.gz
tar -xzf listmonk_6.1.0_linux_amd64.tar.gz

# 生成配置文件并编辑
./listmonk --new-config

# 初始化数据库
./listmonk --install

# 启动服务
./listmonk

发送第一封 Newsletter

  1. 登录后进入 Lists 页面创建邮件列表
  2. 通过导入 CSV 或 API 添加订阅者
  3. 进入 Campaigns 页面，点击 New Campaign
  4. 使用内置编辑器编写邮件内容（支持模板）
  5. 选择目标列表，设置发送参数
  6. 发送或设定定时发送
