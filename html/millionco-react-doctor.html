项目简介

React Doctor 是由 Million.js 团队（创始人 Aiden Bai）开源的 React 代码质量诊断工具。一条命令扫描整个代码库，输出 0-100 健康评分和可操作的诊断报告。它特别针对 AI 编程 Agent 生成的低质量 React 代码设计——在 AI 编程助手（Cursor、Claude Code、Copilot 等）遍地走的 2026 年，React Doctor 就是你的代码质量守门员。支持 Next.js、Vite、React Native，内置 60+ 规则覆盖状态管理、性能、架构、安全、可访问性和死代码检测。

0-100 健康评分 60+ 规则 AI Agent 集成 GitHub Actions ESLint + oxlint 插件 Next.js / Vite / RN Node.js API
六大核心能力
🏥
0-100 健康评分
一条命令输出直观的代码健康评分。75+ 为 Great，50-74 为 Needs Work，50 以下为 Critical。团队可追踪分数变化趋势，量化代码质量。
🤖
AI Agent 深度集成
运行 install 命令即可教 Cursor、Claude Code、Codex 等 50+ AI Agent React 最佳实践。让 AI 从源头停止写坏代码，而不仅是事后检测。
🔍
60+ 专业规则
覆盖状态与副作用、性能反模式、架构问题、安全漏洞、可访问性、死代码六大维度。规则根据框架和 React 版本自动切换。
⚡
CI/CD 集成
官方 GitHub Action 支持 PR 自动评论、分数输出、diff 模式仅扫描变更文件。配合 --fail-on 参数可在 CI 中阻断低质量合并。
🔌
双引擎 Lint 插件
同一套规则同时提供 oxlint 插件和 ESLint 插件，可接入项目已有的任何 Lint 引擎。自动合并现有 .oxlintrc.json / .eslintrc.json 配置。
📊
Node.js API + 排行榜
提供 diagnose() 编程 API，可集成到自定义工具链。官方排行榜展示知名项目评分：nodejs.org 87 分、tldraw 76 分、excalidraw 69 分。

应用场景
🤖
AI 辅助开发团队
Cursor/Copilot/Claude Code 生成的 React 代码质量参差不齐。React Doctor 在 CI 中自动检测 AI 生成的反模式，确保 AI 辅助代码质量可控。

团队代码审查
GitHub Action 在 PR 中自动评论诊断结果，用 0-100 分数量化代码质量。团队设定分数门槛（如 ≥70 才能合并），让 Code Review 更客观高效。
🏗️
大型项目重构
对于百万行级别的 React 代码库（已有实际案例），React Doctor 的 --diff 模式只扫描变更文件，--json 输出结构化报告，方便追踪重构进度。
📚
教学与学习
React 初学者和 AI 编程用户可通过诊断报告学习 React 最佳实践。--explain 参数详细解释每条规则触发原因，是最好的交互式学习工具。

3. GitHub Actions CI 集成
