📋 项目简介

RTK (Rust Token Killer) 是一个高性能 CLI 代理工具，能够将 AI 编程助手中的 LLM token 消耗降低 60-90%。它作为 AI 编码工具和终端命令之间的智能中间层，拦截并压缩常用开发命令的输出，再传递给 LLM 上下文。


核心价值：一个 30 分钟的 Claude Code 会话中，标准输出约消耗 118,000 tokens，使用 RTK 后仅需约 23,900 tokens。

🚀 快速上手指南

1. 安装（一键）

# macOS / Linux (推荐)
curl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/refs/heads/master/install.sh | sh

# Homebrew
brew install rtk

# Cargo
cargo install --git https://github.com/rtk-ai/rtk

2. 配置 AI 工具

# Claude Code（推荐）
rtk init -g

# 验证安装
rtk --version
rtk gain

# 重启 AI 工具后生效

3. 日常使用（自动生效）

# Hook 自动生效，正常使用即可
git status # 自动 → rtk git status（200 tokens 而非 2000）
git diff # 自动 → rtk git diff
cargo test # 自动 → rtk cargo test（仅显示失败）
