📋项目简介与核心功能

Telegraf 是由 InfluxData 开发的开源数据采集代理（Agent），使用 Go 语言编写。它是一个插件驱动的服务器代理，能够从数据库、系统、进程、IoT 设备和各种 API 中收集指标和事件数据，并将其写入多种后端存储。

核心定位：可观测性基础设施中的"数据搬运工" — 负责从各种数据源采集指标、日志和事件，经处理后路由到目标存储系统。

核心功能

  • 300+ 插件生态：涵盖输入（Input）、输出（Output）、处理器（Processor）、聚合器（Aggregator）四大类
  • 零依赖部署：编译为独立静态二进制文件，无需任何外部依赖
  • TOML 配置：简洁明了的声明式配置，无歧义易维护
  • 数据处理管线：内置聚合、过滤、转换等数据处理能力
  • 自定义插件：支持用户通过 exec 或 Go 插件扩展功能

🚀快速上手指南

1. 安装

# macOS
brew install telegraf

# Ubuntu / Debian
sudo apt-get install telegraf

# Docker
docker pull telegraf

# 直接下载二进制
wget https://dl.influxdata.com/telegraf/releases/telegraf-38.4.0_linux_amd64.tar.gz

2. 创建配置文件

# 生成默认配置
telegraf config > telegraf.conf

# 仅生成 cpu + mem 输入 + influxdb 输出的精简配置
telegraf config --input-filter cpu:mem --output-filter influxdb_v2

3. 配置示例（采集系统指标写入 InfluxDB）

# telegraf.conf
[agent]
  interval = "10s"
  flush_interval = "10s"

[[inputs.cpu]]
  percpu = true
  totalcpu = true

[[inputs.mem]]

[[inputs.disk]]

[[inputs.net]]

[[outputs.influxdb_v2]]
  urls = ["http://localhost:8086"]
  token = "your-token"
  organization = "my-org"
  bucket = "metrics"

4. 启动

# 前台运行（调试）
telegraf --config telegraf.conf

# 作为系统服务
sudo systemctl start telegraf

# Docker 运行
docker run -d --name telegraf \
  -v /path/to/telegraf.conf:/etc/telegraf/telegraf.conf:ro \
  telegraf

5. 验证

# 查看采集到的指标（调试模式）
telegraf --config telegraf.conf --test

# 查看内部指标
telegraf --config telegraf.conf --input-filter internal
