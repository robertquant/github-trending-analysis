📋项目简介与核心功能

daily_stock_analysis（简称 DSA）是一个基于大语言模型（LLM）的智能股票分析系统，支持 A股、港股、美股 三大市场的自选股每日自动分析。它将多源行情数据、实时新闻、技术指标和舆情分析融合，通过 LLM 生成结构化的「决策仪表盘」，并推送到企业微信/飞书/Telegram/Discord/Slack/邮件等多个渠道。

🚀快速上手指南

方式一：GitHub Actions（5分钟部署）

1. Fork 本仓库（顺手 Star ⭐） 2. Settings → Secrets → Actions → 配置 API Key： - ANSPIRE_API_KEYS 或 AIHUBMIX_KEY 3. 配置通知渠道（如 TELEGRAM_BOT_TOKEN） 4. 配置自选股：STOCK_LIST = "600519,hk00700,AAPL" 5. 启用 Actions → 手动测试 → 完成！

方式二：本地运行

git clone https://github.com/ZhuLinsen/daily_stock_analysis.git cd daily_stock_analysis pip install -r requirements.txt cp .env.example .env # 编辑配置 python main.py # 运行分析 python main.py --webui # 启动 Web 工作台
