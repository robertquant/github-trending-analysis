📄 项目简介 & 核心功能

Presenton 是一款完全开源的 AI 演示文稿生成工具，支持通过自然语言提示词或上传文档自动生成专业的 PPT 演示文稿。项目定位为 Gamma、Beautiful AI、Decktopus 的开源替代品，最大特色是无 SaaS 锁定、无强制订阅、完全掌控模型和数据。

🎯 AI 演示文稿生成

从自然语言提示词或上传文档（PDF、Word 等）自动生成完整演示文稿，支持自定义幻灯片数量、语言、语调和模板。

🎨 自定义模板 & 布局

使用 HTML + Tailwind CSS 创建无限自定义设计模板，支持从现有 PowerPoint 文档逆向生成 AI 模板。

🔒 完全本地化 / 自托管

通过 Docker 一键部署或使用桌面应用（Mac/Windows/Linux），所有数据处理在本地完成，零隐私风险。

🤖 多模型支持 (BYOK)

支持 OpenAI、Gemini、Anthropic、Azure、Bedrock、Fireworks、Together、Ollama、LM Studio 等十余种 LLM 提供商。

🚀 演示文稿生成 API

内置 RESTful API 服务，支持通过 HTTP Basic Auth 认证调用，可集成到自动化工作流中批量生成演示文稿。

📦 PPTX & PDF 导出

生成的演示文稿可直接导出为完全可编辑的 PPTX（PowerPoint）或 PDF 格式，兼容 Office 生态。

⚙ 技术架构 & 特点

Presenton 采用 Next.js (前端) + FastAPI (后端) + Electron (桌面封装) 的三层架构，容器化部署基于 Docker。

方式一：Docker 一键启动（推荐）

方式二：API 调用生成演示文稿

curl -u admin:password \ -X POST http://localhost:5000/api/v1/ppt/presentation/generate \ -H "Content-Type: application/json" \ -d '{ "content": "AI 技术在金融领域的应用", "n_slides": 8, "language": "Chinese", "template": "general", "export_as": "pptx" }' # 返回结果 { "presentation_id": "d3000f96-...", "path": "/app_data/.../AI_技术在金融领域的应用.pptx", "edit_path": "/presentation?id=d3000f96-..." }

方式三：桌面应用

# 克隆仓库并安装依赖 git clone https://github.com/presenton/presenton.git cd presenton/electron npm run setup:env # 开发模式运行 npm run dev
