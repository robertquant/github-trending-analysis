📋 项目简介

Context Mode 是一个基于 MCP (Model Context Protocol) 的服务器，专门解决 AI 编程 Agent 的上下文窗口浪费问题。一次 Playwright 快照消耗 56KB，20 个 GitHub Issues 占用 59KB——工具输出在 30 分钟内就能吃掉 40% 的上下文。Context Mode 通过沙箱化、智能压缩、会话延续和代码化思考四大机制，实现 98% 上下文节省，将有效会话时间从 ~30 分钟延长到 ~3 小时。

🚀 快速上手指南

1. Claude Code 安装

claude mcp add context-mode -- npx -y @anthropic/context-mode@latest

2. Cursor 安装

// .cursor/mcp.json
{
  "mcpServers": {
    "context-mode": {
      "command": "npx",
      "args": ["-y", "@anthropic/context-mode@latest"]
    }
  }
}

3. 基本使用

# 查看上下文统计
ctx_stats

# 执行命令（结果不入上下文）
ctx_execute("cat large-log.log | grep ERROR | wc -l")

# 索引文档到知识库
ctx_index("./docs", "project-docs")

# BM25 搜索
ctx_search("authentication flow")
