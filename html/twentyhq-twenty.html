📋 项目简介与核心功能

Twenty 是 GitHub 上增长最快的开源 CRM 项目，定位为 Salesforce 的开放替代方案。 它为技术团队提供了构建自定义 CRM 的全套模块——对象(Objects)、视图(Views)、工作流(Workflows)和智能体(Agents)， 并且支持以代码方式定义和版本管理，就像管理软件栈中的其他部分一样。

核心功能

  • 对象定义即代码 — 通过 SDK 用 TypeScript 定义数据模型、字段和视图
  • 可自定义管道视图 — 销售管道、看板视图灵活配置
  • 工作流自动化 — Webhook + 自动化工作流引擎
  • AI Agent 集成 — 原生 MCP 协议支持，设计之初就为 AI 准备
  • 自托管 / 云部署 — Docker Compose 一键部署或使用托管云服务
  • CLI 脚手架 — npx create-twenty-app 快速创建应用
