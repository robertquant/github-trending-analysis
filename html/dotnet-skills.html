项目简介与核心功能

dotnet/skills 是 Microsoft .NET 官方团队于 2026 年 3 月开源的项目，旨在为 AI 编程代理（如 GitHub Copilot、Claude Code、Cursor、Codex CLI）提供 .NET 和 C# 领域的专业知识包。

每一个"技能"（Skill）是一个结构化的知识包，包含意图识别、任务特定上下文和支持文件，使 AI 代理能够在处理 .NET 任务时做出更精准的决策，减少试错和幻觉。

技术架构与特点

基于 Agent Skills 开放标准

项目遵循 agentskills.io 开放标准，技能以 SKILL.md 文件格式组织，包含结构化的知识描述、工作流指引和最佳实践。这种轻量级格式让任何支持该标准的 AI 编码代理都能直接消费。

插件化架构

采用 Marketplace 插件市场模式，每个插件聚焦一个 .NET 子领域（如数据访问、构建系统、测试等），用户可按需安装。支持多平台接入：

  • Copilot CLI / Claude Code — 通过 /plugin 命令安装
  • VS Code — Preview 支持，Copilot Chat 中输入 /plugins
  • Cursor — 内置 Marketplace 支持
  • Codex CLI — 使用 skill-installer 工具安装

持续集成与质量保障

项目配备自动化流水线，每夜构建（nightly build），并通过 Dashboard 展示各插件的准确性和效率评分趋势。GitHub Actions 驱动的 CI/CD 确保技能内容持续更新。

关键设计决策

  • 知识即代码 — 技能以 Markdown 文件存储，版本可控、可审查
  • 领域边界清晰 — 12 个插件各司其职，避免知识交叉污染
  • MIT 开源 — 企业可自由使用、修改和贡献
  • 官方背书 — 由实际发布 .NET 的团队维护，确保知识的权威性

快速上手指南

方式一：Claude Code / Copilot CLI

# 1. 添加 Marketplace
/plugin marketplace add dotnet/skills

# 2. 安装所需插件（如核心 .NET + ASP.NET）
/plugin install dotnet@dotnet-agent-skills
/plugin install dotnet-aspnet@dotnet-agent-skills

# 3. 重启加载插件

# 4. 更新插件（可选）
/plugin update dotnet@dotnet-agent-skills

方式二：Cursor IDE

# 1. 打开 Cursor Marketplace 面板
# 2. 搜索 ".NET" 或浏览 cursor.com/marketplace
# 3. 一键安装所需插件

方式三：Codex CLI

skill-installer install https://github.com/dotnet/skills/tree/main/plugins/dotnet/skills/<skill-name>
