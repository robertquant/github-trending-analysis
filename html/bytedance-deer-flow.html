核心架构

DeerFlow 2.0 是从零完全重写的版本，基于 LangGraph + LangChain 构建。它不只是一个研究工具，而是一个完整的 Agent 运行时环境。

多代理编排 (Multi-Agent Orchestration)
基于LangGraph的有向图编排，SuperAgent自动拆解复杂任务并分派给并行执行的子代理。每个子代理拥有独立上下文，支持长时运行（多小时级别任务）。
🛡️
Docker 沙箱执行
每个任务在隔离的Docker容器中运行，拥有完整文件系统。支持Bash执行、文件I/O、图片查看，安全隔离主机环境。支持本地/Docker/Kubernetes三种执行模式。
🧩
Skills 技能系统
基于Markdown定义的结构化技能模块，支持深度研究、报告生成、幻灯片创建、网页生成、图片/视频生成等。开发者可轻松创建自定义技能。
🧠
长期记忆 & 上下文工程
跨会话持久化记忆，子代理上下文隔离与压缩，自动摘要和工具调用恢复。让Agent在长任务中保持连贯性，不会因上下文溢出而"失忆"。
📡
MCP Server 支持
原生支持Model Context Protocol，可通过HTTP/SSE接入外部工具和数据源。扩展Agent的能力边界，连接企业内部系统和第三方服务。
💬
6大IM渠道
原生集成 Telegram、Slack、飞书、微信、企业微信、钉钉。同时支持 Claude Code 终端交互和 Embedded Python Client 嵌入式调用。

快速开始

# 方式一：Docker 一键部署（推荐） git clone https://github.com/bytedance/deer-flow.git cd deer-flow

# 配置环境变量 cp .env.example .env # 编辑 .env 填入 LLM API Key（支持任何 OpenAI 兼容接口）

# Docker 启动 docker compose up -d

# 访问 Web UI # http://localhost:3000

# 方式二：本地开发 pip install -e ".[dev]" python -m src.main

# 方式三：嵌入式 Python Client from deerflow import DeerFlowClient

client = DeerFlowClient(base_url="http://localhost:8000") result = client.run( task="分析2026年AI Agent市场趋势，生成深度研究报告", skills=["deep_research", "report"] )
