📋 项目简介

GenericAgent 是一个自演化 AI 智能体框架，由复旦大学团队开发（论文 arXiv:2604.17091）。其核心理念是「任务结晶为技能」——Agent 完成的每项任务都会自动提炼成可复用的技能节点，逐步构建个人的技能树，越用越强。

整个框架仅约 3,000 行核心代码，由 9 个原子工具 + 约 100 行的 Agent Loop 驱动，却实现了远超体量的能力：5 层分层记忆系统、真实浏览器注入、多 LLM 后端支持，以及从 Streamlit 到飞书/企业微信/钉钉的 10+ 种前端界面。

核心功能

  • 自演化技能系统 — 任务完成后自动结晶为技能节点，形成个人技能树，支持技能复用与组合
  • 5 层记忆架构 — L0(Meta Rules) → L1(Insight Index) → L2(Global Facts) → L3(Task Skills/SOPs) → L4(Session Archive)，跨会话持久化
  • 极致 Token 效率 — 上下文窗口始终 < 30K tokens，远低于竞品的 200K-1M
  • 真实浏览器注入 — 保留登录态的真实浏览器操作，支持外卖点餐、量化选股等复杂场景
  • 多 LLM 后端 — Claude、Gemini、Kimi、MiniMax 等，一键切换
  • 10+ 前端界面 — Streamlit、Terminal UI、Qt、Telegram、QQ、微信、飞书、企业微信、钉钉、Codeg

Agent Loop 工作流程

  1. Observe — 接收用户输入或环境反馈
  2. Think — 查询记忆系统，检索相关技能与历史经验
  3. Act — 调用原子工具执行操作
  4. Reflect — 评估结果，提炼 Insight 写入 L1 层
  5. Crystallize — 将成功路径编码为技能节点写入 L3 层

5 层记忆架构详解

🚀 快速上手

# 克隆仓库
git clone https://github.com/lsdefine/GenericAgent.git
cd GenericAgent

# 安装依赖
pip install -r requirements.txt

# 配置 LLM API Key（以 Claude 为例）
export ANTHROPIC_API_KEY="your-api-key"

# 启动 Streamlit 界面
python -m genericagent.frontends.streamlit

# 或使用终端界面
python -m genericagent.frontends.terminal
