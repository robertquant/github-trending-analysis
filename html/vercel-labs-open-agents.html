☁️ 项目简介与核心功能

Open Agents 是 Vercel Labs 发布的开源参考应用，用于构建和运行后台云端编码 Agent。包含完整的 Web UI、Agent 运行时、沙箱编排和 GitHub 集成——从提示词到代码变更，全程无需保持电脑开机。

核心架构：Agent ≠ Sandbox

这是整个项目最关键的架构决策：Agent 不在 VM 内运行。Agent 在沙箱外部运行，通过文件读写、搜索、Shell 命令等工具与沙箱交互。这种分离带来了巨大的灵活性和可靠性。

核心能力

🔄 Durable Workflow
基于 Workflow SDK 的持久化执行。Agent 不受单次请求生命周期限制，可跨越多个持久化步骤继续运行。断线重连后自动恢复。
🛡️ 隔离沙箱
基于 Vercel Sandbox 的隔离 VM 环境。支持快照恢复、端口暴露 (3000/5173/4321/8000)、空闲自动休眠。
🐙 GitHub 深度集成
仓库克隆、分支操作、自动 Commit/Push、PR 创建。GitHub App 安装式访问，支持组织级部署。
🛑 98% 错误循环减少
内置 Auto-Debug 机制。Agent 遇到错误自动修复，避免陷入死循环。支持 1000 倍更大的项目。
⏰ 无超时限制
Agent 可以自主工作数小时甚至更久。不依赖你的笔记本电脑保持开机。后台持续运行。
🔗 多 Agent 支持
支持子 Agent、技能系统和多 Agent 并行执行。可同时运行多个 Agent 处理不同任务。
🎤 语音输入
可选集成 ElevenLabs 语音转录。用语音描述任务，Agent 自动执行。
📋 会话分享
只读链接分享 Agent 会话。团队成员可以查看 Agent 的工作过程和结果。

🚀 快速上手

1. 一键部署到 Vercel

1. Fork vercel-labs/open-agents 到你的 GitHub 2. 在 Vercel 导入 Fork 的仓库（Neon Postgres 自动配置） 3. 生成密钥: openssl rand -base64 32 → BETTER_AUTH_SECRET 4. 设置环境变量: POSTGRES_URL, BETTER_AUTH_SECRET 5. 部署获取生产 URL → 创建 Vercel OAuth App → 配置回调 URL 6. (可选) 创建 GitHub App 实现完整编码 Agent 流程

2. 本地开发

# 克隆仓库 git clone https://github.com/vercel-labs/open-agents.git cd open-agents # 安装依赖 bun install # 配置环境变量 cp apps/web/.env.example apps/web/.env # 编辑 .env 填入必要值 # 或从已关联的 Vercel 项目拉取 vc env pull # 启动开发服务器 bun run web

3. 常用命令

bun run web # 启动开发服务器 bun run check # Lint + 格式检查 bun run fix # Lint + 格式修复 bun run typecheck # 类型检查所有包 bun run ci # 完整 CI: check + typecheck + test + migration bun run sandbox:snapshot-base # 刷新沙箱基础快照
