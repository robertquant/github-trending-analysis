📖 项目简介与核心功能

agentmemory 是专为 AI 编程 Agent 设计的持久记忆引擎。它解决了 AI 编程工具（Claude Code、Cursor、Codex CLI 等）每次会话结束后遗忘一切的痛点——自动捕获 Agent 操作、压缩为可搜索记忆、在下次会话注入正确上下文。

🏗️ 技术架构与特点

  • iii-engine 运行时 — 基于 Worker/Function/Trigger 三原语构建，替代 Express + SQLite + Redis + pm2 全栈
  • 4层记忆整合 — Working(工作记忆) → Episodic(情景记忆) → Semantic(语义记忆) → Procedural(程序记忆)，灵感来自人脑睡眠巩固
  • 三流检索 — BM25 关键词 + Vector 向量 + 知识图谱，RRF 融合排序
  • 自动捕获 — 12 个 Hooks 零手动操作（SessionStart/PostToolUse/Stop 等）
  • 记忆生命周期 — Ebbinghaus 遗忘曲线衰减、矛盾检测、自动驱逐
  • 隐私优先 — API Key/Secrets 自动过滤、本地自托管
  • 6种嵌入供应商 — 推荐 Local (all-MiniLM-L6-v2，免费离线)，也支持 OpenAI/Gemini/Voyage/Cohere/OpenRouter

🎯 应用场景

  • 跨会话编程 — Session 1 搭建 JWT 认证，Session 2 Agent 自动知道中间件位置、测试覆盖和库选择
  • 团队协作 — 通过 Namespaced 共享记忆，团队成员共享项目上下文
  • 多 Agent 协作 — 一个记忆服务器供 Claude Code + Cursor + Gemini CLI 等多个 Agent 共享
  • 项目管理 — 自动追踪 Action、依赖关系、优先级队列（Frontier）
  • 代码审查 — 捕获历史 Bug 模式和修复方案，自动预防类似问题
  • 会话回放 — 支持 JSONL 导入和时序回放，可回溯任何历史操作
