📄 项目简介与核心功能

GTweak 是一款便携式 Windows 系统优化配置工具，使用 C# / WPF 构建，基于 .NET Framework 4.8。它将 30+ 种系统调优操作整合到一个图形界面中，无需安装，即开即用，覆盖隐私保护、系统精简、界面定制、性能优化、服务管理等多个维度。

核心功能模块

🔒 隐私保护（Confidentiality）
禁用 Windows/NVIDIA/Intel 遥测与键击记录器，阻止微软影子域名数据收集，禁用任务计划中的用户数据收集任务
🛠️ 系统精简（System）
禁用 Windows Defender / SmartScreen / VBS / UAC，暂停更新，卸载 OneDrive / Edge / WebView2，移除 Cortana / Copilot / Recall
🎨 界面定制（Interface）
更换主题、调整窗口设置、自定义任务栏布局和图标，禁用个性化广告与系统通知
⚡ 性能优化（Performance）
应用极限性能电源方案，禁用不必要服务，清理 RAM/临时文件/图标缓存，NTFS 压缩节省空间
💻 服务管理（Services）
禁用不必要的系统服务，禁用 IPv6/Teredo/ISATAP 协议，禁用磁盘碎片整理与诊断工具
🔧 高级工具（Addons）
以 TrustedInstaller 权限执行自定义脚本（.ps1/.cmd/.bat/.reg），查看硬件配置与系统监控

独有亮点

  • Windows 激活 — 支持 HWID 和 KMS 两种激活方式（需注意合规性）
  • TrustedInstaller 提权 — 自定义脚本可以最高系统权限运行
  • 多语言支持 — 社区驱动的国际化翻译（中文、韩语、法语等）
  • 便携零安装 — 单文件可执行，适合 PE 环境或 U盘携带

🚀 快速上手指南

下载最新版本
前往 GitHub Releases 下载最新 v5.2.0 的 .zip 压缩包
解压并添加杀毒白名单
解压到任意目录。如果 Windows Defender 拦截，请将 GTweak 添加到排除项： 
设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护 → 排除项 → 添加文件夹
以管理员身份运行
右键 GTweak.exe → 以管理员身份运行。所有系统级修改操作需要管理员权限。
创建系统还原点
首次使用建议先创建还原点：系统属性 → 系统保护 → 创建，方便回滚。
按需选择优化项
在左侧导航栏切换模块（隐私 / 系统 / 界面 / 服务 / 应用 / 工具），勾选需要优化的项目，点击应用即可。建议先从隐私保护模块开始。
