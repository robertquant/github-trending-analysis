📋 项目简介与核心功能

anthropics/skills 是 Anthropic 发布的官方 Agent Skills 公共仓库，定义了一种全新的 AI Agent 能力封装标准。每个 Skill 是一个包含 SKILL.md 文件的文件夹，其中包含 YAML 前置元数据和指令，让 Claude 能够动态加载并执行专业化任务。Skills 覆盖创意设计（艺术、音乐、设计）、技术开发（Web 测试、MCP 服务器生成）和企业工作流（沟通、品牌）等广泛场景。

🧩 模块化架构

每个 Skill 自包含在独立文件夹中，通过 SKILL.md 定义元数据、指令和触发条件，支持动态加载和组合。

🏪 插件市场

Claude Code 支持 Plugin Marketplace，用户可通过 /plugin marketplace add 一键注册仓库并安装 Skills。

📄 文档处理能力

内置 docx、pdf、pptx、xlsx 文档技能，展示了在 AI 产品中实际使用的复杂 Skill 参考实现。

🔧 跨平台支持

Skills 可在 Claude Code、Claude.ai 和 Claude API 中使用，覆盖 16+ AI 工具的开放标准。

📝 开放标准

Agent Skills 规范托管在仓库的 ./spec 目录，社区可参与制定和改进标准。

🤝 合作伙伴生态

Notion 等合作伙伴已提供官方 Skills，生态正在快速扩张中。

仓库结构

anthropics/skills/
├── skills/           # Skill 示例集合
│   ├── docx/           # Word 文档技能 (source-available)
│   ├── pdf/            # PDF 技能 (source-available)
│   ├── pptx/           # PowerPoint 技能 (source-available)
│   ├── xlsx/           # Excel 技能 (source-available)
│   └── [更多技能]/     # 创意、技术、企业类技能
├── spec/             # Agent Skills 开放规范
└── template/         # Skill 模板（快速创建新 Skill）

关键技术特点

  • 极简创建：仅需一个 SKILL.md 文件即可创建 Skill，前置元数据只需 name 和 description 两个字段
  • 动态加载：Claude 根据上下文自动识别并加载匹配的 Skill，无需手动切换
  • 可组合性：多个 Skills 可以组合使用，构建复杂的工作流
  • 双许可证：示例 Skills 使用 Apache 2.0 开源，文档处理 Skills 为 source-available（可参考但不可商用）
  • Plugin 架构：支持 Marketplace 分发，提供 document-skills 和 example-skills 两个插件包

🚀 快速上手指南

注册 Marketplace（Claude Code）

在 Claude Code 中运行：

/plugin marketplace add anthropics/skills

安装 Skills 插件

选择并安装所需的插件包：

# 安装文档处理技能
/plugin install document-skills@anthropic-agent-skills

# 安装示例技能
/plugin install example-skills@anthropic-agent-skills

使用 Skill

安装后直接在对话中提及即可触发：

"使用 PDF skill 提取 path/to/some-file.pdf 中的表单字段"

创建自定义 Skill

基于模板创建自己的 Skill：

# 复制模板目录
cp -r template/ my-skill/

# 编辑 SKILL.md
---
name: my-custom-skill
description: 我的自定义技能描述
---

# 添加指令内容...

也可以通过 Claude API 上传和使用 Skills：
