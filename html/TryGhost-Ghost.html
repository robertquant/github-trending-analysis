📖 项目简介与核心功能

Ghost 是由 Ghost Foundation 维护的开源出版平台，自 2013 年发布以来已发展为最流行的 Node.js CMS 之一。它专注于现代内容发布，将博客、Newsletter、会员订阅和付费内容整合在一个统一的平台中。

核心功能

  • 专业编辑器 — 基于 Markdown 的富文本编辑器，支持拖拽图片、嵌入卡片、实时预览
  • 原生 Newsletter — 内置邮件发送功能，直接从后台向订阅者推送内容
  • 会员订阅 — 原生支持免费/付费会员体系，Stripe 集成实现内容变现
  • Headless CMS — 完整的 REST API + Admin API，支持与任意前端框架搭配
  • 主题系统 — Handlebars 模板引擎 + 自定义主题，灵活控制外观
  • SEO 优化 — 内置站点地图、结构化数据、社交媒体标签、Canonical URL
  • 自动化运维 — ghost-cli 一键部署、自动 SSL、一键更新

🚀 快速上手指南

1

安装 Ghost CLI

通过 npm 全局安装 Ghost 命令行工具

npm install ghost-cli -g
2

本地安装（开发体验）

1 分钟内启动本地 Ghost 实例

ghost install local
3

生产环境部署

在服务器上完整安装，自动配置 SSL（Let's Encrypt）

ghost install
4

或使用 Docker

通过 Docker 快速启动，适合容器化部署

docker run -d -p 2368:2368 ghost
5

或选择 Ghost(Pro) 托管

2 分钟创建站点，CDN/备份/安全全托管，收入 100% 归 Ghost Foundation

# 访问 https://ghost.org 开始创建
