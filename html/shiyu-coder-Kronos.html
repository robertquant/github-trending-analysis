核心架构

Kronos 将金融市场 K线数据视为一种"语言"，通过两阶段框架实现对金融时序的建模与预测。

🔢
Stage 1: BSQ K线分词器
采用 Binary Space Quantization (BSQ) 算法，将连续的 OHLCV K线数据量化为层次化的离散 Token。 不同于简单的均匀分箱，BSQ 在二进制空间中保留金融数据的局部结构和时序依赖关系。
🧠
Stage 2: 自回归 Transformer
在离散化 Token 上进行大规模自回归预训练。模型学习了金融市场的"语法"——包括趋势、波动率、形态模式等隐含规律， 从而具备 Zero-shot 通用预测能力。
📊
多尺度预测
层次化 Token 设计支持多尺度预测：从分钟级到日级，从价格预测到波动率估计， 单一模型覆盖多种金融预测任务。
⚡
合成K线生成
作为语言模型的自然副产品，Kronos 能够生成逼真的合成 K线数据， 在生成保真度上比传统方法提升 22%，可用于数据增强和策略回测。

快速开始

# 安装依赖 pip install kronos

# 加载模型并进行预测 from kronos import KronosPredictor

# 初始化预测器（自动下载预训练权重） predictor = KronosPredictor(model_name="kronos-base")

# 对单只股票进行预测 prediction = predictor.predict(
  symbol="BTC/USDT",
  interval="1h",
  horizon=24  # 预测未来 24 根 K 线 )

# 批量预测（多 GPU 并行） results = predictor.predict_batch(
  symbols=["AAPL", "GOOGL", "MSFT"],
  interval="1d",
  horizon=5
)

# 基于 Qlib 的 A 股微调 torchrun --nproc_per_node=4 finetune.py \\
  --model kronos-base \\
  --market cn_a_share \\
  --data_dir ./data
