📄 项目简介与核心功能

CFnew 是一个基于 Cloudflare Workers/Pages 平台的多功能代理部署工具，由开发者 byJoey 创建并维护。该项目从经典的 zizifn/edgetunnel 改进而来，在继承原有能力的基础上，大幅扩展了协议支持、管理功能和用户体验。

CFnew 的核心理念是零成本部署、图形化管理、多协议共存。用户只需一个 Cloudflare 免费账号，即可在几分钟内部署一个支持 VLESS、Trojan、XHTTP 等协议的代理服务，并通过浏览器中的图形界面进行所有配置管理。

⚙ 技术架构与特点

架构概览

CFnew 运行在 Cloudflare Workers 的边缘计算平台上，利用 Cloudflare 全球 CDN 网络实现低延迟的代理转发。整体架构由以下几个核心部分组成：

组件技术作用
Worker 主程序JavaScript / Cloudflare Workers Runtime处理代理协议解析和流量转发
KV 存储Cloudflare KV Namespace持久化配置数据，支持图形化管理
配置面板HTML/CSS/JS（内嵌）Web 端可视化管理界面
优选引擎Workers Cron Trigger每 15 分钟自动优选 IP
API 层RESTful API外部程序动态管理优选 IP 列表
订阅生成动态模板引擎根据客户端类型自动生成订阅配置

关键技术特点

  • 零服务器成本 — 完全运行在 Cloudflare 免费套餐上，每天 10 万次免费请求
  • KV 配置热更新 — 使用 Cloudflare KV 存储配置，5 小时内存缓存，减少 99% 以上 KV 读取量
  • 无效请求拦截 — 非法路径直接返回 404，不再触发 KV 读取，提升性能和安全性
  • Path 参数覆盖 — 在分享链接的 path 里直接写参数，无需为每个节点单独部署 Worker
  • 智能地区匹配 — 自动检测 Worker 所在地区，优先选择同地区的 ProxyIP
  • 兼容 Xray-core v26.3.27 — 保持与最新 Xray 核心的兼容性

🚀 快速上手指南

Worker 部署方式

注册 Cloudflare 账号
访问 cloudflare.com 注册免费账号
创建 Worker
进入 Workers 和 Pages → 创建 Worker → 上传 CFnew 的 worker.js 文件
设置环境变量
在 Worker 设置中添加 u（你的 UUID）作为必需变量
配置兼容日期
设置 → 运行时 → 兼容性日期选择 2026-01-20
创建 KV 命名空间（推荐）
在 Workers 中创建 KV 命名空间，绑定环境变量 C，启用图形化管理
访问管理面板
访问 https://你的worker.workers.dev/{UUID} 进行图形化配置

基础环境变量配置

# 必需变量
u = 你的UUID

# 可选变量
d = /mypath          # 自定义订阅路径
p = 1.1.1.1:443      # ProxyIP 地址
wk = SG              # Worker 地区代码
ev = yes             # 启用 VLESS（默认启用）
et = yes             # 启用 Trojan
ex = yes             # 启用 XHTTP
ech = yes            # 启用 ECH

客户端订阅

在支持订阅的客户端中添加订阅地址：

https://你的worker.workers.dev/{UUID或自定义路径}

支持的客户端会根据 User-Agent 自动返回对应格式的配置文件。
