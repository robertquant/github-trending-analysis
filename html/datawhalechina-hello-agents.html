📋 项目简介

Hello-Agents：AI Agent 时代的系统学习指南

datawhalechina/hello-agents（全名《从零开始构建智能体》）是 Datawhale 社区推出的系统性智能体学习教程。如果说 2024 年是"百模大战"元年，2025 年开启了"Agent 元年"，那么 Hello-Agents 正是为了填补当前 Agent 教育的空白而生。

教程明确区分了两种 Agent 构建路线：软件工程类 Agent（Dify、Coze、n8n 等流程驱动工具）与 AI Native Agent（真正以 AI 驱动的智能体）。本教程聚焦后者，带领学习者从核心原理出发，深入经典范式，最终亲手构建属于自己的多智能体应用。

作为拥有 44K+ Stars 的中文开源教程项目，Hello-Agents 已成为中国最大的 AI Agent 学习社区之一，配套自研框架 HelloAgents V1.0.0、PDF 下载、在线阅读、视频课程（规划中）等完整学习资源。
