📋 项目简介与核心功能

qiaomu-anything-to-notebooklm 是一个 Claude Code Skill，它能用自然语言把任何内容变成任何格式。用户只需一句话，AI 就会自动完成：内容获取 → 格式转换 → 上传 NotebookLM → AI 生成目标格式的全流程。

15+ 种内容源

微信公众号、YouTube、X/Twitter、播客（小宇宙/喜马拉雅/B站）、PDF、EPUB、Word、Excel、PPT、图片、音频、网页、搜索查询

6 层付费墙绕过

代理服务 → Bot UA 伪装 → 通用绕过 → archive.today → Google Cache → 本地工具，支持 300+ 付费网站（NYT/WSJ/FT/Economist 等）

8 种输出格式

播客（MP3）、PPT（PDF）、思维导图、Quiz、视频、报告、信息图、闪卡 — 自然语言触发，全自动生成

深度分析模式

三轮递进式提问（概览→深度挖掘→综合反刍），利用 NotebookLM 会话上下文，生成 12 个深度问答

中文生态深度整合

微信公众号 MCP 浏览器模拟、小宇宙/喜马拉雅播客转写、飞书文档输出 — 专为中文用户打造

极简安装

只需 Python 3.9+ 和 Git，一键 install.sh 安装所有依赖，3 步即可开始使用
