📋 项目简介与核心功能

GitHub Spec Kit 是 GitHub 官方推出的开源工具包，实现了 Spec-Driven Development（规格驱动开发，SDD）方法论。核心理念是：先写规格说明，再让 AI 编码代理自动生成实现。

传统的软件开发中，规格文档往往是"一次性脚手架"，写完就被丢弃。Spec Kit 彻底翻转了这个逻辑——规格说明变成了可执行的第一等公民，直接驱动 AI 代理生成高质量的工作代码。

核心功能

  • Specify CLI — 命令行工具，一键初始化 SDD 项目结构
  • 六步工作流 — Constitution → Specify → Clarify → Plan → Tasks → Implement
  • 30+ AI 代理集成 — 支持 Claude Code、GitHub Copilot、Gemini、Codex、Cursor 等
  • 丰富的扩展生态 — 100+ 社区扩展（Jira 集成、安全审计、BDD 测试等）
  • 可定制预设 — 通过 Presets 自定义工作流格式和术语
  • Slash 命令系统 — 在 AI 代理中直接使用 /speckit.* 系列命令

扩展与预设系统

Spec Kit 提供了灵活的 扩展 (Extensions) + 预设 (Presets) 双层定制体系：

  • 扩展：添加新功能（Jira 集成、安全审计、代码审查等）
  • 预设：自定义工作流格式（合规要求、术语定制、语言本地化等）
  • 项目级覆盖：单项目微调，无需创建完整预设

模板解析遵循优先级：项目覆盖 > 预设 > 扩展 > 核心默认

👥 适合谁使用

强烈推荐

  • AI 编码代理的重度用户 — 如果你每天都在用 Claude Code / Copilot / Cursor，Spec Kit 能让你的产出质量上一个台阶
  • 从 Vibe Coding 转向结构化开发的团队 — 受够了 AI 生成代码质量不稳定的团队
  • 技术负责人 / 架构师 — 需要通过规格说明来控制 AI 编码方向的人
  • 企业开发团队 — 需要合规、审计、标准化 AI 辅助开发的组织

可以考虑

  • 独立开发者 — 即使是小项目，SDD 也能帮你减少 AI 编码的返工率
  • 开源贡献者 — 用 Spec Kit 来规划和管理你的开源项目

可能不太适合

  • 追求极速原型的人 — 如果只需要快速 POC，完整的 SDD 流程可能略显冗长
  • 不使用 AI 编码代理的人 — Spec Kit 的核心价值依赖于 AI 代理来执行实现

🚀 快速上手指南

Step 1: 安装 Specify CLI

# 推荐：通过 uv 安装（需先安装 uv） uv tool install specify-cli --from git+https://github.com/github/spec-kit.git # 或者用 pipx pipx install git+https://github.com/github/spec-kit.git

Step 2: 初始化项目

# 创建新项目 specify init my-project # 或在现有项目中初始化（选择你的 AI 代理） specify init . --integration copilot specify init . --integration claude

Step 3: 在 AI 代理中执行 SDD 工作流

# 1. 建立项目原则 /speckit.constitution Create principles focused on code quality and testing # 2. 定义你要构建的功能 /speckit.specify Build a photo album app with drag-and-drop organization # 3. 澄清需求 /speckit.clarify # 4. 制定技术方案 /speckit.plan Use React + TypeScript + SQLite # 5. 生成任务清单 /speckit.tasks # 6. 执行实现 /speckit.implement

Step 4: 安装扩展增强功能

# 浏览可用扩展 specify extension search # 安装 Jira 集成扩展 specify extension add spec-kit-jira # 安全审查扩展 specify extension add spec-kit-security-review
