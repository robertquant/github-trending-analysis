📋 项目简介与核心功能

cmux 是由 Manaflow（Y Combinator 孵化的两人创业公司）开发的开源 macOS 终端模拟器。它基于 Ghostty（由 Mitchell Hashimoto 创建的高性能终端）构建，使用 Swift/AppKit 原生开发，非 Electron，启动快、内存占用低。

cmux 的核心定位是为同时运行多个 AI 编程 Agent 的开发者提供高效的多会话管理方案。当开发者同时运行 10+ 个 Claude Code / Codex 会话时，cmux 能让每个会话的状态一目了然。

核心功能

通知环（Notification Rings）
Agent 等待输入时，对应窗格显示蓝色光环，侧边栏标签高亮。快捷键 Cmd+Shift+U 跳转到最近未读。
垂直 + 水平标签页
侧边栏显示 Git 分支、关联 PR 状态/编号、工作目录、监听端口和最新通知文本。支持水平和垂直分屏。
内置浏览器
从 agent-browser 移植的可编程浏览器 API。Agent 可获取可访问性树、点击元素、填写表单、执行 JS。可与终端并排显示。
SSH 集成
cmux ssh user@remote 创建远程工作区。浏览器窗格通过远程网络路由，localhost 直接可用。支持拖拽图片上传（scp）。
Claude Code Teams
cmux claude-teams 一键启动 Claude Code 的 teammate 模式。队友以原生分屏形式出现，无需 tmux。
会话恢复
退出时自动保存会话状态。重新打开恢复窗口布局、工作目录、滚动历史和浏览器 URL。支持 Claude Code、Codex、Gemini 等 15+ 种 Agent 的自动恢复。

🏗️ 技术架构与特点

技术栈

Swift AppKit libghostty Sparkle (自动更新) GPU 加速渲染

架构特点

  • 原生 macOS 应用 — 使用 Swift + AppKit 而非 Electron/Tauri，启动快、内存占用低
  • 基于 libghostty — 复用 Ghostty 的终端渲染引擎，GPU 加速，性能优秀
  • 兼容 Ghostty 配置 — 自动读取 ~/.config/ghostty/config，迁移零成本
  • CLI + Socket API — 全面可编程，可创建工作区、分屏、发送按键、自动化浏览器
  • OSC 通知协议 — 支持终端序列 OSC 9/99/777，通过 cmux notify CLI 集成 Agent hooks
  • Sparkle 自动更新 — 安装一次，后续自动更新

🎯 应用场景

  • 多 Agent 并行开发 — 同时运行多个 Claude Code / Codex 会话，每个处理不同任务（前端、后端、测试），通过通知系统精准知道哪个 Agent 需要响应
  • Code Review 工作流 — 在分屏中同时运行代码审查 Agent 和开发 Agent，侧边栏查看 PR 状态
  • 远程开发 — 通过 SSH 连接远程服务器，浏览器窗格通过远程网络路由，无需额外端口转发
  • 团队协作 — 使用 Claude Code Teams 模式，让多个 AI Agent 作为队友协作开发
  • Web 自动化测试 — 内置浏览器可与开发服务器交互，Agent 直接点击、填表、验证 UI
  • CI/CD 监控 — 在分屏中运行部署脚本，通知系统在需要人工介入时提醒

🔥 为什么火（Trending 原因）

  • AI 编程的刚需痛点：当开发者同时运行 10+ 个 AI Agent 时，原生终端的通知管理几乎是空白。cmux 精准切入这个痛点。
  • Ghostty 生态加持：Mitchell Hashimoto（HashiCorp 创始人）创建的 Ghostty 本身就是热门项目，cmux 在其基础上构建，自然获得关注。
  • 原生性能优势：与 Electron/Tauri 方案形成鲜明对比。Swift + AppKit 原生开发打动了注重性能的开发者。
  • 两个月破万 Star：增长速度惊人，社区讨论和口碑传播效应明显。
  • YC 背景：Manaflow 是 Y Combinator 孵化项目，有一定曝光度。
  • "原语而非方案"的哲学：cmux 不规定使用方式，而是提供可组合的基础设施，让开发者自己构建工作流。这种理念深受资深开发者认可。
  • Agent 生态爆发：Claude Code、Codex、Gemini CLI 等 Agent 工具在 2025 年爆发式增长，cmux 正好提供了管理这些工具的最佳终端环境。

🚀 快速上手指南

安装 cmux
推荐使用 Homebrew 安装：
brew tap manaflow-ai/cmux brew install --cask cmux
或从 GitHub Releases 下载 DMG 安装。
首次启动
macOS 可能提示"无法验证开发者"，点击"打开"即可。cmux 会自动读取现有的 Ghostty 配置（主题、字体、颜色）。
设置 Agent Hooks
安装通知钩子，让 AI Agent 的通知与 cmux 集成：
# 安装所有已检测到的 Agent hooks cmux hooks setup # 或指定特定 Agent cmux hooks setup codex cmux hooks setup --agent opencode
开始多会话开发
# 在不同工作区启动多个 Agent cmux # 打开 cmux，⌘N 创建新工作区 # 或一键启动 Claude Code Teams cmux claude-teams # SSH 到远程服务器 cmux ssh user@remote
使用通知系统
当 Agent 等待输入时：
• 蓝色光环出现在对应窗格
• 侧边栏标签高亮
• 按 ⌘⇧U 跳转到最近未读
• 按 ⌘I 打开通知面板查看所有通知
