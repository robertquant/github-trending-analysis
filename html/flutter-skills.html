📋 项目简介

Flutter Skills：框架官方拥抱 AI Agent 的标志性项目

flutter/skills 是 Google Flutter 团队推出的 官方 Agent Skills 仓库。它提供了一套结构化的技能提示词（Skill Prompts），让 AI 编码助手（Claude Code、Cursor、GitHub Copilot 等）在 Flutter 项目中能够执行复杂的开发流程。

这个项目的核心洞察是：通用的 AI 编码助手在面对 Flutter 特有的架构模式（Riverpod、Bloc、Freezed）、布局系统、无障碍标准时，往往产出质量低下的代码。flutter/skills 通过 Skills 即领域知识注入 的方式解决这一问题。

作为 Flutter 2026 AI 战略的重要组成部分，flutter/skills 与 MCP Server、AI Rules 一起构成了 Flutter 的 AI-First 开发者体验三驾马车。Flutter 也因此成为 首个推出官方 Agent Skills 的主流 UI 框架。

🛠️ 11 个官方 Skills

flutter-accessibility-audit

触发无障碍扫描，自动添加 Semantics 组件和缺失标签。让 Flutter 应用对所有用户可访问。

flutter-add-integration-test

配置 Flutter Driver，将 MCP 操作转换为持久集成测试。自动化用户流程测试。

flutter-add-widget-preview

使用 previews.dart 系统添加交互式 Widget 预览。确保组件设计和交互测试的一致性。

flutter-add-widget-test

使用 WidgetTester 实现组件级测试，验证 UI 渲染和用户交互（点击、滚动、输入）。

flutter-apply-architecture-best-practices

使用推荐的分层架构（UI / Logic / Data）搭建 Flutter 应用。新项目或重构利器。

flutter-build-responsive-layout

使用 LayoutBuilder、MediaQuery、Expanded/Flexible 创建自适应布局。适配手机/平板/桌面。

flutter-fix-layout-issues

修复 Flutter 布局错误（溢出、无限约束）。解决 "RenderFlex overflowed" 等经典报错。

flutter-implement-json-serialization

创建带 fromJson/toJson 方法的模型类。使用 dart:convert 进行 JSON 序列化。

flutter-setup-declarative-routing

使用 go_router 配置 MaterialApp.router，支持 URL 路由和深度链接。

flutter-setup-localization

添加 flutter_localizations 和 intl 依赖，配置 l10n.yaml。一键启用多语言支持。

flutter-use-http-package

使用 http 包执行 GET/POST/PUT/DELETE 请求。Flutter 项目中调用 REST API 的标准方式。
