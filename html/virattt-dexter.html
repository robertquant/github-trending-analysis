About

什么是 Dexter？

一个开源的自主金融研究 AI 代理，由前 Airbnb/Acorns 工程师 Virat 创建，核心代码不到 200 行，却构建了完整的金融研究代理系统。

🧠

自主思考

不同于简单的问答工具，Dexter 会自主思考、规划和学习。它将复杂的金融问题分解为可执行的子任务，逐步深入研究。

✅

自我验证

内置验证代理会严格检查每个分析结果的准确性、一致性和逻辑连贯性，确保金融分析结果可信可靠。

📈

实时数据

通过 Financial Datasets API 获取实时市场数据，包括股票价格、P/E 比率、行业平均值等关键金融指标。

🛡

安全机制

循环检测和步数限制防止代理失控执行，Scratchpad 日志完整记录推理过程，确保可审计性。

Architecture

四代理协作架构

Dexter 采用多代理架构，四个专业化代理分工协作，模拟完整的金融研究团队。

Planning Agent
将复杂金融查询分解为可执行的细粒度任务
例如：将"分析AAPL是否被低估"拆解为6个子任务
Action Agent
执行任务，通过 Financial Datasets API 获取实时市场数据
获取股价、历史数据、行业指标等
Validation Agent
严格检查输出结果的准确性、一致性和逻辑连贯性
交叉验证数据，防止幻觉和错误
Answer Agent
将经过验证的研究发现综合为最终的金融分析报告
输出可信的、经过验证的结论

Quick Start

快速上手

三步启动 Dexter，开始你的 AI 金融研究之旅。

terminal 
# Step 1: 克隆仓库并安装依赖
git clone https://github.com/virattt/dexter.git
cd dexter
bun install

# Step 2: 配置 API 密钥
cp .env.example .env
# 编辑 .env 填入: OPENAI_API_KEY, FINANCIAL_DATASETS_API_KEY

# Step 3: 启动 Dexter
bun run start

# 示例查询：
> "分析苹果公司（AAPL）是否被低估，基于 P/E 比率和行业数据"

# Dexter 会自动分解为：
# 1. 获取当前股价
# 2. 获取历史 P/E 比率
# 3. 获取行业平均 P/E
# 4. 计算估值指标
# 5. 验证数据一致性
# 6. 综合生成分析报告
