项目简介

AiToEarn 是一个开源的 AI 内容营销智能体平台，核心理念是"用 AI 赚钱"。它为 OPC（一人公司）、创作者、品牌与企业提供从内容创作 → 多平台发布 → 自动互动 → 效果变现的全链路 AI 自动化能力。平台覆盖全球 12 个主流社交媒体（抖音、小红书、快手、B站、TikTok、YouTube、Facebook、Instagram、Threads、X、Pinterest、LinkedIn），通过 AI Agent 自动化大幅降低内容运营成本，并通过内置的内容交易市场帮助创作者直接变现。

AI 内容自动化 12+ 平台分发 内容交易市场 MCP 协议 Docker 部署 Electron 桌面端 浏览器插件
四大核心 Agent 能力
💰
Monetize · 内容变现
平台最核心的能力——帮助创作者赚钱。内置内容交易市场，创作者可接商家的推广任务，按 CPS（按成交）、CPE（按互动）、CPM（按曝光）三种模式结算，结果导向，公平透明。
📢
Publish · 多平台发布
一键将内容分发到全球 12+ 主流平台，告别逐个手动发布。支持日历排期功能，像排日程一样统一规划所有平台的内容发布时间，大幅提升运营效率。
💬
Engage · 智能互动
通过浏览器插件实现全平台自动化互动运营：自动点赞、收藏、关注，AI 智能评论回复，评论中高转化信号挖掘（如"求链接""怎么买"），品牌舆情实时监测。
🎨
Create · AI 内容创作
Agent 驱动的内容生产线：自动调用视频生成模型（Grok、Veo、Seedance）、图片模型（Nano Banana），支持视频翻译带口型匹配、批量内容生成，适合矩阵账号运营。

快速上手指南

方式一：网页直接使用（零配置）

直接打开 aitoearn.cn（中国用户）或 aitoearn.ai（国际用户），注册即可使用。

方式二：Docker 私有化部署

Terminal
# 克隆仓库 git clone https://github.com/yikart/AiToEarn.git cd AiToEarn # 一键启动（含 MongoDB + Redis） docker compose up -d # 访问 http://localhost:8080

方式三：MCP 集成 Claude / Cursor

claude_desktop_config.json
{ "mcpServers": { "aitoearn": { "type": "http", "url": "https://aitoearn.ai/api/unified/mcp", "headers": { "x-api-key": "你的API-Key" } } } }
⚠️ 注意：发布内容需要通过 OAuth 登录社交媒体账号。Docker 自部署用户建议配置 Relay（借用官方凭据），避免自行申请各平台开发者账号。
