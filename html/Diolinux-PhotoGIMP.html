📖 项目简介

PhotoGIMP 是一个免费、社区驱动的补丁项目，由巴西 Linux 博主 Diolinux 创建和维护。它通过替换 GIMP 的配置文件，将 GIMP 3.0+ 的界面布局、工具栏位置、快捷键方案全面改造为与 Adobe Photoshop 一致的体验。

与传统"魔改"不同，PhotoGIMP 不修改 GIMP 源码，只是覆盖配置文件（快捷键、布局、主题等），因此不会影响 GIMP 的核心功能，也不会删除你的自定义画笔、字体和插件。

✨ 核心功能

Photoshop 风格工具栏

工具重新排列，位置与 Photoshop 一致。画笔、橡皮擦、移动工具等都在你习惯的位置。

Photoshop 快捷键

完全按照 Adobe 官方 Windows 版文档映射快捷键，B 选画笔、V 选移动、E 选橡皮擦，无需重新学习。

最大化画布空间

默认设置优化了面板布局，提供最大工作区域，减少干扰，专注创作。

自定义启动画面

独特的 PhotoGIMP 启动画面和图标，安装后在系统菜单中以独立应用呈现。

跨平台支持

完整支持 Linux（Flatpak/原生包）、Windows、macOS 三大平台。

安全可逆

仅替换配置文件，不碰源码。删除配置文件夹即可完全恢复 GIMP 原始状态。

🏗️ 技术架构与特点

PhotoGIMP 的核心原理是替换 GIMP 的用户配置文件，而非修改源代码：

配置文件 作用
shortcutsrc键盘快捷键映射，对齐 Photoshop 方案
toolrc工具配置和排序
sessionrc窗口布局和面板位置
dockrc停靠面板/面板配置
gimprc通用 GIMP 偏好设置（画布、网格等）
contextrc活动工具/颜色上下文设置
splashes/自定义 PhotoGIMP 启动画面
theme.cssUI 主题微调样式
templaterc预定义画布模板

设计亮点：仅通过配置层改造，而非源码层面的修改。这意味着每次 GIMP 更新后，PhotoGIMP 都能快速适配，维护成本极低。

🚀 快速上手指南

安装 GIMP 3.0+
# Linux (Flatpak)
flatpak install flathub org.gimp.GIMP

# 或访问 gimp.org 下载
启动并关闭 GIMP 一次

这一步确保 GIMP 生成所需的配置文件夹。

备份现有配置（可选）
# Linux
cp -r ~/.config/GIMP/3.0 ~/GIMP-3.0-backup

# Windows: 复制 %APPDATA%\GIMP\3.0
下载并解压 PhotoGIMP
# 从 GitHub Releases 下载最新版本
https://github.com/Diolinux/PhotoGIMP/releases

# Linux: 解压到家目录（覆盖 ~/.config 和 ~/.local）
# Windows: 解压到 %APPDATA%\GIMP
启动 GIMP，享受 Photoshop 体验

你将看到新的启动画面和 Photoshop 风格的界面布局。
