📋 项目简介

CocoIndex 是一个开源的增量数据框架，专为长周期 AI Agent 设计。它将代码库、会议记录、Slack 消息、PDF、视频等数据源转化为实时、持续刷新的上下文——且只处理增量变化（Δ）。

核心理念："React for data engineering" — 声明目标状态，引擎自动保持同步。

🚀 快速上手

1. 安装

pip install cocoindex

2. 最小示例 — 文档索引

import cocoindex as coco
from cocoindex.connectors import localfs, postgres
from cocoindex.ops.text import RecursiveSplitter

@coco.fn(memo=True)
async def index_file(file, table):
  for chunk in RecursiveSplitter().split(await file.read_text()):
    table.declare_row(text=chunk.text, embedding=embed(chunk.text))

coco.App(coco.AppConfig(name="docs"), main, src="./docs").update_blocking()
