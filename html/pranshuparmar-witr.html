witr - Why Is This Running?

一个跨平台 CLI 工具，追踪进程、服务或端口的起源和责任链，用人类可读的方式解释为什么某个东西正在运行。不再需要手动组合 ps、lsof、ss、pstree。

📄 Apache-2.0 ⭐ 16,536 stars 🛠️ Go 🌐 Linux / macOS / Windows / FreeBSD 👥 pranshuparmar

🎯 核心功能

🔍

进程溯源追踪

展示进程的完整祖辈链（parent chain），从 init 系统到目标进程，说明"谁启动了谁"。

💻

交互式 TUI 模式

实时终端仪表盘，支持搜索、过滤、导航，直观探索系统运行状态。

🔌

容器感知

自动检测 Docker、Podman、Kubernetes、Containerd 容器环境并标注。

🔒

服务检测

识别 systemd、launchd、Windows Services、rc.d 等服务管理器关联。

🚨

健康警告

自动标注：以 root 运行、公网端口绑定、高内存占用等潜在风险。

🎥

录制回放

atop 风格的录制回放模式，可事后分析"那一瞬间发生了什么"。

🔎

多维度查询

按进程名、PID、端口号、打开的文件 — 多种入口快速定位目标。

📄

丰富输出格式

标准、简洁、树形、JSON、环境变量、详细 — 六种格式适配不同场景。

💻 使用示例

基本用法 — 查询进程

# 查询某个进程为什么在运行
witr nginx

# 通过 PID 查询
witr --pid 1234

# 查询占用某个端口的进程
witr --port 8080

# 查询打开了某个文件的进程
witr --file /var/log/syslog

# 以 JSON 格式输出（适合脚本集成）
witr --format json nginx

# 启动交互式 TUI 模式
witr -i

典型输出解读

  Process:     nginx (PID 1234, root)
  Status:      Running since 2026-05-15 06:30:22
  Parent:      systemd (PID 1)
  Service:     nginx.service (enabled)
  Container:   —
  Ports:       0.0.0.0:80, 0.0.0.0:443
  ⚠ Health:  Root process, Public port bindings
  Ancestry:    systemd → nginx (master) → nginx (worker)
  Started by:  systemctl enable --now nginx

🎯 应用场景

场景 1：SSH 登录陌生服务器
快速理解"这个系统上到底在跑什么" — 不需要翻遍 /etc、crontab、systemd 配置。
场景 2：排障与安全审计
发现可疑进程时，一条命令追溯其来源、服务归属、网络监听、文件访问。
场景 3：容器环境调试
自动识别容器类型，展示宿主机与容器的映射关系。
场景 4：新员工入职
快速了解生产服务器上运行的服务拓扑，缩短上手时间。
场景 5：CI/CD 调试
在构建环境中排查端口冲突、进程残留等"为什么还挂着"的问题。

🔥 为什么火 (Trending 原因)

  • 填补真实痛点 — 每个 Linux 用户都问过"为什么这个进程在运行"，但从来没有一个专门的工具来回答这个问题。
  • "一个工具替代一串命令" — 不再需要 ps + lsof + ss + systemctl + pstree 的组合拳。
  • 极低上手门槛 — 单一二进制、零配置、brew install 即用。
  • 社区热议 — Hacker News、Reddit r/commandline、YouTube 等多平台讨论引爆传播。
  • TUI 体验优秀 — 交互式终端界面美观实用，符合现代 CLI 工具审美。
  • 命名即品牌 — "Why Is This Running?" 这个名字本身就是最好的推广，任何人看到名字就知道它是干什么的。
  • 时机恰好 — 在 DevOps/SRE 文化和"可观测性"热潮下，系统理解的工具需求正旺。

🚀 快速上手指南

1. 安装

# macOS / Linux (Homebrew)
brew install witr

# Go Install
go install github.com/pranshuparmar/witr@latest

# 下载预编译二进制
curl -sL https://github.com/pranshuparmar/witr/releases/latest/download/witr-linux-amd64 -o witr
chmod +x witr && sudo mv witr /usr/local/bin/

2. 基本使用

# 查看某个进程为什么在运行
witr nginx

# 交互式模式
witr -i

# 查看占用 8080 端口的进程
witr --port 8080

# JSON 输出（用于脚本）
witr --format json nginx | jq .

3. 进阶技巧

# 录制系统状态供事后分析
witr record -o session.witr

# 回放录制
witr replay session.witr

# 树形展示进程祖辈关系
witr --format tree nginx

# 显示环境变量
witr --format env nginx
