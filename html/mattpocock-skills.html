📚 项目简介与核心功能

mattpocock/skills 是由 TypeScript 社区知名专家 Matt Pocock（Total TypeScript 作者）开源的 AI 编码代理技能集合。项目口号直截了当："Skills for Real Engineers. Straight from my .claude directory."——这些技能是作者日常做真实工程时使用的工具，而非花哨的"vibe coding"。

项目聚焦于解决 AI 编码代理（如 Claude Code、Codex 等）在实际开发中的四大痛点：

  • 沟通失准：Agent 没有理解你真正想要什么 → /grill-me、/grill-with-docs
  • 冗余输出：Agent 不知道项目术语，用 20 个词表达 1 个词能说清的事 → 共享语言（CONTEXT.md）
  • 代码不工作：Agent 缺乏反馈循环，盲目编码 → /tdd、/diagnose
  • 屎山代码：Agent 加速编码的同时也加速了软件熵 → /improve-codebase-architecture

⚙ 技术架构与特点

项目采用技能（Skills）架构——每个技能是一个独立的 Markdown/Shell 文件，可被 AI 编码代理直接加载为 slash command。架构特点如下：

  • 极简设计：每个 Skill 是一个独立文件，小巧、可组合、易修改
  • 模型无关：支持 Claude Code、Codex 及任何支持 custom skills 的代理
  • 一键安装：通过 npx skills@latest add mattpocock/skills 安装
  • 渐进式披露：技能按功能分层，入门仅需 30 秒
  • 工程实践驱动：基于数十年软件工程经验提炼（TDD、DDD、ADR 等）
# 30 秒安装
npx skills@latest add mattpocock/skills

🛠 核心技能清单

项目分为三大类，共 15+ 个技能：

💻 工程类（Engineering）

/grill-with-docs
深度需求对齐 + 构建共享语言（CONTEXT.md）+ ADR 决策记录。最强大的技能之一
/tdd
红-绿-重构循环，每次一个垂直切片，为 Agent 提供持续反馈
/diagnose
系统化调试循环：复现 → 最小化 → 假设 → 检测 → 修复 → 回归测试
/improve-codebase-architecture
发现代码库的"深化"机会，结合 CONTEXT.md 和 ADR 进行架构改进
/to-prd
将对话上下文自动合成为 PRD（产品需求文档），提交为 GitHub Issue
/to-issues
将计划/PRD 分解为可独立认领的 GitHub Issues（垂直切片）
/triage
通过状态机流程对 Issues 进行分类和标记
/zoom-out
让 Agent 跳出细节，从系统全局视角理解代码
/prototype
快速构建一次性原型，验证设计方案

⚡ 生产力类（Productivity）

/grill-me
无情面试模式——对计划/设计进行穷举式追问，直到所有决策分支被覆盖
/caveman
超压缩通信模式，削减约 75% token 用量，保留完整技术准确性
/handoff
将当前对话压缩为交接文档，方便另一个 Agent 继续工作
/write-a-skill
用正确的结构创建新技能——渐进披露 + 绑定资源
