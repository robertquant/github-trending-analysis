📋 项目简介

FinceptTerminal 是一个专业级开源金融分析平台，定位为 Bloomberg Terminal 的免费替代品（Bloomberg 年费约 $24,000-$27,000）。采用 C++20 + Qt6 原生开发，内嵌 Python 进行分析计算，提供单一原生二进制文件，无需 Electron/Web 运行时。

金融分析 投资研究 AI 代理 量化交易 实时数据 地缘政治 多券商集成

🚀 快速上手

方式一：下载安装包（推荐）

从 GitHub Releases 下载对应平台安装包

平台文件
Windows x64FinceptTerminal-Windows-x64-setup.exe
Linux x64FinceptTerminal-Linux-x64.run
macOS ARMFinceptTerminal-macOS-arm64.dmg

方式二：一键构建

git clone https://github.com/Fincept-Corporation/FinceptTerminal.git
cd FinceptTerminal
chmod +x setup.sh && ./setup.sh

方式三：Docker

git clone https://github.com/Fincept-Corporation/FinceptTerminal.git
cd FinceptTerminal
docker build -t fincept-terminal .
docker run --rm -e DISPLAY=$DISPLAY \
  -v /tmp/.X11-unix:/tmp/.X11-unix fincept-terminal
