📖 项目简介与核心功能

Rowboat 是一个开源、本地优先的 AI Coworker——它连接你的邮件、日历、会议记录，自动构建长期的知识图谱，并基于这些上下文帮助你完成实际工作。所有数据以 Obsidian 兼容的 Markdown 文件存储在本地，完全透明可编辑。

核心理念：大多数 AI 工具每次对话都从零开始检索上下文。Rowboat 则维护长期积累的知识图谱——上下文随时间复合增长，关系明确且可审查，笔记由你控制而非隐藏在模型中。

  • 知识图谱记忆 — 自动从邮件、会议、文档中提取人物、项目、决策、承诺等实体及关系
  • Obsidian 兼容 — 纯 Markdown + backlinks，可用 Obsidian 直接打开编辑
  • 工作助手 — 会议准备、邮件起草、文档/PPT 生成、语音备忘录转写
  • Live Notes — 自动跟踪人物、公司、主题的实时笔记
  • BYO Model — 支持 Ollama/LM Studio 本地模型，或自带 API Key
  • MCP 扩展 — 通过 Model Context Protocol 连接外部工具和自动化

🏗️ 技术架构与特点

  • Obsidian Vault 格式 — 底层数据结构是纯 Markdown 文件 + wiki-links，与 Obsidian 完全兼容，用户可直接编辑
  • 知识图谱引擎 — 通过 Markdown backlinks 构建可导航的关系图谱，人物、项目、决策形成网络
  • 多源数据摄入 — Gmail、Google Calendar、Google Drive、Fireflies 会议记录，Composio 集成生态
  • 19 个内置 Skills — 以 Markdown 文件分发的内置技能（Gmail 集成、日程调度、文档生成等）
  • 语音全链路 — Deepgram 语音输入 + ElevenLabs 语音输出，语音备忘录自动转写为 Markdown
  • Exa 搜索集成 — 内置高质量 Web 搜索，支持基于知识图谱的研究任务
  • 桌面应用 — Mac / Windows / Linux 全平台支持，本地运行
  • 隐私优先 — 所有数据存储在本地，无专有格式，无云锁定
# 典型使用场景 "帮我准备和 Alex 的会议" → 从知识图谱提取历史决策、待办、相关邮件 "做一份下季度 Roadmap PPT" → 基于项目上下文自动生成 PDF 幻灯片 "追踪这家竞品的最新动态" → Live Notes 自动从 X/Reddit/新闻聚合更新

🎯 应用场景

  • 会议准备 — 从过往决策、邮件线程、待办问题中生成精准简报或语音摘要
  • 邮件起草 — 基于历史上下文和承诺关系，起草有上下文感知的邮件回复
  • 文档与 PPT 生成 — 从持续积累的项目上下文中生成文档、演示文稿、PDF 幻灯片
  • 跟进追踪 — 捕获决策、行动项、负责人，确保不遗漏
  • 竞品/市场监控 — Live Notes 自动跟踪特定人物、公司或话题的动态
  • 语音备忘录 — 录制语音笔记，自动转写为结构化知识图谱条目
