项目简介与核心功能

FadCam 是一款由 FadSec Lab 开发的开源、无广告 Android 多媒体录制套件。它集成了后台视频录制、行车记录仪、屏幕录制、局域网直播和远程摄像头控制等多种功能，主打隐私优先和无广告体验。

🎬

FadRec 屏幕录制

全功能屏幕录制，支持标注工具（画笔、橡皮擦、文字、形状），多层编辑与版本控制，无限撤销/重做

🏠

FadCam Remote

通过局域网实时直播摄像头画面，支持远程控制录制、调整设置、开关手电筒，实时监控电量与存储状态

📸

行车记录仪 & 后台录制

支持息屏后台录制，使用 Fragmented MP4 格式零损风险，大文件自动分割，支持广角摄像头

🎥

视频 & 音频控制

多分辨率 + 60/90fps 支持，自定义水印文字叠加，地理标记嵌入，可自定义音频比特率和采样率

📁

文件管理

增强缩略图显示，按日期/大小排序过滤，回收站支持恢复与自动清理，内置 ExoPlayer 播放器

🎨

精美界面

Material Design 设计，7+ 主题（含 AMOLED），15+ 自定义图标，独立 beta 安装不冲突

技术架构与特点

技术栈

Java Android SDK ExoPlayer MediaCodec Material Design Fragmented MP4 Nominatim (OSM)

核心架构特点

  • Fragmented MP4 (fMP4) 格式 — 采用分段式 MP4 封装，确保录制过程中即使意外中断也不会导致文件损坏，这是专业行车记录仪级别的可靠性
  • 前台 Service + 后台录制 — 利用 Android Foreground Service 实现息屏后台持续录制，配合通知栏控制面板
  • 局域网直播架构 — 设备端运行轻量 HTTP 服务器，通过 Web 界面实现实时画面预览和远程控制
  • ExoPlayer 集成 — 内置 Google ExoPlayer 播放器，支持多种格式流畅播放
  • App Shortcuts — 支持三个快捷操作（开始录制、停止录制、切换手电筒），可映射到硬件按键
  • 零数据收集 — 完全不收集用户数据，无追踪，无广告，真正的隐私优先

基本使用

  • 后台录制：打开 App → 点击录制按钮 → 锁屏或切换 App → 录制继续进行
  • 远程监控：确保手机和电脑在同一局域网 → 启用 Remote → 在浏览器输入显示的地址
  • 屏幕录制：切换到 FadRec 模式 → 开始录制 → 使用浮动工具栏添加标注
