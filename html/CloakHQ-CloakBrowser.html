📋 项目简介与核心功能

什么是 CloakBrowser？

CloakBrowser 是一个基于 Chromium 源码修改 的隐身浏览器，通过在 C++ 层面修改浏览器指纹来绕过所有主流反机器人检测系统。它不是通过 JavaScript 注入或配置参数伪装，而是直接编译进 Chromium 二进制文件，使检测系统将其识别为真实浏览器——因为它的确是真实浏览器。

源码级 C++ 补丁

57 个源码级补丁覆盖 canvas、WebGL、音频、字体、GPU、屏幕、WebRTC、网络计时、自动化信号和 CDP 输入行为。编译进二进制而非注入 JS。

人性化行为模拟

humanize=True 一行代码启用人类级鼠标轨迹（贝塞尔曲线）、键盘输入节奏、滚动模式。24/24 行为检测信号通过。

顶级的检测通过率

reCAPTCHA v3 评分 0.9（人类级别）、通过 Cloudflare Turnstile、FingerprintJS、BrowserScan 等超过 30 个检测站点的测试。

零配置即插即用

只需 3 行代码即可替代 Playwright/Puppeteer。支持 Python 和 JavaScript，二进制文件自动下载，无需手动配置。

🔥 为什么火（Trending 原因）

1. 解决真实痛点

浏览器自动化被反机器人系统封杀是开发者普遍头疼的问题。传统方案（playwright-stealth、undetected-chromedriver）依赖 JS 注入或配置补丁，每次 Chrome 更新都会失效。CloakBrowser 从源码层面解决问题，可靠性根本不同。

2. AI Agent 生态爆发

随着 browser-use、Crawl4AI、LangChain 等 AI 浏览器 Agent 框架快速增长，隐身浏览器成为刚需基础设施。CloakBrowser 完美契合这一趋势，提供了开箱即用的集成方案。

3. 零门槛迁移

只需替换一行 import 语句即可从 Playwright 迁移，API 完全兼容。开发者无需学习新工具，这极大地降低了采用成本。

4. 开源免费

同类商业产品（Multilogin、GoLogin、AdsPower）月费数十美元。CloakBrowser 完全免费开源（MIT 协议），加上自托管 Profile Manager，对个人开发者和中小企业极具吸引力。

🚀 快速上手指南

Python 快速开始

1
安装包：pip install cloakbrowser
2
编写代码：
from cloakbrowser import launch

browser = launch()
page = browser.new_page()
page.goto("https://protected-site.com")
# 不再被封！
browser.close()
3
运行脚本，二进制文件自动下载（~200MB），首次启动即用。

JavaScript / Node.js 快速开始

1
安装包：npm install cloakbrowser playwright-core
2
编写代码：
import { launch } from 'cloakbrowser';

const browser = await launch();
const page = await browser.newPage();
await page.goto('https://protected-site.com');
await browser.close();

Docker 一键测试

docker run --rm cloakhq/cloakbrowser cloaktest

从 Playwright 迁移（一行改动）

# 改之前
from playwright.sync_api import sync_playwright
pw = sync_playwright().start()
browser = pw.chromium.launch()

# 改之后
from cloakbrowser import launch
browser = launch()

# 剩余代码完全不变
page = browser.new_page()
page.goto("https://example.com")
