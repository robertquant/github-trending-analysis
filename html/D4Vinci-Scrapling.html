📋 项目简介

Scrapling 是一个革命性的 Python Web 爬虫框架，由 Karim Shoair (D4Vinci) 开发。其核心创新在于自适应解析——当目标网站更新页面结构时，Scrapling 能够智能地重新定位目标元素，让你的爬虫不再因网站改版而失效。

从简单的 HTTP 请求到大规模并发爬取，从 Cloudflare 绕过到 AI 辅助提取，Scrapling 真正做到了 "One library, zero compromises"。

🚀 快速上手

1. 安装

pip install "scrapling[all]"
scrapling install # 安装浏览器依赖

2. 基础请求

from scrapling.fetchers import Fetcher

page = Fetcher.get('https://example.com/')
titles = page.css('h1::text').getall()

3. 绕过 Cloudflare

from scrapling.fetchers import StealthyFetcher

page = StealthyFetcher.fetch(
  'https://protected-site.com',
  headless=True,
  solve_cloudflare=True
)
data = page.css('.content').getall()

4. 完整爬虫

from scrapling.spiders import Spider, Response

class MySpider(Spider):
  name = "demo"
  start_urls = ["https://example.com/"]
  concurrent_requests = 10

  async def parse(self, response):
    for item in response.css('.product'):
      yield {"title": item.css('h2::text').get()}

result = MySpider().start()
result.items.to_json("output.json")

5. CLI 工具 (无需编程)

scrapling shell # 交互式爬虫 Shell
scrapling extract get 'https://example.com' output.md
scrapling extract stealthy-fetch 'https://protected.com' data.html --solve-cloudflare
