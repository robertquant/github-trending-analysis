Overview

项目简介

jcode 是一个用 Rust 编写的下一代编程代理框架（Coding Agent Harness）。它不是又一个 AI 编程助手，而是一个"元框架"——负责管理 AI 编程代理与代码环境之间的全部交互，包括请求编排、工具提供、上下文保持和多代理协调。

简单理解：Claude Code、Codex CLI 等是"驾驶员"，而 jcode 是"赛车底盘"——换任何 AI 模型都能在上面跑。

Quick Start

快速上手

1
安装 jcode
Terminal
# macOS & Linux $ curl -fsSL https://raw.githubusercontent.com/1jehuang/jcode/master/scripts/install.sh | bash # macOS Homebrew $ brew tap 1jehuang/jcode && brew install jcode # Windows PowerShell PS> irm https://raw.githubusercontent.com/1jehuang/jcode/master/scripts/install.ps1 | iex
2
配置 AI Provider
Terminal
# 使用已有的 Claude 订阅 $ jcode login --provider claude # 使用 OpenAI/ChatGPT $ jcode login --provider openai # 使用 GitHub Copilot $ jcode login --provider copilot # 使用本地 Ollama $ jcode login --provider ollama
3
开始使用
Terminal
# 启动交互式 TUI $ jcode # 非交互式运行 $ jcode run "say hello" # 恢复之前的会话 $ jcode --resume fox # 启动后台服务器 + 多客户端 $ jcode serve $ jcode connect
