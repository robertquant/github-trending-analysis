📋 项目简介

Dograh 是一个完全开源的语音 AI Agent 平台，由 YC 校友和有退出经验的创始人团队打造。它定位为 Vapi 和 Retell 的开源替代方案，让用户能够通过拖拽式工作流构建器快速创建生产级语音 Agent，无需按分钟付费。


核心理念：100% 开源、可自托管、零供应商锁定。从零到运行一个语音 Bot，只需不到 2 分钟。

🎯 核心亮点

无需 API 密钥即可启动 — Dograh 内置自动生成的密钥和自带的 LLM / TTS / STT 技术栈。连接你自己的密钥用于 LLM、TTS、STT 或电话线路（如 Twilio、Vonage、Telnyx）随时可用。

⚡ 核心功能

🎙️ 语音能力

🏗️ 技术架构与特点

架构概览

Dograh 基于 Pipecat 框架构建，这是一个专为实时音视频 AI 应用设计的开源框架。平台采用模块化设计，核心组件包括：


组件 说明 特点
工作流引擎 拖拽式可视化构建器 无需代码，直观设计对话流
语音处理层 STT → LLM → TTS 流水线 可替换每个环节的模型
电话集成层 多运营商 SIP/PSTN 网关 Twilio、Vonage、Telnyx 等
部署层 Docker Compose 容器化 一条命令启动全栈
Web 界面 管理仪表板 + Web Call 浏览器内直接测试语音 Agent

🔑 架构关键设计

Dograh 的核心引擎基于 Pipecat，这意味着它继承了 Pipecat 在实时音视频处理方面的优势，包括 WebSocket 连接管理、音频帧处理、以及灵活的 Bot 框架集成。同时，Dograh 在上层封装了更友好的工作流 UI 和一键部署体验。

🚀 快速上手指南

Step 1: 一键部署 (60秒)

bash
curl -o docker-compose.yaml \ https://raw.githubusercontent.com/dograh-hq/dograh/main/docker-compose.yaml \ && REGISTRY=ghcr.io/dograh-hq ENABLE_TELEMETRY=true \ docker compose up --pull always

首次启动约需 2-3 分钟下载所有镜像。

Step 2: 创建第一个语音 Bot

1. 打开 http://localhost:3010

浏览器访问 Dograh 管理界面

2. 选择模式并命名

选择「入站」或「出站」，给 Bot 命名（如「客户线索筛选」）

3. 描述使用场景

用 5-10 个词描述场景（如「筛选保险表单中的购买意向」）

4. 点击 Web Call

直接在浏览器中与你的语音 Agent 对话！无需任何 API 密钥。

Step 3: 接入电话线路 (可选)

yaml
# 在 Dograh 仪表板中配置电话运营商 # 支持: Twilio / Vonage / Telnyx / Vobiz / Cloudonix # 仅需填入: Account SID + Auth Token # 系统自动处理 Webhook 和路由配置

💡 提示

如需在远程服务器部署，请参考 官方文档 中的 HTTPS 配置指南。
