🚀 快速上手

三步开始创作

1

安装 ACE-Step 引擎

克隆并安装 ACE-Step 1.5 AI 音乐生成模型（首次运行自动下载模型 ~5GB）

git clone https://github.com/ace-step/ACE-Step-1.5
cd ACE-Step-1.5
uv venv && uv pip install -e .
2

安装并启动 ACE-Step UI

一键安装并启动前端界面

git clone https://github.com/fspecii/ace-step-ui
cd ace-step-ui
./setup.sh # Linux/macOS
./start-all.sh # 一键启动全部服务
3

开始创作音乐！

打开浏览器访问，即可开始生成 AI 音乐

# 本地访问
http://localhost:3000

# 局域网其他设备访问
http://YOUR_IP:3000

💡 更简单的方式：Pinokio 一键安装

下载 Pinokio，搜索 "ACE-Step UI"，一键安装所有依赖，无需终端操作。支持 Windows / macOS / Linux。

📋 系统要求

硬件与软件需求

最低配置（无 LLM）

  • NVIDIA GPU: 4GB+ VRAM
  • Node.js: 18+
  • Python: 3.10+
  • 磁盘空间: ~5GB（模型）

推荐配置（含 LLM 思考模式）

  • NVIDIA GPU: 12GB+ VRAM
  • Python: 3.11 推荐
  • CUDA: 12.8
  • FFmpeg 已安装

跨平台支持

  • Windows: 一键 bat 脚本 / 便携包
  • Linux: 一键 shell 脚本
  • macOS: 完整支持
  • AMD / Intel GPU: 通过 ComfyUI
