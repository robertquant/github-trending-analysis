📋 项目简介

Understand-Anything 是一个将任意代码库、知识库或文档转化为交互式知识图谱的开源工具。它通过多智能体（Multi-Agent）流水线扫描项目，提取每个文件、函数、类和依赖关系，构建可探索、可搜索、可交互的知识图谱，并提供可视化 Dashboard。

核心定位：解决开发者面对庞大代码库时"无从下手"的痛点，让理解代码像浏览地图一样直观。支持 Claude Code、Cursor、VS Code Copilot、Codex、Gemini CLI 等 14+ 主流 AI 编程平台。

✨ 核心功能

🗺️ 结构化图谱
将代码库可视化为交互式知识图谱，每个文件、函数、类都是可点击、可搜索的节点
🏢 业务逻辑视图
Domain View 展示代码如何映射到真实业务流程——领域、流程、步骤一目了然
🧭 引导式导览
自动生成按依赖关系排序的架构导览，以正确的顺序学习代码库
🔍 语义搜索
支持模糊搜索和语义搜索，"哪些部分处理认证？"即可获取相关结果
📊 Diff 影响分析
提交前查看代码变更对系统的影响范围，理解变更的涟漪效应
🎭 个性化适配
Dashboard 根据用户角色（初级开发者、PM、高级用户）调整详细程度
🏗️ 分层可视化
按架构层自动分组——API、Service、Data、UI、Utility，配有颜色编码图例
📚 知识库分析
支持分析 Karpathy 模式的 LLM Wiki，提取实体、声明和隐含关系

🏗️ 技术架构

Understand-Anything 采用 Tree-sitter + LLM 混合架构，让静态分析和 LLM 各自发挥所长：

源代码
→
Tree-sitter
确定性解析
→
Multi-Agent
并行分析
→
知识图谱 JSON
→
交互式
Dashboard

Multi-Agent Pipeline

Agent职责
project-scanner发现文件，检测语言和框架
file-analyzer提取函数、类、导入关系，生成图谱节点和边
architecture-analyzer识别架构分层
tour-builder生成引导式学习导览
graph-reviewer验证图谱完整性和引用完整性
domain-analyzer提取业务领域、流程和步骤
article-analyzer从 Wiki 文章中提取实体和隐含关系

设计亮点：Tree-sitter 保证结构分析的确定性（相同代码始终生成相同的边），LLM 负责语义理解（文件的用途、架构层分配、业务领域映射），两者互补且可增量更新。

🎯 应用场景

  • 新人入职 — 加入新团队面对 20 万行代码，快速理解整体架构和核心模块
  • 开源贡献 — 浏览大型开源项目前，先生成知识图谱把握全局
  • 代码审查 — PR Review 前用 Diff Impact Analysis 理解变更影响范围
  • 遗留代码重构 — 可视化老旧系统的依赖关系，制定安全重构策略
  • 技术文档 — Docs-as-Code 实践，图谱 JSON 直接提交到 Git，团队共享
  • 知识管理 — 分析 LLM Wiki / 知识库，发现概念间的隐含关联

🚀 快速上手

方式一：Claude Code 原生安装

# 从 Plugin Marketplace 安装
/plugin marketplace add Lum1104/Understand-Anything
/plugin install understand-anything

方式二：一行命令安装（支持 Codex / Gemini CLI / Cursor 等）

# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/Lum1104/Understand-Anything/main/install.sh | bash

# Windows (PowerShell)
iwr -useb https://raw.githubusercontent.com/Lum1104/Understand-Anything/main/install.ps1 | iex
