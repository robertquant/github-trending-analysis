📖项目简介与核心功能

Understand-Anything 是由 Yuxiang Lin (Lum1104) 开发的开源工具，核心理念是 "Graphs that teach > graphs that impress"——图谱的价值在于教学，而非炫技。

它使用多 Agent 流水线分析你的项目，提取每个文件、函数、类和依赖关系，构建一个完整的知识图谱，并提供可交互的 Web Dashboard 让你可视化浏览、搜索和提问。

一句话总结：你刚加入一个 20 万行代码的团队，不知道从哪开始？Understand-Anything 帮你一键生成整个代码库的交互式知识图谱，让你从全局视角理解架构。

🏗️技术架构与特点

Understand-Anything 的核心是一个 6 Agent 协作流水线，结合 LLM 智能与静态分析，实现代码理解的自动化。

Agent职责
project-scanner发现文件、检测语言和框架
file-analyzer提取函数、类、导入；生成图谱节点和边
architecture-analyzer识别架构分层
tour-builder生成引导式学习巡览
graph-reviewer验证图谱完整性和引用完整性
domain-analyzer提取业务域、流程和步骤

关键技术特点：

  • 文件分析器并行运行（最多 5 个并发，每批 20-30 个文件）
  • 支持增量更新——仅重新分析上次运行后变更的文件
  • 输出为纯 JSON，可提交到 Git 仓库供团队共享
  • 支持 12 种编程模式（泛型、闭包、装饰器等）的上下文解释
  • 多语言支持：en, zh, zh-TW, ja, ko, ru

🚀快速上手指南

方式一：Claude Code 原生安装

# 从 Plugin Marketplace 安装
/plugin marketplace add Lum1104/Understand-Anything
/plugin install understand-anything

方式二：一键安装脚本（Codex / Gemini CLI / Cursor 等）

# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/Lum1104/Understand-Anything/main/install.sh | bash

# Windows (PowerShell)
iwr -useb https://raw.githubusercontent.com/Lum1104/Understand-Anything/main/install.ps1 | iex

开始分析：

# 分析当前代码库（生成中文内容）
/understand --language zh

# 提问关于代码库的问题
/understand-chat 支付流程是怎么工作的？

# 分析当前变更的影响范围
/understand-diff

# 深入了解特定文件
/understand-explain src/auth/login.ts

# 生成新人入职指南
/understand-onboard
