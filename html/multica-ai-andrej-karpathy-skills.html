📚 项目简介与核心功能

这个项目由 multica-ai（作者 Forrest Chang / @jiayuan_jy）创建，核心是一个单一的 CLAUDE.md 文件，用于改善 Claude Code 的编程行为。

它源自 AI 领域传奇人物 Andrej Karpathy（OpenAI 联合创始人、前 Tesla AI 总监）在 2026 年 1 月发布的一条病毒式推文。Karpathy 分享了他从 ~80% 手动编码 + 自动补全，转向 ~80% 代理式编码的体验，并精准总结了 LLM 编程的 4 大陷阱。

🎯 四大核心原则

1Think Before Coding

先思考再编码。不假设、不隐藏困惑、呈现权衡取舍。如果不确定就提问，而不是盲目猜测。

2Simplicity First

简单至上。只写解决问题的最少代码。不需要的功能不写，不需要的抽象不做。200 行能变成 50 行就重写。

3Surgical Changes

精准手术式修改。只触碰必须改的代码。不"顺便"重构、不改动无关代码、匹配已有风格。

4Goal-Driven Execution

目标驱动执行。将命令式任务转化为可验证的目标。写测试定义"完成"，让 AI 循环直到通过。
