📚 项目简介与核心功能

multica-ai/andrej-karpathy-skills 是由开发者 Forrest Chang 创建的项目（后转移至 multica-ai 组织），将 Andrej Karpathy 在 2026 年 1 月发布的一系列关于 LLM 编程助手表象的深度观察，提炼成一个可直接使用的 CLAUDE.md 文件。

"The models make wrong assumptions on your behalf and just run along with them without checking. They don't manage their confusion, don't seek clarifications, don't surface inconsistencies, don't present tradeoffs, don't push back when they should."
— Andrej Karpathy

项目仅约 70 行 Markdown，却精准解决了 AI 编程助手最常犯的四大类问题，通过将其放入项目的 CLAUDE.md 文件，即可让 Claude Code 自动遵循这些最佳实践。

四大核心原则

01

Think Before Coding

不要假设、不要隐藏困惑、呈现权衡。在动手之前先想清楚，不确定就问，有歧义就列出多种解读。

02

Simplicity First

最小化代码量解决问题，不做没被要求的功能、不为单次使用构建抽象、200 行能变 50 行就重写。

03

Surgical Changes

只动必须改的代码，不"顺手"重构不相关的内容，不删不是自己引入的死代码，每一行变更都应追溯到用户请求。

04

Goal-Driven Execution

把祈使式任务转为可验证目标："添加验证"变成"为无效输入写测试，然后让它们通过"。LLM 擅长循环直到满足明确目标。

设计哲学

  • 问题驱动：每条原则精确对应 Karpathy 观察到的一个 LLM 失败模式
  • 可验证性：每条原则附带"检测标准"—— 如果一个高级工程师说这太复杂了，那就简化它
  • 审慎优先于速度：对于非平凡任务偏向谨慎，简单任务则由判断力决定
  • 插件化：可作为 Claude Code Plugin 安装，跨项目生效

或手动安装（per-project）

# 已有项目（追加）
