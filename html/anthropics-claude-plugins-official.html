📚 项目简介与核心功能

claude-plugins-official 是 Anthropic 官方维护的 Claude Code 插件市场目录。它为 Claude Code（Anthropic 的 AI 编程助手）提供了一个集中式的插件发现、安装和管理平台。

核心定位： 类似于 VS Code 扩展市场、npm 生态，但专门为 Claude Code AI 编程助手打造。用户可以通过一条命令安装由 Anthropic 官方或社区开发的高质量插件。

核心功能

  • 插件市场（Marketplace） —— 提供集中化的插件浏览、发现和安装体验
  • 双轨制插件来源 —— /plugins（Anthropic 内部开发）+ /external_plugins（社区/第三方提交）
  • 一键安装 —— 通过 /plugin install {name}@claude-plugins-official 命令即可安装
  • 标准化插件结构 —— 每个插件包含 plugin.json 元数据、MCP 配置、命令、代理和技能定义
  • 质量审核机制 —— 外部插件需满足质量和安全标准才能被收录
  • 内置 Discover Tab —— 在 Claude Code 中直接浏览 /plugin > Discover
