📖 项目简介与核心功能

yt-dlp 是一个功能极其丰富的命令行音视频下载工具，支持 数千个网站。它是经典项目 youtube-dl 的继任者（基于已停止维护的 youtube-dlc 分支），已成为互联网视频下载领域的绝对标准。

项目由社区驱动，拥有数百名贡献者，持续快速迭代。从 YouTube、Bilibili、Twitch 到 Twitter/X、TikTok 等几乎所有主流视频平台，yt-dlp 都能胜任下载任务。

核心功能亮点

🎬 多站点支持

支持数千个视频网站，包括 YouTube、Bilibili、Twitch、Twitter/X、TikTok、Vimeo、Niconico 等主流平台

🎯 SponsorBlock 集成

可自动标记/移除 YouTube 视频中的赞助片段、片头、片尾等段落，实现无广告观看

🔄 智能格式选择

支持 -S 参数按分辨率、编码器、比特率等灵活排序，比 youtube-dl 的 -f 更直观强大

🍪 浏览器 Cookie 导入

自动从 Chrome、Firefox、Edge 等主流浏览器提取 Cookie，解决需要登录的视频下载问题

⚡ 并发下载

支持 -N 参数多线程并发下载 DASH/HLS 分片，大幅提升下载速度

🔌 插件系统

支持第三方 Extractor 和 PostProcessor 插件，无限扩展功能

📺 直播流支持

支持从直播开始处下载（--live-from-start），支持 YouTube、Twitch 等平台

🛡️ TLS 指纹伪装

通过 curl_cffi 模拟真实浏览器的 TLS 指纹，绕过反爬虫检测

架构亮点

  • Extractor 模式：每个网站对应一个独立的 Extractor 类，解耦清晰，易于维护和扩展
  • 三频道发布：stable（月更）→ nightly（日更）→ master（每次推送），用户可按需选择更新频率
  • 配置文件层级：支持 Main → Portable → Home → User → System 五层配置加载
  • 输出模板引擎：支持字段遍历、算术运算、日期格式化、正则匹配等高级模板语法
  • Python API 嵌入：可通过 from yt_dlp import YoutubeDL 直接嵌入 Python 项目

🚀 快速上手指南

安装

# Windows (推荐) winget install yt-dlp # macOS brew install yt-dlp # Linux / pip 通用 pip install -U "yt-dlp[default]" # 使用官方二进制（推荐） curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -o ~/.local/bin/yt-dlp chmod a+rx ~/.local/bin/yt-dlp

常用命令

# 下载最佳质量视频（默认行为） yt-dlp "https://www.youtube.com/watch?v=VIDEO_ID" # 仅提取音频为 MP3 yt-dlp -x --audio-format mp3 "URL" # 使用预设快速下载（mp3/aac/mp4/mkv） yt-dlp -t mp3 "URL" # 下载最高 720p 的视频 yt-dlp -S res:720 "URL" # 从浏览器导入 Cookie（下载需登录的视频） yt-dlp --cookies-from-browser chrome "URL" # 移除赞助片段 yt-dlp --sponsorblock-remove all "URL" # 下载播放列表，按上传年份分类 yt-dlp -o "%(upload_date>%Y)s/%(title)s.%(ext)s" "PLAYLIST_URL" # 并发下载 8 个分片 yt-dlp -N 8 "URL" # 下载直播从头开始 yt-dlp --live-from-start "LIVE_URL" # 更新到 nightly 频道（推荐） yt-dlp --update-to nightly

Python API 嵌入

from yt_dlp import YoutubeDL URLS = ['https://www.youtube.com/watch?v=BaW_jenozKc'] with YoutubeDL({'format': 'mp3'}) as ydl: ydl.download(URLS)
