Overview

项目简介

🌊
什么是 Ruflo?
Ruflo（原名 Claude Flow）是由 rUv 开发的开源企业级 Agent 编排平台，专为 Claude 生态设计。一个 init 命令即可让 Claude Code 获得完整的"神经系统" — Agent 自组织成蜂群、从每次任务中学习、跨会话记忆，并通过联邦协议安全地与其他机器上的 Agent 协作。底层策略引擎使用 Rust 编写的 WASM 内核驱动。
🏗️
核心理念
"Ru" 来自 rUv，"flo" 来自 flow。 作者热爱 Rust、心流状态和构建"感觉必然"的产品。核心理念是：你只需继续写代码，Ruflo 负责所有协调工作。不需要学习 314 个 MCP 工具或 26 个 CLI 命令 — hooks 系统自动路由任务、学习成功模式并在后台协调 Agent。

Target Audience

适合谁使用?

✅
强烈推荐
  • Claude Code 重度用户 — 项目管理的复杂度已超出单 Agent 能力
  • AI 工程团队 — 需要多 Agent 协作处理大型代码库
  • 企业安全团队 — 需要 AI Agent 的合规与审计能力
  • 全栈开发者 — TypeScript 生态友好，NPM 即装即用
⚡
需要考虑
  • Python 纯生态团队 — 可能更适合 LangGraph / CrewAI
  • 轻量级需求 — 如果只需简单 Agent 对话，无需编排平台
  • 非 Claude 用户 — 核心优势绑定 Claude 生态
  • 离线环境 — 联邦功能需要网络连接
