📖 项目简介

DigitalPlat FreeDomain 是一个开源的免费域名注册平台，由 Edward Hsing 在 15 岁时创建，如今已发展为服务全球 40 万+ 用户的基础设施项目。它提供多种免费域名后缀，允许用户注册独一无二的域名并绑定到 Cloudflare、FreeDNS 等任何 DNS 服务商，让任何人都能零成本拥有自己的网络身份。

🚀 快速上手指南

访问官网注册

打开 domain.digitalplat.org，使用 GitHub 账号登录并完成身份验证

选择域名后缀

从可用的后缀中选择（如 .us.kg、.dpdns.org、.qzz.io），输入想要的域名前缀

注册域名

确认域名可用后，点击注册。系统即时分配，无需等待审核

配置 DNS

将域名指向你的 DNS 服务商（推荐 Cloudflare），添加 A/CNAME 记录指向你的服务器

部署上线

配置 Web 服务器（Nginx/Caddy 等），绑定域名，你的网站即可上线

# 示例：使用 Cloudflare 管理 DNS 1. 在 FreeDomain 注册 yourname.us.kg 2. 登录 Cloudflare → 添加站点 → 输入 yourname.us.kg 3. 在 FreeDomain 面板中将 NS 记录改为 Cloudflare 提供的 NS 4. 在 Cloudflare 添加 DNS 记录： A yourname.us.kg → 你的服务器IP 5. 等待 DNS 传播（通常几分钟）
