📋 项目简介与核心功能

gstack 是 Y Combinator 总裁兼 CEO Garry Tan 的个人 AI 辅助开发工作流开源项目。它将 Anthropic 的 Claude Code CLI 工具转变为一个完整的虚拟工程团队，通过 23 个精心设计的专家角色技能（slash commands），覆盖从产品构思到部署上线的完整软件开发生命周期。

核心理念：一个人 + AI 工具 = 一个完整的工程团队。Garry Tan 在 60 天内兼职交付了 3 个生产级服务、40+ 个功能，同时全职管理 Y Combinator。他声称 2026 年的有效代码产出率是 2013 年的 810 倍。

核心工作流 — "Sprint" 模型：

  1. Think（思考） — /office-hours 六个关键问题重构产品思路
  2. Plan（规划） — /plan-ceo-review CEO 级战略审视，/plan-eng-review 工程架构审查
  3. Build（构建） — 基于设计文档和计划自动生成代码
  4. Review（审查） — /review 高级工程师级代码审查
  5. Test（测试） — /qa 用真实浏览器做端到端测试
  6. Ship（发布） — /ship 自动化 PR 创建和测试运行
  7. Reflect（复盘） — /retro 工程经理级迭代回顾

🏗️ 技术架构与特点

gstack 的架构设计围绕 Markdown 驱动 + 角色分离 的理念，每个技能本质上是一个精心编写的 Markdown prompt，通过 Claude Code 的 skill 系统加载。

技术栈：TypeScript（核心逻辑）/ Shell（安装脚本）/ Bun v1.0+（运行时）/ Playwright（浏览器自动化）/ Chromium（无头浏览器）/ Supabase（遥测可选）

关键架构特点：

  • 技能链式传递 — 每个技能的输出自动成为下游技能的输入。/office-hours 生成的设计文档被 /plan-ceo-review 读取，/plan-eng-review 编写的测试计划被 /qa 继承
  • 多 Agent 协调 — 通过 /pair-agent 实现跨 AI 代理（Claude、OpenClaw、Codex、Cursor）的浏览器共享和任务协调
  • 真实浏览器集成 — 基于 Playwright 的 /browse 技能提供真实 Chromium 浏览器操作，支持 Cookie 导入、反检测和截图
  • GBrain 持久记忆 — 基于 PGLite/Supabase 的跨会话知识库，让 AI 代理在不同会话间保持对项目的理解
  • 安全防御层 — 内置 OWASP Top 10 安全审计（/cso）、Prompt 注入防护（22MB ML 分类器）、安全护栏（/careful//freeze）
  • 跨平台支持 — 不仅支持 Claude Code，还支持 Codex CLI、Cursor、OpenCode、Kiro、Slate 等 10 种 AI 编程工具
  • 并行 Sprint — 可同时运行 10-15 个并行开发会话，每个会话独立隔离

🚀 快速上手指南

前置条件： Claude Code、Git、Bun v1.0+（Windows 还需要 Node.js）

30 秒安装：

# 在 Claude Code 中粘贴以下命令 git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack cd ~/.claude/skills/gstack && ./setup

5 步体验完整工作流：

# Step 1: 描述你要构建什么 /office-hours # Step 2: CEO 级战略审视 /plan-ceo-review # Step 3: 工程架构审查 /plan-eng-review # Step 4: 代码审查（有代码变更后） /review # Step 5: 发布 /ship

团队模式（自动更新）：

# 在项目仓库内运行，队友自动获得 gstack (cd ~/.claude/skills/gstack && ./setup --team) && ~/.claude/skills/gstack/bin/gstack-team-init required && git add .claude/ CLAUDE.md && git commit -m "require gstack"
提示：首次使用建议从 /office-hours 开始，描述你想要构建的产品。系统会自动引导你走完整个 Sprint 流程。如果你只想快速体验，直接在一个有代码变更的分支上运行 /review 即可。
