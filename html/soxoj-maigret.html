核心功能
🌐

海量站点覆盖

支持 3,000+ 个网站的账号检测。默认检查 Top 500 站点，使用 -a 扫描全部，或 --tags 按分类/国家筛选。

🔍

智能信息提取

自动提取 PII（个人身份信息）、姓名、位置、简介、头像。交叉关联发现账号之间的链接关系，自动提取关联用户名和 ID。

🔄

递归搜索

使用已发现的用户名和 ID 进行递归搜索。支持 --parse URL 解析页面和 --permute 生成用户名变体组合。

🛡

反检测与代理

检测并部分绕过封锁、审查和 CAPTCHA。完整支持 Tor、I2P 和 HTTP/SOCKS5 代理，适用于 .onion / .i2p 站点。

📊

多格式报告

输出 HTML 交互报告、PDF 存档、XMind 思维导图、CSV/JSON/TXT 数据、D3.js 关系图谱。内置 Web UI 可视化界面。

🐍

Python 库集成

可作为 Python 库嵌入到自己的项目中。CLI 仅是对异步函数的薄封装，支持自定义 OSINT 工作流和管道构建。

为什么火 — Trending 原因分析
01

OSINT 需求爆发

随着网络安全威胁持续增长，OSINT 工具需求呈现爆发式增长。Maigret 作为该领域最全面的用户名搜索工具，自然受到广泛关注。今日新增 1,119 Stars 就是最好的证明。

02

Sherlock 的进化替代

Maigret 最初是 Sherlock 的 fork，但功能已远超原版：Sherlock 仅检查约 400 个站点，Maigret 覆盖 3,000+；增加了信息提取、递归搜索、报告生成等高级功能。被社区广泛认为是 Sherlock 的"升级版"。

03

专业工具集成

被 Social Links API、Social Links Crimewall、UserSearch 等多个专业 OSINT 分析平台采用。Bellingcat 已将其纳入官方调查工具箱，极大地提升了项目知名度和可信度。

04

持续活跃维护

站点数据库每日自动更新（GitHub 源），活跃的社区贡献者不断新增/修复站点。最新版本 v0.5.0 增加了 UnstoppableDomains 支持、memory.lol Twitter 归档搜索等功能。

05

零门槛使用

无需 API Key，一行命令即可运行。提供 CLI / Web UI / Docker / Telegram Bot / Cloud Shell 等多种使用方式，覆盖从新手到专业用户的全场景需求。

快速上手指南
安装 (需要 Python 3.10+) 
# 一行命令安装并使用
pip install maigret
maigret YOUR_USERNAME
基本用法 
# 搜索单个用户名（默认 Top 500 站点）
maigret johndoe

# 生成 HTML 报告
maigret johndoe --html

# 检查所有 3000+ 站点
maigret johndoe -a

# 按标签筛选
maigret johndoe --tags photo,dating

# 通过 Tor 搜索
maigret johndoe --tor-proxy socks5://127.0.0.1:9050
高级用法 
# 解析 URL 并递归搜索
maigret --parse https://twitter.com/johndoe

# 生成用户名排列组合后搜索
maigret john doe --permute

# 导出为交互式关系图
maigret johndoe --graph

# 同时搜索多个用户名
maigret user1 user2 user3 -a
Docker 部署 
# CLI 模式
docker run -v $(pwd)/reports:/app/reports soxoj/maigret:latest johndoe --html

# Web UI 模式（访问 http://localhost:5000）
docker run -p 5000:5000 soxoj/maigret:web
