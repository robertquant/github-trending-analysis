📖 项目简介与核心功能

MasterDnsVPN 是一个科学研究导向的 DNS 隧道 VPN，通过将 TCP 流量封装在 DNS 查询和响应中，在互联网审查和封锁环境中建立通信通道。由开发者 Amin Mahmoudi 创建，在伊朗长达 70+ 天的全国断网中经受住了实战检验。

核心理念：DNS 是互联网基础设施中最不可封禁的协议——封掉 DNS 就等于摧毁网络自身。MasterDnsVPN 利用这一特性，将加密数据伪装成普通 DNS 流量，实现极难被检测和封锁的网络连接。

  • 自定义轻量协议 — 开销仅 5-7 字节，比 DNSTT 低 88%，比 SlipStream 低 71%
  • 低开销 ARQ — 自动重传请求机制，在高丢包环境下保持可靠传输
  • 多路径解析器 — 8 种内置负载均衡模式，自动健康检查与故障切换
  • 会话多路复用 — SOCKS5/4 代理支持，多连接并行传输
  • 灵活加密 — XOR / ChaCha20 / AES-128/192/256-GCM 可选
  • 压缩支持 — ZSTD / LZ4 / ZLIB 可选，进一步降低流量消耗
  • MTU 自动发现 — 自动协商最优传输单元，适应不同网络环境
  • 本地 DNS 缓存 — 内置 DNS 解析器，避免 DNS 泄露

🏗️ 技术架构与特点

  • Go 语言实现 — 97% Go 代码，跨平台编译，单二进制文件部署
  • 自定义隧道协议 — 非基于标准 DNS TXT/CNAME，自研轻量协议实现极低开销
  • ARQ 重传机制 — 低开销自动重传请求，相比标准 TCP 重传更适合 DNS 隧道场景
  • 多路径解析器管理 — 8 种负载均衡策略：轮询、加权、最少连接、延迟优先等
  • 解析器健康检查 — 自动检测不可用解析器并禁用，后台恢复后自动重新激活
  • 数据包复制 — 关键数据包通过多解析器同时发送，提高可靠性
  • MTU 发现与同步 — 客户端与服务端自动协商最优 MTU，避免分片导致的性能下降
  • 打包控制块 — 将多个控制信息打包到单个 DNS 响应中，减少往返次数
# 架构示意 Client App → SOCKS5 Proxy → MasterDnsVPN Client → 加密 + 压缩 + 自定义协议封装 → DNS Queries (通过多个 DNS Resolver) → MasterDnsVPN Server (权威 DNS) → 解密 + 解压 → 目标 TCP 连接 → Internet

🚀 快速上手指南

1

准备服务器

需要一台有公网 IP 的服务器，并拥有一个域名（配置 NS 记录指向服务器）

2

下载并安装

从 GitHub Releases 下载对应平台版本

3

配置服务端

编辑 server.json 配置域名、加密方式、监听端口等参数

# 启动服务端 ./MasterDnsVPN -config server.json
4

配置客户端

编辑 client.json，填入域名、DNS 解析器列表、加密参数

# 启动客户端 (SOCKS5 代理) ./MasterDnsVPN -config client.json
5

使用代理

客户端启动后监听 SOCKS5 代理 (默认 127.0.0.1:1080)，浏览器或系统代理指向该地址即可
