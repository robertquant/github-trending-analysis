📋 项目简介与核心功能

Agents Towards Production 是由 AI 教育者 Nir Diamant 创建的开源实战教程合集，旨在帮助开发者将 GenAI Agent 从原型阶段推进到生产级部署。项目提供了 28 个端到端、代码优先的教程，覆盖了构建生产级 AI Agent 所需的全部关键组件。

核心理念：The open-source playbook for turning AI agents into real-world products.

教程覆盖的核心模块

  • 🔌 工具集成 — 安全的工具调用（OAuth2 认证、人类-in-the-loop 控制）
  • 📊 数据处理 — Web 数据采集（Bright Data、Tavily 实时搜索）
  • 🔍 RAG & 知识管理 — 生产级 RAG 系统（Contextual AI 平台）
  • 🧠 记忆系统 — 双重记忆（短期/长期）、语义搜索（Redis、Mem0、Cognee）
  • 🚀 部署 — Docker 容器化、AWS Bedrock AgentCore、Ollama 本地部署
  • 👥 多 Agent 协调 — A2A 协议、多 Agent 通信
  • 🔒 安全 — 输入/输出/工具安全防护（LlamaFirewall、Apex 安全评估）
  • 🧩 Agent 框架 — LangGraph、FastAPI、MCP 协议、Kotlin/Koog
  • 🛠️ 模型定制 — Fine-tuning 领域专家 Agent
  • 🔍 可观测性 — LangSmith 追踪与调试
  • 📊 评估 — 自动化 Agent 评估与行为分析（IntellAgent）
  • 🖥️ UI/前端 — Streamlit 聊天机器人界面
LangGraph LangSmith FastAPI Docker Redis MCP A2A Protocol Ollama

🏗️ 技术架构与特点

项目采用模块化教程设计，每个教程都是独立可运行的 Jupyter Notebook 或 Python 脚本，覆盖 AI Agent 生命周期的各个阶段。

AI Agent 生产级架构

架构分层：
编排层 (LangGraph) → 记忆层 (Redis/Mem0/Cognee) → 工具层 (MCP/Arcade) → 安全层 (LlamaFirewall) → 可观测层 (LangSmith) → 评估层 (IntellAgent) → 部署层 (Docker/AWS/Ollama)

🚀 快速上手指南

1. 克隆仓库

git clone https://github.com/NirDiamant/agents-towards-production.git
cd agents-towards-production

2. 选择教程并安装依赖

# 例如：多工具 Agent 编排教程
cd tutorials/agentic-applications-by-xpander.ai
pip install -r meeting-recorder-agent/requirements.txt

3. 运行教程

# Jupyter Notebook 交互式学习
jupyter notebook tutorial.ipynb

# 或直接运行 Python 脚本
python app.py

推荐学习路径

入门：LangGraph 状态工作流 → Streamlit UI → Docker 容器化
