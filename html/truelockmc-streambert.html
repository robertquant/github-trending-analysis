JavaScript Electron React Vite Zero Ads & Tracking

🎬 项目简介

Streambert 是一款基于 Electron 的跨平台桌面应用，让用户可以免费流式观看和下载全球任何电影、电视剧和动漫。项目最大的卖点是完全无广告、无追踪，以隐私为核心理念。

该项目由独立开发者 truelockmc（true_lock）创建，最新版本为 v2.4，支持 Windows、Linux（.deb / .AppImage / .pacman）全平台，并已上线 Pinokio 应用商店。

Electron React (JSX) Vite TMDB API AniList API FFmpeg VidSrc / 2Embed AllManga.to

✨ 核心功能

🎦

流媒体播放

通过 VidSrc、videasy.net、2Embed 等源直接播放电影、电视剧和动漫，速度比浏览器更快

🏗️ 技术架构与特点

Streambert 采用经典的 Electron + React + Vite 架构，将前端渲染与原生桌面能力结合：

Project Root
├── main.js              # Electron 主进程
├── preload.js           # 安全桥接（contextBridge）
├── vite.config.js       # Vite 构建配置
├── src/
│   ├── App.jsx          # React 根组件
│   ├── main.jsx         # React 入口
│   ├── components/      # UI 组件（17个模块化组件）
│   │   ├── MediaCard.jsx
│   │   ├── DownloadModal.jsx
│   │   ├── TrendingCarousel.jsx
│   │   └── ...
│   ├── pages/           # 页面（首页/电影/剧集/下载/设置/资料库）
│   ├── ipc/             # IPC 通信层（下载/播放/存储/字幕/allmanga）
│   ├── utils/           # 工具函数（API/字幕/备份/评分等）
│   └── styles/          # 全局样式 + 自定义字体

架构亮点：

  • IPC 分层设计：主进程与渲染进程通过 preload.js 安全桥接，ipc/ 目录按功能模块化（downloads、player、storage、subtitles、allmanga）
  • 多源聚合：视频源（VidSrc/2Embed）、元数据源（TMDB/AniList）、动漫源（AllManga.to）三层解耦
  • 原生下载能力：利用 FFmpeg 处理 .m3u8 流，支持多线程下载
  • 模块化组件：17 个独立组件，每个 Modal/页面/工具各自封装

🚀 快速上手指南

前置要求：

  • Node.js >= 22.12.0（仅源码构建需要）
  • 免费的 TMDB API Read Access Token
  • FFmpeg（仅下载功能需要）

方式一：预编译安装（推荐）

# Linux (.deb)
sudo dpkg -i streambert_*.deb

# Arch Linux (.pacman)
sudo pacman -U streambert-*.pacman

# AppImage
chmod +x Streambert-x64.AppImage && ./Streambert-x64.AppImage

# Windows
# 下载 Streambert Setup *.exe 并运行

方式二：从源码构建

git clone https://github.com/truelockmc/streambert.git
cd streambert
npm install
npm run build        # 通用构建
# 或
npm run build:deb    # 构建 .deb 包
npm run build:appimage  # 构建 AppImage

首次启动：应用会提示输入 TMDB API Key，获取方式参见项目 README 中的指南。只需输入一次，后续自动保存。
