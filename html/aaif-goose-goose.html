1. 项目简介与核心功能

Goose 最初由 Block（原 Square）创建，于 2026 年 4 月正式迁入 Linux 基金会旗下的 Agentic AI Foundation（AAIF），成为首批入驻项目之一（与 MCP、agents.md 并列）。它是一个通用型、本地运行的 AI Agent，远超代码补全——可用于研究、写作、自动化、数据分析等任何任务。

🎯 核心理念：从建议到行动

传统 AI 编程工具只提供代码建议，Goose 则能直接执行操作——安装包、运行命令、编辑文件、执行测试、操作浏览器，真正将 LLM 输出连接到真实世界的行动。

✨ 核心功能

  • 三种使用形态：原生桌面应用（macOS/Linux/Windows）、CLI 命令行、API 嵌入式
  • 15+ LLM 提供商：Anthropic、OpenAI、Google、Ollama、OpenRouter、Azure、Bedrock 等
  • ACP 订阅直连：可使用已有的 Claude、ChatGPT、Gemini 订阅，无需额外 API Key
  • 70+ 扩展：通过 MCP（Model Context Protocol）开放标准连接各种工具和服务
  • 交互式组件：MCP Server 可返回交互式 UI 组件（如图表），而非纯文本
  • Rust 原生性能：高性能、跨平台、安全可靠
  • 自定义发行版：可构建预配置 Provider、扩展和品牌的自有 Goose 版本

🔌 ACP：订阅直连

Goose 的 ACP（Agent Connect Protocol）允许用户直接使用已有的 Claude、ChatGPT、Gemini 订阅来驱动 Agent，无需购买额外 API Key。这大幅降低了使用门槛。

📊 交互式 MCP 组件

传统 Agent 交互仅限文本，但 Goose 允许 MCP Server 返回交互式 UI 组件。例如股票查询 Agent 可直接在聊天窗口渲染 K 线图组件，而非仅返回数字字符串。

7. 快速上手指南

安装 CLI

# macOS / Linux curl -fsSL https://github.com/aaif-goose/goose/releases/download/stable/download_cli.sh | bash # Windows (PowerShell) irm https://github.com/aaif-goose/goose/releases/download/stable/download_cli.ps1 | iex

桌面应用

# 从 GitHub Releases 下载对应平台安装包 # macOS: Goose.dmg # Linux: Goose.AppImage / .deb # Windows: Goose.exe

配置 LLM Provider

# 使用 ACP 订阅（无需 API Key） # 在桌面应用中登录 Claude / ChatGPT / Gemini 账号 # 或使用 API Key export ANTHROPIC_API_KEY=your_key export OPENAI_API_KEY=your_key export GOOGLE_API_KEY=your_key

启用扩展

# 在 ~/.config/goose/config.yaml 中配置扩展 extensions: - name: developer-tools - name: browser - name: file-system - name: custom-mcp-server cmd: node /path/to/mcp-server.js

开始使用

# CLI 模式 goose session start # 在对话中直接描述任务 > 帮我创建一个 React 项目并配置 TypeScript > 分析这个 CSV 文件并生成可视化图表 > 修复这个 Python 脚本中的 Bug
