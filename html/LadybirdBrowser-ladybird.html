🌐 项目概览

什么是 Ladybird？

Ladybird 是一个由 Andreas Kling 发起的完全独立的 Web 浏览器项目。它源自 SerenityOS 社区，于 2024 年独立为专门的浏览器项目。与几乎市场上所有其他浏览器不同，Ladybird 不使用 Chromium/Blink、Firefox/Gecko 或 WebKit 的任何代码——它拥有完全自主的渲染引擎、JavaScript 引擎、网络栈和图形库。

为什么它重要？

当前浏览器引擎市场呈现出极端的垄断格局：Blink（Chrome/Edge/Brave 等）约 80%，WebKit（Safari）约 17%，Gecko（Firefox）仅约 3%。整个 Web 生态实际上被两家公司的渲染引擎控制。Ladybird 的出现意味着可能存在第四个完全独立的引擎选择，这对 Web 标准的多样性、开放性和抗风险能力至关重要。

🏗️ 架构设计

多进程架构

Ladybird 采用现代浏览器标准的多进程架构，每个标签页运行在独立的 WebContent 进程中，通过 IPC 与主 UI 进程通信。ImageDecoder 和 RequestServer 也各自独立运行，实现了资源隔离和安全性沙箱化。

💡 关键洞察

浏览器引擎市场当前面临的核心风险：标准收敛。当只有 2-3 个引擎时，Web 标准实际上由引擎实现决定，而非规范驱动。Ladybird 作为一个独立实现，能提供宝贵的"第二意见"——当一个网站在 Blink 和 Ladybird 中表现不同时，它帮助识别模糊的规范边界和实现偏差。
