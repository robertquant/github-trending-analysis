📚 项目简介与核心功能

oh-my-pi (omp) 是一款面向终端的全功能 AI 编程代理，由 Can Boluk 基于 Mario Zechner 的 Pi 项目深度扩展而来。它不是简单的代码补全工具，而是一个将 IDE 级别的代码智能完整搬入终端的编程助手。

核心理念："将 IDE 的能力内置于代理" — 从 LSP 语义理解、DAP 调试器驱动，到 AST 结构化编辑、浏览器自动化，所有能力都原生集成在进程内，无需外部依赖。

🛠 核心数据

  • 40+ 个 LLM 提供商（Anthropic, OpenAI, Gemini, xAI, Groq, Mistral, 本地 Ollama 等）
  • 32 个内置工具（read, write, edit, search, bash, eval, lsp, debug, browser 等）
  • 13 个 LSP 操作（诊断、导航、符号、重命名、代码操作等）
  • 27 个 DAP 调试操作（断点、单步、线程、栈帧、变量检查等）
  • ~27,000 行 Rust 核心代码（搜索、Shell、AST、语法高亮、PTY 全部进程内实现）
  • 跨平台：macOS, Linux, Windows（无需 WSL）

⚙ 技术架构与特点

Hashline 哈希锚定编辑
模型通过内容哈希锚点定位修改位置，而非逐行重述代码。避免空白符冲突和 "找不到字符串" 循环。Grok 4 Fast 在相同任务下输出 token 减少 61%。
LSP 深度集成
所有写入操作经过 LSP 处理：重命名自动更新所有引用、re-exports、barrel 文件。代理拥有与 IDE 完全相同的代码理解能力。
DAP 调试器驱动
直接驱动 lldb/dlv/debugpy 调试器，设断点、单步执行、检查变量。告别 print 调试，代理可以真正理解程序运行时状态。
Rust 原生核心
ripgrep、glob、find、shell (brush) 全部链接进进程，消除 fork/exec 开销。三个 Rust crate（pi-natives, pi-shell, pi-ast）通过 N-API 暴露给 TypeScript。
子代理系统
task 工具将任务分发到隔离的 worktree 子代理，返回 schema 验证的类型化结果。支持并行执行、IRC 进程间通信、独立工具面。
持久 Python + JS 执行
内建持久化 Python 和 Bun worker 内核，支持从内部回调代理工具。可在一个会话中混合使用 Python 数据分析和 JavaScript 可视化。
时间旅行流规则 (TTSR)
规则在模型偏离时通过正则匹配中断流，注入系统提醒后从同一点重试。零上下文税的实时纠偏。
Hindsight 记忆系统
会话间持久化记忆：retain 写入事实、recall 检索、reflect 综合。项目级隔离，跨会话持续学习代码库。
14 种 Web 搜索后端
支持 Exa, Brave, Jina, Perplexity, Gemini 等 14 种搜索后端。自动将 GitHub、arXiv、Stack Overflow 转为结构化 Markdown。
浏览器自动化
基于 Puppeteer 的浏览器驱动，默认隐身模式。可驱动任何 Electron 应用（如 Slack），代理可像读取本地文件一样读取网页。
GitHub 即文件系统
PR、Issue 通过 pr://、issue:// 协议作为路径读取。无需学习额外工具，read 一个接口搞定所有。
配置无缝继承
自动识别并加载 .claude, .cursor, .windsurf, .gemini, .codex, .cline 等八种格式的现有配置，零迁移成本。

🚀 快速上手指南

安装 oh-my-pi
# macOS / Linux (推荐) curl -fsSL https://omp.sh/install | sh # 或通过 Bun bun install -g @oh-my-pi/pi-coding-agent # Windows (PowerShell) irm https://omp.sh/install.ps1 | iex
配置 API 密钥
# 使用 OAuth 登录（支持 Anthropic, Google, GitHub Copilot 等） omp /login # 或设置环境变量 export ANTHROPIC_API_KEY=sk-ant-... export OPENAI_API_KEY=sk-...
进入项目目录并启动
cd your-project omp # 或单次提问模式 omp -p "解释这个项目的主要模块" # 使用慢速模型深度推理 omp --slow # 使用计划模式 omp --plan
