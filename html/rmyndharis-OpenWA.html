📚 项目简介与核心功能

OpenWA 是一个完全开源、可自托管的 WhatsApp API 网关，由开发者 Yudhi Armyndharis (rmyndharis) 创建。它为需要完全控制消息基础设施的开发者设计，无需供应商锁定或隐藏付费。

该项目基于可插拔架构（Pluggable Architecture），允许用户通过配置切换数据库引擎（SQLite/PostgreSQL）、存储后端（Local/S3）和缓存层（Memory/Redis），无需修改任何应用代码。

🎯 核心架构亮点

  • 模块化设计：会话管理、消息处理、Webhook、群组、联系人、认证、基础设施、健康检查等独立模块
  • 适配器模式：数据库、存储、缓存均通过适配器接口抽象，支持运行时切换
  • HMAC 签名 Webhook：实时事件推送，支持 HMAC 签名验证保障安全
  • API Key 认证 + CIDR 白名单：双重安全机制，支持 IP 级别访问控制
  • 审计日志：追踪所有 API 操作，满足合规需求
  • Docker Profile 部署：从基础 SQLite 到全栈（PostgreSQL + Redis + MinIO + Traefik）灵活组合

🚀 快速上手指南

方式一：Docker 部署（推荐）

# 克隆并启动
git clone https://github.com/rmyndharis/OpenWA.git
cd OpenWA
docker compose -f docker-compose.dev.yml up -d

# 访问
# 仪表板: http://localhost:2886
# API: http://localhost:2785/api
# Swagger: http://localhost:2785/api/docs

方式二：本地开发

# 克隆仓库
git clone https://github.com/rmyndharis/OpenWA.git
cd OpenWA

# 安装依赖
npm install

# 启动（配置文件首次运行自动生成）
npm run dev

发送第一条消息

# 创建会话
curl -X POST http://localhost:2785/api/sessions \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{"name": "my-bot"}'

# 启动会话并获取二维码
curl -X POST http://localhost:2785/api/sessions/{sessionId}/start \
  -H "X-API-Key: YOUR_API_KEY"

# 用 WhatsApp 扫描二维码后发送消息
curl -X POST http://localhost:2785/api/sessions/{sessionId}/messages/send-text \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{"chatId": "628123456789@c.us", "text": "Hello from OpenWA!"}'

生产部署（全栈）

# 基础生产环境（SQLite）
docker compose up -d

# PostgreSQL + Redis + 仪表板 + Traefik 反向代理
docker compose --profile full up -d
