项目简介

核心定位

Agent Skills 是一个为 AI 编码代理设计的生产级工程技能包。它将资深软件工程师在日常开发中遵循的工作流、质量关卡和最佳实践，编码为结构化的 Markdown 文件，使 AI 代理（如 Claude Code、Cursor、Copilot 等）能够系统性地遵循这些工程标准。

项目核心理念：AI 编码代理默认走最短路径 — 跳过规格说明、测试、安全审查等关键步骤。Agent Skills 通过结构化工作流和反合理化表（Anti-rationalization Tables），强制 AI 代理执行与资深工程师同等水平的工程纪律。

作者背景

Addy Osmani — Google Cloud AI 总监，前 Google Chrome 团队核心工程师。著有《Learning JavaScript Design Patterns》、《Learning Patterns》等技术书籍，在 Web 性能优化和软件工程实践领域具有全球影响力。他将 Google 多年积累的工程文化（如 Hyrum's Law、Beyonce Rule、Shift Left 等）融入了这套技能包中。

技术亮点与设计哲学

🎯 过程导向而非散文

每个 Skill 是一个工作流（有步骤、检查点、退出标准），而非参考文档。代理按步骤执行，而非"阅读理解"。

🙄 反合理化机制

每个技能包含一个"借口 vs 反驳"表。例如代理说"我晚点再加测试"，技能会明确回应为什么不可以跳过。

✅ 验证不可妥协

每个技能以证据要求结束 — 测试通过、构建输出、运行时数据。"看起来对了"永远不够。

🎨 渐进式披露

SKILL.md 是入口点，补充参考材料仅在需要时加载，最小化 Token 消耗。

🌟 Google 工程文化基因

技能包植入了来自 Google 工程文化的核心概念：Hyrum's Law（API设计）、Beyonce Rule 和测试金字塔（测试）、变更大小控制和审查速度规范（代码审查）、Chesterton's Fence（简化）、主干开发（Git）、Shift Left 和 Feature Flags（CI/CD）、代码即负债思维（废弃管理）。这些不是抽象原则，而是直接嵌入到代理遵循的逐步工作流中。
