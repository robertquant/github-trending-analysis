⚡ 项目简介与核心功能

Hysteria 是一个功能丰富、速度极快的代理和转发工具，由 apernet 团队基于 Go 语言开发。其核心亮点在于使用了定制的 QUIC 协议，专门针对高丢包、不稳定的网络环境进行了优化。

⚡ 极致速度

基于定制 QUIC 协议，在高丢包网络下性能远超传统 TCP 代理，连接建立速度快，传输效率高。

🛡 抗审查能力

协议伪装为标准 HTTP/3 流量，审查者很难在不造成大规模误伤的情况下检测和封锁。

🔨 多种代理模式

支持 SOCKS5、HTTP Proxy、TCP/UDP 转发、Linux TProxy、TUN 模式，覆盖几乎所有使用场景。

🌐 跨平台

支持所有主流平台和架构（Linux、Windows、macOS、ARM、MIPS 等），部署灵活。

🔒 Hysteria Realms (P2P)

独特的 P2P 穿透功能，无需公网 IP 即可在家庭网络、移动热点等环境中托管代理服务器。

📈 可配置拥塞控制

v2.8.0+ 支持 BBR 和 Reno 拥塞控制算法，提供三种 BBR 配置（标准/保守/激进）。

🚀 快速上手指南

1. 安装（一键脚本）

# Linux 一键安装
bash <(curl -fsSL https://get.hy2.sh/)

2. 服务端配置

# /etc/hysteria/config.yaml
listen: :443

tls:
  cert: /path/to/cert.pem
  key: /path/to/key.pem

auth:
  type: password
  password: your-strong-password

masquerade:
  type: proxy
  proxy:
    url: https://news.ycombinator.com
    rewriteHost: true

3. 客户端配置

server: your-server.com:443

auth: your-strong-password

socks5:
  listen: 127.0.0.1:1080
http:
  listen: 127.0.0.1:8080

4. 启动服务

# 服务端
hysteria server -c /etc/hysteria/config.yaml

# 客户端
hysteria client -c config.yaml
