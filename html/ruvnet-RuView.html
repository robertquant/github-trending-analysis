📌 项目简介与核心功能

RuView 是一个基于 WiFi 信号的开源空间智能感知平台，由 ruvnet 开发维护。它将普通 WiFi 路由器发出的无线电波转化为实时感知数据——检测人员存在、测量呼吸和心率、追踪运动轨迹、监控房间状态——全部无需摄像头、无需穿戴设备、甚至可以穿墙工作。

核心思想：每个人体在 WiFi 信号场中都会产生独特的散射模式。RuView 通过 ESP32-S3 传感器捕获信道状态信息（CSI），利用 AI 模型将这些信号变化转化为可操作的空间数据。

核心技术亮点

  • WiFlow 架构 — 17 COCO 关键点姿态估计，无需摄像头训练（10 传感器信号自监督）
  • 自学习 WiFi AI (ADR-024) — 128 维嵌入向量，自监督对比学习，55 KB 模型可运行在 ESP32
  • 60 个 WASM 边缘模块 — 13 个类别、609 个测试，直接在 ESP32 上运行（5-30 KB/模块）
  • 多频 Mesh 扫描 — 6 个 WiFi 通道跳频，利用邻居路由器作为免费雷达照射源
  • Ed25519 见证链 — 每次测量都有密码学认证
  • MicroLoRA 适配 — 每个房间仅 1,792 参数微调，93% 减少重训练数据需求

🚀 快速上手指南

方式一：Docker 体验（无需硬件）

docker pull ruvnet/wifi-densepose:latest
docker run -p 3000:3000 ruvnet/wifi-densepose:latest
# 打开 http://localhost:3000 查看模拟演示

方式二：ESP32-S3 硬件感知（$9）

# 1. 刷入固件
python -m esptool --chip esp32s3 --port COM9 --baud 460800 \
  write_flash 0x0 bootloader.bin 0x8000 partition-table.bin \
  0xf000 ota_data_initial.bin 0x20000 esp32-csi-node.bin

# 2. 配网
python firmware/esp32-csi-node/provision.py --port COM9 \
  --ssid "YourWiFi" --password "secret" --target-ip 192.168.1.20

# 3. 启动感知服务
node scripts/rf-scan.js --port 5006           # 实时 RF 房间扫描
node scripts/snn-csi-processor.js --port 5006  # SNN 实时学习
node scripts/mincut-person-counter.js --port 5006  # 人数统计
