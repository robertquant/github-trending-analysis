项目简介

让 AI 真正理解 n8n 工作流

三步开始使用

1

安装并运行

使用 npx n8n-mcp 一键启动，或通过 Docker 镜像 ghcr.io/czlonkowski/n8n-mcp 部署。也支持一键部署到 Railway。

2

配置 AI 客户端

在 Claude Desktop 的 claude_desktop_config.json 中添加 MCP 服务器配置，或按照文档配置 Cursor、VS Code、Windsurf 等客户端。

3

开始对话

对 Claude 说"帮我创建一个 Slack 通知工作流"，AI 会自动搜索节点、选择模板、验证配置、生成完整工作流。
