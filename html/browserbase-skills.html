Project Overview

项目简介

browserbase/skills 是 Browserbase 推出的一套 AI 编码代理浏览器技能插件，让 Claude Code、Cursor、Codex 等 AI 编码助手能够像人类一样浏览和操作网页——从简单的页面抓取到复杂的表单填写、CAPTCHA 破解，甚至自动化下单。

Browserbase 是一家专注于 "Browser-as-a-Service" 的云基础设施公司，已融资 4000 万美元，为 AI Agent 提供可扩展的远程浏览器环境，内置反检测、住宅代理、验证码解决等企业级能力。

🌐 Browser-as-a-Service · AI Agent · Cloud Browser
