👀 项目简介与核心功能

Free Claude Code 是一个轻量级的本地代理服务器（Proxy），它拦截 Claude Code 发出的 Anthropic API 请求，并将其路由到 10+ 种替代提供商，包括免费的 NVIDIA NIM、Kimi、DeepSeek、OpenRouter，以及本地模型（Ollama、LM Studio、llama.cpp）。

核心功能

  • 即插即用代理 - 无需修改 Claude Code 本身，通过环境变量即可接入
  • 10+ Provider 后端 - NVIDIA NIM、Kimi、Wafer、OpenRouter、DeepSeek、LM Studio、llama.cpp、Ollama、OpenCode Zen、Z.ai
  • 分层模型路由 - Opus/Sonnet/Haiku 流量可分别路由到不同 Provider
  • 原生 Model Picker - 支持 Claude Code 的 /model 模型选择器
  • 流式输出 & Tool Use - 完整支持 streaming、工具调用、thinking blocks
  • Discord/Telegram Bot - 可通过消息平台远程使用 Claude Code，支持语音
  • VS Code / JetBrains 支持 - 原生集成主流 IDE 扩展
  • 本地 Admin UI - 可视化管理界面配置 Provider 和设置

⚡ 快速上手指南

1. 安装 Claude Code

npm install -g @anthropic-ai/claude-code

2. 安装运行时

curl -LsSf https://astral.sh/uv/install.sh | sh
uv self update
uv python install 3.14

3. 获取 NVIDIA NIM API Key（免费）

访问 build.nvidia.com/settings/api-keys 创建免费 API Key

4. 安装并启动代理

uv tool install --force git+https://github.com/Alishahryar1/free-claude-code.git
fcc-server

5. 配置 Admin UI

打开 http://127.0.0.1:8082/admin，粘贴 NVIDIA NIM API Key，点击 Validate → Apply

6. 启动 Claude Code

fcc-claude

代理会自动设置环境变量并启动 Claude Code，默认使用 nvidia_nim/z-ai/glm4.7 模型。
