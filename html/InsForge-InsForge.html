🌐 项目概览

什么是 InsForge？

InsForge 是一个专为 AI 编码代理和 AI 代码编辑器（Cursor、Claude Code、Windsurf、Lovable 等）设计的后端开发平台。它在 AI 代理和后端基础设施之间构建了一个语义层，使 AI 代理能够理解、推理并端到端地操作数据库、认证、存储等后端原语。简单来说：让 AI 代理可以自己搭建和管理生产级后端。

核心理念：从 DX 到 AX

传统后端平台（Supabase、Firebase 等）为人类开发者设计，强调开发者体验（DX）。InsForge 则开创了"代理体验"（Agent Experience, AX）的理念——后端不再需要人类手动配置，AI 代理通过 MCP Server 语义层即可完成数据库建表、认证配置、存储管理、函数部署等所有操作。

语义层架构

InsForge 的核心创新在于在 AI 编码代理和后端原语之间插入了一个语义层。这个语义层执行"后端上下文工程"，使代理能够理解、操作和检查后端系统。代理可以获取后端文档和可用操作、直接配置后端原语、通过结构化 Schema 检查后端状态和日志。

5 容器 Docker 架构

InsForge 通过 Docker Compose 部署，由 5 个核心容器组成：PostgreSQL 数据库、PostgREST API 层、Deno Functions 运行时、认证服务和前端应用。支持多项目并行运行，每个项目使用不同端口和独立数据库隔离。

🔧 MCP Server：AI 代理的后端桥梁

InsForge MCP Server 是整个平台的核心差异化组件。它为 AI 编码助手提供对后端的直接访问能力：数据库查询、Schema 管理、存储操作等。开发者只需在 AI 编辑器中配置 MCP 连接，即可让 AI 代理全权管理后端。

🔥 热门原因分析

  1. 精准踩中 AI Vibe Coding 浪潮 2025-2026 年 AI 编码代理爆发式增长，Cursor、Claude Code 等工具让"用自然语言写代码"成为主流。但 AI 代理擅长生成代码却不擅长配置基础设施——InsForge 精准解决了这个痛点。
  2. MCP 协议生态的先行者 Model Context Protocol (MCP) 正在成为 AI 工具互联的标准协议。InsForge 作为首批提供原生 MCP Server 的后端平台，让 AI 代理直接操作后端成为现实，这赋予了它极强的先发优势。
  3. "AI 原生 Supabase" 的清晰定位 用一句话就能让开发者理解价值主张——Supabase 为人设计，InsForge 为 AI 设计。这种类比降低了理解门槛，同时暗示了巨大的市场潜力。
  4. Y Combinator 背书 经过 6 次申请最终被 YC 录取的故事本身就有极强的话题性。YC 的背书为项目带来了可信度、网络效应和社区关注度。
  5. 完全开源 + 自托管友好 Apache 2.0 协议、Docker Compose 一键部署、5 容器架构——开发者可以轻松在本地或自己的服务器上运行，不存在供应商锁定风险。这种开放态度赢得了社区的广泛认可。
  6. 从 Prompt 到生产的端到端体验 YouTube 教程展示了令人印象深刻的演示：一条 Prompt 就能建好数据库、配置认证、部署上线。这种"魔法感"极大地激发了社交媒体传播。

🚀 快速开始

方式一：云端托管 (insforge.dev)

访问 insforge.dev 注册即可使用，无需本地安装。

方式二：Docker Compose 自托管

# 前置条件: Docker + Node.js # 克隆仓库 git clone https://github.com/InsForge/InsForge.git cd InsForge cp .env.example .env # 启动所有服务 docker compose -f docker-compose.prod.yml up

连接 MCP Server

# 1. 打开 http://localhost:7130 # 2. 按照指引连接 InsForge MCP Server # 3. 在 AI 编辑器中验证连接： I'm using InsForge as my backend platform, call InsForge MCP's fetch-docs tool to learn about InsForge instructions.
