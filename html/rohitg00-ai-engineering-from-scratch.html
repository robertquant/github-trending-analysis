项目简介与核心功能

AI Engineering from Scratch 是由 Rohit Ghumare 发起的开源 AI 工程学习课程，目标是填补一个关键缺口："84% 的学生已经在使用 AI 工具，但只有 18% 觉得自己做好了专业使用的准备。"

不同于市面上碎片化的教程，该项目提供了从底层数学到前沿 Agent 工程的完整学习路径：

  • 从零构建 — 每个算法先从纯数学推导开始，再手写代码实现，最后才引入生产级框架
  • 可交付成果 — 每节课产出可复用的 artifact：Prompt 模板、Skill 文件、Agent 或 MCP Server
  • 多语言支持 — Python（80.8%）、TypeScript、Rust、Julia 四种语言实现
  • 渐进式路径 — 20 个阶段线性堆叠，从数学基础到自主系统到最终毕业项目
python typescript rust julia deep-learning transformers llm agents mcp generative-ai computer-vision nlp reinforcement-learning

为什么火？Trending 原因分析

1. 精准定位市场缺口

引用权威数据（84% 使用 AI vs 18% 感觉准备好）直击痛点，在 AI 工具爆发但系统性教学稀缺的背景下，提供了一条清晰的学习路径。

2. "从零构建"的方法论优势

与 fast.ai 的"自顶向下"不同，该项目采用严格的"自底向上"——先从数学推导写出算法，再引入 PyTorch/sklearn。学完后真正理解底层原理。

3. 每节课产出可复用工具

不仅学习理论，每节课都产出可安装到 Claude / Cursor 的 skill、prompt 或 MCP server。到课程结束，学员拥有 435 个可实际使用的 AI 工具。

4. 覆盖 2026 年前沿技术

内容更新至最新：DeepSeek-V3 架构、EAGLE-3 推测解码、MCP 协议、A2A 协议、Claude Code 权限模式等，时效性极强。

5. 社区驱动力强

被 ByteByteGo 评为"2026 年最有影响力的 AI GitHub 仓库之一"，LinkedIn / X / Reddit 大量推荐，55,593 月访问量。

快速上手指南

在线阅读（零安装）
直接访问 aiengineeringfromscratch.com，选择任意已完成的课程阅读。
克隆并运行
git clone https://github.com/rohitg00/ai-engineering-from-scratch.git
cd ai-engineering-from-scratch
python phases/01-math-foundations/01-linear-algebra-intuition/code/vectors.py
测试你的水平
在 Claude / Cursor / Codex 等支持 SkillKit 的编辑器中运行： 
# 10 道题定位你的起始阶段
/find-your-level

# 测验某个阶段的理解度
/check-understanding 3
安装课程 Skills 到你的 AI 代理
# 安装所有 skills（SkillKit 布局）
python3 scripts/install_skills.py ~/.claude/skills

# 只安装某个阶段
python3 scripts/install_skills.py ./out --phase 14

# 按标签过滤
python3 scripts/install_skills.py ./out --tag rag
