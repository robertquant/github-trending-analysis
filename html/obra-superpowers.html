📖 项目简介与核心功能

Superpowers 由 Jesse Vincent（Prime Radiant 团队）创建，是一个为 AI 编程代理设计的完整软件开发方法论。它不是简单的提示词模板，而是一套基于可组合技能（Composable Skills）构建的结构化工作流系统。

核心理念：AI 编程代理不应该直接跳入写代码，而应该先理解需求、设计方案、制定计划、再通过子代理驱动开发（Subagent-Driven Development）执行。

核心功能

  • 头脑风暴（Brainstorming） — 不急于写代码，先通过苏格拉底式提问精炼需求，产出设计文档
  • 结构化规划（Writing Plans） — 将工作分解为 2-5 分钟的细粒度任务，每个任务有精确的文件路径、完整代码和验证步骤
  • 子代理驱动开发（Subagent-Driven Development） — 为每个任务分派独立子代理，包含两阶段审查（规格合规 + 代码质量）
  • TDD 强制执行 — 严格执行 RED-GREEN-REFACTOR 循环，先写失败测试，再写最小代码通过
  • 代码审查（Code Review） — 自动在任务之间触发审查，严重问题阻断进度
  • Git Worktree 隔离 — 自动在新分支上创建隔离工作区
  • 分支完成流程 — 验证测试、提供合并/PR/保留/丢弃选项

🔄 核心工作流程

1

Brainstorming — 头脑风暴

激活于写代码之前。通过提问精炼想法，探索替代方案，分段展示设计供验证，保存设计文档。

2

Using Git Worktrees — 创建隔离工作区

设计批准后激活。在新分支上创建隔离工作区，运行项目设置，验证测试基线。

3

Writing Plans — 编写实施计划

将工作分解为 2-5 分钟的小任务。每个任务有精确的文件路径、完整代码和验证步骤。

4

Subagent-Driven Development — 子代理驱动开发

为每个任务分派独立子代理，包含两阶段审查（规格合规 + 代码质量），可连续自主工作数小时。

5

TDD + Code Review + Finish — 测试驱动、审查、完成

强制 RED-GREEN-REFACTOR 循环。任务间自动审查，完成后验证测试并提供合并选项。

🔨 技术架构与特点

架构设计

  • 技能组合系统 — 每个技能是独立的 Markdown 文件，自动触发而非手动调用
  • 跨平台适配 — 同一套技能可运行在 Claude Code、Codex、Cursor 等 8+ 平台
  • 零配置工作 — 安装后自动激活，代理在任何任务前自动检查相关技能
  • 强制工作流 — 不是建议而是强制性的工作流，确保每次都遵循最佳实践

技术特点

  • 基于 SKILL.md 的声明式技能定义
  • 支持插件市场分发（Plugin Marketplace）
  • 技能自动触发机制（Auto-trigger）
  • 子代理并发执行能力
  • Git Worktree 隔离开发

🎯 应用场景

💻 日常软件开发

使用 AI 编程代理进行功能开发时，Superpowers 确保代理遵循结构化流程而非随意生成代码。特别适合需要高质量代码的团队项目。

🔧 Bug 修复与调试

系统化调试技能引导代理通过 4 阶段根因分析定位问题，而非随意尝试修复，减少"改了这里又坏了那里"的情况。

🚀 大型功能开发

子代理驱动开发让 AI 可以自主连续工作数小时，每个任务独立审查，适合需要大量代码变更的复杂功能。

🤝 团队协作

标准化的工作流让团队成员的 AI 辅助开发产出一致质量的代码，降低代码审查负担。
