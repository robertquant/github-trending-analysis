🌐 项目概览

什么是 Claude for Financial Services？

这是 Anthropic 官方开源的金融服务业 AI 代理参考实现。它不是通用 AI 模型的简单包装，而是一套完整的、面向金融行业特定工作流的垂直解决方案——从投行并购顾问到基金经理报表分析，从 KYC 合规审查到私募股权尽调，每个场景都有专门的 AI Agent 和配套 Skills。

核心设计理念：垂直 AI 平台

与 OpenAI、Google 等公司专注于通用 AI 能力不同，Anthropic 选择了一条"垂直深耕"的道路。Claude for Financial Services 不是 Demo 或实验项目，而是经过 Accenture、FIS 等全球顶级咨询和金融科技公司验证的生产级系统。其设计假设是：AI 的最大商业价值不在于通用对话，而在于深度嵌入特定行业的专业知识和工作流程。

🚀 快速开始

方式一：Claude Cowork 插件（最快上手）

# 1. 克隆仓库 git clone https://github.com/anthropics/financial-services.git cd financial-services # 2. 在 Claude.ai 中安装 Cowork Plugin # 选择需要的 Plugin 目录（如 plugins/investment-banking/） # 3. 开始使用 Skills /comps # 生成可比公司分析 /dcf # 构建 DCF 估值模型 /earnings # 分析最新财报

方式二：Managed Agents API（企业集成）

# 通过 API 部署 Agent import anthropic client = anthropic.Anthropic() # 调用 Earnings Reviewer Agent response = client.agents.run( agent_id="earnings-reviewer", messages=[{ "role": "user", "content": "分析 Apple 2026 Q1 财报" }] )

连接 MCP 数据源

# 配置 MCP 连接器（以 Morningstar 为例） # 在 .mcp.json 中添加： { "mcpServers": { "morningstar": { "command": "npx", "args": ["-y", "@anthropic/mcp-morningstar"], "env": { "MORNINGSTAR_API_KEY": "your-api-key" } } } }
