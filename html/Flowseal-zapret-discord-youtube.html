⚙ 核心功能
01

DPI 流量绕过

通过操纵网络数据包特征（TTL、窗口大小、分段等）欺骗 ISP 的深度包检测系统，使其无法识别和拦截目标流量。

02

多服务支持

支持 YouTube、Discord、Telegram (Web版) 等主流服务，可通过配置文件自由添加更多需要绕过的域名和 IP。

03

多策略切换

提供 General、ALT、FAKE 等多种绕过策略，适配不同 ISP 和网络环境。用户可逐一测试找到最佳方案。

04

一键安装服务

通过 service.bat 脚本将策略安装为 Windows 系统服务，实现开机自动启动，无需手动运行。

05

内置诊断工具

提供 Run Diagnostics 和 Run Tests 功能，自动检测常见问题并测试不同策略在不同 CDN 上的可用性。

06

灵活的规则管理

支持自定义域名列表、IP 集合和排除规则，满足个性化需求。自动更新 IPSet 和 Hosts 文件。

工作原理流程

1
WinDivert 拦截流量 — 在内核层截获所有网络数据包
▾
2
策略规则处理 — winws.exe 根据选定策略修改数据包特征
▾
3
DPI 欺骗 — 修改后的数据包无法被 DPI 系统正确识别
▾
4
流量放行 — ISP 的 DPI 系统放行流量，用户正常访问目标服务
