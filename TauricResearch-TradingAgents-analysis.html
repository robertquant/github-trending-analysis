一、项目概述

TradingAgents 是由 Tauric Research 团队开发的开源多智能体 LLM 金融交易框架。该项目灵感来源于真实世界中的交易公司组织结构，通过部署多个由大型语言模型（LLM）驱动的专业化智能体来协同完成金融交易决策。

项目的核心论文发表于 arXiv（编号 2412.20138），由 Yijia Xiao、Edward Sun、Di Luo 和 Wei Wang 共同撰写，并通过了 OpenReview 的同行评审。框架基于 LangGraph 构建，确保了高度的灵活性和模块化设计。

自发布以来，该项目在 GitHub 上获得了快速增长——曾在单周内获得超过 9,300 个 Star，成为金融/AI 社区最受关注的开源交易框架之一。社区也已衍生出如 AlpacaTradingAgent 等扩展项目。

TradingAgents 采用分层智能体架构，模拟真实交易公司的组织结构和工作流程。整个系统由 LangGraph 编排，各智能体通过结构化辩论和信息传递机制协同工作。

2.1 分析师团队（Analyst Team）

四个专业化分析师智能体，分别负责不同维度的市场信息收集与分析：

角色职责数据源
基本面分析师评估公司财务状况和业绩指标，识别内在价值和潜在风险信号财务报表、公司公告
情绪分析师聚合新闻标题、StockTwits 和 Reddit 舆论，评估短期市场情绪StockTwits, Reddit, 新闻
新闻分析师监控全球新闻和宏观经济指标，解读事件对市场的影响全球新闻源、宏观数据
技术分析师利用技术指标（如 MACD 和 RSI）检测交易模式和预测价格走势价格数据、技术指标

2.2 研究员团队（Researcher Team）

包含看多（Bull）和看空（Bear）两个研究员智能体。他们批判性地评估分析师团队的洞察，通过结构化辩论机制来平衡潜在收益与固有风险。这种辩论机制是框架的核心创新之一——模拟真实交易公司中不同观点的碰撞。

2.3 交易员（Trader Agent）

综合分析师和研究员的报告，做出知情的交易决策，确定交易的时机和规模。

2.4 风险管理与投资组合经理

风险管理团队持续评估市场波动性、流动性等风险因素，调整交易策略并向投资组合经理提供评估报告。投资组合经理负责最终批准或否决交易提案。批准的交易将发送至模拟交易所执行。

2.5 持久化与恢复机制

决策日志：每次运行自动追加决策记录至 ~/.tradingagents/memory/trading_memory.md，下次运行时自动获取已实现回报（含相对 SPY 的 Alpha），生成反思段落并注入投资组合经理的提示中。

检查点恢复：通过 --checkpoint 启用。LangGraph 在每个节点后保存状态，崩溃或中断的运行可从最后成功步骤恢复。

2.6 多模型支持架构

框架采用双模型分层策略：

  • deep_think_llm（深度思考模型）：用于复杂推理任务，如 GPT-5.5
  • quick_think_llm（快速思考模型）：用于简单任务，如 GPT-5.4-mini

支持 15+ 种 LLM 提供商，包括 OpenAI、Google、Anthropic、xAI、DeepSeek、Qwen（国际/国内双端点）、GLM、MiniMax、OpenRouter、Ollama 本地模型、Azure OpenAI 等。

三、核心创新点

1. 交易公司组织模拟

首创将真实交易公司的组织结构映射为多智能体系统。每个智能体扮演明确的角色（分析师、研究员、交易员、风控、经理），形成完整的决策链。这种设计比单一 LLM 直接生成交易信号更加可靠和可解释。

2. 结构化辩论机制

引入看多/看空研究员的双边辩论机制，模拟真实交易决策中不同观点的碰撞。通过结构化的多轮辩论（可配置辩论轮数），确保交易决策充分考虑了多方观点，避免单一视角带来的偏见。

3. 基于经验的持续学习

决策日志系统自动跟踪每次交易的实际回报，生成反思总结，并在后续分析中注入历史经验。这使得系统能够从过去的成功和失败中学习，逐步改进决策质量。

4. 多提供商弹性架构

支持 15+ 种 LLM 提供商，包括中国大模型（Qwen、GLM、MiniMax）的国际/国内双端点部署。用户可以根据成本、延迟和性能需求灵活选择模型组合，甚至支持本地 Ollama 模型实现完全离线运行。

5. 全球市场覆盖

不仅限于美股，还支持港股、日股、伦股、印度、加拿大、澳大利亚、中国A股以及加密货币市场。使用 Yahoo Finance 交易所后缀代码自动识别公司和基准指数。
