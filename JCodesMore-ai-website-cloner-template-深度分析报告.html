项目概述

ai-website-cloner-template 是开发者 JCodesMore 推出的一个可复用 GitHub 模板（template repository），核心定位是"用 AI 编码代理（AI coding agent）把任意网站逆向工程成一个干净、现代的 Next.js 代码库"。用户只需点击 GitHub 的「Use this template」创建自己的副本，启动 AI 代理，运行 /clone-website <目标网址> 一条指令，代理便会自动检查目标站点、提取设计 token 与素材、撰写组件规格，并并行派发多个构建代理重建每一个区块。

它与传统「网站克隆/截图转代码」工具的本质区别在于：它不是某个具体产品，而是一套方法论的载体（methodology-as-code）——把人类逆向重构网站时的最佳实践（取色、量尺寸、拆组件、并行造、对像素）固化为一份可执行的 AI 代理指令（skill）。项目明确推荐使用 Claude Code 搭配 Opus 4.7 以获得最佳效果，但同时兼容 Codex CLI、Cursor、GitHub Copilot、Gemini CLI 等共 13 种主流 AI 编码代理。

"Point it at a URL, run /clone-website, and your AI agent will inspect the site, extract design tokens and assets, write component specs, and dispatch parallel builders to reconstruct every section."

项目以 MIT 协议完全开源，前置条件极简（Node.js 24+ 与一个 AI 编码代理），凭借「一行命令克隆网站」的强感知卖点与出色的多代理兼容性，在 GitHub 上快速起势、登上 Trending 榜，成为 2026 年 AI 编码代理生态中颇具代表性的「skill / 模板」类资产。

核心创新点

🔀 并行构建代理 + git worktree

第 4 阶段为每个区块/组件在独立 git worktree 中派发一个 builder 代理，实现真并行、互不冲突地重建整个页面。这是把「单线程顺序写码」升级为「多代理并行施工」的关键工程突破，大幅压缩克隆耗时。

📐 精确计算值，杜绝猜测

builder 代理内联接收 getComputedStyle() 的精确像素值、交互模型、多状态内容、响应式断点——不靠 AI 猜尺寸，从根上压低还原误差，这是它比一般「截图转代码」更准的底气。

🎯 单一真相源 · 一次编写多平台

AGENTS.md + SKILL.md 两份真相源，配合 sync 脚本自动重生成 13 种代理的配置。维护成本低、跨平台一致性高，是「跨 AI 代理可移植工程」的范例。

🔍 五阶段流水线 · 视觉差异闭环

侦察→基础→规格→并行构建→装配质检，最后一步对克隆结果与原站做视觉 diff，形成「重建→比对」的质量闭环，让结果可量化、可验收。

🧩 Template 模式 · 即用即走

以 GitHub template repository 形态分发，用户「Use this template」即得独立仓库，生成的网站改动留在自己账户、不污染上游。无需安装额外软件，门槛极低。

🎨 现代产物栈 · oklch 设计 token

产物直接采用 Next.js 16 + React 19 + Tailwind v4（oklch 色彩 token）+ shadcn/ui，生成的是可直接二次开发的现代工程，而非一次性 HTML——这是它适合「平台迁移」的关键。
