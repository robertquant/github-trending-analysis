📋 项目概述

Twenty CRM 是一个完全开源的新一代客户关系管理系统，由 TwentyHQ 团队开发，定位为 Salesforce 和 HubSpot 的开源替代方案。项目诞生于创始人在使用 HubSpot 时遭遇付费墙限制的痛点 —— 仅为追踪 500 个联系人就需要支付每月 50 美元。

Twenty 不只是一个传统 CRM 的开源复刻。它将 CRM 重构为一个可编程的业务平台，让技术团队可以用管理产品的方式管理 CRM：自定义对象、字段、视图和工作流，就像版本控制代码一样管理业务逻辑。

项目于 2023 年创立，入选 Y Combinator S23 批次，2024 年 11 月完成由 Runa Capital 领投的 500 万美元种子轮融资（含 HubSpot 高管在内的 50+ 投资者参与），目前在 GitHub 上拥有超过 45,000 颗星标，是 2025-2026 年度最受关注的开源 CRM 项目。

CRM 开源 TypeScript 全栈 AI 原生 MCP 集成 Y Combinator S23 可编程平台

架构特点：

  • 前后端 100% TypeScript 覆盖，类型安全贯穿全栈
  • GraphQL API + Codegen 实现强类型的数据通信
  • Jotai 原子化状态管理替代传统 Redux，更轻量灵活
  • NestJS 模块化后端架构，支持四类 API（GraphQL、REST、Webhooks、MCP）
  • 支持自托管部署，也可使用官方云服务
  • 原生 MCP (Model Context Protocol) 集成，支持 AI 助手自然语言操作 CRM 数据

💡 核心创新点

  • 可编程 CRM 层：CRM 对象、字段、视图和逻辑像产品基础设施一样可版本化管理，从根本上解决了「通用 CRM 无法满足特定业务需求」的矛盾
  • AI 原生设计：通过 MCP (Model Context Protocol) 标准，Twenty 能与 Claude 等 AI 助手无缝对接，实现自然语言查询和操作 CRM 数据，将 CRM 变为 AI Agent 可直接调用的工具
  • 零供应商锁定：完全开源（AGPLv3），数据自主可控，自托管免费，不锁定在任何特定云平台上
  • 模块化架构：团队表示其核心优势不仅在于 CRM，更在于作为构建任何业务工具的通用平台
  • 开发者优先理念：四类 API 接口、实时 Webhook、完善的开发文档和贡献指南，面向技术团队而非销售人员

🎯 应用场景

  • B2B 销售团队：管理销售管道、跟踪客户互动、自动化工作流
  • 技术驱动型公司：需要高度定制化 CRM 以匹配独特业务流程的团队
  • AI Agent 生态：作为 AI Agent 的数据后端，让 AI 助手直接读写客户数据
  • 中小企业：无法负担 Salesforce/HubSpot 高额许可费用的成长期企业
  • 数据合规需求：需要完全控制客户数据存储和处理的组织
  • 工作流自动化：与 n8n 等自动化工具集成，构建端到端业务自动化

Twenty 的核心差异化在于：它不试图复制 Salesforce 的所有功能，而是重新定义 CRM 应该如何被构建和使用 —— 像管理代码一样管理业务逻辑，像调用 API 一样让 AI 操作 CRM。

🔮 综合评估

优势：

  • 完全免费自托管，无供应商锁定，数据主权完整
  • 现代技术栈（TypeScript + React + NestJS）对开发者友好
  • AI 原生设计，MCP 标准集成走在行业前列
  • 45K+ Stars 活跃社区，Y Combinator 和顶级 VC 支持
  • 可编程化程度高，适配复杂业务需求能力强

风险与不足：

  • 功能完整度尚不及 Salesforce 成熟生态（AppExchange）
  • 团队规模较小（约 11 人），迭代速度受限于人力
  • AGPLv3 许可证对商业闭源集成有约束
  • 企业级功能（合规审计、SLA 保障）仍在建设中

结论：Twenty CRM 是目前最具潜力的开源 CRM 项目。它不仅仅是 Salesforce 的免费替代品，更是在重新思考 CRM 应该如何在 AI 时代工作。对于技术能力较强、重视数据主权和定制化的团队而言，Twenty 是 2026 年最值得投入的开源 CRM 选择。
