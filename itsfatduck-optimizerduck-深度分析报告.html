项目概述

optimizerDuck 是开发者 itsfatduck 推出的 Windows 桌面优化工具。它的核心信念是：Windows 本身没问题，但一次干净的安装总会带来一堆你从未听说过的后台服务、遥测、预装应用和计划任务，悄悄消耗 CPU、内存和磁盘；同时，一些能真正发挥硬件潜力的功能却默认未启用。

optimizerDuck 提供单一界面来清理臃肿项、解锁被埋没的好功能。它应用针对性的系统调优以减少开销、阻断不受欢迎的行为，并内置若干管理工具，让你看到「什么在跑」、移除「不想要的」，并在出问题时一键回滚任何改动。

「每一个优化都可以手动完成，optimizerDuck 只是让你更容易地应用它们。」——所有调优项均源自成熟工具与社区指南，没有 AI 生成、没有盲目堆砌。

项目采用 GPL v3 完全开源，每个 Release 都由 GitHub Actions 从公开源码自动构建，无隐藏修改、无构建后注入的未签名二进制；应用本身零遥测、零分析、零回连，完全离线运行。

技术架构

optimizerDuck 是一个现代 .NET 原生桌面应用，技术选型偏向「正统的 Windows 客户端工程」而非脚本拼凑：

维度实现
运行时框架WPF on .NET 10，使用 WPF UI 库实现 Fluent 风格界面
部署方式无安装程序，单个 .exe 直接运行（绿色便携）
主题系统Dark（默认）/ Light / High Contrast，支持 Mica 云母背景效果
回滚引擎四类回滚步骤（Registry、Service、Scheduled Task、Shell），JSON 持久化状态 + 线程安全文件 I/O
特性发现优化项与功能分类通过 反射 + 自定义特性（Attribute）自动发现，无需手动注册
备份系统本地文件夹式备份，每一次改动都写一份回滚文件，支持一键还原
构建透明Release 由 GitHub Actions 从公开源码自动产出，可自行 dotnet build 编译验证
国际化社区协作翻译，覆盖 10 种语言（英/越/繁中/简中/俄/法/韩/西/日/波兰）
权限需管理员权限运行（修改系统设置与注册表）

核心创新点

🔁 可逆性优先设计

  • 每一次改动都先生成回滚文件，再写入系统
  • UI 内一键撤销单项或全部回滚

  • GPL v3 全开源，GitHub Actions 自动构建
  • 可自行 dotnet build 复现二进制
