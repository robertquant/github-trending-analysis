📋 项目概述

apple/container 是 Apple 于 WWDC 2025 首次发布的开源项目，旨在为 macOS 提供原生的 Linux 容器运行能力。该项目完全使用 Swift 编写，针对 Apple Silicon（M1/M2/M3/M4 系列芯片）深度优化，通过轻量级虚拟机（Lightweight VM）实现 Linux 容器的创建与运行。

该项目由两个核心组件构成：

  • container（CLI 工具）：命令行工具，提供类似 Docker 的用户体验，用于管理容器的生命周期、镜像构建与分发。
  • Containerization（Swift 框架）：底层 Swift 包，提供容器、镜像和进程管理的 API，基于 Apple Virtualization Framework 构建。

项目完全兼容 OCI（Open Container Initiative）标准，可以拉取、运行和推送任何标准容器注册表中的镜像。截至 2026 年 6 月，该项目已发布至 v0.8.0 版本，经历了 7 个月的快速迭代，并在 WWDC 2026 上引入了"Container Machines"新特性。

🔑 关键数据： 开源于 WWDC 2025（2025 年 6 月）发布 · 当前版本 v0.8.0 · 纯 Swift 编写 · 仅支持 macOS 26+ 和 Apple Silicon · OCI 标准兼容

🏗️ 技术架构

整体架构设计

apple/container 采用 "VM-per-container"（每容器一虚拟机） 架构模型。每个 Linux 容器都运行在自己独立的轻量级虚拟机中，而非共享宿主机内核（如传统 Linux 容器方案）。这种设计在安全性和隔离性方面具有显著优势。

在 WWDC 2026 上，Apple 引入了 Container Machines 概念——一种轻量级、持久化的 Linux 环境工具。与传统的临时性容器不同，Container Machines 提供持久化的 Linux 运行环境，适用于需要长期运行的开发场景。

💡 核心创新点

1. VM-per-Container 安全模型

不同于 Docker 等传统方案共享 Linux 内核的做法，apple/container 为每个容器创建独立的轻量级虚拟机。这意味着：

  • 容器间的内核级隔离，安全性大幅提升
  • 单个容器被攻破不会影响其他容器或宿主机
  • 利用 Apple Silicon 的硬件虚拟化支持，性能开销极低

2. 亚秒级启动速度

通过高度优化的 Linux 内核配置和最小化运行时环境，容器启动时间达到亚秒级（<1s），显著快于 Docker Desktop 的启动流程。

3. 原生 macOS 集成

  • 利用 Apple 的 Virtualization.framework 实现硬件加速虚拟化
  • 与 macOS 安全模型深度集成，符合 Apple 的安全与隐私标准
  • 利用 Rosetta 2 实现透明二进制翻译（如需要）

4. Swift 原生生态

作为纯 Swift 项目，可以无缝集成到 Swift 应用中。开发者可以直接通过 Swift API 编程管理容器，为 macOS 应用提供 Linux sidecar 能力。

5. OCI 标准兼容

完全兼容 OCI（Open Container Initiative）镜像标准，现有的 Docker Hub、GHCR 等注册表中的镜像可以直接使用，降低了迁移成本。
