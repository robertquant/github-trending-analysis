LTX-2 · 音视频基础模型

首个将现代视频生成全部核心能力融入单一模型的 DiT 开源音视频基础模型

由以色列创意软件公司 Lightricks 推出，LTX-2 是一款基于非对称双流扩散变换器（Asymmetric Dual-Stream DiT）的音视频生成基础模型。它能在单次前向传播中生成同步的视频与音频，原生支持 4K 分辨率、约 50fps 高帧率、长达 10–20 秒的片段，并可在消费级 NVIDIA GPU 上本地运行。官方仓库提供完整的推理代码、LoRA/全参微调训练器，以及十余条生产级生成流水线。

📌一、项目概述

LTX-2 是 Lightricks 团队推出的开源音视频生成基础模型，被视为 LTX-Video 的下一代继任者。其核心定位是："首个将现代视频生成全部核心能力——同步音视频、高保真、多性能档位、生产级输出、API 访问与开放访问——集中到单一 DiT 模型之中"。

不同于传统方案将音频与视频割裂生成再后期合成，LTX-2 采用单一统一模型同时产出画面与声音，从根本上解决了"会动的画面却是哑的"这一行业痛点。它面向内容创作者、独立电影人与开发者，提供从免费本地推理到云端 API 的完整光谱。

🔑 一句话定位

一个真正开放的、可在消费级 GPU 本地运行的"AI 拍片引擎"——一次推理，同步得到带声画的成片。

🏗️二、技术架构

LTX-2 的技术细节详载于论文 "LTX-2: Efficient Joint Audio-Visual Foundation Model"（arXiv:2601.03233）。其核心是非对称双流扩散变换器（Asymmetric Dual-Stream DiT）架构。

核心架构示意

输入：文本提示 / 首帧图像 / 尾帧 / 参考视频 / 音频 │ ├──▶ 视频流（Video Stream · 14B 参数） ──┐ │ 处理高信息密度的时空像素特征 │ │ │ 双向交叉注意力 ├──▶ 音频流（Audio Stream · 5B 参数） ──┤ （Bidirectional Cross-Attention） │ 处理低信息密度的频谱声学特征 │ 实现"声画对齐/同步" │ │ └──▶ 模态感知无分类器引导（Modality-aware CFG） │ ▼ 单一模型 · 单次前向传播 → 同步的 视频 + 音频 （原生最高 4K / ~50fps / 10–20s 片段）

关键架构要点

为何"非对称"？
视频与音频的信息密度差异巨大。架构按各自需求差异化分配参数——视频 14B、音频 5B，避免单一巨型多模态 DiT 的臃肿开销，同时保持同步质量。
双向交叉注意力
两路流之间双向耦合，使声画在生成时即可对齐（如脚步声踩在画面落地瞬间），而非后期拼接。
模态感知 CFG
针对不同模态采用差异化的无分类器引导，提升可控性与生成稳定性。
文本编码器
采用 Gemma 3 作为文本编码器，理解细粒度的镜头描述。

Monorepo 三大模块

模块职责说明
ltx-core核心模型实现DiT 主体、推理栈与底层工具，是整个系统的引擎。
ltx-pipelines高级流水线封装文生视频、图生视频、音频生视频等十余条开箱即用的生成流水线。
ltx-trainer训练 / 微调提供 LoRA、全参微调（FFT）、IC-LoRA 的训练与精调工具链。

十余条生产级生成流水线

  • TI2VidTwoStagesPipeline — 生产级文/图生视频，2× 上采样（推荐）
  • TI2VidTwoStagesHQPipeline — 采用 res_2s 二阶采样器，步数更少画质更佳
  • TI2VidOneStagePipeline — 单阶段生成，适合快速原型
  • DistilledPipeline — 最快推理，仅 8 个预定义 sigma（阶段1 8步 / 阶段2 4步）
  • ICLoraPipeline — 视频生视频、图生视频变换（基于蒸馏模型）
  • KeyframeInterpolationPipeline — 关键帧图像间插值
  • A2VidPipelineTwoStage — 由输入音频驱动生成视频
  • RetakePipeline — 仅重新生成已有视频中的某个时间区域
  • HDRICLoraPipeline — HDR 输出，经 LogC3 逆解码输出线性浮点帧，可导出 EXR 并做色调映射
  • LipDubPipeline — 唇形同步配音、改词重述、匹配说话人身份

性能与优化手段

极速推理
优化配置下约 1.22 秒/段；相较同类开源模型快 2–3 倍，部分场景达 ~7 倍。
FP8 量化
--quantization fp8-cast（配 bf16）或 fp8-scaled-mm（Hopper + TensorRT-LLM），显著降低显存占用。
注意力优化
Blackwell B200 用 FlashAttention 4；其余 CUDA 用 xFormers。
梯度估计
可将推理步数从 40 降至 20–30 而画质不降。
蒸馏模型
LTX-2.3-22b-distilled 系列，8 步即出片，提速最高 60%。
显存友好
大显存可关闭阶段间自动显存清理以进一步提速。

💡三、核心创新点

① 首个单模型音视频基础模型
在一个 DiT 内集成 T2V / I2V / V2V / 首尾帧 / 音频生视频 / 同步音频 / 可变帧率等全部现代视频生成能力，告别"多模型拼接"。
② 非对称双流架构
按模态信息密度差异分配算力（视频14B / 音频5B），在效率与同步质量间取得平衡，是高效联合建模的范式创新。
③ 真正的"全开放"
不仅开放权重，更开放训练代码，可本地复现与二创——业界少见的"truly open weights"。
④ 消费级 GPU 本地运行
配合 FP8 量化与蒸馏策略，单张消费级 NVIDIA 显卡即可本地生成 4K 声画，无需昂贵的 A100/H100 集群。
⑤ 丰富的可控生成 LoRA 家族
配套镜头运动（Dolly、Jib、Static）、姿态控制、细节增强、HDR、唇形配音等 IC-LoRA，实现电影级镜头语言控制。
⑥ 电影级 HDR 管线
原生支持 LogC3 逆解码 → 线性浮点帧 → EXR 导出 → 色调映射，可直连专业后期/调色流程。

🎬四、应用场景

LTX-2 面向从个人创作者到专业制作团队的完整光谱，尤其突出"本地、可控、声画一体"三大特征。

独立短片与电影制作
电影人无需昂贵设备即可原型化镜头、生成 B-roll，甚至产出完整短片；首尾帧与镜头控制 LoRA 实现精准运镜。
商业广告与营销内容
快速产出带音效/配乐的成片级广告，配合 LTX Studio 做团队协作；HDR 管线满足交付级质量。
音乐 MV 与短视频
音频生视频（A2V）让画面随音乐节拍起舞；社区已用于 Instagram/Reels 的变速、转场、胶片损伤等电影感效果。
YouTube / 长视频内容
配合 LTX Director Multi 等社区工作流，可生成 AI 短片、动画故事、实验视频，单条可达数十秒。
配音 / 唇形重制（LipDub）
为已有视频重配音、改词、匹配说话人音色与口型，适用于本地化与二次创作。
关键帧插值与镜头接续
在多张关键帧间平滑插值，构建连续镜头叙事。
局部重做（Retake）
只重生成不满意的时间片段，节省整片重跑成本，迭代效率高。
研究与二创
开放的训练代码允许学术与工程团队微调专属风格/角色 LoRA，构建私有视频生成底座。

🎯 最佳适配人群

⚔️五、竞品对比

当前开源视频模型呈"三足鼎立"：LTX（速度与本地化）、Wan（综合画质）、Hunyuan（摄影真实感）。Sora 2 等闭源模型因访问受限、所有权缺失而逐步被市场边缘化。

模型开源核心优势主要短板音视频同步
LTX-2（Lightricks） ✅ 权重+训练 极速（2–3× 快，最高 7×）、消费级 GPU 本地运行、声画一体单模型、ComfyUI 核心内置 复杂提示的画质上限略逊 Wan；生态尚在成熟中 ✅ 原生
Wan 2.2 / 2.5（阿里） ✅ 开放权重 开源阵营综合画质/运动/语义最佳；训练数据更庞大 更慢、显存需求更高；音频能力非单一模型原生 ✗ 需外挂
HunyuanVideo（腾讯） ✅ 开放权重 摄影真实感强、支持数字人/avatar 资源占用重、速度较慢 ✗ 需外挂
