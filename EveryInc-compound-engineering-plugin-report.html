项目概述

EveryInc/compound-engineering-plugin 是由 Every（EveryInc）团队开发的开源 AI 编码工作流插件，核心理念源自"复合工程"（Compound Engineering）—— 每一次工程工作都应该让后续工作变得更容易，而非更困难。

该插件为 Claude Code、OpenAI Codex、Cursor、GitHub Copilot 等 10+ 种主流 AI 编码工具提供了一套结构化的 Plan → Execute → Review → Learn 工作流。通过 37 个技能（Skills）和 51 个代理（Agents），将 AI 辅助编码从简单的代码生成转变为一个完整、可迭代、可持续学习的工程实践。

项目采用 TypeScript 编写，使用 Bun 作为构建工具，以 MIT 协议开源。截至目前已获得 17,100+ Stars，是目前 GitHub 上最受欢迎的 AI 编码工作流增强工具之一。

技术架构

核心设计理念

Compound Engineering 的哲学是 "80% 在规划和审查，20% 在执行"。与传统开发中技术债务不断累积不同，该插件通过系统化的工作流让知识复利增长：好的头脑风暴让计划更精准，好的计划让执行更小，好的审查捕捉模式而不仅仅是 Bug，好的复合笔记让下一个 Agent 不需要从零开始学习。

工作流引擎

命令阶段功能

插件采用适配器模式（Adapter Pattern），核心逻辑通过统一的 Plugin Manifest 定义，然后通过转换器（Converter）适配不同平台的格式：

  • 原生支持：Claude Code、Cursor、Codex（通过插件市场直接安装）
  • 原生插件：GitHub Copilot（VS Code Plugin from Source）、Factory Droid、Qwen Code
  • 转换器支持：OpenCode、Pi、Gemini CLI、Kiro CLI（通过 Bun 转换器安装）

核心创新点

1. 知识复利模型

最核心的创新。传统开发中每次编码都在增加技术债务，而 Compound Engineering 让每次编码都产生可复用的知识资产。头脑风暴优化计划，计划指导未来计划，审查捕捉深层模式，复合笔记让下一个 Agent 无需从零开始。这是一个正反馈循环。

2. 前置规划范式

将 80% 的精力放在规划和审查上，而非直接编码。这颠覆了"AI 辅助编码 = 快速写代码"的常见思路，转而强调深思熟虑后再执行。执行阶段因为规划充分而变得简短高效。

3. 多代理审查系统

/ce-code-review 使用多代理（Multi-Agent）并行审查，不同于单 LLM 调用的代码审查。多个 Agent 可以从不同维度（安全性、性能、可维护性、架构一致性）同时审查代码，更接近真实的高质量人工 Code Review。

4. 跨平台统一工作流

同一套 Compound Engineering 工作流可以在 Claude Code、Codex、Cursor、Copilot 等 10+ 种工具中使用。用户不会因为切换 AI 编码工具而丢失工程纪律。这在 AI 编码工具百花齐放的 2026 年尤为重要。

5. 产品脉搏闭环

/ce-product-pulse 将用户真实使用数据（错误率、性能、使用量）反馈到工作流中，形成从"战略 → 规划 → 执行 → 审查 → 复合 → 真实数据反馈 → 战略更新"的完整闭环。
